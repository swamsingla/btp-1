## Introduction  
Have you ever combined two groups of objects into one larger group? For example, merging a group of students who play cricket with those who play football creates a new group of students who play either sport. Just like arithmetic operations combine numbers, **operations on sets** combine sets to form new sets. In this topic, we explore how to perform operations such as **union**, **intersection**, **difference**, and **complement** on sets. These operations help us analyze relationships between different sets systematically. By the end of this lesson, you’ll understand how to construct and interpret results of these operations using precise mathematical definitions.  

---

## Explanation  

### **Union of Sets**  
Let $ A $ and $ B $ be any two sets. The **union** of $ A $ and $ B $, denoted by $ A \cup B $, is the set containing all elements that belong to $ A $, to $ B $, or to both.  

> **Definition**: $ A \cup B = \{ x : x \in A \text{ or } x \in B \} $  
> **Symbol**: $\cup $ represents union.  
> **Property**: The union of two sets always contains at least as many elements as the individual sets.  

#### Example:  
If $ A = \{1, 2, 3\} $ and $ B = \{3, 4, 5\} $, then:

$$
A \cup B = \{1, 2, 3, 4, 5\}

$$  
Notice that the element $3 $ appears in both sets but is listed only once in the union.  

#### Visual Representation:  
A **Venn diagram** can illustrate the union of two sets. Draw two overlapping circles; the shaded area representing $ A \cup B $ includes all regions inside either circle.  

---

### **Intersection of Sets**  
Although the source text begins with the union of sets, the broader topic of operations on sets includes the **intersection** of sets, which is briefly mentioned in later sections of the chapter. Here’s a concise overview:  

> **Definition**: $ A \cap B = \{ x : x \in A \text{ and } x \in B \} $  
> **Symbol**: $\cap $ represents intersection.  
> **Property**: The intersection contains only elements common to both sets.  

#### Example:  
If $ A = \{1, 2, 3\} $ and $ B = \{3, 4, 5\} $, then:

$$
A \cap B = \{3\}

$$  

---

### **Difference of Sets**  
Another operation discussed in the chapter is the **difference** of sets:  

> **Definition**: $A - B = \{ x : x \in A \text{ and } x \notin B \} $  
> **Symbol**: $-$ represents difference.  
> **Property**: The difference removes elements of $ B $ from $ A $.  

#### Example:  
If $ A = \{1, 2, 3\} $ and $ B = \{3, 4, 5\} $, then:

$$
A - B = \{1, 2\}

$$  

---

### **Complement of a Set**  
The **complement** of a set $A $, denoted by $ A'$ or $ A^c $, consists of all elements in the universal set $ U $ that are not in $ A $:  

> **Definition**: $ A' = \{ x \in U : x \notin A \} $  
> **Symbol**: $'$ or $^c $ denotes complement.  
> **Property**: The complement depends on the universal set.  

#### Example:  
If $ U = \{1, 2, 3, 4, 5\} $ and $ A = \{1, 2, 3\} $, then:

$$
A' = \{4, 5\}

$$

## Solved Examples  

### **Example 1:**  
Let $A = \{1, 2, 3\} $ and $ B = \{3, 4, 5\} $. Find $ A \cup B $.  
**Solution:**  
Combine all unique elements from $ A $ and $ B $:

$$
A \cup B = \{1, 2, 3, 4, 5\}

$$  

### **Example 2:**  
Let $A = \{2, 4, 6\} $ and $ B = \{4, 6, 8\} $. Find $ A \cap B $.  
**Solution:**  
Identify common elements:

$$
A \cap B = \{4, 6\}

$$  

### **Example 3:**  
Let $A = \{1, 2, 3\} $ and $ B = \{3, 4, 5\} $. Find $ A - B $.  
**Solution:**  
Remove elements of $ B $ from $ A $:

$$
A - B = \{1, 2\}

$$  

### **Example 4:**  
Let $U = \{1, 2, 3, 4, 5\} $ and $ A = \{1, 2, 3\} $. Find $ A'$.  
**Solution:**  
List elements in $ U $ not in $ A $:

$$
A' = \{4, 5\}

$$  

### **Example 5:**  
Let $A = \{a, b, c\} $ and $ B = \{c, d, e\} $. Find $ A \cup B $ and $ A \cap B $.  
**Solution:**

$$
A \cup B = \{a, b, c, d, e\}, \quad A \cap B = \{c\}

$$

## Summary  
- The **union** of sets combines all elements from two sets: $A \cup B = \{x : x \in A \text{ or } x \in B\} $.  
- The **intersection** retains only common elements: $ A \cap B = \{x : x \in A \text{ and } x \in B\} $.  
- The **difference** removes elements of one set from another: $ A - B = \{x : x \in A \text{ and } x \notin B\} $.  
- The **complement** includes all elements not in the set: $ A' = \{x \in U : x \notin A\} $.  
- Operations on sets depend on the **universal set** $ U $.  
- Venn diagrams visually represent these operations.  

---

## Key Formulas  

| Formula | Description |  
|--------|------------|  
| $ A \cup B $ | Union of sets $ A $ and $ B $ |  
| $ A \cap B $ | Intersection of sets $ A $ and $ B $ |  
| $ A - B $ | Difference of sets $ A $ and $ B $ |  
| $ A'$ | Complement of set $ A $ with respect to universal set $ U $ |  
| $ x \in A $ | Element $ x $ belongs to set $ A $ |  
| $ x \notin A $ | Element $ x $ does not belong to set $ A $ |

## Student Corner  

### **Common Mistakes**  
1. **Incorrectly listing duplicate elements** in unions: Always ensure elements are unique.  
   - **Correction**: Use set notation to automatically eliminate duplicates.  
2. **Confusing union and intersection**: Remember $ A \cup B $ includes *all* elements, while $ A \cap B $ includes *only* common elements.  

### **Exam Tips**  
- **Draw Venn diagrams** for visual clarity, especially for complex problems involving multiple operations.  
- **Use set notation** consistently to avoid confusion.  

### **Memory Aid**  
- **UNION** = “U” for “Union”, combining all elements.  
- **INTERSECTION** = “I” for “Intersect”, sharing common elements.
