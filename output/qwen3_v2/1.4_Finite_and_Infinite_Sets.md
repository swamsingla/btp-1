## Introduction  
Imagine trying to count the number of stars in the night sky versus counting the number of books on your shelf. One task is straightforward, while the other feels impossible due to sheer scale. This analogy mirrors the core idea behind **finite** and **infinite sets**.  

In this section, you will learn:  
- What defines a **finite set** versus an **infinite set**.  
- How to identify whether a set is finite or infinite using examples.  
- Why certain sets, like the set of natural numbers, are inherently infinite.  

By the end, you’ll be able to classify sets based on their size and understand the practical implications of infinity in mathematics.

## Explanation  

### **Definition of Finite and Infinite Sets**  
> A set is **finite** if it contains a definite number of elements. Otherwise, it is **infinite**.  
- A **finite set** has a **cardinality** (number of elements) equal to a natural number. For example, $ A = \{1, 2, 3, 4, 5\} $ is finite with $ n(A) = 5 $.  
- An **infinite set** has an unbounded number of elements. For example, the set of natural numbers $ \mathbb{N} = \{1, 2, 3, \dots\} $ is infinite.  

> **Note**: The cardinality of an empty set $ n(\emptyset) = 0 $, making it a finite set.  

### **Representing Infinite Sets**  
Infinite sets cannot be fully listed in **roster form** because their elements are limitless. Instead, they are represented using **ellipses (`...`)** to indicate continuation.  
- Example: $ \{1, 2, 3, \dots\} $ denotes the set of natural numbers.  
- Example: $ \{\dots, -2, -1, 0, 1, 2, \dots\} $ denotes the set of integers.  

> **Important**: Not all infinite sets can be expressed in roster form. For example, the set of real numbers $ \mathbb{R} $ lacks a discernible pattern for enumeration.  

### **Examples from the Source Text**  
1. **Finite Sets**:  
   - $ A = \{1, 2, 3, 4, 5\} $ → $ n(A) = 5 $.  
   - $ B = \{a, b, c, d, e, g\} $ → $ n(B) = 6 $.  
   - $ C = \{\text{men living currently}\} $ → Finite (though the exact count is unknown).  

2. **Infinite Sets**:  
   - $ G = \{\text{points on a line}\} $ → Infinite (infinitely many points exist).  
   - $ \mathbb{N} = \{1, 2, 3, \dots\} $ → Infinite.  

### **Key Properties**  
- A set is **finite** if its elements can be counted completely.  
- A set is **infinite** if it cannot be counted completely.  
- The **cardinality** $ n(S) $ of a finite set is a natural number; for infinite sets, $ n(S) $ is undefined.

## Solved Examples  

### **Example 1:**  
Determine whether the set $ S = \{x \in \mathbb{N} \mid (x - 1)(x - 2) = 0\} $ is finite or infinite.  

**Solution:**  
- Solve the equation: $ (x - 1)(x - 2) = 0 \Rightarrow x = 1 $ or $ x = 2 $.  
- Thus, $ S = \{1, 2\} $.  
- Since $ S $ has exactly 2 elements, it is **finite**.  

### **Example 2:**  
State whether the set $ T = \{x \in \mathbb{N} \mid x^2 = 4\} $ is finite or infinite.  

**Solution:**  
- Solve $ x^2 = 4 \Rightarrow x = 2 $ (since $ x \in \mathbb{N} $).  
- Therefore, $ T = \{2\} $.  
- $ T $ has 1 element, so it is **finite**.  

### **Example 3:**  
Explain why the set $ G = \{\text{points on a line}\} $ is infinite.  

**Solution:**  
- A straight line contains infinitely many points. No matter how many points you list, there will always be more.  
- Hence, $ G $ is **infinite**.  

### **Example 4:**  
Is the set $ P = \{x \in \mathbb{N} \mid x \text{ is prime} \} $ finite or infinite?  

**Solution:**  
- Prime numbers are natural numbers greater than 1 divisible only by 1 and themselves (e.g., 2, 3, 5, 7, ...).  
- There are infinitely many prime numbers (proven by Euclid’s theorem).  
- Thus, $ P $ is **infinite**.  

### **Example 5:**  
Why can’t the set of real numbers $ \mathbb{R} $ be expressed in roster form?  

**Solution:**  
- Real numbers include all rational and irrational numbers, forming a dense and uncountably infinite set.  
- Their elements lack a repeating pattern or structure that allows full enumeration.  
- Therefore, $ \mathbb{R} $ cannot be written in roster form.

## Practice Problems  

### **Problem 1 (Easy):**  
Which of the following sets is finite?  
**(a)** $ \{x \in \mathbb{Z} \mid x < 10\} $  
**(b)** $ \{x \in \mathbb{R} \mid x^2 + 1 = 0\} $  
**(c)** $ \{x \in \mathbb{N} \mid x \text{ is even} \} $  

### **Problem 2 (Medium):**  
Determine whether the set $ Q = \{x \in \mathbb{N} \mid 2x - 1 = 0\} $ is finite or infinite.  

### **Problem 3 (Hard):**  
Prove that the set of all integers $ \mathbb{Z} $ is infinite.  

### **Problem 4 (Medium):**  
Can the set $ \{1, 2, 3, \dots, 100\} $ be classified as finite or infinite? Justify.  

---

## Answers  

### **Answer to Problem 1:**  
**(a)** Finite: $ \{x \in \mathbb{Z} \mid x < 10\} = \{..., -2, -1, 0, 1, 2, ..., 9\} $ has a definite number of elements (up to 9).  
**(b)** Finite: $ \{x \in \mathbb{R} \mid x^2 + 1 = 0\} = \emptyset $ (no real solutions).  
**(c)** Infinite: The set of even natural numbers $ \{2, 4, 6, ...\} $ is infinite.  

### **Answer to Problem 2:**  
Solve $ 2x - 1 = 0 \Rightarrow x = \frac{1}{2} $. Since $ \frac{1}{2} \notin \mathbb{N} $, the set $ Q = \emptyset $, which is **finite**.  

### **Answer to Problem 3:**  
The set $ \mathbb{Z} = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\} $ includes infinitely many negative and positive integers. No upper or lower bound exists, so $ \mathbb{Z} $ is **infinite**.  

### **Answer to Problem 4:**  
The set $ \{1, 2, 3, \dots, 100\} $ has exactly 100 elements. Since the number of elements is finite, it is a **finite set**.

## Summary  
- **Finite sets** have a definite number of elements (e.g., $ n(A) = 5 $).  
- **Infinite sets** cannot be counted completely (e.g., $ \mathbb{N} $).  
- Cardinality $ n(S) $ is defined only for finite sets.  
- Infinite sets often use ellipses (`...`) in roster form.  
- Examples of infinite sets: $ \mathbb{N} $, $ \mathbb{Z} $, $ \mathbb{R} $.  
- The empty set $ \emptyset $ is a special case of a finite set.

## Student Corner  
### **Common Mistakes**  
- **Mistake:** Confusing "finite" with "countable."  
  **Correction:** A finite set is always countable, but not all infinite sets are countable (e.g., $ \mathbb{R} $).  
- **Mistake:** Assuming all infinite sets can be written in roster form.  
  **Correction:** Only structured infinite sets (like $ \mathbb{N} $) can use ellipsis; others (like $ \mathbb{R} $) cannot.  

### **Exam Tips**  
- Always specify whether a set is finite or infinite based on its elements' countability.  
- Use the term "cardinality" precisely for finite sets.  

### **Memory Aid**  
**"F" for Finite**, **"I" for Infinite** → Remember that finite sets have a fixed number of elements, while infinite sets stretch endlessly.
