## Introduction  
Intervals are fundamental tools to describe continuous ranges of real numbers. This section explores how intervals act as subsets of the real number system, distinguishing between open, closed, and half-open intervals. By mastering these concepts, students will gain clarity on representing and analyzing numerical ranges in algebra and calculus.  

---

## Explanation  

### **Definitions**  
- **Open Interval**: An interval that includes all real numbers between two endpoints but excludes the endpoints themselves. Denoted by parentheses: $(a, b) $, where $ a, b \in \mathbb{R} $ and $ a < b $.

$$ (a, b) = \{x \in \mathbb{R} \mid a < x < b\}

$$  
- **Closed Interval**: An interval that includes both endpoints. Denoted by square brackets: $[a, b] $, where $ a, b \in \mathbb{R} $ and $ a < b $.

$$ [a, b] = \{x \in \mathbb{R} \mid a \leq x \leq b\}

$$  
- **Half-Open Intervals**: Intervals that include one endpoint but exclude the other.  
  - $[a, b) = \{x \in \mathbb{R} \mid a \leq x < b\} $  
  - $ (a, b] = \{x \in \mathbb{R} \mid a < x \leq b\} $  

> **Note**: Intervals are subsets of $\mathbb{R} $, and they contain infinitely many elements.  

### **Length of an Interval**  
The length of an interval $ (a, b) $, $ [a, b] $, $ [a, b) $, or $ (a, b] $ is defined as $ b - a $.

$$ \text{Length} = b - a

$$  

### **Examples of Intervals**  
- The set $\{x \in \mathbb{R} \mid -5 < x \leq 7\} $ is written as the interval $ (-5, 7] $.  
- The interval $ [-3, 5) $ corresponds to $\{x \in \mathbb{R} \mid -3 \leq x < 5\} $.  

> **Important**: Always verify whether endpoints are included or excluded based on the interval notation.  

---

## Solved Examples  

### **Example 1**  
Determine whether the interval $ (-2, 5) $ is a subset of $ [-3, 7] $.  

**Solution:**  
- The interval $ (-2, 5) $ includes all real numbers greater than $-2 $ and less than $ 5 $.  
- The interval $ [-3, 7] $ includes all real numbers from $-3 $ to $ 7 $, inclusive.  
- Since $-2 > -3 $ and $ 5 < 7 $, every element of $ (-2, 5) $ lies within $ [-3, 7] $.  
Thus, $ (-2, 5) \subset [-3, 7] $.  

---

### **Example 2**  
Convert the set $\{x \in \mathbb{R} \mid 0 \leq x < 4\} $ into interval notation.  

**Solution:**  
- The condition $ 0 \leq x < 4 $ indicates the interval includes $ 0 $ but excludes $ 4 $.  
- Therefore, the interval notation is $ [0, 4) $.  

---

### **Example 3**  
Find the length of the interval $ ( -\infty, 0 ) $.  

**Solution:**  
- The interval $ ( -\infty, 0 ) $ represents all negative real numbers.  
- However, the concept of length applies only to bounded intervals.  
- Hence, the length of unbounded intervals like $ ( -\infty, 0 ) $ is undefined.  

---

### **Example 4**  
Given $ A = [1, 3] $ and $ B = (0, 4) $, determine $ A \cap B $.  

**Solution:**  
- $ A = [1, 3] $ includes all numbers from $ 1 $ to $ 3 $, inclusive.  
- $ B = (0, 4) $ includes all numbers between $ 0 $ and $ 4 $, excluding $ 0 $ and $ 4 $.  
- The intersection $ A \cap B $ consists of numbers common to both intervals: $ 1 \leq x \leq 3 $.  
Thus, $ A \cap B = [1, 3] $.

## Practice Problems  

### **Problem 1 (🟢 Easy)**  
Write the interval notation for the set $\{x \in \mathbb{R} \mid -2 \leq x < 5\} $.  

### **Problem 2 (🟡 Medium)**  
Check if $ [1, 5] $ is a subset of $ (0, 6) $. Justify your answer.  

### **Problem 3 (🔴 Hard)**  
Calculate the length of the interval $ [ -\infty, 10 ] $ and explain why it cannot be calculated.  

### **Problem 4 (🟡 Medium)**  
If $ C = (2, 7) $ and $ D = [1, 8] $, find $ C \cup D $ and represent it in set-builder form.  

---

## Answers  

### **Answer 1**  
The set $\{x \in \mathbb{R} \mid -2 \leq x < 5\} $ is represented as $ [-2, 5) $.  

### **Answer 2**  
Yes, $ [1, 5] \subset (0, 6) $. All elements of $ [1, 5] $ satisfy $ 0 < x < 6 $, so the entire interval lies within $ (0, 6) $.  

### **Answer 3**  
The interval $ [ -\infty, 10 ] $ is unbounded on the left. Length is only defined for bounded intervals, so it cannot be calculated.  

### **Answer 4**  
- $ C = (2, 7) $ includes numbers greater than $ 2 $ and less than $ 7 $.  
- $ D = [1, 8] $ includes numbers from $ 1 $ to $ 8 $, inclusive.  
- Their union $ C \cup D $ covers all numbers from $ 1 $ to $ 8 $, excluding $ 2 $ and $ 7 $.  
Set-builder form: $\{x \in \mathbb{R} \mid 1 \leq x < 2 \text{ or } 2 < x < 7 \text{ or } 7 < x \leq 8\} $.

## Summary  
- **Intervals** are subsets of $\mathbb{R} $ describing continuous ranges.  
- **Open intervals** exclude endpoints; **closed intervals** include them.  
- **Half-open intervals** include one endpoint.  
- The **length** of an interval $ (a, b) $ is $ b - a $.  
- Intervals help define domains/ranges in functions and analyze set relationships.  

---

## Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ (a, b) $ | Open interval excluding $ a $ and $ b $ |  
| $ [a, b] $ | Closed interval including $ a $ and $ b $ |  
| $ [a, b) $ | Half-open interval including $ a $ but excluding $ b $ |  
| $ (a, b] $ | Half-open interval excluding $ a $ but including $ b $ |  
| $\text{Length} = b - a $ | For bounded intervals $ (a, b) $, $ [a, b] $, etc. |

## Student Corner  

### **Common Mistakes**  
1. Confusing open and closed intervals (e.g., mistaking $ (a, b) $ for $ [a, b] $).  
2. Incorrectly assuming unbounded intervals have a finite length.  

### **Exam Tip**  
Remember: Parentheses denote exclusion of endpoints, while brackets denote inclusion. Draw number lines to visualize intervals during exams.
