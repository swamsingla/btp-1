## Introduction  
Have you ever grouped similar items in your daily life? For example, organizing your books by subject or categorizing fruits in a basket. These groupings are essentially **sets**, a foundational concept in mathematics. In this topic, you’ll explore how mathematicians formally define and work with sets. By the end, you’ll understand how sets form the basis for advanced topics like functions, relations, and probability. This section introduces the historical context of sets and their role in modern mathematics.

## Explanation  

### **What is a Set?**  
A **set** is a well-defined collection of distinct objects, called **elements**. These elements can be anything—numbers, letters, shapes, or even other sets.  

> **Definition**: A set is a collection of well-defined objects.  
> **Notation**: Sets are denoted by uppercase letters like $ A $, $ B $, $ C $, etc. Elements are listed within curly braces, e.g., $ A = \{1, 2, 3\} $.  

### **Set Representation**  
Sets can be represented in three ways:  
1. **Roster Method**: Listing all elements explicitly, e.g., $ A = \{1, 2, 3\} $  
2. **Set-builder Notation**: Describing elements using conditions, e.g., $ A = \{x \mid x \text{ is a prime number less than 10}\} $  
3. **Venn Diagrams**: Visual representations using closed curves (discussed later)  

### **Empty Set**  
An **empty set** (also called a null set) contains no elements. It is denoted by $\emptyset $ or $\{\} $.  

> **Definition**: The **empty set** is a set with no elements.  
> **Note**: $\emptyset \neq \{\emptyset\} $; the former has no elements, the latter contains one element (the empty set itself).  

### **Finite and Infinite Sets**  
- A **finite set** has a countable number of elements (e.g., $ A = \{1, 2, 3\} $)  
- An **infinite set** has an uncountable number of elements (e.g., $ N = \{1, 2, 3, \dots\} $)  

> **Definition**: A **finite set** is a set with a definite number of elements. A **infinite set** has infinitely many elements.  

### **Equal Sets**  
Two sets are **equal** if they contain exactly the same elements, regardless of order.  

> **Definition**: Two sets $ A $ and $ B $ are **equal** (denoted $ A = B $) if every element of $ A $ is in $ B $ and vice versa.  

### **Subsets**  
A set $ A $ is a **subset** of $ B $ if every element of $ A $ is also in $ B $.  

> **Definition**: If every element of $ A $ is in $ B $, then $ A $ is a **subset** of $ B $ (denoted $ A \subset B $).  
> **Note**: $ A \subset B $ means $ A $ may or may not be equal to $ B $.  

### **Universal Set**  
The **universal set** $ U $ contains all elements under consideration in a particular context.  

> **Definition**: The **universal set** is the set containing all elements relevant to a discussion.  

### **Intervals as Subsets of Real Numbers**  
Intervals are subsets of $\mathbb{R} $ defined by inequalities:  
- Closed interval: $ [a, b] = \{x \in \mathbb{R} \mid a \leq x \leq b\} $  
- Open interval: $ (a, b) = \{x \in \mathbb{R} \mid a < x < b\} $  
- Half-open intervals: $ [a, b) $ or $ (a, b] $  

> **Definition**: An **interval** is a subset of real numbers bounded by two endpoints.

## Solved Examples  

**Example 1:**  
Represent the set of vowels in the English alphabet using roster method.  
**Solution:**  
The vowels are $ a, e, i, o, u $. Thus, the set is $ V = \{a, e, i, o, u\} $.  

**Example 2:**  
Identify whether $\emptyset $ is a subset of $\{1, 2, 3\} $.  
**Solution:**  
Yes. By definition, the empty set is a subset of every set. So, $\emptyset \subset \{1, 2, 3\} $.  

**Example 3:**  
Is $\{1\} $ a subset of $\{1, 2\} $?  
**Solution:**  
Yes. Since $ 1 \in \{1, 2\} $, the singleton set $\{1\} $ is a subset of $\{1, 2\} $.  

**Example 4:**  
Find the union of $ A = \{1, 2\} $ and $ B = \{2, 3\} $.  
**Solution:**  
The union $ A \cup B $ combines all elements from both sets:

$$
A \cup B = \{1, 2, 3\}

$$  

**Example 5:**  
State whether the interval $[1, 5] $ is a subset of $\mathbb{R} $.  
**Solution:**  
Yes. All elements of $ [1, 5] $ are real numbers, so it is a subset of $\mathbb{R} $.

## Practice Problems  

1. 🟢 **Easy**: Represent the set of even numbers between 1 and 10 using roster method.  
2. 🟡 **Medium**: Prove that $\emptyset \subset A $ for any set $ A $.  
3. 🔴 **Hard**: Given $ A = \{x \in \mathbb{Z} \mid x < 5\} $ and $ B = \{x \in \mathbb{Z} \mid x > -3\} $, find $ A \cap B $.  

**Answers:**  

1. **Answer**: $ A = \{2, 4, 6, 8\} $  
   **Steps**: List all integers divisible by 2 between 1 and 10.  

2. **Answer**: $\emptyset \subset A $ is always true.  
   **Steps**: By definition, the empty set has no elements, so vacuously satisfies $ A \subset B $.  

3. **Answer**: $ A \cap B = \{-2, -1, 0, 1, 2, 3, 4\} $  
   **Steps**: $ A = \{-4, -3, -2, -1, 0, 1, 2, 3, 4\} $, $ B = \{-2, -1, 0, 1, 2, 3, 4, 5, 6, \dots\} $. Their intersection is the overlap.

## Summary  
- A **set** is a well-defined collection of elements.  
- The **empty set** has no elements ($\emptyset $).  
- A set is **finite** if it has a countable number of elements.  
- Two sets are **equal** if they contain identical elements.  
- A set $ A $ is a **subset** of $ B $ if all elements of $ A $ belong to $ B $.  
- The **universal set** $ U $ contains all relevant elements.  
- **Intervals** are subsets of $\mathbb{R} $ defined by inequalities.

## Student Corner  
### **Common Mistakes**  
- ❌ Confusing $\subset $ with $\subseteq $: Remember, $\subset $ implies proper subset (excluding equality).  
- ❌ Misrepresenting intervals: $ [a, b] $ includes endpoints, while $ (a, b) $ does not.  

### **Exam Tips**  
- Always define sets clearly using either roster or set-builder notation.  
- Draw Venn diagrams for subset relationships to visualize.  

### **Memory Aid**  
**PEMDAS** for set operations: Parentheses → Exponents (intervals) → Multiplication (intersection) → Division (difference) → Addition (union) → Subtraction (complement).
