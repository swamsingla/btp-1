## Introduction  
Have you ever combined two groups of friends to form a larger group? Or merged two lists of items to avoid duplicates? This is similar to the **union of sets**, a fundamental operation in set theory. In this topic, you’ll learn how to combine two sets while ensuring each element appears only once. By the end, you’ll be able to define the union operation, apply its properties, and solve problems using Venn diagrams. This builds on your prior knowledge of sets and prepares you for more complex operations like intersection and complements.  

---

## Explanation  

### Definition of Union  
The **union** of two sets $ A $ and $ B $ is a new set containing all elements that belong to $ A $, to $ B $, or to both. The symbol $\cup $ denotes the union. Mathematically, this is written as:

$$
A \cup B = \{ x : x \in A \text{ or } x \in B \}

$$  
> **Important Note**: Elements common to both $A $ and $ B $ are included only once in the union.  

### Properties of Union  
These properties govern how unions behave under various conditions:  
1. **Commutative Law**:

$$
   A \cup B = B \cup A

$$  
   *The order of sets does not affect the union.*  

2. **Associative Law**:

$$
   (A \cup B) \cup C = A \cup (B \cup C)

$$  
   *Grouping does not change the result.*  

3. **Identity Element Law**:

$$
   A \cup \emptyset = A

$$  
   *The empty set $\emptyset $ does not alter the union.*  

4. **Idempotent Law**:

$$
   A \cup A = A

$$  
   *Combining a set with itself yields the same set.*  

5. **Law of Universal Set**:

$$
   U \cup A = U

$$  
   *The union of a set with the universal set $U $ is always $ U $.*  

### Visual Representation  
The union of two sets is often illustrated using **Venn diagrams** (see Figure 1.4 in the source text). The shaded region represents all elements in $ A $ or $ B $.

## Solved Examples  

### **Example 1:**  
Let $ A = \{2, 4, 6, 8\} $ and $ B = \{6, 8, 10, 12\} $. Find $ A \cup B $.  
**Solution:**  
- List all elements from $ A $: $ 2, 4, 6, 8 $  
- List all elements from $ B $: $ 6, 8, 10, 12 $  
- Combine them, removing duplicates: $ 2, 4, 6, 8, 10, 12 $ 

$$
A \cup B = \{2, 4, 6, 8, 10, 12\}

$$  

### **Example 2:**  
Let $A = \{a, e, i, o, u\} $ and $ B = \{a, i, u\} $. Show that $ A \cup B = A $.  
**Solution:**  
- Since all elements of $ B $ are already in $ A $, adding them doesn’t change $ A $.

$$
A \cup B = \{a, e, i, o, u\} = A

$$  
*This demonstrates that the union of a set with its subset is the set itself.*  

### **Example 3:**  
Let $X = \{\text{Ram, Geeta, Akbar}\} $ and $ Y = \{\text{Geeta, David, Ashok}\} $. Interpret $ X \cup Y $.  
**Solution:**  
- $ X \cup Y = \{\text{Ram, Geeta, Akbar, David, Ashok}\} $  
- This represents the set of students in **either** the hockey team (**X**) or the football team (**Y**) or both.  

### **Example 4:**  
If $ A = \{1, 2, 3\} $ and $ B = \{3, 4, 5\} $, find $ A \cup B $ and verify the **commutative law**.  
**Solution:**  
- $ A \cup B = \{1, 2, 3, 4, 5\} $  
- Swap $ A $ and $ B $: $ B \cup A = \{3, 4, 5, 1, 2\} = \{1, 2, 3, 4, 5\} $ 

$$
A \cup B = B \cup A

$$  
*Confirmed via direct comparison.*

## Practice Problems  

### **Problem 1 (Easy):**  
Let $P = \{1, 3, 5\} $ and $ Q = \{2, 4, 6\} $. Find $ P \cup Q $.  
**Difficulty:** 🟢 Easy  

### **Problem 2 (Medium):**  
If $ R = \{a, b, c\} $ and $ S = \{b, c, d\} $, prove that $ R \cup S = R \cup \{d\} $.  
**Difficulty:** 🟡 Medium  

### **Problem 3 (Hard):**  
Given $ T = \{x : x \text{ is a prime number less than 10}\} $ and $ U = \{x : x \text{ is an even number less than 10}\} $, find $ T \cup U $ and show that it satisfies the **idempotent law**.  
**Difficulty:** 🔴 Hard  

### **Problem 4 (Medium):**  
In a class of 30 students, 15 play cricket and 12 play basketball. If 5 students play both sports, find the total number of students who play either sport using the union operation.  
**Difficulty:** 🟡 Medium  

---

## Answers  

### **Answer to Problem 1:**  
- $ P \cup Q = \{1, 2, 3, 4, 5\} $  
*Combine elements from both sets, ensuring uniqueness.*  

### **Answer to Problem 2:**  
- $ R \cup S = \{a, b, c, d\} $  
- $ R \cup \{d\} = \{a, b, c, d\} $  
*Both unions yield the same set, confirming equality.*  

### **Answer to Problem 3:**  
- $ T = \{2, 3, 5, 7\} $, $ U = \{2, 4, 6, 8\} $  
- $ T \cup U = \{2, 3, 4, 5, 6, 7, 8\} $  
- $ T \cup T = \{2, 3, 5, 7\} = T $  
*Idempotent law holds.*  

### **Answer to Problem 4:**  
- Students playing cricket: $ 15 $  
- Students playing basketball: $ 12 $  
- Overlap (both sports): $ 5 $  
- Total = $ 15 + 12 - 5 = 22 $  
*Using $|T \cup U| = |T| + |U| - |T \cap U|$.*

## Summary  
- The **union** of sets $ A $ and $ B $ combines all unique elements from both sets.  
- Key properties: Commutative, Associative, Identity Element, Idempotent, and Universal Set laws.  
- Venn diagrams visually represent unions as shaded regions covering all elements in $ A $ or $ B $.  
- Example: $ A \cup B = \{x : x \in A \text{ or } x \in B\} $.  
- Union is foundational for analyzing overlaps and combinations in set theory.  

---

## Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ A \cup B = \{x : x \in A \text{ or } x \in B\} $ | Definition of union |  
| $ A \cup B = B \cup A $ | Commutative Law |  
| $ (A \cup B) \cup C = A \cup (B \cup C) $ | Associative Law |  
| $ A \cup \emptyset = A $ | Identity Element Law |  
| $ A \cup A = A $ | Idempotent Law |  
| $ U \cup A = U $ | Universal Set Law |

### **Question 1 (2 Marks):**  
If $ M = \{1, 2, 3\} $ and $ N = \{3, 4, 5\} $, find $ M \cup N $.  
**Approach:** Combine elements of $ M $ and $ N $, ensuring no duplicates.

Prove that $ A \cup B = B \cup A $ using the definition of union.  
**Approach:** Show that every element in $ A \cup B $ is also in $ B \cup A $ and vice versa.

What is the identity element for the union operation?  
**Approach:** Recall the definition of the empty set’s role in unions.

## Student Corner  

### **Common Mistakes**  
1. **Including duplicates**: Forgetting to remove repeated elements (e.g., writing $ A \cup B = \{1, 2, 2, 3\} $ instead of $\{1, 2, 3\} $).  
   **Correction**: Always list unique elements.  
2. **Confusing union with intersection**: Mixing up “or” (union) with “and” (intersection).  
   **Correction**: Use the definition: $ x \in A \cup B $ means $ x $ is in $ A $ or $ B $.  

### **Exam Tips**  
- Draw **Venn diagrams** to visualize unions, especially for multi-set problems.  
- Practice identifying identities (like $\emptyset $) and verifying properties.  

### **Memory Aid**  
**"Union: All elements, no repeats!"**  
Remember to combine sets and eliminate duplicates when calculating $ A \cup B $.
