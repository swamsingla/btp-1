## Prerequisites  
Before diving into the concept of equal sets, ensure you have a solid foundation in:  
- **Basic set notation**: Understanding how to represent sets using curly braces `{}` and describe elements within them.  
- **Element membership**: Knowing how to denote whether an element belongs to a set using the symbol `$\in $` (e.g., `$ 2 \in \{1, 2, 3\} $`).  
- **Empty set**: Recognizing that a set with no elements is denoted by `$\emptyset $` or `$\phi $`.  

These foundational ideas are critical for grasping how sets compare and interact, particularly when determining equality.

## Introduction  
Imagine two groups of people at a party: one group consists of your friends, and the other includes everyone who shares your birthday. If both groups contain exactly the same individuals, they’re essentially the same group, even though described differently. This is analogous to **equal sets** in mathematics—sets that share precisely the same elements.  

In this topic, you’ll learn how to identify when two sets are equal, explore examples, and apply this concept to solve problems. By the end, you’ll be able to determine whether sets are equal simply by comparing their elements!  

---  

## Explanation  
### **Definition of Equal Sets**  
Two sets **A** and **B** are said to be **equal**, written as **A = B**, if they contain exactly the same elements. This means:  
- Every element of **A** is also an element of **B**, and  
- Every element of **B** is also an element of **A**.  

This mutual inclusion ensures that neither set has extra or missing elements compared to the other.  

> **Definition 3**: *Two sets A and B are said to be equal if they have exactly the same elements and we write A = B. Otherwise, the sets are said to be unequal and we write A ≠ B.*  

### **Key Properties of Equal Sets**  
- **Order doesn’t matter**: The arrangement of elements in a set is irrelevant. For example, `$\{1, 2, 3\} = \{3, 2, 1\} $`.  
- **Duplicates don’t affect equality**: Repeating elements in a set does not change its identity. For instance, `$\{1, 2, 2, 3\} = \{1, 2, 3\} $`.  
- **Equality is symmetric**: If **A = B**, then **B = A**.  

### **How to Determine Equality**  
To check if two sets are equal:  
1. List all elements of both sets.  
2. Compare each element systematically.  
3. If all elements match exactly, the sets are equal; otherwise, they are not.  

This process is straightforward but requires careful attention to detail, especially when dealing with large or abstract sets.

## Solved Examples  
**Example 1:**  
Let **A** = `{1, 2, 3, 4}` and **B** = `{3, 1, 4, 2}`. Are **A** and **B** equal?  

**Solution:**  
- Both sets contain the elements `1`, `2`, `3`, and `4`.  
- The order of elements does not matter.  
- Since all elements of **A** are in **B** and vice versa, **A = B**.  

**Example 2:**  
Let **A** be the set of prime numbers less than `6`, and **P** be the set of prime factors of `30`. Are **A** and **P** equal?  

**Solution:**  
- Prime numbers less than `6`: `$ A = \{2, 3, 5\} $`.  
- Prime factors of `30`: `$ P = \{2, 3, 5\} $` (since `2 × 3 × 5 = 30`).  
- Both sets contain the same elements.  
- Hence, **A = P**.  

**Example 3:**  
Consider the sets **C** = `{x : x² = 25}` and **D** = `{x : x² − 2x − 15 = 0}`. Are **C** and **D** equal?  

**Solution:**  
- Solve for **C**:

$$
  x^2 = 25 \implies x = \pm5 \implies C = \{-5, 5\}

$$  
- Solve for **D**:

$$
  x^2 - 2x - 15 = 0 \implies (x - 5)(x + 3) = 0 \implies x = 5, -3 \implies D = \{-3, 5\}

$$  
- **C** contains `-5` and `5`, while **D** contains `-3` and `5`.  
- Since the elements differ, **C ≠ D**.  

**Example 4:**  
Are the sets **X** = `{A, L, L, O, Y}` and **B** = `{L, O, Y, A, L}` equal?  

**Solution:**  
- Repetition of elements does not affect set equality.  
- Removing duplicates: **X = {A, L, O, Y}** and **B = {A, L, O, Y}**.  
- Both sets have identical elements.  
- Therefore, **X = B**.

## Practice Problems  
**Problem 1 (🟢 Easy):**  
Identify whether the following pairs of sets are equal:  
- **A** = `{1, 2, 3}`, **B** = `{3, 2, 1}`  
- **C** = `{a, b, c}`, **D** = `{c, b, a}`  

**Problem 2 (🟡 Medium):**  
Let **E** = `{x : x is a natural number and x < 4}` and **F** = `{1, 2, 3}`. Are **E** and **F** equal? Justify.  

**Problem 3 (🔴 Hard):**  
Given **G** = `{x : x² = 16}` and **H** = `{x : x² − 4x − 12 = 0}`, determine if **G = H**.  

**Problem 4 (🟡 Medium):**  
Which of the following sets are equal?  
- **P** = `{x : x is a vowel in “MATHEMATICS”}`  
- **Q** = `{x : x is a vowel in “CONCENTRATION”}`  

---  

## Answers  
**Problem 1 Solution:**  
- **A = B** because both sets contain the same elements `{1, 2, 3}` regardless of order.  
- **C = D** for the same reason.  

**Problem 2 Solution:**  
- **E** = `{1, 2, 3}` (natural numbers less than `4` are `1, 2, 3`).  
- **F** = `{1, 2, 3}`.  
- Since both sets have identical elements, **E = F**.  

**Problem 3 Solution:**  
- Solve **G**:

$$
  x^2 = 16 \implies x = \pm4 \implies G = \{-4, 4\}

$$  
- Solve **H**:

$$
  x^2 - 4x - 12 = 0 \implies (x - 6)(x + 2) = 0 \implies x = 6, -2 \implies H = \{-2, 6\}

$$  
- **G ≠ H** because the elements differ.  

**Problem 4 Solution:**  
- **P** = vowels in “MATHEMATICS”: `{A, E, I}`.  
- **Q** = vowels in “CONCENTRATION”: `{O, E, A, I}`.  
- **P ≠ Q** because **Q** contains an additional element `O`.

## Summary  
- **Equal sets** have exactly the same elements, regardless of order or repetition.  
- To check equality, compare all elements systematically.  
- The notation **A = B** indicates sets are equal; **A ≠ B** means they are not.  
- Duplicates in a set do not alter its identity (e.g., `{1, 1, 2} = {1, 2}`).  
- The empty set (`$\emptyset $`) is unique—it has no elements and cannot be equal to any non-empty set.

## Key Formulas  
| Formula | Description |  
|--------|-------------|  
| **A = B** | Sets **A** and **B** are equal if they contain the same elements. |  
| **A ≠ B** | Sets **A** and **B** are unequal if at least one element differs. |  
| **n(A)** | Cardinality of set **A** (number of distinct elements in **A**). |  
| **{x : P(x)}** | Set-builder notation: elements **x** satisfying condition **P(x)**. |

## Student Corner  
### **Common Mistakes**  
1. **Confusing equality with subsets**: Remember, equality requires *exactly* the same elements, not just a subset relationship.  
2. **Ignoring duplicate elements**: Sets automatically remove duplicates, so `{1, 1, 2}` is still equal to `{1, 2}`.  
3. **Misinterpreting set-builder notation**: Always clarify the condition defining the set’s elements.  

### **Exam Tips**  
- When proving equality, always verify both directions: **A ⊆ B** and **B ⊆ A**.  
- For abstract sets, substitute values or simplify expressions to identify matching elements.  

### **Memory Aid**  
**"EQUAL SETS: Same Elements, Same Identity!"**  
Use this phrase to remember that equality depends solely on shared elements, not order or repetition.
