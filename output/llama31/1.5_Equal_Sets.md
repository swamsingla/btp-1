# 1.5 Equal Sets

> **Grade 11** | **Chapter 1: SETS**

---

## Prerequisites
To understand this topic, students should already know:

* Understanding of set notation and element membership ($a \in A $ means "$ a $ belongs to set $ A $")
* Basic knowledge of how to identify and write down elements of a set
* Familiarity with set equality ($ A = B $ means sets $ A $ and $ B $ have the same elements)

## Introduction
Are you familiar with the idea of comparing sets? Think about it - if you had two groups of people, say, a group of friends at school and a group of friends from your neighborhood, how would you determine if they were the same group? Would it matter if the people were listed in a different order?

In this topic, we'll explore what makes two sets equal, and how to identify pairs of equal sets. By the end of this topic, you'll be able to define and recognize equal sets, and apply this knowledge to solve various problems.


## Explanation
> Definition: **Equal Sets**
Two sets $ A $ and $ B $ are said to be equal if they have exactly the same elements, denoted by $ A = B $. Conversely, if $ A $ and $ B $ do not have the same elements, we write $ A \neq B $.

> Note: Repetition of elements in a set does not change the set. For example, the sets $ A = \{1, 2, 3\} $ and $ B = \{2, 1, 3, 3\} $ are equal because each element of $ A $ is also an element of $ B $.

### Example 1: Equality of Sets

Let $ A = \{1, 2, 3, 4\} $ and $ B = \{3, 1, 4, 2\} $. Determine if $ A $ and $ B $ are equal sets.

Solution: 
Since every element of $ A $ is also an element of $ B $ and vice versa, we can conclude that $ A = B $.

### Example 2: Prime Numbers

Let $ A $ be the set of prime numbers less than 6 and $ P $ be the set of prime factors of 30. Determine if $ A $ and $ P $ are equal sets.

Solution: 
First, let's find the prime numbers less than 6: $ A = \{2, 3, 5\} $. Next, let's find the prime factors of 30: $ P = \{2, 3, 5\} $. Since both sets have the same elements, we conclude that $ A = P $.


### Example 3: Non-Equivalence

Let $ A = \{0\} $ and $ B = \{x : x > 15 \text{ and } x < 5\} $. Determine if $ A $ and $ B $ are equal sets.

Solution: 
Since 0 does not satisfy either condition of $ B $, we conclude that $ A \neq B $.


### Example 4: Subset Relationship

Let $ C = \{x : x - 5 = 0\} $ and $ D = \{x : x^2 = 25\} $. Determine if $ C $ and $ D $ are equal sets.

Solution: 
First, solve the equation $ x - 5 = 0 $: $ x = 5 $. So, $ C = \{5\} $. Now, solve the equation $ x^2 = 25 $: $ x = \pm 5 $. Therefore, $ D = \{-5, 5\} $. Since $ C $ and $ D $ have different elements, we conclude that $ C \neq D $.


### Example 5: Multiple Solutions

Let $ E = \{x : x \text{ is an integral positive root of the equation } x^2 - 2x - 15 = 0\} $. Determine if there exists any other set $ F $ such that $ E = F $.

Solution: 
To find the roots of the quadratic equation $ x^2 - 2x - 15 = 0 $, factor the left-hand side: $ (x - 5)(x + 3) = 0 $. This gives us two possible values for $ x $: $ x = 5 $ and $ x = -3 $. However, since we're looking for an integral positive root, only $ x = 5 $ satisfies the conditions. Hence, $ E = \{5\} $.


## Practice Problems
### Problem 1: 🟢 Easy
Let $ A = \{1, 2, 3\} $ and $ B = \{3, 2, 1, 4\} $. Are $ A $ and $ B $ equal sets?
### Problem 2: 🟡 Medium
Let $ C = \{x : x > 10 \text{ and } x < 20\} $ and $ D = \{x : x^2 = 36\} $. Are $ C $ and $ D $ equal sets?
### Problem 3: 🔴 Hard
Let $ E = \{x : x \text{ is an integer and } x^2 - 2x - 6 = 0\} $. Find the set $ F $ such that $ E = F $.
### Problem 4: 🟢 Easy
Let $ G = \{1, 2, 3, 4, 5\} $ and $ H = \{5, 4, 3, 2, 1\} $. Are $ G $ and $ H $ equal sets?
### Problem 5: 🟡 Medium
Let $ I = \{x : x \text{ is a rational number and } x^2 - 2x - 1 = 0\} $. Find the set $ J $ such that $ I = J $.


## Answers
### Problem 1:
Since every element of $ A $ is also an element of $ B $ and vice versa, we conclude that $ A = B $.

### Problem 2:
First, solve the inequality $ x > 10 $ and $ x < 20 $: $ 11 \leq x \leq 19 $. Now, solve the equation $ x^2 = 36 $: $ x = \pm 6 $. Therefore, $ D = \{-6, 6\} $. Since $ C $ and $ D $ have different elements, we conclude that $ C \neq D $.

### Problem 3:
To find the roots of the quadratic equation $ x^2 - 2x - 6 = 0 $, factor the left-hand side: $ (x - 3)(x + 2) = 0 $. This gives us two possible values for $ x $: $ x = 3 $ and $ x = -2 $. However, since we're looking for an integer, only $ x = 3 $ satisfies the conditions. Hence, $ E = \{3\} $. To find the corresponding set $ F $, we note that $ E $ has only one element, so $ F $ must also contain only one element, which is the negative root: $ F = \{-2\} $.

### Problem 4:
Since every element of $ G $ is also an element of $ H $ and vice versa, we conclude that $ G = H $.

### Problem 5:
To find the roots of the quadratic equation $ x^2 - 2x - 1 = 0 $, factor the left-hand side: $ (x - 1)^2 - 2 = 0 $. This gives us two possible values for $ x $: $ x = 1 \pm \sqrt{2} $. Since we're looking for a rational number, neither $ 1 + \sqrt{2} $ nor $ 1 - \sqrt{2} $ satisfies the conditions. However, this is incorrect. Let us re-evaluate our work. 

The factored form $ (x - 1)^2 - 2 = 0 $ actually becomes $ (x-1-\sqrt{2})(x-1+\sqrt{2})=0 $. This gives us two possible values for $ x $: $ x = 1 - \sqrt{2} $ and $ x = 1 + \sqrt{2} $. Neither of these two values are rational numbers. Our initial assessment was wrong; the set $ I $ contains no elements, so the set $ J $ must also be the empty set $\emptyset $.


## Summary
• Two sets $ A $ and $ B $ are equal if they have exactly the same elements.
• Repetition of elements in a set does not change the set.
• If every element of $ A $ is also an element of $ B $ and vice versa, then $ A = B $.
• If $ A $ and $ B $ have different elements, then $ A \neq B $.
• If $ A $ and $ B $ have exactly the same elements, then $ A = B $.
• If $ A $ and $ B $ have different elements, then $ A \neq B $.
• The equality of sets is often represented by the equation $ A = B $.
• The non-equality of sets is often represented by the equation $ A \neq B $.

## Key Formulas

| $ A \neq B $ | Two sets $ A $ and $ B $ are unequal if they do not have the same elements. |

## Student Corner
### Common Mistakes
• Not checking if the elements of two sets are exactly the same before concluding that they are equal.
• Assuming that the order of elements in a set matters when determining whether two sets are equal.

### Exam Tips
• Make sure to carefully read the problem statement and check if the sets are defined correctly.
• When working with large sets, try breaking them down into smaller sub-sets to make comparison easier.

### Memory Aid
To remember that two sets are equal if they have exactly the same elements, recall the phrase "Elements are Equal, Sets are Equal."
