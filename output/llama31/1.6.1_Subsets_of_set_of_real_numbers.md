## Introduction
In this topic, we will explore various subsets of the set of real numbers, denoted by $\mathbb{R} $. These subsets play a crucial role in understanding different types of numbers and their relationships. By the end of this topic, you will understand the definitions of several important subsets of $\mathbb{R} $ and how they are related to each other.

## Explanation
### Definition of Subsets
> **Definition**: A set $ A $ is said to be a subset of a set $ B $, denoted by $ A \subset B $, if every element of $ A $ is also an element of $ B $. Similarly, $ A $ is said to be a proper subset of $ B $, denoted by $ A \subsetneq B $, if every element of $ A $ is an element of $ B $, but there exists at least one element in $ B $ which is not an element of $ A $.

### Important Subsets of Real Numbers
We will now define several important subsets of $\mathbb{R} $:

* The set of natural numbers, denoted by $\mathbb{N} $, is defined as $\mathbb{N} = \{x \in \mathbb{R} : x \text{ is a positive integer}\} $.
* The set of integers, denoted by $\mathbb{Z} $, is defined as $\mathbb{Z} = \{x \in \mathbb{R} : x \text{ is an integer}\} $.
* The set of rational numbers, denoted by $\mathbb{Q} $, is defined as $\mathbb{Q} = \{x \in \mathbb{R} : x = \frac{p}{q}, \text{ where } p, q \in \mathbb{Z} \text{ and } q \neq 0\} $.
* The set of irrational numbers, denoted by $\mathbb{T} $, is defined as $\mathbb{T} = \{x \in \mathbb{R} : x \notin \mathbb{Q}\} $.

> **Properties of Subsets**
* $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} $ and $\mathbb{T} \subset \mathbb{R} $.
* $\mathbb{N} \not\subset \mathbb{T} $.

### Key Terms

| --- | --- |

| Proper Subset | A set $ A $ is a proper subset of a set $ B $ if every element of $ A $ is an element of $ B $, but there exists at least one element in $ B $ which is not an element of $ A $. |

## Solved Examples

**Example 1:** Determine whether the set $\{2, 4, 6, 8\} $ is a subset of $\mathbb{N} $.
**Solution:** Since every element of $\{2, 4, 6, 8\} $ is a positive integer, we have $\{2, 4, 6, 8\} \subset \mathbb{N} $.

**Example 2:** Show that $\mathbb{N} \subset \mathbb{Z} $.
**Solution:**

Since every natural number is an integer, we need to show that for any $ x \in \mathbb{N} $, $ x \in \mathbb{Z} $.
Let $ x \in \mathbb{N} $.
Then $ x $ is a positive integer.
By definition of $\mathbb{Z} $, since $ x $ is an integer, $ x \in \mathbb{Z} $.
Therefore, $\mathbb{N} \subset \mathbb{Z} $.

**Example 3:** Find an example of a set that is a subset of both $\mathbb{Q} $ and $\mathbb{R} $ but not a subset of $\mathbb{Z} $.
**Solution:** Consider the set $\left\{\frac{1}{2}, \frac{1}{3}, \frac{1}{4}\right\} $.
This set is a subset of $\mathbb{Q} $ because every element is a rational number.
It is also a subset of $\mathbb{R} $ because every element is a real number.
However, it is not a subset of $\mathbb{Z} $ because none of the elements are integers.

**Example 4:** Determine whether the set $\{2, 4, 6, 8, 10\} $ is a proper subset of $\mathbb{Z} $.
**Solution:** Since every element of $\{2, 4, 6, 8, 10\} $ is an integer, we have $\{2, 4, 6, 8, 10\} \subset \mathbb{Z} $.
However, there exist elements in $\mathbb{Z} $, such as $-\pi $, which are not in $\{2, 4, 6, 8, 10\}.
Therefore, $\{2, 4, 6, 8, 10\} $ is a proper subset of $\mathbb{Z} $.

## Summary
Here are the key concepts and formulas covered in this topic:
* A set $ A $ is a subset of a set $ B $ if every element of $ A $ is an element of $ B $: $ A \subset B $
* A set $ A $ is a proper subset of a set $ B $ if every element of $ A $ is an element of $ B $, but there exists at least one element in $ B $ which is not an element of $ A $: $ A \subsetneq B $
* The set of natural numbers, denoted by $\mathbb{N} $, is defined as $\mathbb{N} = \{x \in \mathbb{R} : x \text{ is a positive integer}\} $
* The set of integers, denoted by $\mathbb{Z} $, is defined as $\mathbb{Z} = \{x \in \mathbb{R} : x \text{ is an integer}\} $
* The set of rational numbers, denoted by $\mathbb{Q} $, is defined as $\mathbb{Q} = \{x \in \mathbb{R} : x = \frac{p}{q}, \text{ where } p, q \in \mathbb{Z} \text{ and } q \neq 0\} $
* The set of irrational numbers, denoted by $\mathbb{T} $, is defined as $\mathbb{T} = \{x \in \mathbb{R} : x \notin \mathbb{Q}\} $

## Student Corner
**Common Mistake:** Not distinguishing between a subset and a proper subset.
**Tip:** Remember that a subset is a set whose elements are all contained in another set, while a proper subset is a set whose elements are all contained in another set, but it does not contain all the elements of the larger set.

**Memory Aid:** Think of a subset as a smaller pizza inside a bigger pizza, and a proper subset as a smaller pizza that is completely inside the bigger pizza but does not touch the crust.
