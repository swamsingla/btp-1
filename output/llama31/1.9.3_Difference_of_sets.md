# 1.9.3 Difference of sets

> **Grade 11** | **Chapter 1: SETS**

---

## Prerequisites
To understand the concept of difference of sets, students should have a good grasp of basic set theory, including:
* Understanding of set notation and element membership ($x \in A $ means $ x $ belongs to set $ A $)
* Familiarity with basic set operations like union ($\cup $) and intersection ($\cap $)
* Ability to work with set builder notation

## Introduction
Imagine having a group of friends who love different types of music. Some of them love rock music, while others prefer pop music. To find out which songs they like, we need to compare their favorite genres. This is similar to finding the difference between two sets. In this chapter, we will explore how to find the difference of two sets, denoted by $ A - B $. 

By the end of this topic, you will be able to define the difference of two sets, find the difference of various sets, and represent it using Venn diagrams. You will also understand that the difference of two sets can be represented using set-builder notation.

## Explanation

> **Definition:** The difference of two sets $ A $ and $ B $ is the collection of elements which belong to $ A $ but not to $ B $. Symbolically, we write $ A - B $ and read as “$ A $ minus $ B $”.

> **Theorem:** $ A - B = \{ x : x \in A \land x \notin B \} $

> **Property:** The difference of two sets $ A $ and $ B $ is not necessarily equal to the difference of $ B $ and $ A $, i.e., $ A - B \neq B - A $.

### Example 1:

Suppose $ A = \{ 1, 2, 3, 4, 5, 6 \} $ and $ B = \{ 2, 4, 6, 8 \} $. Then,

$$
A - B = \{ 1, 3, 5 \}

$$

because the elements $1, 3, 5 $ belong to $ A $ but not to $ B $.

Similarly,

$$
B - A = \{ 8 \}

$$

since the element $8 $ belongs to $ B $ but not to $ A $.

### Example 2:

Let $ V = \{ a, e, i, o, u \} $ and $ B = \{ a, i, k, u \} $. Then,

$$
V - B = \{ e, o \}

$$

because the elements $e, o $ belong to $ V $ but not to $ B $.

Similarly,

$$
B - V = \{ k \}

$$

since the element $k $ belongs to $ B $ but not to $ V $.

### Remark:

Note that the sets $ A - B $, $ A \cap B $, and $ B - A $ are mutually disjoint sets, i.e., the intersection of any two of these sets is the null set.

## Solved Examples

### Example 3:

Let $ A = \{ 3, 5, 7, 9, 11 \} $ and $ B = \{ 7, 9, 11, 13 \} $. Find $ A - B $ and $ B - A $.

**Solution:**

First, let us find $ A - B $.
Since the elements $ 3, 5 $ belong to $ A $ but not to $ B $, we have,

$$
A - B = \{ 3, 5 \}.

$$

Now, let us find $B - A $. Since the element $ 13 $ belongs to $ B $ but not to $ A $, we have,

$$
B - A = \{ 13 \}.

$$

### Example 4:

Let $A = \{ x : x \text{ is a natural number and } x \le 6 \} $ and $ B = \{ x : x \text{ is a natural number and } 6 < x \le 8 \} $. Find $ A - B $ and $ B - A $.

**Solution:**

First, let us find $ A - B $. Since the elements $ 1, 2, 3, 4, 5, 6 $ belong to $ A $ but not to $ B $, we have,

$$
A - B = \{ 1, 2, 3, 4, 5, 6 \}.

$$

Now, let us find $B - A $. Since the element $ 7 $ belongs to $ B $ but not to $ A $, we have,

$$
B - A = \{ 7 \}.

$$

### Example 5:

Let $A = \{ x : x \text{ is a prime number and } x \le 7 \} $ and $ B = \{ x : x \text{ is an even prime number and } x \le 7 \} $. Find $ A - B $ and $ B - A $.

**Solution:**

First, let us find $ A - B $. Since the elements $ 2, 3, 5, 7 $ belong to $ A $ but not to $ B $, we have,

$$
A - B = \{ 2, 3, 5, 7 \}.

$$

Now, let us find $B - A $. Since there are no elements in $ B $ except for $ 2 $, we have,

$$
B - A = \{ 2 \}.

$$

### Example 6:

Let $A = \{ 3, 5, 7, 9, 11 \} $ and $ B = \phi $. Find $ A - B $.

**Solution:**

Since the set $ B $ is empty, we have

$$
A - B = A = \{ 3, 5, 7, 9, 11 \}.

$$

### Example 7:

Let $A = \phi $ and $ B = \{ 7, 9, 11, 13 \} $. Find $ A - B $.

**Solution:**

Since the set $ A $ is empty, we have

$$
A - B = \emptyset.

$$

## Practice Problems

### Problem 1 (🟢 Easy)
Find the difference of the following pairs of sets:
(i) $A = \{ 1, 2, 3 \} $ and $ B = \{ 1, 2, 3, 4 \} $
(ii) $ V = \{ a, e, i, o, u \} $ and $ B = \{ a, b, c \} $
(iii) $ A = \{ x : x \text{ is a natural number and } x \le 6 \} $ and $ B = \{ x : x \text{ is a natural number and } 6 < x \le 8 \} $

### Problem 2 (🟢 Easy)
Let $ A = \{ 3, 5, 7 \} $ and $ B = \{ 7, 9, 11 \} $. Is $ A - B $ equal to $ B - A $?

### Problem 3 (🟢 Easy)
Let $ A = \{ 1, 2, 3 \} $ and $ B = \{ 4, 5, 6 \} $. Find $ (A - B) \cup (B - A) $.

### Problem 4 (🔴 Hard)
Let $ A = \{ x : x \text{ is a natural number and } x \le 100 \} $ and $ B = \{ x : x \text{ is a perfect square and } x \le 100 \} $. Find $ A - B $.

## Answers

### Problem 1
(i) $ A - B = \emptyset $
(ii) $ V - B = \{ e, i, o \} $
(iii) $ A - B = \{ 6 \} $

### Problem 2
No, $ A - B \neq B - A $

### Problem 3
$ (A - B) \cup (B - A) = \{ 1, 2, 3, 4, 5, 6 \} $

### Problem 4
$ A - B = \{ x : x \text{ is a natural number and } x \le 100 \text{ and } x \text{ is not a perfect square} \} $

### Solution to Problem 4

To solve this problem, we need to find all natural numbers less than or equal to $ 100 $ that are not perfect squares.

First, let us find all perfect squares less than or equal to $ 100 $:

$$
\begin{array}{|c|c|}
\hline
\text{Perfect Square} & \text{Value} \\
\hline
1^2 & 1 \\
2^2 & 4 \\
3^2 & 9 \\
4^2 & 16 \\
5^2 & 25 \\
6^2 & 36 \\
7^2 & 49 \\
8^2 & 64 \\
9^2 & 81 \\
10^2 & 100 \\
\hline
\end{array}

$$

There are $10 $ perfect squares less than or equal to $ 100 $. Therefore, there are $ 99 - 10 + 1 = 90 $ natural numbers less than or equal to $ 100 $ that are not perfect squares.

Hence,

$$
A - B = \{ x : x \text{ is a natural number and } x \le 100 \text{ and } x \text{ is not a perfect square} \}.

$$

## Summary
Key Concepts and Formulas:
• Definition of difference of two sets: $A - B = \{ x : x \in A \land x \notin B \} $
• The difference of two sets is not necessarily equal to the difference of the second set and the first set, i.e., $ A - B \neq B - A $
• The difference of two sets can be represented using Venn diagrams.
• The difference of two sets can be found using set-builder notation.

## Student Corner

### Common Mistakes
Typical errors that students make when working with difference of sets include:
* Not paying attention to the direction of the subtraction sign.
* Failing to identify the elements that belong to one set but not to the other.

### Exam Tips
When answering questions about difference of sets, make sure to:
* Clearly identify the sets involved.
* Pay close attention to the direction of the subtraction sign.
* Identify the elements that belong to one set but not to the other.

### Memory Aid
One way to remember the difference of two sets is to think of it as "all elements in $ A $ but not in $ B $", or simply "all elements that are unique to $ A $".
