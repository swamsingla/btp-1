# 1.9.1 Union of sets

> **Grade 11** | **Chapter 1: SETS**

## Prerequisites
To understand this topic, students should have a good grasp of:

* Understanding of set notation and element membership ($a \in A $)
* Familiarity with basic set operations such as addition and multiplication of integers
* Basic algebraic manipulations and logical reasoning skills

## Introduction
Do you often find yourself wondering how to combine information from different sources? For instance, think about a bookstore where you want to buy books on Mathematics and Physics. You might have separate shelves for Mathematics and Physics books, but you need to consider the entire collection of books available on these subjects. That's exactly what we're going to explore in this topic - combining sets to form a new set!

In this topic, you'll learn about the **union of sets**, which allows us to combine two or more sets into a single set, considering all the unique elements from each set. This operation is denoted by the symbol $\cup $ and is essential in various applications, including data analysis, probability theory, and computer science.

## Explanation
### Definition of Union of Sets

> The union of two sets $ A $ and $ B $ is the set $ C $ which consists of all those elements which are either in $ A $ or in $ B $ (including those which are in both). In symbols, we write:

$$

A \cup B = \{ x : x \in A \text{ or } x \in B \}

$$

### Properties of Union of Sets

> Some properties of the operation of union are listed below:

$$
\begin{aligned}
i)\quad A \cup B &= B \cup A \qquad (\text{Commutative law})\\
ii)\quad (A \cup B) \cup C &= A \cup (B \cup C) \qquad(\text{Associative law}) \\
iii)\quad A \cup \phi &= A \qquad (\text{Law of identity element, } \phi \text{ is the identity of } \cup) \\
iv)\quad A \cup A &= A \qquad (\text{Idempotent law})\\
v)\quad U \cup A &= U \qquad (\text{Law of U})
\end{aligned}

$$

### Example 1:

Let $A = \{2, 4, 6, 8\} $ and $ B = \{6, 8, 10, 12\} $. Find $ A \cup B $.

Solution: We have $ A \cup B = \{2, 4, 6, 8, 10, 12\} $.

### Example 2:

Let $ A = \{a, e, i, o, u\} $ and $ B = \{a, i, u\} $. Show that $ A \cup B = A $.

Solution: We have, $ A \cup B = \{a, e, i, o, u\} = A $. This example illustrates that the union of sets $ A $ and its subset $ B $ is the set $ A $ itself, i.e., if $ B \subset A $, then $ A \cup B = A $.

### Example 3:

Let $ X = \{Ram, Geeta, Akbar\} $ be the set of students of Class XI, who are in the school hockey team. Let $ Y = \{Geeta, David, Ashok\} $ be the set of students from Class XI who are in the school football team. Find $ X \cup Y $ and interpret the set.

Solution: We have, $ X \cup Y = \{Ram, Geeta, Akbar, David, Ashok\} $. This is the set of students from Class XI who are in the hockey team or the football team or both.

### Example 4:

Find $ (A \cup B) \cup C $ and $ A \cup (B \cup C) $ where $ A = \{1, 2, 3\} $, $ B = \{3, 4, 5\} $ and $ C = \{5, 6, 7\} $.

Solution: 
We have,
$ (A \cup B) = \{1, 2, 3, 4, 5\} $ and
$ B \cup C = \{3, 4, 5, 6, 7\} $.
Therefore,
$ (A \cup B) \cup C = \{1, 2, 3, 4, 5, 6, 7\} $ and
$ A \cup (B \cup C) = \{1, 2, 3, 4, 5, 6, 7\} $.

### Example 5:

Show that $ A \cup \phi = A $, where $ A = \{1, 2, 3\} $.

Solution: We have, $ A \cup \phi = \{1, 2, 3\} = A $.


## Practice Problems

### Problem 1: 🟢 Easy
Let $ A = \{x, y, z\} $ and $ B = \{y, z, w\} $. Find $ A \cup B $.

### Problem 2: 🟢 Easy
Show that $ A \cup B = B \cup A $ where $ A = \{a, b, c\} $ and $ B = \{c, d, e\} $.

### Problem 3: 🔴 Hard
Let $ A = \{1, 2, 3, 4\} $ and $ B = \{4, 5, 6\} $. Find $ (A \cup B) \cup C $ and $ A \cup (B \cup C) $ where $ C = \{6, 7, 8\} $.

### Problem 4: 🟢 Easy
Find $ X \cup Y $ where $ X = \{p, q, r\} $ and $ Y = \{r, s, t\} $.

### Problem 5: 🟡 Medium
Show that $ A \cup \phi = A $, where $ A = \{1, 2, 3\} $.

### Answers:

#### Solution to Problem 1:
We have, $ A \cup B = \{x, y, z, w\} $.

#### Solution to Problem 2:
We have, $ A \cup B = \{a, b, c, d, e\} $ and $ B \cup A = \{a, b, c, d, e\} $. Therefore, $ A \cup B = B \cup A $.

#### Solution to Problem 3:
We have, $ (A \cup B) = \{1, 2, 3, 4, 5, 6\} $ and $ B \cup C = \{4, 5, 6, 7, 8\} $. Therefore, $ (A \cup B) \cup C = \{1, 2, 3, 4, 5, 6, 7, 8\} $ and $ A \cup (B \cup C) = \{1, 2, 3, 4, 5, 6, 7, 8\} $.

#### Solution to Problem 4:
We have, $ X \cup Y = \{p, q, r, s, t\} $.

#### Solution to Problem 5:
We have, $ A \cup \phi = \{1, 2, 3\} = A $.

## Summary
• The union of two sets $ A $ and $ B $ is denoted by $ A \cup B $ and consists of all elements that belong to $ A $ or $ B $ (or both).
• The commutative law states that $ A \cup B = B \cup A $.
• The associative law states that $ (A \cup B) \cup C = A \cup (B \cup C) $.
• The law of identity element states that $ A \cup \phi = A $.
• The idempotent law states that $ A \cup A = A $.
• The law of U states that $ U \cup A = U $.

## Student Corner

### Common Mistakes:
- Not considering common elements while finding the union of sets.
- Writing $ A \cup B $ as $ A + B $ instead of using the union symbol $\cup $.

### Exam Tips:
- When finding the union of two sets, make sure to consider all elements belonging to either set.
- Pay attention to the commutative law of union, which states that $ A \cup B = B \cup A $.

### Memory Aid:
- To remember that the union of two sets includes all elements from both sets, simply recall that the union is like a big container holding everything.
