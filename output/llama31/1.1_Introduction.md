## Introduction

Have you ever tried organizing your bookshelf, clothes closet, or digital files? We often group similar items together to make them easier to find and manage. This concept of grouping objects into collections is essential in mathematics, particularly in the study of **sets**. A set is a collection of unique objects, known as elements, that can be anything: numbers, letters, people, or even ideas. In this topic, we'll explore the basics of sets, including their representations, and how they're used in various branches of mathematics.

By the end of this topic, you'll be able to define and represent sets, identify the empty set, determine the cardinality of finite sets, and understand the relationships between different sets.

## Explanation

### Definition of a Set

> A **set** is a collection of unique objects, called **elements**, that can be anything.
 
> The elements of a set are usually represented in a particular order, but the order does not matter. For example, {a, b, c} represents the same set as {c, b, a}.
 
> Two sets are equal if and only if they contain exactly the same elements.
 
> The number of elements in a set is called the **cardinality** of the set.
 
> The **empty set**, denoted by ∅ or $\emptyset $, is a set containing no elements.

### Georg Cantor and the Theory of Sets

The theory of sets was developed by German mathematician Georg Cantor (1845-1918), who first encountered sets while working on "problems on trigonometric series". His work laid the foundation for modern mathematics, and sets continue to play a crucial role in various areas of mathematics.

### Representation of Sets

Sets can be represented in several ways:

* **Roster Method**: Elements are listed within curly brackets, separated by commas.
* **Rule Method**: Elements are described using a rule or a condition.
* **Interval Notation**: Used to describe intervals of real numbers.

For example, the set of odd integers can be represented as:
* Roster Method: {1, 3, 5,...}
* Rule Method: {x ∈ Z : x is an odd integer}
* Interval Notation: (-∞, ∞) ∩ Z

### Cardinality of Sets

The **cardinality** of a set is the number of elements it contains. A set is said to be **finite** if it has a finite number of elements, and **infinite** otherwise.

## Solved Examples

### Example 1: Finding the Cardinality of a Set

Let A = {1, 2, 3, 4}. Find n(A), the cardinality of set A.

**Solution:**

n(A) = number of elements in set A
= 4

Therefore, n(A) = 4.

### Example 2: Describing a Set Using the Rule Method

Describe the set A = {1, 3, 5, 7, 9} using the rule method.

**Solution:**

Set A consists of all odd integers greater than 0 and less than 10.

### Example 3: Identifying the Empty Set

Is the set B = {} an empty set?

**Solution:**

Since B contains no elements, it is indeed an empty set (∅).

### Example 4: Comparing Sets

Are the sets A = {1, 2, 3} and B = {3, 2, 1} equal?

**Solution:**

Yes, since both sets contain the same elements, regardless of their order.

### Example 5: Determining Subset Relationship

Is the set A = {1, 2, 3} a subset of the set B = {1, 2, 3, 4, 5}?

**Solution:**

Yes, since every element of A is also an element of B.

## Summary

* A set is a collection of unique objects, called elements.
* Sets can be represented using the roster method, rule method, or interval notation.
* The cardinality of a set is the number of elements it contains.
* A set is said to be finite if it has a finite number of elements; infinite otherwise.
* The empty set is a set containing no elements.
* Two sets are equal if and only if they contain exactly the same elements.
* A subset relationship exists if every element of one set is also an element of the other set.

## Student Corner

### Common Mistakes

* Confusing set equality with subset relationship.
* Failing to check if every element of one set is also an element of the other set when determining subset relationship.
* Misrepresenting sets using incorrect notation.

### Exam Tips

* Make sure to clearly define the set and its elements.
* Use the correct notation and symbols when representing sets.
* Check if every element of one set is also an element of the other set when determining subset relationship.
