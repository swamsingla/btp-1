## Introduction
Do you think you understand who belongs to a particular group? Can you tell if someone is part of your class, school, or even your favorite club? In mathematics, we have similar ideas about groups of objects called **sets**, and we want to talk about how certain sets relate to each other. Specifically, we're going to explore the concept of subsets, which is a fundamental idea in set theory.

By the end of this topic, you'll be able to define what a subset is, identify subsets within different sets, and understand the relationship between subsets and their parent sets.

## Explanation
> Definition 4: A set $ A $ is said to be a **subset** of a set $ B $ if every element of $ A $ is also an element of $ B $. This is denoted as $ A \subset B $.
> 
This definition can also be written as: $ A \subset B $ if $ a \in A \Rightarrow a \in B $.

To illustrate this, let's consider an example. Suppose we have two sets: $ X $ represents all students in a school, while $ Y $ represents all students in a particular class. Since every student in $ Y $ is also a student in $ X $, we can say that $ Y $ is a subset of $ X $, denoted as $ Y \subset X $.

Now, let's take a closer look at the definition:

$$

A \subset B \text{ if } a \in A \Rightarrow a \in B.

$$

This reads: "A is a subset of B if a being an element of A implies that a is also an element of B."

We can represent this visually as:

$$

A \subset B \Longleftrightarrow \forall a \in A, a \in B

$$

Notice that $A $ might not necessarily equal $ B $, but since every element of $ A $ is also an element of $ B $, we have $ A \subset B $.

On the other hand, if $ A $ is not a subset of $ B $, we write $ A \not\subset B $.

### Relationship between Subset and Superset
> If $ A \subset B $ and $ A \neq B $, then $ A $ is called a **proper subset** of $ B $, and $ B $ is called a **superset** of $ A $.

For instance, let $ A = \{1, 2, 3\} $ and $ B = \{1, 2, 3, 4\} $. Here, $ A $ is a proper subset of $ B $ because $ A \subset B $ and $ A \neq B $.

### Singleton Set
A set containing only one element is called a **singleton set**. For example, $\{a\} $ is a singleton set.

## Practice Problems
### Problem 1 🟢 Easy
Determine if the set $\{x : x \in \mathbb{Z}\} $ is a subset of the set $\{y : y \in \mathbb{R}\} $.
### Problem 2 🟡 Medium
Let $ A = \{2, 4, 6, 8\} $ and $ B = \{2, 3, 4, 5\} $. Is $ A \subset B $?
### Problem 3 🔴 Hard
Prove that if $ A \subset B $ and $ B \subset C $, then $ A \subset C $.

### Answers
#### Problem 1
**Answer:** Yes, since every integer is a real number.

**Solution:** To prove this, suppose $ x \in \{x : x \in \mathbb{Z}\} $. Then, by definition, $ x \in \mathbb{Z} $. But $\mathbb{Z} \subset \mathbb{R} $, so $ x \in \mathbb{R} $. Hence, $\{x : x \in \mathbb{Z}\} \subset \{y : y \in \mathbb{R}\} $.

#### Problem 2
**Answer:** No.

**Solution:** Check if every element of $ A $ is an element of $ B $. However, $ 6 \in A $ but $ 6 \notin B $. So, $ A \not\subset B $.

#### Problem 3
**Answer:** Yes.

**Solution:** Suppose $ a \in A $. Since $ A \subset B $, we have $ a \in B $. Now, since $ B \subset C $, we have $ a \in C $. Hence, $ A \subset C $.

## Summary
* A set $ A $ is a subset of a set $ B $ if every element of $ A $ is also an element of $ B $, denoted as $ A \subset B $.
* A proper subset is a subset that is not equal to the parent set.
* A singleton set is a set containing only one element.
* A set $\varnothing $ is a subset of every set.
* If $ A \subset B $ and $ A \neq B $, then $ A $ is a proper subset of $ B $, and $ B $ is a superset of $ A $.

## Student Corner
### Common Mistakes
* Confusing the symbol $\subset $ with the symbol $\subseteq $.
* Assuming that every element of the parent set is also an element of the subset.

### Exam Tips
* Always read the question carefully and clearly understand what is being asked.
* Make sure to use the correct notation and symbols.

### Memory Aid
* Think of a subset as a smaller container inside a larger container. If everything in the smaller container fits inside the larger container, then it is a subset!
