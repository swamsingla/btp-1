## Introduction
Intervals are a fundamental concept in mathematics, particularly in real analysis. In this section, we will explore how intervals can be represented as subsets of the set of real numbers, denoted by R. We will discuss different types of intervals, such as open, closed, and half-open intervals, and how they can be denoted using set-builder notation and interval notation.

## Explanation
### Definition of Intervals
An interval is a set of real numbers that includes all the points between two given endpoints. There are three types of intervals:

> **Open Interval**: An open interval is a set of real numbers that does not include its endpoints. It is denoted by $ (a, b) $ and can be written as $\{y : a < y < b\} $.
> 
> **Closed Interval**: A closed interval is a set of real numbers that includes its endpoints. It is denoted by $ [a, b] $ and can be written as $\{x : a \leq x \leq b\} $.
>
> **Half-Open Intervals**: Half-open intervals are sets of real numbers that include one endpoint and exclude the other. They are denoted by $ (a, b] $ and $ [a, b) $, and can be written as $\{x : a \leq x < b\} $ and $\{x : a < x \leq b\} $ respectively.

### Length of an Interval
The length of an interval is defined as the difference between its endpoints. For an interval $ (a, b) $, the length is given by $ (b-a) $. Similarly, the lengths of intervals $ [a, b] $, $ [a, b) $, and $ (a, b] $ are also $ (b-a) $.

### Important Properties
> * An interval contains infinitely many points.
> * The set of real numbers can be represented as the union of all possible intervals.
> * Any interval is a subset of the set of real numbers.

## Solved Examples

**Example 1:**
Find the set-builder notation for the interval $ (-5, 7] $.

**Solution:**
To find the set-builder notation for the interval $ (-5, 7] $, we need to determine the conditions for the elements in the set. Since the interval includes $-5 $ and excludes $ 7 $, the set-builder notation is $\{x : -5 \leq x < 7\} $.

**Example 2:**
Determine whether the set $ A = (-3, 5) $ is a subset of the set $ B = [-7, 9] $.

**Solution:**
Since the set $ A $ does not include the point $-3 $ and the set $ B $ includes the point $-3 $, we can conclude that $ A \subset B $.

**Example 3:**
Find the length of the interval $ (a, b) $.

**Solution:**
The length of the interval $ (a, b) $ is given by $ (b-a) $.

### Answers:

**Step 1:** Determine whether the set $ C $ includes the point $-∞$.
Since the set $ C $ does not include the point $-∞$, it cannot be a subset of the set $ D $.
**Step 2:** Determine whether the set $ C $ includes the point $ 5 $.
Since the set $ C $ includes the point $ 5 $, we can conclude that $ C \not\subset D $.

### Problem 2:
**Step 1:** Determine the conditions for the elements in the set $ (-7, -2] $.
The set $ (-7, -2] $ includes the point $-7 $ and excludes the point $-2 $.
**Step 2:** Write the set-builder notation for the interval $ (-7, -2] $.
The set-builder notation is $\{x : -7 \leq x < -2\} $.

### Problem 3:
**Step 1:** Determine the length of the interval $ [-3, 7) $.
The length of the interval $ [-3, 7) $ is given by $ (7-(-3)) $.

$ (7-(-3)) = 10 $

### Problem 4:

The set $ (4, ∞) $ excludes the point $ 4 $.
**Step 2:** Write the set-builder notation for the interval $ (4, ∞) $.
The set-builder notation is $\{x : 4 < x \} $.

## Summary
• An open interval is a set of real numbers that does not include its endpoints, denoted by $ (a, b) $.
• A closed interval is a set of real numbers that includes its endpoints, denoted by $ [a, b] $.
• Half-open intervals are sets of real numbers that include one endpoint and exclude the other.
• The length of an interval is defined as the difference between its endpoints.
• An interval contains infinitely many points.
• The set of real numbers can be represented as the union of all possible intervals.
• Any interval is a subset of the set of real numbers.

## Key Formulas
| Formula | Description |
| --- | --- |

| $ (a, b] $ | Half-open interval from $ a $ to $ b $, including $ a $ and excluding $ b $ |

## Student Corner

* Failing to distinguish between open, closed, and half-open intervals.
* Misunderstanding the definition of the length of an interval.
