## Introduction
Imagine you have a collection of books on your bookshelf. Now imagine another collection of books from your friend's library. How would you combine these two collections into a new collection? This is similar to what we're going to explore in this topic - combining sets using different operations. You'll learn about the union of sets, intersection of sets, and difference of sets, and understand how these operations can be used to create new sets from existing ones.

## Explanation

### Definition of Union of Sets
> **Union of Sets**: The union of two sets $ A $ and $ B $, denoted by $ A \cup B $, is the set containing all elements that belong to either $ A $ or $ B $ or both.

Given two sets $ A $ and $ B $, the union of $ A $ and $ B $ is the set

$$

A \cup B = \{ x : x \in A \text{ or } x \in B \}.

$$

### Example
Suppose we have two sets $A = \{1, 2, 3, 4\} $ and $ B = \{3, 4, 5, 6\} $. Then the union of $ A $ and $ B $ is

$$

A \cup B = \{1, 2, 3, 4, 5, 6\}.

$$

### Properties of Union of Sets
> **Commutative Property of Union**: $A \cup B = B \cup A $
> **Associative Property of Union**: $ (A \cup B) \cup C = A \cup (B \cup C) $

### Definition of Intersection of Sets
> **Intersection of Sets**: The intersection of two sets $ A $ and $ B $, denoted by $ A \cap B $, is the set containing all elements that belong to both $ A $ and $ B $.

Given two sets $ A $ and $ B $, the intersection of $ A $ and $ B $ is the set

$$

A \cap B = \{ x : x \in A \text{ and } x \in B \}.

$$

### Example
Using the same sets $A = \{1, 2, 3, 4\} $ and $ B = \{3, 4, 5, 6\} $, the intersection of $ A $ and $ B $ is

$$

A \cap B = \{3, 4\}.

$$

### Properties of Intersection of Sets
> **Commutative Property of Intersection**: $A \cap B = B \cap A $
> **Associative Property of Intersection**: $ (A \cap B) \cap C = A \cap (B \cap C) $

### Definition of Difference of Sets
> **Difference of Sets**: The difference of two sets $ A $ and $ B $, denoted by $ A - B $ or $ A \setminus B $, is the set containing all elements that belong to $ A $ but not to $ B $.

Given two sets $ A $ and $ B $, the difference of $ A $ and $ B $ is the set

$$

A - B = \{ x : x \in A \text{ and } x \notin B \}.

$$

### Example
Again, using the same sets $A = \{1, 2, 3, 4\} $ and $ B = \{3, 4, 5, 6\} $, the difference of $ A $ and $ B $ is

$$

A - B = \{1, 2\}.

$$

## Solved Examples

**Example 1**
Find $A \cup B $ if $ A = \{1, 2, 3\} $ and $ B = \{2, 3, 4, 5\} $.
**Solution:**
We need to find the set containing all elements that belong to either $ A $ or $ B $ or both. Therefore,

$$

A \cup B = \{1, 2, 3, 4, 5\}.

$$

**Example 2**
Find $A \cap B $ if $ A = \{1, 2, 3, 4\} $ and $ B = \{3, 4, 5, 6\} $.
**Solution:**
We need to find the set containing all elements that belong to both $ A $ and $ B $. Therefore,

$$

A \cap B = \{3, 4\}.

$$

**Example 3**
Find $A - B $ if $ A = \{1, 2, 3, 4\} $ and $ B = \{3, 4, 5, 6\} $.
**Solution:**
We need to find the set containing all elements that belong to $ A $ but not to $ B $. Therefore,

$$

A - B = \{1, 2\}.

$$

**Example 4**
Let $A = \{x \in \mathbb{R} : 0 < x < 3\} $ and $ B = \{x \in \mathbb{R} : 2 < x < 4\} $. Find $ A \cup B $.
**Solution:**
We need to find the set containing all elements that belong to either $ A $ or $ B $ or both. Since $ A $ contains all elements between $ 0 $ and $ 3 $, and $ B $ contains all elements between $ 2 $ and $ 4 $, the union is simply the set of all elements greater than $ 0 $ and less than $ 4 $. Therefore,

$$

A \cup B = \{x \in \mathbb{R} : 0 < x < 4\}.

$$

**Example 5**
Let $A = \{1, 2, 3, 4\} $ and $ B = \{4, 5, 6, 7\} $. Find $ (A \cup B) \cap C $ if $ C = \{3, 4, 5, 6\} $.
**Solution:**
First, let's find the union of $ A $ and $ B $:

$$

A \cup B = \{1, 2, 3, 4, 5, 6, 7\}.

$$

Then, taking the intersection of this result with $C $, we get

$$

(A \cup B) \cap C = \{3, 4, 5, 6\}.

$$

## Practice Problems

Let $A = \{1, 2, 3, 4\} $ and $ B = \{3, 4, 5, 6\} $. Find $ A \cap B $.

**Answer:**
To solve this problem, we need to find the set containing all elements that belong to both $ A $ and $ B $. Therefore, $ A \cap B = \boxed{\{3, 4\}} $.

🟢 **Problem 2**
Let $ A = \{x \in \mathbb{R} : 0 < x < 3\} $ and $ B = \{x \in \mathbb{R} : 2 < x < 4\} $. Find $ A - B $.

**Answer:**
To solve this problem, we need to find the set containing all elements that belong to $ A $ but not to $ B $. Since $ A $ contains all elements between $ 0 $ and $ 3 $, and $ B $ contains all elements between $ 2 $ and $ 4 $, the difference is simply the set of all elements between $ 0 $ and $ 2 $. Therefore, $ A - B = \boxed{\{x \in \mathbb{R} : 0 < x < 2\}} $.

🔴 **Problem 3**
Let $ A = \{1, 2, 3, 4\} $ and $ B = \{4, 5, 6, 7\} $. Find $ (A \cup B) \cap C $ if $ C = \{3, 4, 5, 6\} $.

**Answer:**
To solve this problem, we need to find the union of $ A $ and $ B $, then take the intersection of this result with $ C $. First, let's find the union of $ A $ and $ B $:

$$

A \cup B = \{1, 2, 3, 4, 5, 6, 7\}.

$$

Then, taking the intersection of this result with $C $, we get

$$

(A \cup B) \cap C = \boxed{\{3, 4, 5, 6\}}.

$$

🟢 **Problem 4**
Let $A = \{x \in \mathbb{R} : 0 < x < 3\} $ and $ B = \{x \in \mathbb{R} : 2 < x < 4\} $. Find $ A \cup B $.

**Answer:**
To solve this problem, we need to find the set containing all elements that belong to either $ A $ or $ B $ or both. Since $ A $ contains all elements between $ 0 $ and $ 3 $, and $ B $ contains all elements between $ 2 $ and $ 4 $, the union is simply the set of all elements greater than $ 0 $ and less than $ 4 $. Therefore, $ A \cup B = \boxed{\{x \in \mathbb{R} : 0 < x < 4\}} $.

🟢 **Problem 5**
Let $ A = \{1, 2, 3, 4\} $ and $ B = \{4, 5, 6, 7\} $. Find $ A \cap (B \cup C) $ if $ C = \{3, 4, 5, 6\} $.

**Answer:**
To solve this problem, we need to find the union of $ B $ and $ C $, then take the intersection of this result with $ A $. First, let's find the union of $ B $ and $ C $:

$$

B \cup C = \{3, 4, 5, 6, 7\}.

$$

Then, taking the intersection of this result with $A $, we get $ A \cap (B \cup C) = \boxed{\{4\}} $.

## Summary
• The union of two sets $ A $ and $ B $ is the set containing all elements that belong to either $ A $ or $ B $ or both.
• The intersection of two sets $ A $ and $ B $ is the set containing all elements that belong to both $ A $ and $ B $.
• The difference of two sets $ A $ and $ B $ is the set containing all elements that belong to $ A $ but not to $ B $.
• The commutative property of union states that $ A \cup B = B \cup A $.
• The associative property of union states that $ (A \cup B) \cup C = A \cup (B \cup C) $.
• The commutative property of intersection states that $ A \cap B = B \cap A $.
• The associative property of intersection states that $ (A \cap B) \cap C = A \cap (B \cap C) $.

## Student Corner

### Common Mistakes
* Not considering that the union of two empty sets is still the empty set.
* Assuming that the intersection of two sets always results in an empty set.

### Exam Tips
* When finding the union of two sets, make sure to include all elements that belong to either set or both.
* When finding the intersection of two sets, make sure to only include elements that belong to both sets.

### Memory Aid
* To remember the commutative property of union, think of switching the order of the sets like swapping two bags of toys – the contents remain the same.
