These prerequisites ensure that students can comprehend the abstract nature of finite and infinite sets.

## Introduction
Do you think there's a limit to how many items can exist in a collection? Let's explore the concept of finite and infinite sets to find out! In this topic, we'll learn about the difference between sets that have a countable number of elements and those that don't.

By the end of this topic, you'll be able to identify whether a set is finite or infinite and understand the implications of this classification. This knowledge will help you build upon the foundation laid in previous chapters and prepare you for more advanced mathematical concepts.

## Explanation
### Definition of Finite and Infinite Sets

> A set which is empty or consists of a definite number of elements is called finite; otherwise, the set is called infinite.

Let's consider an example to illustrate this concept:

Suppose we have three sets:

$$

A = \{1, 2, 3, 4, 5\}, \quad B = \{a, b, c, d, e, g\}, \quad C = \{\text{men living presently in different parts of the world}\}.

$$

We can see that $A $ and $ B $ contain a definite number of elements, namely 5 and 6 respectively. However, the number of elements in $ C $ is unknown and could be quite large.

In general, the number of elements in a set is denoted by $ n(S) $, where $ S $ is the set in question. If $ n(S) $ is a natural number, then $ S $ is said to be a non-empty finite set.

On the other hand, a set with an infinite number of elements is called an infinite set. An example of an infinite set is the set of natural numbers, $\mathbb{N} $.

### Properties of Finite and Infinite Sets

> A set which is empty or consists of a definite number of elements is called finite; otherwise, the set is called infinite.

Some important properties of finite and infinite sets are listed below:

* If a set has a finite number of elements, it can be represented in roster form by writing down all its elements within braces { }.
* Infinite sets cannot be represented in roster form because the number of elements is not finite.
* Not all infinite sets can be described in the roster form. For example, the set of real numbers cannot be described in this form because the elements of this set do not follow any particular pattern.

### Examples of Finite and Infinite Sets

> Consider the following sets:
>
> (i) Let $ W $ be the set of the days of the week. Then $ W $ is finite.
>
> (ii) Let $ S $ be the set of solutions of the equation $ x^2 - 16 = 0 $. Then $ S $ is finite.
>
> (iii) Let $ G $ be the set of points on a line. Then $ G $ is infinite.

## Solved Examples

### Example 1:
Determine whether the following set is finite or infinite: $\{x \in \mathbb{N}: x(x-1)=0\} $.

**Solution:**
Since $ x(x-1) = 0 $ implies $ x=0 $ or $ x=1 $, the set is equal to $\{0, 1\} $. Therefore, it is finite.

### Example 2:
Find the number of elements in the set $\{x \in \mathbb{Z}: x^2 = 25\} $.

**Solution:**
The equation $ x^2 = 25 $ has two solutions: $ x=-5 $ and $ x=5 $. Therefore, the set is $\{-5, 5\} $ and has 2 elements.

### Example 3:
Determine whether the set $\{x \in \mathbb{N}: 2x+1=0\} $ is finite or infinite.

**Solution:**
Since the equation $ 2x+1=0 $ has no solutions in the set of natural numbers, the set is empty, i.e., $\varnothing $. Therefore, it is finite.

### Example 4:
Find the number of elements in the set $\{x \in \mathbb{N}: x\text{ is even}\} $.

**Solution:**
This set includes all the even natural numbers, which are $ 2, 4, 6, \ldots $. Since there are infinitely many even natural numbers, the set is infinite.

### Example 5:
Determine whether the set $\{x \in \mathbb{N}: x<0\} $ is finite or infinite.

**Solution:**
Since there are infinitely many negative natural numbers, the set is infinite.

## Practice Problems

### Problem 1: 🟢 Easy
Determine whether the set $\{x \in \mathbb{Z}: x^2 = 36\} $ is finite or infinite.

### Problem 2: 🟡 Medium
Find the number of elements in the set $\{x \in \mathbb{N}: x(x+1)=30\} $.

### Problem 3: 🔴 Hard
Determine whether the set $\{x \in \mathbb{Q}: x^2 < 2\} $ is finite or infinite.

### Problem 4: 🟢 Easy
Find the number of elements in the set $\{x \in \mathbb{Z}: x^2 = 49\} $.

### Problem 5: 🟡 Medium
Determine whether the set $\{x \in \mathbb{N}: 3x+1=0\} $ is finite or infinite.

### Answers:

#### Problem 1:
The set $\{x \in \mathbb{Z}: x^2 = 36\} $ has two elements: $ x = -6 $ and $ x = 6 $. Therefore, it is finite.

#### Problem 2:
The equation $ x(x+1)=30 $ has two solutions: $ x=5 $ and $ x=-6 $. Therefore, the set has 2 elements.

#### Problem 3:
Since $ x^2 < 2 $ implies $-\sqrt{2} < x < \sqrt{2} $, the set is infinite.

#### Problem 4:
The set $\{x \in \mathbb{Z}: x^2 = 49\} $ has two elements: $ x = -7 $ and $ x = 7 $. Therefore, it is finite.

#### Problem 5:
The equation $ 3x+1=0 $ has no solutions in the set of natural numbers. Therefore, the set is empty, i.e., $\varnothing $, and hence finite.

## Summary
• A set which is empty or consists of a definite number of elements is called finite.
• A set which is infinite has an uncountable number of elements.
• Infinite sets cannot be represented in roster form.
• Some infinite sets cannot be described in roster form.
• Finite sets can be represented in roster form.
• Natural numbers are an example of an infinite set.

## Student Corner

### Common Mistakes:

* Assuming that all infinite sets can be represented in roster form.
* Confusing the concepts of finite and infinite sets.

### Exam Tips:

* Always check if a set is finite or infinite before attempting to represent it in roster form.
* Use the fact that a finite set has a definite number of elements to determine its cardinality.

### Memory Aid:
Remember the phrase "Finite is Finitely Many Elements Inside", which reminds you that a finite set has a countable number of elements.
