## Introduction  
Have you ever wondered if a set can exist without containing any elements? This seems impossible, yet in mathematics, such a set is known as the **empty set**. In this lesson, we’ll explore the definition, properties, and examples of the empty set, a fundamental concept in set theory. By the end, you’ll be able to identify empty sets in various contexts and understand their significance in problem-solving.  

---

## Explanation  

### Definition of the Empty Set  
**The empty set** (also called the null set or void set) is a set that contains **no elements**. It is denoted by the symbol **φ** (phi) or by the curly braces **{}**.  

> **Property**: The empty set is a subset of every set. Symbolically, for any set $ A $, $ \varnothing \subseteq A $.  

### Key Concepts  
- **Empty Set**: A set with zero elements.  
- **Null Set**: Synonymous with the empty set.  
- **Void Set**: Another term for the empty set.  

### Examples from the Source Text  
1. **Set B**:  
   $ B = \{ x : x \text{ is a student presently studying in both Classes X and XI} \} $  
   Since no student can belong to two classes simultaneously, $ B = \varnothing $.  

2. **Set A**:  
   $ A = \{ x : 1 < x < 2, x \in \mathbb{N} \} $  
   There are no natural numbers between 1 and 2, so $ A = \varnothing $.  

3. **Equation-Based Examples**:  
   - $ C = \{ x : x^2 - 2 = 0 \text{ and } x \in \mathbb{Q} \} $ → No rational solution exists, so $ C = \varnothing $.  
   - $ D = \{ x : x^2 = 4 \text{ and } x \text{ is odd} \} $ → No odd integers satisfy $ x^2 = 4 $, so $ D = \varnothing $.  

These examples illustrate that the empty set arises when a condition cannot be satisfied by any element.

## Solved Examples  

### Example 1: Identifying an Empty Set  
Let $ E = \{ x : x \text{ is a positive integer less than 0} \} $. Is $ E $ an empty set?  

**Solution**:  
- Positive integers are $ 1, 2, 3, ... $.  
- No positive integer satisfies $ x < 0 $.  
- Therefore, $ E = \varnothing $.  

### Example 2: Solving an Equation with Constraints  
Let $ F = \{ x : x^2 = -9 \text{ and } x \in \mathbb{R} \} $. Determine whether $ F $ is empty.  

**Solution**:  
- The equation $ x^2 = -9 $ has no real solutions (since squaring a real number yields non-negative results).  
- Hence, $ F = \varnothing $.  

### Example 3: Logical Conditions  
Let $ G = \{ x : x \text{ is a multiple of 5 and 7, but not divisible by 35} \} $. Is $ G $ empty?  

**Solution**:  
- Multiples of both 5 and 7 are multiples of $ \text{lcm}(5,7) = 35 $.  
- Therefore, $ G $ contains no elements.  
- Conclusion: $ G = \varnothing $.

## Practice Problems  

1. 🟢 **Easy**: Let $ P = \{ x : x \in \mathbb{Z} \text{ and } x > 5 \text{ and } x < 3 \} $. Is $ P $ empty?  
   **Answer**: Yes, $ P = \varnothing $.  

2. 🟡 **Medium**: Let $ Q = \{ x : x^2 + 1 = 0 \text{ and } x \in \mathbb{R} \} $. Prove $ Q $ is empty.  
   **Answer**: $ x^2 + 1 = 0 $ implies $ x^2 = -1 $, which has no real solutions.  

3. 🔴 **Hard**: Let $ R = \{ x : x \text{ is a prime number greater than 2 and even} \} $. Show $ R = \varnothing $.  
   **Answer**: The only even prime number is 2; thus, $ R $ contains no elements.  

---

## Summary  
- The **empty set** (∅ or {}) contains **no elements**.  
- It is a **subset** of every set.  
- Examples include sets defined by contradictory conditions or unsolvable equations.  
- Always check if a condition can be satisfied by any element to determine emptiness.  

---

## Student Corner  

### Common Mistakes  
1. **Confusing ∅ with {∅}**: The empty set $ \varnothing $ has **no elements**, whereas $ \{\varnothing\} $ contains one element (the empty set itself).  
2. **Overlooking Edge Cases**: For example, assuming $ \mathbb{N} $ starts at 0 may lead to incorrect conclusions about sets like $ \{ x : 0 < x < 1, x \in \mathbb{N} \} $.  

### Memory Aid  
- Remember **φ** (the Greek letter phi) as the symbol for the empty set—it’s a hollow circle, representing “nothing.”  

### Exam Tip  
- When encountering conditions like $ x^2 = -1 $ or $ x \in \mathbb{N} $ and $ x < 1 $, immediately suspect an empty set!
