## Introduction  
Sets form the foundation of modern mathematics, serving as building blocks for concepts like relations, functions, and probability. This chapter introduces the idea of a *set*, its representations, and its significance in various mathematical fields. By the end of this section, you’ll understand how sets are defined, represented, and why they were pioneered by mathematician Georg Cantor.  

---

## Explanation  
A **set** is a well-defined collection of distinct objects, called **elements**, which can be numbers, letters, or any other entities. Sets are fundamental because they allow us to organize and analyze mathematical structures systematically.  

### Key Concepts  
- **Set**: A collection of unique elements (e.g., {1, 2, 3}).  
- **Element**: An object belonging to a set (e.g., 1 is an element of {1, 2, 3}).  
- **Representation**: Sets can be expressed in two primary ways:  
  - **Roster Form**: Listing all elements within curly braces (e.g., {a, b, c}).  
  - **Set-Builder Notation**: Describing elements using a rule or property (e.g., {x | x ∈ ℕ ∧ x < 5}).  

> **Note**: The order of elements in a set does not matter, and duplicates are excluded (e.g., {1, 1, 2} is equivalent to {1, 2}).  

Georg Cantor’s work on trigonometric series led to the formalization of set theory, revolutionizing mathematics. His ideas underpin modern analysis, topology, and logic.

## Solved Examples  
**Example 1:**  
Represent the set of vowels in the English alphabet using both roster and set-builder notation.  

**Step 1:** Identify the vowels: {a, e, i, o, u}.  
**Step 2:** Roster form: {a, e, i, o, u}.  
**Step 3:** Set-builder notation: {x | x is a vowel in the English alphabet}.  

**Example 2:**  
List the elements of the set {x | x is an integer such that 0 < x < 6}.  

**Step 1:** Determine integers satisfying 0 < x < 6: 1, 2, 3, 4, 5.  
**Step 2:** Roster form: {1, 2, 3, 4, 5}.  

**Example 3:**  
Express the set of prime numbers less than 10 in set-builder form.  

**Step 1:** Prime numbers less than 10 are 2, 3, 5, 7.  
**Step 2:** Set-builder notation: {x | x is a prime number and x < 10}.

## Practice Problems  
1. **🟢 Easy**: Write the set {2, 4, 6, 8} in set-builder form.  
   **Answer**: {x | x is an even natural number less than 10}  

2. **🟡 Medium**: List the elements of {x | x ∈ ℤ ∧ −3 ≤ x ≤ 3}.  
   **Answer**: {−3, −2, −1, 0, 1, 2, 3}  

3. **🔴 Hard**: Describe the set {1, 3, 5, 7, 9} using a property related to odd numbers.  
   **Answer**: {x | x is an odd natural number less than 10}

## Summary  
- A **set** is a collection of distinct elements.  
- Elements are listed in **roster form** or described via **set-builder notation**.  
- Sets are essential for defining relations, functions, and advanced mathematical concepts.  
- Georg Cantor’s work established set theory as a cornerstone of modern mathematics.

## Student Corner  
### Common Mistakes  
- ❌ Confusing **roster form** with **set-builder notation** (e.g., mixing {1, 2, 3} with {x | x ∈ ℕ ∧ x ≤ 3}).  
- ❌ Including duplicate elements in a set (e.g., {1, 1, 2} is invalid; it becomes {1, 2}).  

### Memory Aid  
**"Roster Rule":** Always enclose elements in curly braces and ensure uniqueness.  
**"Set-Builder Trick":** Use "x |" to separate elements from their defining condition.  

### Exam Tip  
When representing sets, prioritize clarity over complexity. For large or infinite sets, set-builder notation is often more efficient.
