## Introduction  
Understanding when two sets are *equal* is fundamental in set theory. This lesson explores the concept of equal sets, how to identify them, and practical examples to solidify your grasp. By the end, you’ll confidently determine whether two sets share identical elements and apply this knowledge to solve problems.  

---

## Explanation  
### **Definition of Equal Sets**  
Two sets **A** and **B** are said to be **equal** (**A = B**) if they contain **exactly the same elements**, regardless of the order or repetition of elements.  

> **Property**: For sets **A** and **B**, $ A = B $ if and only if every element of **A** is in **B** and vice versa.  

### Key Concepts  
- **Elements**: Individual objects in a set (e.g., 1, 2, 3 in {1, 2, 3}).  
- **Equality**: Two sets are equal if their elements match completely.  
- **Repetition Irrelevance**: Repeating elements in a set does not alter its identity (e.g., {1, 2, 3} = {1, 1, 2, 2, 3}).  

### Example Analysis  
#### Example 1:  
Let **A** = {1, 2, 3, 4} and **B** = {3, 1, 4, 2}.  
- Every element of **A** is in **B**, and vice versa.  
- Hence, **A = B**.  

#### Example 2:  
Let **A** be the set of primes less than 6 ({2, 3, 5}) and **P** be the set of prime factors of 30 ({2, 3, 5}).  
- Both sets have the same elements.  
- Thus, **A = P**.

## Solved Examples  
### **Example 1**: Determine equal sets from the following:  
- **A** = {0},  
- **B** = {x : x > 15 and x < 5},  
- **C** = {x : x – 5 = 0},  
- **D** = {x : x² = 25},  
- **E** = {x : x is an integral positive root of x² – 2x – 15 = 0}.  

**Step-by-Step Solution**:  
1. **A** = {0}; **B** = ∅ (empty set) → **A ≠ B**.  
2. **C** = {5} (since x – 5 = 0 ⇒ x = 5).  
3. **D** = {-5, 5} (since x² = 25 ⇒ x = ±5).  
4. **E** = {5} (roots of x² – 2x – 15 = 0 are 5 and -3; only 5 is positive).  
5. Compare sets: **C = E** = {5}; others differ.  

**Conclusion**: Only **C** and **E** are equal.  

### **Example 2**: Check equality of sets **X** and **B**:  
- **X** = Set of letters in “ALLOY” = {A, L, O, Y} (repeats ignored),  
- **B** = Set of letters in “LOYAL” = {L, O, Y, A} (repeats ignored).  

**Conclusion**: **X = B** because both contain {A, L, O, Y}.

## Practice Problems  
1. **🟢 Easy**: Identify equal sets from the following:  
   - **P** = {1, 2, 3}, **Q** = {3, 2, 1}, **R** = {1, 1, 2, 3}.  
   - **Answer**: **P = Q = R**.  

2. **🟡 Medium**: Let **M** = {x : x is a vowel in “MATHEMATICS”}, **N** = {A, E, I, O, U}. Are **M** and **N** equal?  
   - **Answer**: No, **M** = {A, E, I} ≠ **N**.  

3. **🔴 Hard**: Solve for **A** = {x ∈ ℕ : x² ≤ 4} and **B** = {x ∈ ℝ : x² – 3x + 2 = 0}. Are **A** and **B** equal?  
   - **Answer**: No, **A** = {-2, -1, 0, 1, 2}, **B** = {1, 2}.  

---

## Summary  
- **Equal Sets**: Two sets are equal if they have exactly the same elements.  
- **Irrelevant Order/Repetition**: {1, 2, 3} = {3, 2, 1} = {1, 1, 2, 2, 3}.  
- **Notation**: $ A = B $ means **A** and **B** are equal; $ A ≠ B $ otherwise.  
- **Null Set**: A set with no elements is denoted by ∅.  
- **Finite vs Infinite**: A set with limited elements is finite; otherwise, it’s infinite.  

---

## Student Corner  
### **Common Mistakes**  
- ❌ Confusing **equality** with **subset relationship**: Not all subsets are equal.  
- ❌ Overlooking repeated elements: {1, 2, 2} ≠ {1, 2}? No—sets ignore repetitions.  

### **Exam Tip**  
Use the **"Element Check Method"**: For any two sets, verify if every element of one set is present in the other.  

### **Memory Aid**  
**"Same Elements, Same Set"**: Remember, equal sets are like twins—they share *every* element without exception!
