## Introduction  
Set theory extends the idea of arithmetic operations to collections of objects. In this section, we explore how to combine sets using the **union** operation, similar to how addition combines numbers. By the end of this lesson, you’ll understand how to find the union of two sets and apply its properties to solve problems.  

---

## Explanation  
### **Union of Sets**  
Let **A** and **B** be any two sets. The **union** of **A** and **B**, denoted by $ A \cup B $, is the set of all elements that belong to **A**, to **B**, or to both.  
>

$$ A \cup B = \{ x : x \in A \text{ or } x \in B \}

$$  
This operation ensures that duplicate elements are included only once in the resulting set.  

#### Key Properties of Union  
1. **Commutative Property**: $ A \cup B = B \cup A $  
2. **Associative Property**: $ (A \cup B) \cup C = A \cup (B \cup C) $  
3. **Identity Element**: $ A \cup \emptyset = A $, where $ \emptyset $ is the empty set.  
4. **Subset Property**: If $ A \subseteq B $, then $ A \cup B = B $.  

Note: The union operation differs from **intersection** (which includes only common elements) and **difference** (which removes elements from one set).  

---

## Solved Examples  
**Example 1:**  
Let $ A = \{1, 2, 3\} $ and $ B = \{3, 4, 5\} $. Find $ A \cup B $.  
**Solution:**  
Step 1: List all elements in **A** and **B**:  
$ A = \{1, 2, 3\} $, $ B = \{3, 4, 5\} $.  
Step 2: Combine elements, removing duplicates:  
$ A \cup B = \{1, 2, 3, 4, 5\} $.  

**Example 2:**  
If $ A = \{a, b\} $ and $ B = \{b, c, d\} $, compute $ A \cup B $.  
**Solution:**  
Step 1: Identify unique elements from both sets:  
$ A \cup B = \{a, b, c, d\} $.  

**Example 3:**  
Given $ A = \{1, 2, 3\} $ and $ B = \{2, 3, 4\} $, verify the **commutative property**.  
**Solution:**  
Compute $ A \cup B $ and $ B \cup A $:  
Both equal $ \{1, 2, 3, 4\} $, confirming $ A \cup B = B \cup A $.

## Practice Problems  
1. **🟢 Easy**: Let $ A = \{2, 4, 6\} $ and $ B = \{4, 6, 8\} $. Find $ A \cup B $.  
   **Answer**: $ \{2, 4, 6, 8\} $  

2. **🟡 Medium**: If $ A = \{x : x \text{ is a prime number less than 10}\} $ and $ B = \{x : x \text{ is an even number less than 10}\} $, determine $ A \cup B $.  
   **Answer**: $ \{2, 3, 5, 7\} \cup \{2, 4, 6, 8\} = \{2, 3, 4, 5, 6, 7, 8\} $  

3. **🔴 Hard**: Given three sets $ A = \{1, 2\} $, $ B = \{2, 3\} $, and $ C = \{3, 4\} $, prove that $ (A \cup B) \cup C = A \cup (B \cup C) $.  
   **Answer**: Both sides simplify to $ \{1, 2, 3, 4\} $.  

---

## Summary  
- The **union** of two sets $ A $ and $ B $ is written as $ A \cup B $.  
- It includes all elements from both sets, with no duplicates.  
- Union satisfies **commutative** and **associative** properties.  
- The identity element for union is the **empty set** $ \emptyset $.  
- Always check for overlapping elements to avoid repetition.  

---

## Student Corner  
### **Common Mistakes**  
1. **Duplicates**: Forgetting to remove repeated elements in the union result.  
2. **Confusing with Intersection**: Mixing up union ($ \cup $) with intersection ($ \cap $).  

### **Memory Aid**  
Recall the symbol $ \cup $ resembles a "V", just like combining sets merges their contents.  

### **Exam Tip**  
When dealing with multiple sets, draw Venn diagrams to visualize unions and ensure clarity.
