## Introduction  
Sets are fundamental tools in mathematics, allowing us to organize and analyze collections of objects systematically. This lesson explores how to define sets, identify their elements, and represent them using two common methods: **roster form** and **set-builder form**. By the end of this section, you’ll understand how to determine whether a collection qualifies as a set and how to express it clearly.  

---  

## Explanation  

### **What is a Set?**  
A **set** is a *well-defined* collection of distinct objects. These objects, called **elements**, can be numbers, letters, or any other entities. For a collection to qualify as a set, there must be a clear rule to determine if a given object belongs to it.  

> **Definition**: A set is a well-defined collection of distinct objects.  

### **Notation and Symbols**  
- Sets are typically denoted by **capital letters** (e.g., $ A, B, C $).  
- Elements are represented by **small letters** (e.g., $ a, b, c $).  
- The symbol $ \in $ means "is an element of," while $ \notin $ means "is not an element of."  
  - Example: If $ a \in A $, then $ a $ is part of set $ A $.  
  - Example: If $ b \notin A $, then $ b $ is not part of set $ A $.  

### **Types of Sets**  
Standard sets in mathematics include:  
- $ \mathbb{N} $: Natural numbers $ \{1, 2, 3, \dots\} $  
- $ \mathbb{Z} $: Integers $ \{\dots, -2, -1, 0, 1, 2, \dots\} $  
- $ \mathbb{Q} $: Rational numbers $ \left\{ \frac{p}{q} \mid p, q \in \mathbb{Z}, q \neq 0 \right\} $  
- $ \mathbb{R} $: Real numbers (all rational and irrational numbers)  
- Positive subsets: $ \mathbb{Z}^+, \mathbb{Q}^+, \mathbb{R}^+ $  

### **Representation Methods**  
#### **1. Roster Form**  
List all elements within curly braces $ \{ \} $, separated by commas.  
- Example: The set of vowels in English is $ V = \{a, e, i, o, u\} $.  

#### **2. Set-Builder Form**  
Describe the set using a rule or property that defines its elements.  
- Example: The set of even natural numbers less than 10 is $ E = \{x \in \mathbb{N} \mid x < 10 \text{ and } x \text{ is even}\} $.  

> **Note**: A collection is a set only if it is *well-defined*. For instance, "five most renowned mathematicians" is not a set because criteria for "renown" are subjective.

## Solved Examples  

### **Example 1**  
Determine if $ 3 \in P $, where $ P $ is the set of prime factors of 30.  

**Solution**:  
- Prime factors of 30 are $ 2, 3, 5 $.  
- So, $ P = \{2, 3, 5\} $.  
- Since $ 3 \in P $, the statement is true.  

### **Example 2**  
Represent the set of odd natural numbers less than 10 using both methods.  

**Solution**:  
- **Roster form**: $ O = \{1, 3, 5, 7, 9\} $.  
- **Set-builder form**: $ O = \{x \in \mathbb{N} \mid x < 10 \text{ and } x \text{ is odd}\} $.  

### **Example 3**  
Express the solution set of $ x^2 - 5x + 6 = 0 $ in roster form.  

**Solution**:  
- Solve the quadratic equation:

$$
  x^2 - 5x + 6 = 0 \implies (x - 2)(x - 3) = 0 \implies x = 2 \text{ or } x = 3

$$  
- Solution set: $ S = \{2, 3\} $.

## Practice Problems  

1. 🟢 Determine if $ 5 \in \mathbb{Z}^+ $.  
   **Answer**: Yes.  

2. 🟡 Express the set of multiples of 5 less than 20 in roster form.  
   **Answer**: $ \{5, 10, 15\} $.  

3. 🔴 Identify which of the following is a well-defined set:  
   - (i) "Popular books of the 21st century"  
   - (ii) "All cities in India with population over 1 million"  
   **Answer**: (ii) only.  

---  

## Summary  
- A **set** is a well-defined collection of distinct objects.  
- **Elements** are individual members of a set, denoted by $ \in $ or $ \notin $.  
- Two representation methods: **roster form** (listing elements) and **set-builder form** (describing a rule).  
- Standard sets include $ \mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R} $, and their positive counterparts.  

---  

## Student Corner  
### **Common Mistakes**  
- Confusing **roster form** (explicit listing) with **set-builder form** (implicit rule).  
- Forgetting that sets contain **distinct** elements (e.g., $ \{1, 1, 2\} $ is invalid).  

### **Exam Tip**  
When unsure about a collection’s validity as a set, ask: *"Is there a clear rule to decide membership?"* Always verify this before proceeding!
