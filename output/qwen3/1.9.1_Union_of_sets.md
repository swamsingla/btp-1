## Introduction  
Understanding how to combine sets is fundamental in mathematics. This section introduces the **union of sets**, a crucial operation that merges elements from two sets while eliminating duplicates. By the end of this lesson, you’ll master how to compute unions, recognize their properties, and apply them to real-world scenarios.  

---

## Explanation  
### **Union of Sets**  
The **union** of two sets combines all distinct elements from both sets. Denoted by the symbol $ \cup $, it is defined as:  
>

$$ A \cup B = \{ x : x \in A \text{ or } x \in B \}

$$  
This means the union includes every element that belongs to set $ A $, set $ B $, or both.  

### Key Properties  
- **Commutative Law**: $ A \cup B = B \cup A $  
- **Associative Law**: $ (A \cup B) \cup C = A \cup (B \cup C) $  
- **Identity Element**: $ A \cup \emptyset = A $  
- **Idempotent Law**: $ A \cup A = A $  
- **Universal Set Property**: $ U \cup A = U $, where $ U $ is the universal set.  

### Visual Representation  
The union of sets can be illustrated using **Venn diagrams**. The shaded region representing $ A \cup B $ covers all areas occupied by either set $ A $ or set $ B $.  

---

## Solved Examples  
**Example 1:**  
Let $ A = \{2, 4, 6, 8\} $ and $ B = \{6, 8, 10, 12\} $. Find $ A \cup B $.  
**Solution:**  
Combine all elements from both sets and remove duplicates:

$$ A \cup B = \{2, 4, 6, 8, 10, 12\}

$$  

**Example 2:**  
If $ A = \{a, e, i, o, u\} $ and $ B = \{a, i, u\} $, show that $ A \cup B = A $.  
**Solution:**  
Since all elements of $ B $ are already in $ A $, the union remains $ A $:

$$ A \cup B = \{a, e, i, o, u\} = A

$$  

**Example 3:**  
Let $ X = \{\text{Ram, Geeta, Akbar}\} $ (hockey team) and $ Y = \{\text{Geeta, David, Ashok}\} $ (football team). Find $ X \cup Y $.  
**Solution:**  
Combine elements from both teams, ensuring uniqueness:

$$ X \cup Y = \{\text{Ram, Geeta, Akbar, David, Ashok}\}

$$

## Practice Problems  
1. 🟢 Let $ P = \{1, 3, 5\} $ and $ Q = \{2, 4, 6\} $. Find $ P \cup Q $.  
2. 🟡 If $ M = \{a, b, c\} $ and $ N = \{c, d, e\} $, prove that $ M \cup N = N \cup M $.  
3. 🔴 Given $ R = \{x : x \text{ is a prime number less than 10}\} $ and $ S = \{x : x \text{ is an even number less than 10}\} $, find $ R \cup S $.  

**Answers:**  
1. $ \{1, 2, 3, 4, 5, 6\} $  
2. Prove using the commutative property.  
3. $ \{2, 3, 5, 7\} \cup \{2, 4, 6, 8\} = \{2, 3, 4, 5, 6, 7, 8\} $

## Summary  
- The **union** of sets $ A $ and $ B $ includes all elements from both sets.  
- Symbol: $ A \cup B = \{x : x \in A \text{ or } x \in B\} $.  
- Properties: Commutative, Associative, Identity, Idempotent, and Universal Set.  
- Visualized using **Venn diagrams**.  

---

## Student Corner  
### **Common Mistakes**  
- ❌ Forgetting to remove duplicate elements when forming the union.  
- ❌ Confusing union with intersection (which retains only common elements).  

### **Exam Tip**  
Always verify whether the universal set or empty set is involved, as they simplify union operations significantly.
