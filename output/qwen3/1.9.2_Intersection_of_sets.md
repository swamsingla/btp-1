## Introduction  
Understanding how sets overlap is essential in mathematics. This section explores the **intersection of sets**, a fundamental operation that identifies common elements between two sets. By the end of this topic, you’ll master symbolic notation, solve practical problems, and recognize special cases like disjoint sets.  

## Explanation  
### Key Concepts  
- **Intersection**: The **set of all elements common to both sets A and B**. Denoted by $ A \cap B $.  
- **Disjoint Sets**: Two sets with no elements in common, i.e., $ A \cap B = \emptyset $.  
- **Symbolic Definition**:  
  > $ A \cap B = \{x : x \in A \text{ and } x \in B\} $  

### Properties of Intersection  
> - **Commutative Law**: $ A \cap B = B \cap A $  
> - **Associative Law**: $ (A \cap B) \cap C = A \cap (B \cap C) $  
> - **Law of Empty Set**: $ \emptyset \cap A = \emptyset $, $ U \cap A = A $  
> - **Idempotent Law**: $ A \cap A = A $  
> - **Distributive Law**: $ A \cap (B \cup C) = (A \cap B) \cup (A \cap C) $  

### Visual Representation  
- The **shaded region in a Venn diagram** (Fig 1.5) represents $ A \cap B $.  
- Disjoint sets are depicted as non-overlapping circles (Fig 1.6).  

## Solved Examples  
**Example 1**: Let $ A = \{1, 2, 3, 4\} $ and $ B = \{3, 4, 5\} $. Find $ A \cap B $.  
**Step 1**: Identify common elements: 3, 4.  
**Step 2**: Write result: $ A \cap B = \{3, 4\} $.  

**Example 2**: Let $ X = \{\text{Rahul, Geeta}\} $, $ Y = \{\text{Geeta, Mohan}\} $. Find $ X \cap Y $.  
**Step 1**: Identify common element: Geeta.  
**Step 2**: Result: $ X \cap Y = \{\text{Geeta}\} $.  

**Example 3**: Prove $ A \cap B = B $ if $ B \subset A $.  
**Step 1**: Since every element of $ B $ is in $ A $, $ A \cap B $ contains all elements of $ B $.  
**Step 2**: Therefore, $ A \cap B = B $.  

## Practice Problems  
1. **🟢 Easy**: Let $ P = \{2, 4, 6\} $, $ Q = \{4, 6, 8\} $. Find $ P \cap Q $.  
   *Answer*: $ \{4, 6\} $  
2. **🟡 Medium**: If $ R = \{\text{Apple, Banana}\} $, $ S = \{\text{Banana, Cherry}\} $, find $ R \cap S $.  
   *Answer*: $ \{\text{Banana}\} $  
3. **🔴 Hard**: Show that $ A \cap (B \cup C) = (A \cap B) \cup (A \cap C) $ using Venn diagrams.  

## Summary  
- The **intersection** $ A \cap B $ includes elements common to both sets.  
- **Disjoint sets** have $ A \cap B = \emptyset $.  
- Key properties: Commutative, Associative, Distributive, and Idempotent laws.  
- Always verify whether sets share common elements before applying operations.  

## Student Corner  
### Common Mistakes  
- ❌ Confusing $ \cap $ (intersection) with $ \cup $ (union).  
- ❌ Forgetting to check all elements when identifying intersections.  

### Memory Aid  
**"Intersect" = "Common"**: Remember that $ A \cap B $ means elements shared by both sets.  
**Exam Tip**: Draw Venn diagrams for complex problems to visualize overlaps clearly.
