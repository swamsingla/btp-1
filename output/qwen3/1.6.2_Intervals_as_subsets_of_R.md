## Introduction  
Intervals are fundamental tools to describe subsets of real numbers. In this section, you'll learn how to represent intervals using different notations, distinguish between open, closed, and half-open intervals, and understand their significance in analyzing real-number properties.  

## Explanation  
### Key Concepts  
- **Open Interval**: Denoted by $(a, b) $, it includes all real numbers between $ a $ and $ b $ but excludes $ a $ and $ b $.  
- **Closed Interval**: Denoted by $ [a, b] $, it includes all real numbers between $ a $ and $ b $, including $ a $ and $ b $.  
- **Half-Open Interval**: Includes one endpoint and excludes the other. Examples: $ [a, b) $ includes $ a $ but not $ b $, while $ (a, b] $ includes $ b $ but not $ a $.  

> **Length of an interval**: The length of an interval $ (a, b) $, $ [a, b] $, $ [a, b) $, or $ (a, b] $ is given by $ b - a $.  

### Notation and Representation  
- $ [a, b] = \{x : a \leq x \leq b\} $  
- $ (a, b) = \{x : a < x < b\} $  
- $ [a, b) = \{x : a \leq x < b\} $  
- $ (a, b] = \{x : a < x \leq b\} $  

> **Infinite Intervals**:  
- $ [0, \infty) $ represents non-negative real numbers.  
- $ (-\infty, 0) $ represents negative real numbers.  
- $ (-\infty, \infty) $ represents all real numbers.  

### Properties  
- Intervals are subsets of $\mathbb{R} $ containing infinitely many points.  
- Any interval can be expressed in set-builder form or interval notation.  

## Solved Examples  
**Example 1:** Express $\{x : -5 < x \leq 7\} $ as an interval.  
**Step 1:** Identify the bounds. Lower bound $-5 $ is excluded, upper bound $ 7 $ is included.  
**Step 2:** Apply notation: $ (-5, 7] $.  

**Example 2:** Write $ [-3, 5) $ in set-builder form.  
**Step 1:** Note lower bound $-3 $ is included, upper bound $ 5 $ is excluded.  
**Step 2:** Formulate: $\{x : -3 \leq x < 5\} $.  

**Example 3:** Verify if $ (–3, 5) \subset [–7, 9] $.  
**Step 1:** Recognize $-3 > -7 $ and $ 5 < 9 $.  
**Step 2:** Conclude all elements of $ (–3, 5) $ lie within $ [–7, 9] $.  

## Practice Problems  
1. 🟢 Convert $\{x : 2 \leq x < 8\} $ into interval notation.  
   **Answer:** $ [2, 8) $  
2. 🟡 Determine whether $ (-\infty, 0) $ is a subset of $ (-\infty, 5) $.  
   **Answer:** Yes  
3. 🔴 Express $ [ -1, 4 ] $ in set-builder form.  
   **Answer:** $\{x : -1 \leq x \leq 4\} $  

## Summary  
- **Open interval**: $ (a, b) $ excludes endpoints.  
- **Closed interval**: $ [a, b] $ includes endpoints.  
- **Half-open interval**: Includes one endpoint (e.g., $ [a, b) $).  
- Length of interval: $ b - a $.  
- Intervals are infinite subsets of $\mathbb{R} $.  

## Student Corner  
### Common Mistakes  
- Confusing open and closed intervals (e.g., mixing $ (a, b) $ with $ [a, b] $).  
- Misinterpreting inequalities in set-builder form (e.g., $ x \geq a $ vs. $ x > a $).  

### Memory Aid  
Use **OCA** to recall:  
- **O**pen: $ (a, b) $  
- **C**losed: $ [a, b] $  
- **A**lmost: Half-open intervals like $ [a, b) $ or $ (a, b] $.  

### Exam Tip  
Always double-check endpoints when comparing intervals. For instance, $ [a, b) $ never includes $ b $, even if it’s the upper limit.
