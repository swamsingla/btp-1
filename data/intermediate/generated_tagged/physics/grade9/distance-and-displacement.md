# Distance and Displacement

When you move from one place to another, you cover some ground. In physics, we need exact ways to describe this movement. Two important quantities used to describe motion are distance and displacement. While people often use these words interchangeably in daily life, in physics they mean very different things. Understanding the difference is essential because it helps us describe how an object moves, where it ends up, and how fast it travels.

## What is Distance?

Distance is the total path length covered by an object as it moves from one point to another. It is a scalar quantity, which means it is described by its magnitude or numerical value alone, and does not include any direction. To describe distance, you only need to specify the numerical value of the path length.

Distance is always a positive quantity. Even if an object moves forward and then backward, the distance covered continues to increase because it measures the entire path length traveled. For example, if a person walks around the perimeter of a rectangular basketball court to reach the opposite corner, the distance covered is the sum of all the sides they walked along.

## What is Displacement?

Displacement is the shortest distance measured from the initial position to the final position of an object. It is a vector quantity, which means it has both a magnitude and a direction. The magnitude of the displacement is the numerical value of this shortest path.

Unlike distance, displacement can be zero. If an object returns to its starting point, its final position coincides with its initial position, and therefore, the displacement is zero. However, the distance covered in this journey is not zero because the object still moved along a path.

## Path Length vs. Shortest Path

The difference between distance and displacement becomes clear when we compare the path length with the shortest path. The total path length covered by an object is the distance, while the displacement is the straight line connecting the start and end points.

For instance, consider an object moving along a straight path starting from a reference point O. The object moves to A, then to B, and finally to C. The total path length covered by the object is OA + AC. If OA is 60 km and AC is 35 km, the distance covered is 95 km. The magnitude of the displacement from O to C is 35 km. Thus, the magnitude of the displacement is not equal to the path length.

## Uniform Motion and Non-Uniform Motion

The way we measure distance and displacement is related to how an object moves. An object can move with uniform speed, non-uniform speed, or remain at rest.

When an object travels equal distances in equal intervals of time, it moves with uniform speed. In this case, the distance travelled by the object is directly proportional to the time taken. For uniform speed, a graph of distance travelled against time is a straight line.

If an object does not travel equal distances in equal intervals of time, it moves with non-uniform speed. In this case, the nature of the distance-time graph is different. The graph shows a nonlinear variation of the distance travelled with time.

## Using a Distance-Time Graph

A distance-time graph can be employed to represent the change in the position of an object with time. In this graph, time is taken along the x-axis and distance is taken along the y-axis.

For uniform speed, a graph of distance travelled against time is a straight line. The slope of this straight line represents the speed of the object.

For non-uniform speed, the graph is a curve. The slope of the curve at any point represents the speed of the object at that instant.

## Worked example

A car starts from a point O and travels 40 km east to a point A. Then it travels 30 km west to a point B.

First, we calculate the distance covered. The total path length covered by the car is OA + AB, which is 40 km + 30 km = 70 km. The distance covered is 70 km because distance is the total path length.

Next, we calculate the magnitude of the displacement. The shortest distance measured from the initial position O to the final position B is 10 km east. The magnitude of the displacement is 10 km.

Thus, the magnitude of the displacement (10 km) is not equal to the distance covered (70 km).

## Key points

*   Distance is a scalar quantity described by its numerical value and total path length.
*   Displacement is a vector quantity described by its magnitude and direction as the shortest path.
*   The magnitude of the displacement can be zero, but the distance covered is never zero.
*   Distance is always greater than or equal to the magnitude of the displacement.
*   Distance-time graphs represent the motion of an object, with time on the x-axis and distance on the y-axis.
