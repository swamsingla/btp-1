# ବହୁପଦୀର ଗୁଣନୀୟକୀକରଣ

ଏକ ବହୁପଦୀକୁ (polynomial) ଗୁଣନୀୟକୀକରଣ କରିବାର ଅର୍ଥ ହେଉଛି ଏହାକୁ ଅପେକ୍ଷାକୃତ ସରଳ ବହୁପଦୀଗୁଡ଼ିକର ଗୁଣଫଳ ରୂପେ ଲେଖିବା, ଯାହାକୁ ଏହାର ଗୁଣନୀୟକ (factors) କୁହାଯାଏ। ଏହି ପୃଷ୍ଠାରେ ଆମେ ଗୁଣନୀୟକ ଉପପାଦ୍ୟ (Factor Theorem) ଏବଂ ମଧ୍ୟମ ପଦକୁ ବିଭକ୍ତ କରିବା (splitting the middle term) ପଦ୍ଧତି ବ୍ୟବହାର କରି 2 ଓ 3 ଘାତର ବହୁପଦୀଗୁଡ଼ିକୁ ଗୁଣନୀୟକୀକରଣ କରୁଛୁ।

## ଗୁଣନୀୟକ ଉପପାଦ୍ୟ

ଯଦି $p(x)$ ହେଉଛି $n \geq 1$ ଘାତର (degree) ଏକ ବହୁପଦୀ ଏବଂ $a$ ହେଉଛି ଯେକୌଣସି ବାସ୍ତବ ସଂଖ୍ୟା, ତେବେ (i) ଯଦି $p(a) = 0$ ହୁଏ, ତେବେ $x - a$ ହେଉଛି $p(x)$ ର ଏକ ଗୁଣନୀୟକ, ଏବଂ (ii) ଯଦି $x - a$ ହେଉଛି $p(x)$ ର ଏକ ଗୁଣନୀୟକ, ତେବେ $p(a) = 0$ [S1]। ଏହାକୁ ଗୁଣନୀୟକ ଉପପାଦ୍ୟ କୁହାଯାଏ।

ଏହାର ପ୍ରମାଣରେ ଅବଶିଷ୍ଟ ଉପପାଦ୍ୟ (Remainder Theorem) ବ୍ୟବହାର କରାଯାଏ, ଯାହା ଅନୁଯାୟୀ $p(x) = (x - a)q(x) + p(a)$ [S1]। ଯଦି $p(a) = 0$ ହୁଏ, ତେବେ $p(x) = (x - a)q(x)$, ଯାହା ଦର୍ଶାଏ ଯେ $x - a$ ହେଉଛି $p(x)$ ର ଏକ ଗୁଣନୀୟକ [S1]। ଏହାର ବିପରୀତରେ, ଯଦି $x - a$ ହେଉଛି $p(x)$ ର ଏକ ଗୁଣନୀୟକ, ତେବେ କୌଣସି ବହୁପଦୀ $g(x)$ ପାଇଁ $p(x) = (x - a)g(x)$ ହେବ, ଏବଂ ତେଣୁ $p(a) = (a - a)g(a) = 0$ [S1]।

## ଏକ ରୈଖିକ ଅଭିବ୍ୟକ୍ତି ଗୁଣନୀୟକ କି ନୁହେଁ ତାହା ପରୀକ୍ଷା କରିବା

$x + 2$ ହେଉଛି $x^3 + 3x^2 + 5x + 6$ ର ଏକ ଗୁଣନୀୟକ କି ନୁହେଁ ତାହା ପରୀକ୍ଷା କରିବା ପାଇଁ, ଧ୍ୟାନ ଦିଅନ୍ତୁ ଯେ $x + 2$ ର ଶୂନ୍ୟ (zero) ହେଉଛି $-2$ [S1]। ଧରାଯାଉ $p(x) = x^3 + 3x^2 + 5x + 6$। ତେବେ $p(-2) = (-2)^3 + 3(-2)^2 + 5(-2) + 6 = -8 + 12 - 10 + 6 = 0$ [S1]। ତେଣୁ, ଗୁଣନୀୟକ ଉପପାଦ୍ୟ ଅନୁଯାୟୀ, $x + 2$ ହେଉଛି $x^3 + 3x^2 + 5x + 6$ ର ଏକ ଗୁଣନୀୟକ [S1]।

ସେହି ପରୀକ୍ଷା $2x + 4$ ପାଇଁ ମଧ୍ୟ କାମ କରେ: $s(x) = 2x + 4$ ନେଲେ ଆମେ $s(-2) = 2(-2) + 4 = 0$ ପାଉ, ତେଣୁ $x + 2$ ହେଉଛି $2x + 4$ ର ଏକ ଗୁଣନୀୟକ [S1]। ଗୁଣନୀୟକ ଉପପାଦ୍ୟ ବିନା ମଧ୍ୟ ଆମେ ଏହା ଦେଖିପାରିବା, କାରଣ $2x + 4 = 2(x + 2)$ [S1]।

## ଏକ ସ୍ଥିରାଙ୍କର (constant) ମୂଲ୍ୟ ନିର୍ଣ୍ଣୟ କରିବା

ଯଦି $x - 1$ ହେଉଛି $p(x) = 4x^3 + 3x^2 - 4x + k$ ର ଏକ ଗୁଣନୀୟକ, ତେବେ $p(1) = 0$ [S1]। ବର୍ତ୍ତମାନ $p(1) = 4(1)^3 + 3(1)^2 - 4(1) + k = 4 + 3 - 4 + k$, ଏବଂ ଏହାକୁ 0 ସହିତ ସମାନ କଲେ $k = -3$ ମିଳେ [S1]।

## ମଧ୍ୟମ ପଦକୁ ବିଭକ୍ତ କରିବା

$x^2 + lx + m$ ପରି ଏକ ଦ୍ୱିଘାତ ବହୁପଦୀକୁ (quadratic polynomial) ମଧ୍ୟମ ପଦ $lx$ କୁ $ax + bx$ ଭାବରେ ବିଭକ୍ତ କରି ଗୁଣନୀୟକୀକରଣ କରାଯାଇପାରିବ, ଯେପରି $ab = m$ ହେବ। ତେବେ $x^2 + lx + m = (x + a)(x + b)$ [S1]। ଆମେ ବର୍ତ୍ତମାନ $ax^2 + bx + c$ ପ୍ରକାରର ଦ୍ୱିଘାତ ବହୁପଦୀଗୁଡ଼ିକୁ ଗୁଣନୀୟକୀକରଣ କରୁ, ଯେଉଁଠାରେ $a \neq 0$ ଏବଂ $a$, $b$, $c$ ହେଉଛନ୍ତି ସ୍ଥିରାଙ୍କ [S1]।

ଧରାଯାଉ ଗୁଣନୀୟକଗୁଡ଼ିକ ହେଉଛି $(px + q)$ ଏବଂ $(rx + s)$। ତେବେ $ax^2 + bx + c = (px + q)(rx + s) = prx^2 + (ps + qr)x + qs$ [S1]। $x^2$ ର ସହଗୁଣକଗୁଡ଼ିକୁ ତୁଳନା କଲେ $a = pr$ ମିଳେ, $x$ ର ସହଗୁଣକଗୁଡ଼ିକୁ ତୁଳନା କଲେ $b = ps + qr$ ମିଳେ, ଏବଂ ସ୍ଥିର ପଦଗୁଡ଼ିକୁ ତୁଳନା କଲେ $c = qs$ ମିଳେ [S1]। ତେଣୁ $b$ ହେଉଛି ଦୁଇଟି ସଂଖ୍ୟା $ps$ ଏବଂ $qr$ ର ସମଷ୍ଟି, ଯାହାର ଗୁଣଫଳ ହେଉଛି $(ps)(qr) = (pr)(qs) = ac$ [S1]। ତେଣୁ, $ax^2 + bx + c$ କୁ ଗୁଣନୀୟକୀକରଣ କରିବା ପାଇଁ, ଆମେ $b$ କୁ ଏପରି ଦୁଇଟି ସଂଖ୍ୟାର ସମଷ୍ଟି ଭାବରେ ଲେଖୁ ଯାହାର ଗୁଣଫଳ ହେଉଛି $ac$ [S1]।

ଉଦାହରଣ ସ୍ୱରୂପ, ମଧ୍ୟମ ପଦକୁ ବିଭକ୍ତ କରି $6x^2 + 17x + 5$ କୁ ଗୁଣନୀୟକୀକରଣ କରିବା ପାଇଁ, ଆମେ ଏପରି ଦୁଇଟି ସଂଖ୍ୟା ଖୋଜୁ ଯାହାର ସମଷ୍ଟି 17 ଏବଂ ଯାହାର ଗୁଣଫଳ ହେଉଛି $6 \times 5 = 30$ [S1]। 30 ର ଗୁଣନୀୟକ ଯୋଡ଼ିଗୁଡ଼ିକ ମଧ୍ୟରୁ କେତୋଟି ହେଉଛି 1 ଏବଂ 30, 2 ଏବଂ 15, 3 ଏବଂ 10, 5 ଏବଂ 6। ଏଗୁଡ଼ିକ ମଧ୍ୟରୁ, 2 ଏବଂ 15 ର ସମଷ୍ଟି 17 ହୁଏ [S1]। ତେଣୁ $6x^2 + 17x + 5 = 6x^2 + 2x + 15x + 5 = 2x(3x + 1) + 5(3x + 1) = (3x + 1)(2x + 5)$ [S1]।

ଗୁଣନୀୟକ ଉପପାଦ୍ୟ ମଧ୍ୟ ସେହି ଉତ୍ତର ହିଁ ଦିଏ। ଧରାଯାଉ $6x^2 + 17x + 5 = 6\left(x^2 + \frac{17}{6}x + \frac{5}{6}\right) = 6p(x)$। ଯଦି $a$ ଏବଂ $b$ ହେଉଛନ୍ତି $p(x)$ ର ଶୂନ୍ୟ (zeroes), ତେବେ $6x^2 + 17x + 5 = 6(x - a)(x - b)$ ଏବଂ $ab = \frac{5}{6}$ [S1]। ପରୀକ୍ଷା କରି, $p\left(-\frac{1}{3}\right) = 0$, ତେଣୁ $x + \frac{1}{3}$ ହେଉଛି $p(x)$ ର ଏକ ଗୁଣନୀୟକ, ଏବଂ ସେହିପରି $x + \frac{5}{2}$ ହେଉଛି $p(x)$ ର ଏକ ଗୁଣନୀୟକ [S1]। ତେଣୁ $6x^2 + 17x + 5 = 6\left(x + \frac{1}{3}\right)\left(x + \frac{5}{2}\right) = 6\left(\frac{3x + 1}{3}\right)\left(\frac{2x + 5}{2}\right) = (3x + 1)(2x + 5)$ [S1]। ଏହି ଉଦାହରଣ ପାଇଁ ବିଭକ୍ତ କରିବା ପଦ୍ଧତି ଅଧିକ ସହଜ ମନେହୁଏ [S1]।

## ଏକ ଦ୍ୱିଘାତ ବହୁପଦୀ ପାଇଁ ଗୁଣନୀୟକ ଉପପାଦ୍ୟର ବ୍ୟବହାର

ବର୍ତ୍ତମାନ ଗୁଣନୀୟକ ଉପପାଦ୍ୟ ବ୍ୟବହାର କରି $y^2 - 5y + 6$ କୁ ଗୁଣନୀୟକୀକରଣ କରନ୍ତୁ। ଧରାଯାଉ $p(y) = y^2 - 5y + 6$। ଯଦି $p(y) = (y - a)(y - b)$, ତେବେ ସ୍ଥିର ପଦ (constant term) ହେଉଛି $ab$, ତେଣୁ $ab = 6$, ଏବଂ ଆମେ 6 ର ଗୁଣନୀୟକଗୁଡ଼ିକୁ ଦେଖୁ [S1]। ଆମେ ପାଉ $p(2) = 2^2 - (5 \times 2) + 6 = 0$, ତେଣୁ $y - 2$ ହେଉଛି $p(y)$ ର ଏକ ଗୁଣନୀୟକ [S1]। ସେହିପରି $p(3) = 3^2 - (5 \times 3) + 6 = 0$, ତେଣୁ $y - 3$ ମଧ୍ୟ ଏକ ଗୁଣନୀୟକ ଅଟେ [S1]। ତେଣୁ $y^2 - 5y + 6 = (y - 2)(y - 3)$ [S1]। ଏହି ବହୁପଦୀକୁ ମଧ୍ୟମ ପଦ $-5y$ କୁ ବିଭକ୍ତ କରି ମଧ୍ୟ ଗୁଣନୀୟକୀକରଣ କରାଯାଇପାରିବ [S1]।

## ତ୍ରିଘାତ ବହୁପଦୀର ଗୁଣନୀୟକୀକରଣ

ତ୍ରିଘାତ ବହୁପଦୀ (cubic polynomial) ପାଇଁ, ବିଭକ୍ତ କରିବା ପଦ୍ଧତି ଆରମ୍ଭ କରିବା ପାଇଁ ଉପଯୁକ୍ତ ନୁହେଁ, ଏବଂ ଆମକୁ ପ୍ରଥମେ ଅତିକମରେ ଗୋଟିଏ ଗୁଣନୀୟକ ଖୋଜିବାକୁ ପଡ଼ିବ [S1]।

$p(x) = x^3 - 23x^2 + 142x - 120$ କୁ ବିଚାର କରନ୍ତୁ। ଆମେ $-120$ ର ଗୁଣନୀୟକ ଖୋଜୁ, ଯେପରିକି $\pm 1, \pm 2, \pm 3, \pm 4, \pm 5, \pm 6, \pm 8, \pm 10, \pm 12, \pm 15, \pm 20, \pm 24, \pm 30, \pm 60$ [S1]। ପରୀକ୍ଷା କରି, $p(1) = 1 - 23 + 142 - 120 = 0$, ତେଣୁ $x - 1$ ହେଉଛି $p(x)$ ର ଏକ ଗୁଣନୀୟକ [S1]। ତେବେ $x^3 - 23x^2 + 142x - 120 = x^3 - x^2 - 22x^2 + 22x + 120x - 120 = x^2(x - 1) - 22x(x - 1) + 120(x - 1) = (x - 1)(x^2 - 22x + 120)$, $(x - 1)$ କୁ ସାଧାରଣ ଗୁଣନୀୟକ ରୂପେ ନେଇ [S1]। ଆମେ $p(x)$ କୁ $x - 1$ ଦ୍ୱାରା ଭାଗ କରି ମଧ୍ୟ ଏହା ପାଇପାରିଥାଆନ୍ତେ [S1]।

ଦ୍ୱିଘାତ ବହୁପଦୀ $x^2 - 22x + 120$ କୁ ମଧ୍ୟମ ପଦକୁ ବିଭକ୍ତ କରି କିମ୍ବା ଗୁଣନୀୟକ ଉପପାଦ୍ୟ ବ୍ୟବହାର କରି ଗୁଣନୀୟକୀକରଣ କରାଯାଇପାରିବ [S1]। ମଧ୍ୟମ ପଦକୁ ବିଭକ୍ତ କରି, $x^2 - 22x + 120 = x^2 - 12x - 10x + 120 = x(x - 12) - 10(x - 12) = (x - 12)(x - 10)$ [S1]। ତେଣୁ $x^3 - 23x^2 + 142x - 120 = (x - 1)(x - 10)(x - 12)$ [S1]।

## ସମାଧାନ ସହିତ ଉଦାହରଣ

$x^3 - 2x^2 - 5x + 6$ କୁ ଗୁଣନୀୟକୀକରଣ କରନ୍ତୁ। ସ୍ଥିର ପଦ 6 ର ଗୁଣନୀୟକଗୁଡ଼ିକ ହେଉଛି $\pm 1, \pm 2, \pm 3, \pm 6$। ଧରାଯାଉ $p(x) = x^3 - 2x^2 - 5x + 6$। $x = 1$ ନେଲେ $p(1) = 1 - 2 - 5 + 6 = 0$ ମିଳେ, ତେଣୁ ଗୁଣନୀୟକ ଉପପାଦ୍ୟ ଅନୁଯାୟୀ $x - 1$ ହେଉଛି ଏକ ଗୁଣନୀୟକ [S1]। $x - 1$ ଦ୍ୱାରା ଭାଗ କଲେ, ଆମେ ପାଉ $x^3 - 2x^2 - 5x + 6 = (x - 1)(x^2 - x - 6)$।

ମଧ୍ୟମ ପଦକୁ ବିଭକ୍ତ କରି $x^2 - x - 6$ କୁ ଗୁଣନୀୟକୀକରଣ କରିବା ପାଇଁ, ଆମକୁ ଏପରି ଦୁଇଟି ସଂଖ୍ୟା ଦରକାର ଯାହାର ସମଷ୍ଟି $-1$ ଏବଂ ଯାହାର ଗୁଣଫଳ $-6$ ଅଟେ। ଏଗୁଡ଼ିକ ହେଉଛି $-3$ ଏବଂ $2$। ତେଣୁ $x^2 - x - 6 = x^2 + 2x - 3x - 6 = x(x + 2) - 3(x + 2) = (x - 3)(x + 2)$। ସମ୍ପୂର୍ଣ୍ଣ ଗୁଣନୀୟକୀକରଣ ହେଉଛି $x^3 - 2x^2 - 5x + 6 = (x - 1)(x - 3)(x + 2)$।

## ମୁଖ୍ୟ ବିନ୍ଦୁ

*   ଯଦି $p(x)$ ର ଘାତ $n \geq 1$ ହୁଏ, ତେବେ $x - a$ ହେଉଛି $p(x)$ ର ଏକ ଗୁଣନୀୟକ ଯଦି ଏବଂ କେବଳ ଯଦି $p(a) = 0$ ହୁଏ [S1]।
*   ଯେତେବେଳେ ଏକ ରୈଖିକ ଗୁଣନୀୟକ ଦିଆଯାଇଥାଏ, ସେତେବେଳେ ଏକ ବହୁପଦୀରେ ଏକ ଅଜ୍ଞାତ ସ୍ଥିରାଙ୍କ ଖୋଜିବା ପାଇଁ ଗୁଣନୀୟକ ଉପପାଦ୍ୟ ବ୍ୟବହାର କରାଯାଇପାରିବ [S1]।
*   ମଧ୍ୟମ ପଦକୁ ବିଭକ୍ତ କରି $ax^2 + bx + c$ କୁ ଗୁଣନୀୟକୀକରଣ କରିବା ପାଇଁ, $b$ କୁ ଏପରି ଦୁଇଟି ସଂଖ୍ୟାର ସମଷ୍ଟି ଭାବରେ ଲେଖନ୍ତୁ ଯାହାର ଗୁଣଫଳ ହେଉଛି $ac$ [S1]।
*   ଦ୍ୱିଘାତ ବହୁପଦୀଗୁଡ଼ିକର ଶୂନ୍ୟ (zeroes) ଖୋଜି ସେଗୁଡ଼ିକୁ ଗୁଣନୀୟକୀକରଣ କରିବା ପାଇଁ ମଧ୍ୟ ଗୁଣନୀୟକ ଉପପାଦ୍ୟ ବ୍ୟବହାର କରାଯାଇପାରିବ [S1]।
*   ଏକ ତ୍ରିଘାତ ବହୁପଦୀ ପାଇଁ, ବିଭକ୍ତ କରିବା ପଦ୍ଧତି ଆରମ୍ଭ କରିବା ପାଇଁ ଉପଯୁକ୍ତ ନୁହେଁ, ତେଣୁ ଆମେ ପ୍ରଥମେ ଗୋଟିଏ ଗୁଣନୀୟକ ଖୋଜୁ ଏବଂ ତା'ପରେ ବାକି ଥିବା ଦ୍ୱିଘାତ ବହୁପଦୀକୁ ଗୁଣନୀୟକୀକରଣ କରୁ [S1]।
