# Linear Equations in Two Variables

In earlier classes, you may have studied linear equations in one variable, such as $x + 1 = 0$ [S3]. Such equations have a unique solution that you can represent on a number line. Now, we extend this knowledge to equations involving two variables, such as $x$ and $y$. This chapter explores what it means to solve these equations, how to represent their solutions, and how they relate to the Cartesian plane [S3].

## The Standard Form

A linear equation in two variables is an equation that can be written in the form $ax + by + c = 0$, where $a$, $b$, and $c$ are real numbers, and $a$ and $b$ are not both zero [S1]. You can use any letters for the variables, but $x$ and $y$ are customary [S1]. 

To recognize this form, you might need to rearrange the equation. For example, the equation $2x + 3y = 4.37$ can be written as $2x + 3y - 4.37 = 0$. In this case, $a = 2$, $b = 3$, and $c = -4.37$ [S1]. Even equations that look like they have only one variable are technically linear equations in two variables. For instance, $4 - 3x = 0$ can be expressed as $-3x + 0y + 4 = 0$ [S1].

## Finding Solutions

Because there are two variables, a solution means a pair of values, one for $x$ and one for $y$, which satisfy the given equation [S2]. This solution is written as an ordered pair $(x, y)$, with the value for $x$ written first [S2].

A linear equation in two variables has infinitely many solutions [S2]. To find a solution, you can pick a value for one variable and solve for the other. For example, consider the equation $2x + 3y = 12$. If you choose $x = 3$ and $y = 2$, the equation holds true because $2(3) + 3(2) = 12$ [S2]. This gives the ordered pair $(3, 2)$. However, $(1, 4)$ is not a solution because $2(1) + 3(4) = 14$, which is not $12$ [S2].

## Worked Example

Let us find two different ordered pairs that satisfy the equation $x + 2y = 6$. First, we can pick a value for $x$. If we choose $x = 0$, the equation reduces to $2y = 6$, which gives $y = 3$. This results in the ordered pair $(0, 3)$ [S2]. Next, we can pick a value for $y$. If we choose $y = 0$, the equation reduces to $x = 6$. This gives the ordered pair $(6, 0)$ [S2]. Both of these pairs are valid solutions to the equation.

## Key points

- A linear equation in two variables can be written in the standard form $ax + by + c = 0$, where $a$, $b$, and $c$ are real numbers, and $a$ and $b$ are not both zero [S1].
- A solution to a linear equation in two variables is an ordered pair $(x, y)$ that makes the equation true when the values are substituted [S2].
- A linear equation in two variables has infinitely many solutions, and you can find them by choosing a value for one variable and solving for the other [S2].
- You can represent an equation like $x = -5$ in standard form as $1.x + 0.y + 5 = 0$ [S1].
- You can represent an equation like $y = 2$ in standard form as $0.x + 1.y - 2 = 0$ [S1].
- An easy way to find a solution is to take $x = 0$ to get the corresponding value of $y$, or take $y = 0$ to get the corresponding value of $x$ [S2].
