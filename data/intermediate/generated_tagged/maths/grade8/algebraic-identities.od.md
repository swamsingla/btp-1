# ବୈଜିକ ସର୍ବସମିକା (Algebraic Identities)

ବୈଜିକ ସର୍ବସମିକାଗୁଡ଼ିକ ହେଉଛି ଗାଣିତିକ ସର୍ଟକଟ୍ ଯାହା ଆମକୁ ବୈଜିକ ଅଭିବ୍ୟକ୍ତିଗୁଡ଼ିକୁ ଶୀଘ୍ର ବିସ୍ତାର କିମ୍ବା ସରଳ କରିବାରେ ସାହାଯ୍ୟ କରେ। ପ୍ରତ୍ୟେକ ପଦକୁ ହାତରେ ଗୁଣନ କରିବା ପରିବର୍ତ୍ତେ, ଆମେ କେବଳ କିଛି ପଦକ୍ଷେପରେ ଉତ୍ତର ଖୋଜିବା ପାଇଁ ମାନକ ପ୍ୟାଟର୍ଣ୍ଣ ବ୍ୟବହାର କରିପାରିବା। ଯେତେବେଳେ ଆପଣ ବଡ଼ ସଂଖ୍ୟା ହିସାବ କରୁଛନ୍ତି କିମ୍ବା ବୀଜଗଣିତରେ ଜଟିଳ ଅଭିବ୍ୟକ୍ତିଗୁଡ଼ିକୁ ସରଳ କରୁଛନ୍ତି, ସେତେବେଳେ ଏହି ପ୍ୟାଟର୍ଣ୍ଣଗୁଡ଼ିକ ବହୁତ ଉପଯୋଗୀ ହୋଇଥାଏ।

## ସମଷ୍ଟିର ବର୍ଗ: $(a + b)^2$

ସବୁଠାରୁ ସାଧାରଣ ପ୍ୟାଟର୍ଣ୍ଣ ମଧ୍ୟରୁ ଗୋଟିଏ ହେଉଛି ସମଷ୍ଟିର ବର୍ଗ। ଯେତେବେଳେ ଆପଣ ଏକ ଦ୍ୱିପଦୀକୁ ନିଜ ସହିତ ଗୁଣନ କରନ୍ତି, ଆପଣ ଏକ ତ୍ରିପଦୀ ପାଆନ୍ତି। ନିୟମଟି ହେଉଛି ଯେ ସମଷ୍ଟିର ବର୍ଗ ପ୍ରଥମ ପଦର ବର୍ଗ, ଦୁଇଟି ପଦର ଗୁଣଫଳର ଦୁଇଗୁଣ, ଏବଂ ଦ୍ୱିତୀୟ ପଦର ବର୍ଗ ସହିତ ସମାନ। ପ୍ରତୀକରେ, ଏହାକୁ $(a + b)^2 = a^2 + 2ab + b^2$ [S2] ଭାବରେ ଲେଖାଯାଏ।

ଆସନ୍ତୁ ସଂଖ୍ୟା ବ୍ୟବହାର କରି ଏକ ଉଦାହରଣ ଦେଖିବା। ଧରିନିଅନ୍ତୁ ଆମେ $65^2$ ର ମୂଲ୍ୟ ବାହାର କରିବାକୁ ଚାହୁଁଛୁ। ଆମେ 65 କୁ $60 + 5$ ରେ ଭାଙ୍ଗିପାରିବା। ସର୍ବସମିକା ବ୍ୟବହାର କରି, ଆମେ ହିସାବ କରୁ $(60 + 5)^2 = 60^2 + 2(60 \times 5) + 5^2 = 3600 + 600 + 25 = 4225$ [S2]। 65 କୁ ସିଧାସଳଖ 65 ଦ୍ୱାରା ଗୁଣନ କରିବା ତୁଳନାରେ ଏହି ପଦ୍ଧତି ଅନେକ ସମୟ ବଞ୍ଚାଏ।

## ବିୟୋଗଫଳର ବର୍ଗ: $(a - b)^2$

ଅନ୍ୟ ଏକ ଉପଯୋଗୀ ପ୍ୟାଟର୍ଣ୍ଣ ହେଉଛି ବିୟୋଗଫଳର ବର୍ଗ। ଯେତେବେଳେ ଆପଣ ଏକ ଦ୍ୱିପଦୀର ବର୍ଗ କରନ୍ତି ଯେଉଁଠାରେ ଦ୍ୱିତୀୟ ପଦକୁ ବିୟୋଗ କରାଯାଏ, ମଧ୍ୟମ ପଦଟି ନକାରାତ୍ମକ ହୋଇଯାଏ। ନିୟମ କହୁଛି ଯେ ବିୟୋଗଫଳର ବର୍ଗ ପ୍ରଥମ ପଦର ବର୍ଗ, ଦୁଇଟି ପଦର ଗୁଣଫଳର ଦୁଇଗୁଣ ବିୟୋଗ, ଏବଂ ଦ୍ୱିତୀୟ ପଦର ବର୍ଗ ସହିତ ସମାନ। ଏହାକୁ $(a - b)^2 = a^2 - 2ab + b^2$ [S2] ଭାବରେ ଲେଖାଯାଏ।

ଆମେ ଏହାକୁ $(60 - 5)^2$ ଭାବରେ ଲେଖି $55^2$ ହିସାବ କରିବା ପାଇଁ ବ୍ୟବହାର କରିପାରିବା। ସର୍ବସମିକା ପ୍ରୟୋଗ କରି, ଆମେ ପାଉ $60^2 - 2(60 \times 5) + 5^2 = 3600 - 600 + 25 = 3025$ [S2]। ଧ୍ୟାନ ଦିଅନ୍ତୁ ଯେ ମଧ୍ୟମ ପଦଟି ନକାରାତ୍ମକ ଅଟେ, ଯାହା ଆମକୁ ସଠିକ୍ ଫଳାଫଳ ଦେଇଥାଏ।

## ବର୍ଗର ବିୟୋଗଫଳ: $(a + b)(a - b)$

ତୃତୀୟ ପ୍ୟାଟର୍ଣ୍ଣ ହେଉଛି ବର୍ଗର ବିୟୋଗଫଳ। ଯେତେବେଳେ ଆପଣ ସମାନ ଦୁଇଟି ପଦର ସମଷ୍ଟି ଏବଂ ବିୟୋଗଫଳକୁ ଗୁଣନ କରନ୍ତି, ମଧ୍ୟମ ପଦଗୁଡ଼ିକ ବାତିଲ ହୋଇଯାଏ। ଫଳାଫଳ କେବଳ ପ୍ରଥମ ପଦର ବର୍ଗ ବିୟୋଗ ଦ୍ୱିତୀୟ ପଦର ବର୍ଗ ଅଟେ। ପ୍ରତୀକରେ, ଏହା ହେଉଛି $(a + b)(a - b) = a^2 - b^2$ [S2]।

ବଡ଼ ସଂଖ୍ୟାଗୁଡ଼ିକୁ ଶୀଘ୍ର ଗୁଣନ କରିବା ପାଇଁ ଏହି ସର୍ବସମିକା ବହୁତ ଉପଯୋଗୀ। ଉଦାହରଣ ସ୍ୱରୂପ, $98 \times 102$ ର ମୂଲ୍ୟ ଖୋଜିବା ପାଇଁ, ଆମେ ଏହାକୁ $(100 - 2)(100 + 2)$ ଭାବରେ ଲେଖିପାରିବା। ସର୍ବସମିକା ବ୍ୟବହାର କରି, ଆମେ ହିସାବ କରୁ $100^2 - 2^2 = 10000 - 4 = 9996$ [S2]। ଲମ୍ବା ଗୁଣନ କରିବା ଅପେକ୍ଷା ଏହି ପଦ୍ଧତି ବହୁତ ଶୀଘ୍ର ହୋଇଥାଏ।

## ତିନୋଟି ପଦର ବିସ୍ତାର: $(a + b + c)^2$

ବେଳେବେଳେ ଆପଣଙ୍କୁ ତିନୋଟି ପଦ ଥିବା ଏକ ଅଭିବ୍ୟକ୍ତିର ବର୍ଗ କରିବାକୁ ପଡିବ। ଏକ ତ୍ରିପଦୀର ବର୍ଗର ନିୟମ ହେଉଛି ପ୍ରତ୍ୟେକ ବ୍ୟକ୍ତିଗତ ପଦର ବର୍ଗ କରିବା ଏବଂ ତାପରେ ପ୍ରତ୍ୟେକ ଯୋଡି ପଦର ଗୁଣଫଳର ଦୁଇଗୁଣ ଯୋଡିବା। ପ୍ରତୀକରେ, ଏହା ହେଉଛି $(a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ca$ [S1]।

## ଦ୍ୱିପଦୀର ଗୁଣଫଳ: $(x + a)(x + b)$

ଯେତେବେଳେ ଆପଣ ସମାନ ଚଳରାଶି ସହିତ ଦୁଇଟି ଦ୍ୱିପଦକୁ ଗୁଣନ କରନ୍ତି, ଆପଣ ପ୍ରଥମ ଦ୍ୱିପଦୀରେ ଥିବା ପ୍ରତ୍ୟେକ ପଦକୁ ଦ୍ୱିତୀୟ ଦ୍ୱିପଦୀରେ ଥିବା ପ୍ରତ୍ୟେକ ପଦ ସହିତ ଗୁଣନ କରି ଅଭିବ୍ୟକ୍ତିକୁ ବିସ୍ତାର କରିପାରିବେ। ଫଳାଫଳ ହେଉଛି ଏକ ଦ୍ୱିଘାତ ଅଭିବ୍ୟକ୍ତି। ଉଦାହରଣ ସ୍ୱରୂପ, $(x + 2)(x + 5)$ ବିସ୍ତାର ହୋଇ $x^2 + 7x + 10$ ହୁଏ [S1]।

## ସମାଧାନ କରାଯାଇଥିବା ଉଦାହରଣ

ଆସନ୍ତୁ ଏକ ସରଳ ବୈଜିକ ଅଭିବ୍ୟକ୍ତିରେ ସମଷ୍ଟିର ବର୍ଗର ସର୍ବସମିକା ପ୍ରୟୋଗ କରିବା। ଆମେ $(3x + 4)^2$ କୁ ବିସ୍ତାର କରିବାକୁ ଚାହୁଁଛୁ। ନିୟମ $(a + b)^2 = a^2 + 2ab + b^2$ ବ୍ୟବହାର କରି, ଆମେ $a = 3x$ ଏବଂ $b = 4$ ନେଉ। ବିସ୍ତାର ହେଉଛି $(3x)^2 + 2(3x \times 4) + 4^2 = 9x^2 + 24x + 16$।

## ମୁଖ୍ୟ ବିନ୍ଦୁ

*   ଏକ ବୈଜିକ ସର୍ବସମିକା ହେଉଛି ଏକ ନିୟମ ଯାହା ଚଳରାଶିର ସମସ୍ତ ମୂଲ୍ୟ ପାଇଁ ସତ୍ୟ ଅଟେ।
*   ସମଷ୍ଟିର ବର୍ଗ ହେଉଛି $(a + b)^2 = a^2 + 2ab + b^2$।
*   ବିୟୋଗଫଳର ବର୍ଗ ହେଉଛି $(a - b)^2 = a^2 - 2ab + b^2$।
*   ଏକ ସମଷ୍ଟି ଏବଂ ଏକ ବିୟୋଗଫଳର ଗୁଣଫଳ ହେଉଛି $(a + b)(a - b) = a^2 - b^2$।
*   $(x + a)(x + b)$ କୁ ବିସ୍ତାର କଲେ $x^2 + (a + b)x + ab$ ମିଳେ।
