# Equivalent Fractions

Equivalent fractions are different fractions that represent the exact same value or the exact same length. For example, if you take a piece of paper and fold it in half, the shaded half is $\frac{1}{2}$. If you fold the same paper into four equal strips and shade two of them, you get $\frac{2}{4}$. Because both shaded areas cover the exact same physical space, they represent the exact same amount. Understanding equivalent fractions is very important because it helps us compare different fractions, find a common denominator, and add or subtract them easily [S1].

## Finding Equivalent Fractions

We can find equivalent fractions by multiplying both the numerator and the denominator of a given fraction by the same non-zero number. Let us look at the fraction $\frac{1}{2}$. If we multiply the numerator and the denominator by 2, we get $\frac{2}{4}$. If we multiply them by 3, we get $\frac{3}{6}$. If we multiply them by 4, we get $\frac{4}{8}$. All of these fractions are equivalent to $\frac{1}{2}$ because they represent the exact same value. This is the fundamental rule for creating equivalent fractions: whatever you do to the top number, you must also do to the bottom number [S1].

## Using a Fraction Wall

A fraction wall is a great way to visualize equivalent fractions. Imagine a strip of paper that represents one whole unit. We can divide this strip into 2 equal parts, 3 equal parts, or 4 equal parts. If we look at the strip divided into 2 parts, we see that $\frac{1}{2}$ of the strip is shaded. Now, if we look at the strip divided into 4 parts, we see that $\frac{2}{4}$ of the strip is shaded. Because both strips represent the exact same length, we can say that $\frac{1}{2} = \frac{2}{4}$ [S1].

We can use this idea to find equivalent fractions for other fractions as well. For example, let us check if $\frac{1}{3}$ and $\frac{2}{6}$ are equivalent fractions. If we look at a fraction wall, we can see that $\frac{1}{3}$ of a strip is the exact same length as $\frac{2}{6}$ of a strip. Therefore, we can say that $\frac{1}{3} = \frac{2}{6}$. We can also see that $\frac{2}{3}$ is equivalent to $\frac{4}{6}$ because both represent the exact same length on the fraction wall [S1].

## The Cross-Multiplication Test

We can use a simple rule to check if two fractions are equivalent without having to draw a fraction wall. The rule is called the cross-multiplication test. To check if two fractions are equivalent, we multiply the numerator of the first fraction by the denominator of the second fraction, and we multiply the denominator of the first fraction by the numerator of the second fraction. If the two products are equal, then the two fractions are equivalent.

Let us try this with the fractions $\frac{1}{2}$ and $\frac{2}{4}$. We multiply the numerator of the first fraction, which is 1, by the denominator of the second fraction, which is 4. We get $1 \times 4 = 4$. We then multiply the denominator of the first fraction, which is 2, by the numerator of the second fraction, which is 2. We get $2 \times 2 = 4$. Because both products are equal, we can say that $\frac{1}{2}$ and $\frac{2}{4}$ are equivalent fractions [S1].

Let us try another example. Let us check if $\frac{3}{5}$ and $\frac{6}{10}$ are equivalent fractions. We multiply the numerator of the first fraction, which is 3, by the denominator of the second fraction, which is 10. We get $3 \times 10 = 30$. We then multiply the denominator of the first fraction, which is 5, by the numerator of the second fraction, which is 6. We get $5 \times 6 = 30$. Because both products are equal, we can say that $\frac{3}{5}$ and $\frac{6}{10}$ are equivalent fractions [S1].

## Why Equivalent Fractions Matter

Equivalent fractions are very useful in everyday life. For example, if you are baking a cake and the recipe calls for $\frac{1}{2}$ a cup of sugar, but you only have a $\frac{1}{4}$ cup measure, you can use equivalent fractions to figure out that you need to use 2 of your $\frac{1}{4}$ cup measures to get the same amount of sugar. You can also use equivalent fractions to compare fractions. If you want to compare $\frac{1}{2}$ and $\frac{3}{6}$, you can use the cross-multiplication test to check if they are equivalent, or you can use equivalent fractions to find a common denominator [S3].

Let us say we have the fraction $\frac{2}{3}$. We want to find an equivalent fraction where the denominator is 6. We can use the rule of multiplying the numerator and the denominator by the same number. We need to multiply the denominator 3 by 2 to get 6. We must also multiply the numerator 2 by 2 to get 4. So, the equivalent fraction is $\frac{4}{6}$. We can check this using the cross-multiplication test. We multiply 2 by 6 to get 12, and we multiply 3 by 4 to get 12. Because both products are equal, we can say that $\frac{2}{3} = \frac{4}{6}$ [S1].
