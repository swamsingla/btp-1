
# భిన్నాల రకాలు

భిన్నాలు (Fractions) అంటే ఒక పూర్తి వస్తువులోని భాగాలను సూచించే విధానం. భిన్నాలలోని వివిధ రకాలను అర్థం చేసుకోవడం వల్ల, పూర్ణాంకాలు కాని సంఖ్యలతో పనిచేయడం సులభం అవుతుంది. వంట చేసేటప్పుడు పదార్థాలను కొలవాలన్నా, పిజ్జాను పంచుకోవాలన్నా లేదా దూరాలను లెక్కించాలన్నా మనం ఈ రకాల భిన్నాలను ఉపయోగిస్తాం.

## ప్రథమ భిన్నాలు (Proper Fractions)

ప్రథమ భిన్నం (proper fraction) అంటే లవం (numerator) హారం (denominator) కంటే చిన్నగా ఉండే భిన్నం. దీని అర్థం ఈ భిన్నం విలువ ఎల్లప్పుడూ ఒకటి కంటే తక్కువే ఉంటుంది [S1]. నంబర్ లైన్ (number line) మీద చూస్తే, ఈ భిన్నాలు సున్నా మరియు ఒకటి మధ్య ఉంటాయి. ఉదాహరణకు, మీరు ఒక చిక్కీ ముక్కను తీసుకుని అందులో $\frac { 1 } { 2 }$ వంతు తిన్నారనుకోండి, మీరు తిన్నది ఒక ప్రథమ భిన్నం. ఎందుకంటే ఇక్కడ లవం $1$, హారం $2$ కంటే చిన్నది [S2].

## అపధార భిన్నాలు (Improper Fractions)

అపధార భిన్నం (improper fraction) అంటే లవం హారం కంటే పెద్దగా ఉండే భిన్నం. దీని అర్థం ఈ భిన్నం విలువ ఒకటి కంటే ఎక్కువగా ఉంటుంది [S1]. ఉదాహరణకు, $\frac {3}{2}, \frac {5}{2}$ మరియు $\frac { 7 } { 2 }$ అన్నీ 1 కంటే పెద్దవే [S1]. వాటిలో ఎన్ని పూర్ణాంకాలు ఉన్నాయో చూడటానికి మనం వాటిని విడదీసి చూడవచ్చు. ఉదాహరణకు, $\frac {5}{2}$ అంటే $2 + \frac {1}{2}$ కి సమానం, ఎందుకంటే ఇందులో రెండు పూర్ణాంకాలు మరియు ఒక అదనపు సగం ఉన్నాయి [S1].

## మిశ్రమ భిన్నాలు (Mixed Fractions)

మిశ్రమ భిన్నం (mixed fraction) అంటే ఒక పూర్ణాంకానికి, ప్రథమ భిన్నాన్ని కలపడం. అపధార భిన్నాన్ని సులభంగా రాయడానికి ఇది ఉపయోగపడుతుంది. లవాన్ని హారంతో భాగించి, శేషాన్ని (remainder) కొత్త లవంగా తీసుకోవడం ద్వారా అపధార భిన్నంలో ఎన్ని పూర్ణాంకాలు ఉన్నాయో తెలుసుకోవచ్చు. ఉదాహరణకు, $\frac { 3 } { 2 } = 1 + \frac {1}{2} = 1\frac {1}{2}$ [S1]. అంటే $\frac { 3 } { 2 }$ అనేది ఒకటిన్నరకు సమానమైన ఒక మిశ్రమ భిన్నం.

## ఏకక భిన్నాలు (Unit Fractions)

ఏకక భిన్నం (unit fraction) అనేది ఒక ప్రత్యేక రకమైన ప్రథమ భిన్నం, ఇందులో లవం ఖచ్చితంగా $1$ ఉంటుంది. సమాన భాగాలుగా విభజించిన ఒక పూర్తి వస్తువులోని ఒక భాగాన్ని మాత్రమే ఇది సూచిస్తుంది. ఉదాహరణకు, $\frac {1}{2}, \frac {1}{3}$ మరియు $\frac {1}{4}$ ఇవన్నీ ఏకక భిన్నాలే [S1, S2]. మీరు ఏకక భిన్నాలను కలిపినప్పుడు, మీకు ఆ సమాన భాగాలు ఎన్ని ఉన్నాయో లెక్కిస్తున్నట్లు లెక్క.

## సాధించిన ఉదాహరణ

ఒక ఆచరణాత్మక పరిస్థితిని చూద్దాం. మీనా ఒక చిక్కీ ముక్కలో $\frac { 1 } { 2 }$ వంతు తింది, ఆమె తమ్ముడు అదే ముక్కలో $\frac { 1 } { 4 }$ వంతు తిన్నాడు [S2]. ఇద్దరూ కలిపి ఎంత తిన్నారో తెలుసుకోవడానికి, మనం ఈ భిన్నాలను కలపవచ్చు. ముందుగా, మనం ఒక సామాన్య హారాన్ని (common denominator) కనుక్కోవాలి. ఇక్కడ హారాలు $2$ మరియు $4$. $2$ మరియు $4$ ల కనిష్ట సామాన్య గుణిజం (least common multiple) $4$ [S2]. లవం మరియు హారాన్ని $2$ తో గుణించడం ద్వారా $\frac { 1 } { 2 }$ ని $4$ హారంగా ఉన్న సమాన భిన్నంగా మారుస్తాం. దీనివల్ల మనకు $\frac { 2 } { 4 }$ వస్తుంది. ఇప్పుడు మనం భిన్నాలను కలపవచ్చు. మనకు $\frac { 2 } { 4 } + \frac { 1 } { 4 } = \frac { 3 } { 4 }$ వస్తుంది. కాబట్టి, మీనా మరియు ఆమె తమ్ముడు ఇద్దరూ కలిపి మొత్తం చిక్కీలో $\frac { 3 } { 4 }$ వంతు తిన్నారు [S2].

## ముఖ్య అంశాలు

- ప్రథమ భిన్నాలలో లవం హారం కంటే చిన్నగా ఉంటుంది మరియు వాటి విలువ ఒకటి కంటే తక్కువే ఉంటుంది [S1].
- అపధార భిన్నాలలో లవం హారం కంటే పెద్దగా ఉంటుంది మరియు వాటి విలువ ఒకటి కంటే ఎక్కువగా ఉంటుంది [S1].
- మిశ్రమ భిన్నాలు ఒక పూర్ణాంకానికి, ప్రథమ భిన్నాన్ని కలపడం ద్వారా ఏర్పడతాయి [S1].
- ఏకక భిన్నాలలో లవం ఖచ్చితంగా $1$ ఉంటుంది [S1, S2].
- వేర్వేరు హారాలు ఉన్న భిన్నాలను కలపాలంటే, ముందుగా సామాన్య హారం ఉన్న సమాన భిన్నాలను కనుక్కొని, ఆపై లవాలను కలపాలి [S2].
