# Fractions

Fractions are numbers of the form $\frac{a}{b}$ that represent parts of a whole [S2]. They are essential in everyday life, from splitting a chocolate bar among friends to measuring ingredients for a recipe. Understanding fractions allows you to work with parts of quantities, which is a fundamental skill in mathematics.

## Parts of a Whole

A fraction describes a portion of a single unit. If you have one whole object and divide it into equal pieces, each piece is a fraction of the whole. For example, if you cut a piece of chikki into two equal parts, each part is $\frac{1}{2}$ of the whole. If you cut it into four equal parts, each part is $\frac{1}{4}$ of the whole [S1]. The line in a fraction separates the numerator, which tells you how many parts you have, from the denominator, which tells you how many equal parts make up the whole.

## Fractions Greater Than One

Sometimes, a fraction is larger than one whole unit. This happens when the numerator is larger than the denominator [S2]. For example, $\frac{3}{2}$ means you have three pieces of size $\frac{1}{2}$. Since two pieces of size $\frac{1}{2}$ make one whole, $\frac{3}{2}$ is equal to $1 + \frac{1}{2}$ [S2]. Similarly, $\frac{5}{2}$ is equal to $2 + \frac{1}{2}$ [S2]. You can think of these as mixed fractions, which combine a whole number with a proper fraction [S2].

## Equivalent Fractions

Equivalent fractions are different fractions that represent the same length or value [S3]. For example, $\frac{1}{2}$ and $\frac{2}{4}$ are equivalent because they both represent the same portion of a whole [S3]. You can find equivalent fractions by multiplying or dividing both the numerator and the denominator by the same non-zero number [S3]. For instance, $\frac{1}{2} = \frac{2}{4} = \frac{4}{8}$ [S3]. A fraction wall is a useful tool to visualize these equivalent fractions, showing that different fractional units can have the same length [S3].

## Adding Fractions

To add fractions, you must first ensure they have the same fractional unit, or denominator [S1]. If the denominators are different, you need to convert the fractions into equivalent fractions with a common denominator [S1].

**Adding Fractions with the Same Denominator**

When fractions have the same denominator, you simply add the numerators and keep the denominator the same [S1]. For example, to find the sum of $\frac{2}{5}$ and $\frac{1}{5}$, you add the numerators: $2 + 1 = 3$. The result is $\frac{3}{5}$ [S1]. This is because each fraction represents parts of the same size, so you are just counting the total number of those parts [S1].

**Adding Fractions with Different Denominators**

When fractions have different denominators, you must find a common denominator [S1]. The easiest way is to multiply the denominators together [S1]. For example, to add $\frac{1}{4}$ and $\frac{1}{3}$, you find a common denominator of $12$ [S1]. You convert $\frac{1}{4}$ to $\frac{3}{12}$ and $\frac{1}{3}$ to $\frac{4}{12}$ [S1]. Then, you add the numerators: $3 + 4 = 7$. The sum is $\frac{7}{12}$ [S1].

**Brahmagupta’s Method**

The method for adding fractions with different denominators was first explicitly described by Brahmagupta in the year 628 CE [S1]. The steps are as follows:

1. Find equivalent fractions so that the fractional unit is common for all fractions. This can be done by finding a common multiple of the denominators, such as the product of the denominators or the smallest common multiple [S1].
2. Add these equivalent fractions with the same fractional units by adding the numerators and keeping the same denominator [S1].
3. Express the result in lowest terms if needed [S1].

For example, to add $\frac{2}{3}$ and $\frac{1}{5}$, the smallest common multiple of 3 and 5 is 15 [S1]. You convert $\frac{2}{3}$ to $\frac{10}{15}$ and $\frac{1}{5}$ to $\frac{3}{15}$ [S1]. Adding these gives $\frac{13}{15}$ [S1].

## Worked example

Let us apply Brahmagupta’s method to find the sum of $\frac{3}{8}$ and $\frac{1}{6}$.

First, find the smallest common multiple of 8 and 6, which is 24 [S1]. Convert $\frac{3}{8}$ to $\frac{9}{24}$ by multiplying the numerator and denominator by 3 [S1]. Convert $\frac{1}{6}$ to $\frac{4}{24}$ by multiplying the numerator and denominator by 4 [S1].

Now, add the numerators: $9 + 4 = 13$ [S1]. The sum is $\frac{13}{24}$ [S1].

## Key points

- A fraction $\frac{a}{b}$ represents $a$ parts of a whole divided into $b$ equal parts [S2].
- Fractions greater than one have a numerator larger than the denominator [S2].
- Equivalent fractions, such as $\frac{1}{2}$ and $\frac{2}{4}$, represent the same value [S3].
- To add fractions, they must have the same denominator [S1].
- Brahmagupta’s method provides a systematic way to add fractions with different denominators by finding a common denominator [S1].
- The result of adding fractions should be expressed in lowest terms if necessary [S1].
