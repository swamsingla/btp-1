
# ଭଗ୍ନାଂଶର ପ୍ରକାରଭେଦ

ଭଗ୍ନାଂଶ ହେଉଛି ଏକ ସମ୍ପୂର୍ଣ୍ଣ ବସ୍ତୁର ଅଂଶଗୁଡ଼ିକୁ ଦର୍ଶାଇବାର ଏକ ଉପାୟ। ବିଭିନ୍ନ ପ୍ରକାରର ଭଗ୍ନାଂଶକୁ ବୁଝିବା ଦ୍ୱାରା, ଆପଣ ସମ୍ପୂର୍ଣ୍ଣ ସଂଖ୍ୟା ନଥିବା ସଂଖ୍ୟାଗୁଡ଼ିକ ସହିତ ସହଜରେ କାମ କରିପାରିବେ। ଏହା ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ କାରଣ ଯେତେବେଳେ ଆପଣ ଉପାଦାନଗୁଡ଼ିକୁ ମାପିବେ, ପିଜା ବାଣ୍ଟିବେ, କିମ୍ବା ଦୂରତା ହିସାବ କରିବେ, ସେତେବେଳେ ଆପଣ ଏହି ପ୍ରକାରଗୁଡ଼ିକୁ ବ୍ୟବହାର କରିବେ।

## ପ୍ରପର ଭଗ୍ନାଂଶ (Proper fraction)

ଏକ ପ୍ରପର ଭଗ୍ନାଂଶ ହେଉଛି ଏପରି ଏକ ଭଗ୍ନାଂଶ ଯେଉଁଠାରେ ଲବ (numerator) ହର (denominator) ଠାରୁ ଛୋଟ ହୋଇଥାଏ। ଏହାର ଅର୍ଥ ହେଉଛି ଭଗ୍ନାଂଶର ମୂଲ୍ୟ ସର୍ବଦା ଏକ ଏକକରୁ କମ୍ ହୋଇଥାଏ [S1]। ଯେତେବେଳେ ଆପଣ ଏକ ସଂଖ୍ୟା ରେଖାକୁ ଦେଖିବେ, ଏହି ଭଗ୍ନାଂଶଗୁଡ଼ିକ ଶୂନ୍ୟ ଏବଂ ଏକ ମଧ୍ୟରେ ରହିବ। ଉଦାହରଣ ସ୍ୱରୂପ, ଯଦି ଆପଣ ଏକ ଖଣ୍ଡ ଚିକ୍ତି ନିଅନ୍ତି ଏବଂ ଏହାର $\frac { 1 } { 2 }$ ଅଂଶ ଖାଆନ୍ତି, ତେବେ ଆପଣ ଏକ ପ୍ରପର ଭଗ୍ନାଂଶ ଖାଇଛନ୍ତି କାରଣ ଲବ $1$ ହର $2$ ଠାରୁ ଛୋଟ ଅଟେ [S2]।

## ଇମପ୍ରପର ଭଗ୍ନାଂଶ (Improper fraction)

ଏକ ଇମପ୍ରପର ଭଗ୍ନାଂଶ ହେଉଛି ଏପରି ଏକ ଭଗ୍ନାଂଶ ଯେଉଁଠାରେ ଲବ ହର ଠାରୁ ବଡ଼ ହୋଇଥାଏ। ଏହାର ଅର୍ଥ ହେଉଛି ଭଗ୍ନାଂଶର ମୂଲ୍ୟ ଏକ ଏକକରୁ ଅଧିକ ହୋଇଥାଏ [S1]। ଉଦାହରଣ ସ୍ୱରୂପ, $\frac {3}{2}, \frac {5}{2}$ ଏବଂ $\frac { 7 } { 2 }$ ସମସ୍ତେ 1 ଏକକରୁ ବଡ଼ ଅଟନ୍ତି [S1]। ସେଗୁଡ଼ିକରେ କେତୋଟି ସମ୍ପୂର୍ଣ୍ଣ ଏକକ ଅଛି ତାହା ଦେଖିବା ପାଇଁ ଆପଣ ସେଗୁଡ଼ିକୁ ଭାଙ୍ଗି ପାରିବେ। ଉଦାହରଣ ସ୍ୱରୂପ, $\frac {5}{2}$ ସମାନ $2 + \frac {1}{2}$ କାରଣ ଏଥିରେ ଦୁଇଟି ସମ୍ପୂର୍ଣ୍ଣ ଏକକ ଏବଂ ଗୋଟିଏ ଅତିରିକ୍ତ ଅଧା ଅଛି [S1]।

## ମିକ୍ସଡ୍ ଭଗ୍ନାଂଶ (Mixed fraction)

ଏକ ମିକ୍ସଡ୍ ଭଗ୍ନାଂଶ ଏକ ସମ୍ପୂର୍ଣ୍ଣ ସଂଖ୍ୟାକୁ ଏକ ପ୍ରପର ଭଗ୍ନାଂଶ ସହିତ ଯୋଡ଼ିଥାଏ। ଏହା ଏକ ଇମପ୍ରପର ଭଗ୍ନାଂଶକୁ ଲେଖିବାର ଏକ ଉପଯୋଗୀ ଉପାୟ। ଆପଣ ଲବକୁ ହର ଦ୍ୱାରା ଭାଗ କରି ଏବଂ ଅବଶିଷ୍ଟ (remainder) କୁ ନୂଆ ଲବ ଭାବରେ ରଖି ଏକ ଇମପ୍ରପର ଭଗ୍ନାଂଶରେ କେତୋଟି ସମ୍ପୂର୍ଣ୍ଣ ଏକକ ଅଛି ତାହା ଜାଣିପାରିବେ। ଉଦାହରଣ ସ୍ୱରୂପ, $\frac { 3 } { 2 } = 1 + \frac {1}{2} = 1\frac {1}{2}$ [S1]। ଏହାର ଅର୍ଥ ହେଉଛି $\frac { 3 } { 2 }$ ହେଉଛି ଏକ ମିକ୍ସଡ୍ ଭଗ୍ନାଂଶ ଯାହା ଏକ ଏବଂ ଅଧା ସହିତ ସମାନ।

## ୟୁନିଟ୍ ଭଗ୍ନାଂଶ (Unit fraction)

ଏକ ୟୁନିଟ୍ ଭଗ୍ନାଂଶ ହେଉଛି ଏକ ସ୍ୱତନ୍ତ୍ର ପ୍ରକାରର ପ୍ରପର ଭଗ୍ନାଂଶ ଯେଉଁଠାରେ ଲବ ଠିକ୍ $1$ ହୋଇଥାଏ। ଏହା ସମାନ ଭାଗରେ ବିଭକ୍ତ ହୋଇଥିବା ଏକ ସମ୍ପୂର୍ଣ୍ଣ ବସ୍ତୁର ଠିକ୍ ଗୋଟିଏ ଅଂଶକୁ ଦର୍ଶାଏ। ଉଦାହରଣ ସ୍ୱରୂପ, $\frac {1}{2}, \frac {1}{3}$ ଏବଂ $\frac {1}{4}$ ସମସ୍ତେ ୟୁନିଟ୍ ଭଗ୍ନାଂଶ ଅଟନ୍ତି [S1, S2]। ଯେତେବେଳେ ଆପଣ ୟୁନିଟ୍ ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ଏକାଠି ଯୋଗ କରନ୍ତି, ଆପଣ କେବଳ ଗଣନା କରୁଛନ୍ତି ଯେ ଆପଣଙ୍କ ପାଖରେ ସେହି ସମାନ ଅଂଶଗୁଡ଼ିକ ମଧ୍ୟରୁ କେତୋଟି ଅଛି।

## ସମାଧାନ କରାଯାଇଥିବା ଉଦାହରଣ (Worked example)

ଆସନ୍ତୁ ଏକ ବାସ୍ତବ ପରିସ୍ଥିତିକୁ ଦେଖିବା। ମୀନା ଏକ ଖଣ୍ଡ ଚିକ୍ତିର $\frac { 1 } { 2 }$ ଅଂଶ ଖାଇଲା ଏବଂ ତା'ର ସାନ ଭାଇ ସେହି ସମାନ ଖଣ୍ଡର $\frac { 1 } { 4 }$ ଅଂଶ ଖାଇଲା [S2]। ସେମାନେ ଏକାଠି କେତେ ଖାଇଲେ ତାହା ଜାଣିବା ପାଇଁ, ଆମେ ଏହି ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ଯୋଗ କରିପାରିବା। ପ୍ରଥମେ, ଆମକୁ ଏକ ସାଧାରଣ ହର (common denominator) ଖୋଜିବାକୁ ପଡ଼ିବ। ହରଗୁଡ଼ିକ ହେଉଛି $2$ ଏବଂ $4$। $2$ ଏବଂ $4$ ର ସର୍ବନିମ୍ନ ସାଧାରଣ ଗୁଣିତକ (least common multiple) ହେଉଛି $4$ [S2]। ଆମେ ଲବ ଏବଂ ହରକୁ $2$ ଦ୍ୱାରା ଗୁଣନ କରି $\frac { 1 } { 2 }$ କୁ $4$ ହର ବିଶିଷ୍ଟ ଏକ ସମାନ ଭଗ୍ନାଂଶରେ ପରିଣତ କରୁ। ଏହା ଆମକୁ $\frac { 2 } { 4 }$ ଦିଏ। ବର୍ତ୍ତମାନ ଆମେ ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ଯୋଗ କରିପାରିବା। ଆମ ପାଖରେ $\frac { 2 } { 4 } + \frac { 1 } { 4 } = \frac { 3 } { 4 }$ ଅଛି। ତେଣୁ, ମୀନା ଏବଂ ତା'ର ଭାଇ ଏକାଠି ମୋଟ ଚିକ୍ତିର $\frac { 3 } { 4 }$ ଅଂଶ ଖାଇଲେ [S2]।

## ମୁଖ୍ୟ ବିନ୍ଦୁ (Key points)

- ପ୍ରପର ଭଗ୍ନାଂଶଗୁଡ଼ିକର ଲବ ହର ଠାରୁ ଛୋଟ ହୋଇଥାଏ ଏବଂ ମୂଲ୍ୟ ଏକ ଏକକରୁ କମ୍ ହୋଇଥାଏ [S1]।
- ଇମପ୍ରପର ଭଗ୍ନାଂଶଗୁଡ଼ିକର ଲବ ହର ଠାରୁ ବଡ଼ ହୋଇଥାଏ ଏବଂ ମୂଲ୍ୟ ଏକ ଏକକରୁ ଅଧିକ ହୋଇଥାଏ [S1]।
- ମିକ୍ସଡ୍ ଭଗ୍ନାଂଶ ଏକ ସମ୍ପୂର୍ଣ୍ଣ ସଂଖ୍ୟାକୁ ଏକ ପ୍ରପର ଭଗ୍ନାଂଶ ସହିତ ଯୋଡ଼ିଥାଏ [S1]।
- ୟୁନିଟ୍ ଭଗ୍ନାଂଶଗୁଡ଼ିକର ଲବ ଠିକ୍ $1$ ହୋଇଥାଏ [S1, S2]।
- ବିଭିନ୍ନ ହର ଥିବା ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ଯୋଗ କରିବା ପାଇଁ, ପ୍ରଥମେ ଏକ ସାଧାରଣ ହର ଥିବା ସମାନ ଭଗ୍ନାଂଶ ଖୋଜନ୍ତୁ ଏବଂ ତାପରେ ଲବଗୁଡ଼ିକୁ ଯୋଗ କରନ୍ତୁ [S2]।
