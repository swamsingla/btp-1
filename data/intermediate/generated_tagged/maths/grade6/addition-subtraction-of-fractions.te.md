
# భిన్నాల కూడిక మరియు తీసివేత

మన దైనందిన జీవితంలో భిన్నాలు (Fractions) ప్రతిచోటా ఉంటాయి. మీరు స్నేహితుడితో పంచుకోవడానికి ఒక చాక్లెట్ బార్‌ను సమాన భాగాలుగా కత్తిరించవచ్చు లేదా ఒక వంటకం కోసం $\frac { 1 } { 2 }$ కప్పు పిండి వంటి పదార్థాలను కొలవవచ్చు. భిన్నాలను కలపడం మరియు తీసివేయడం వల్ల ఈ సమాన భాగాలను కలపడానికి లేదా తీసివేయడానికి సహాయపడుతుంది. ముక్కలు ఒకే పరిమాణంలో ఉన్నప్పుడు, గణితం సులభం. ముక్కలు వేర్వేరు పరిమాణాల్లో ఉన్నప్పుడు, మీరు వాటిని కలపడానికి లేదా తీసివేయడానికి ముందు వాటిని సమానంగా చేయడానికి ఒక ప్రత్యేక ట్రిక్ అవసరం.

## ఒకే హారం (Denominator) ఉన్న భిన్నాలను కలపడం

భిన్నాలకు ఒకే హారం (denominator) ఉన్నప్పుడు, భిన్నం యొక్క భాగం (fractional unit) ఒకటే [S1]. అంటే ముక్కలన్నీ ఒకే పరిమాణంలో ఉంటాయి. మీరు లవాలను (numerators) సులభంగా కలిపి, హారాన్ని (denominator) అలాగే ఉంచవచ్చు. 

ఉదాహరణకు, $\frac { 2 } { 5 }$ మరియు $\frac { 1 } { 5 }$ లను పరిగణించండి. [S1] రెండు భిన్నాలు $\frac { 1 } { 5 }$ అనే భిన్న భాగాన్ని ఉపయోగిస్తాయి, కాబట్టి ప్రతి పట్టీ 5 సమాన భాగాలుగా విభజించబడింది. $\frac { 2 } { 5 }$ అనే భిన్నం ఈ భాగాలలో 2 ని సూచిస్తుంది, మరియు $\frac { 1 } { 5 }$ 1 భాగాన్ని సూచిస్తుంది. మీరు వాటిని కలిపినప్పుడు, మీరు కేవలం షేడ్ చేసిన భాగాల మొత్తం సంఖ్యను లెక్కిస్తున్నారు. [S1] మొత్తంగా 3 షేడ్ చేసిన భాగాలు ఉన్నాయి, కాబట్టి మొత్తం $\frac { 3 } { 5 }$ అవుతుంది.

మరొక ఉదాహరణ $\frac { 4 } { 7 }$ మరియు $\frac { 6 } { 7 }$ లను కలపడం. [S1] హారం 7 కాబట్టి, ప్రతి భిన్నం $\frac { 1 } { 7 }$ పరిమాణంలో ఉన్న భాగాలను సూచిస్తుంది. మీరు లవాలను కలుపుతారు: 4 ప్లస్ 6 సమానం 10. ఇది మీకు $\frac { 1 0 } { 7 }$ ఇస్తుంది. [S1] ముక్కలు అప్పటికే ఒకే పరిమాణంలో ఉన్నందున మీరు హారాన్ని మార్చాల్సిన అవసరం లేదు.

## వేర్వేరు హారాలు (Denominators) ఉన్న భిన్నాలను కలపడం

భిన్నాలకు వేర్వేరు హారాలు ఉన్నప్పుడు, భిన్న భాగాలు వేరుగా ఉంటాయి [S1]. ముక్కలు వేర్వేరు పరిమాణాల్లో ఉన్నందున మీరు లవాలను నేరుగా కలపలేరు. వాటిని కలపడానికి, మీరు మొదట భిన్నాలను ఒకే హారం ఉన్న సమాన భిన్నాలుగా (equivalent fractions) మార్చాలి. [S1] ఇది మీకు ఒక సాధారణ భిన్న భాగాన్ని ఇస్తుంది.

$\frac { 1 } { 4 }$ మరియు $\frac { 1 } { 3 }$ ల మొత్తాన్ని కనుక్కుందాం. [S1] హారాలు 4 మరియు 3. మనకు ఒక సామాన్య హారం (common denominator) కావాలి. హారాల లబ్ధం, 3 గుణించగా 4, మనకు 12 ఇస్తుంది. [S1] మనం 12 హారంతో సమాన భిన్నాలను రాయవచ్చు. $\frac { 1 } { 4 } ,$ కోసం, మనం లవం మరియు హారాన్ని 3 తో గుణించి $\frac { 3 } { 1 2 } .$ పొందుతాము. [S1] $\frac { 1 } { 3 } ,$ కోసం, మనం లవం మరియు హారాన్ని 4 తో గుణించి $\frac { 4 } { 1 2 } .$ పొందుతాము. [S1] ఇప్పుడు రెండు భిన్నాలకు ఒకే భిన్న భాగం, $\frac { 1 } { 1 2 }$ ఉంది. [S1] మనం లవాలను కలపవచ్చు: 3 ప్లస్ 4 సమానం 7. మొత్తం $\frac { 7 } { 1 2 } .$ అవుతుంది. [S1]

## భిన్నాలను కలపడానికి బ్రహ్మగుప్తుని పద్ధతి

భిన్నాలను కలపడానికి స్పష్టమైన పద్ధతి మొదట 628 CE సంవత్సరంలో బ్రహ్మగుప్తునిచే సాధారణీకరించబడింది [S1]. ఈ పద్ధతి కేవలం రెండు మాత్రమే కాకుండా ఎన్ని భిన్నాలనైనా కలపడానికి పనిచేస్తుంది. ఇందులో మూడు సాధారణ దశలు ఉంటాయి.

మొదట, భిన్న భాగం అన్ని భిన్నాలకు సాధారణంగా ఉండేలా సమాన భిన్నాలను కనుగొనండి. [S1] హారాల యొక్క సామాన్య గుణిజం (common multiple) కనుగొనడం ద్వారా మీరు దీన్ని చేస్తారు. ఇది హారాల లబ్ధం కావచ్చు లేదా కనిష్ట సామాన్య గుణిజం [S1] కావచ్చు, దీనిని LCM అని పిలుస్తారు.

రెండవది, ఈ సమాన భిన్నాలను ఒకే భిన్న భాగాలతో కలపండి. [S1] లవాలను కలిపి, అదే హారాన్ని ఉంచడం ద్వారా మీరు దీన్ని చేస్తారు.

మూడవది, అవసరమైతే ఫలితాన్ని అత్యల్ప రూపంలో (lowest terms) వ్యక్తపరచండి. [S1]

$\frac { 2 } { 3 }$ మరియు $\frac { 1 } { 5 }$ ల మొత్తాన్ని కనుగొనడానికి ఈ పద్ధతిని వర్తింపజేద్దాం. [S1] హారాలు 3 మరియు 5. 3 మరియు 5 ల LCM 15. [S1] మనం భిన్నాలను మారుస్తాము: $\frac { 2 } { 3 } = \frac { 2 \times 5 } { 3 \times 5 } = \frac { 1 0 } { 1 5 } ,$ మరియు $\frac { 1 } { 5 } = \frac { 1 \times 3 } { 5 \times 3 } = \frac { 3 } { 1 5 } . [S1]$ ఇప్పుడు మనం లవాలను కలుపుతాము: $\frac { 1 0 } { 1 5 } + \frac { 3 } { 1 5 } = \frac { 1 3 } { 1 5 } . [S1]$

## భిన్నాలను తీసివేయడం

భిన్నాలను తీసివేయడం అనేది కూడిక లాంటి అదే తర్కాన్ని అనుసరిస్తుంది. భిన్నాలకు ఒకే హారం ఉంటే, మీరు లవాలను తీసివేసి, హారాన్ని అలాగే ఉంచుతారు. [S1] భిన్నాలకు వేర్వేరు హారాలు ఉంటే, కూడికలో వలె మీరు మొదట సామాన్య హారంతో సమాన భిన్నాలను కనుగొంటారు. [S1] అప్పుడు మీరు లవాలను తీసివేస్తారు.

ఉదాహరణకు, $\frac { 1 } { 3 }$ నుండి $\frac { 1 } { 6 }$ ను తీసివేయడానికి, 6 మరియు 3 ల కనిష్ట సామాన్య గుణిజం 6 అని మీరు మొదట గమనించండి. [S1] మీరు $\frac { 1 } { 3 }$ ను $\frac { 2 } { 6 } .$ గా తిరిగి వ్రాస్తారు. [S1] ఇప్పుడు మీరు లవాలను తీసివేయవచ్చు: $\frac { 2 } { 6 } - \frac { 1 } { 6 } = \frac { 1 } { 6 } . [S1]$

## సాధించిన ఉదాహరణ (Worked example)

మీరు పండ్ల సలాడ్ తయారు చేస్తున్నారని ఊహించుకోండి. మీరు $\frac { 2 } { 9 }$ కప్పు ఆపిల్స్ మరియు $\frac { 1 } { 6 }$ కప్పు అరటిపండ్లను కలుపుతారు. పండ్ల మొత్తం మొత్తాన్ని కనుగొనడానికి, మీరు ఈ భిన్నాలను కలపాలి. హారాలు 9 మరియు 6. 9 మరియు 6 ల LCM 18. [S1] మీరు భిన్నాలను మారుస్తారు: $\frac { 2 } { 9 } = \frac { 2 \times 2 } { 9 \times 2 } = \frac { 4 } { 1 8 } ,$ మరియు $\frac { 1 } { 6 } = \frac { 1 \times 3 } { 6 \times 3 } = \frac { 3 } { 1 8 } . [S1]$ ఇప్పుడు మీరు లవాలను కలుపుతారు: $\frac { 4 } { 1 8 } + \frac { 3 } { 1 8 } = \frac { 7 } { 1 8 } . [S1]$ మీరు మీ సలాడ్‌కు $\frac { 7 } { 1 8 }$ కప్పు పండ్లను కలిపారు.

## ముఖ్య అంశాలు (Key points)

*   ఒకే హారం ఉన్న భిన్నాలను కలపడం లేదా తీసివేయడం చేసినప్పుడు, మీరు లవాలను కలుపుతారు లేదా తీసివేస్తారు మరియు హారాన్ని అలాగే ఉంచుతారు [S1].
*   వేర్వేరు హారాలు ఉన్న భిన్నాలను కలపడం లేదా తీసివేయడం చేసినప్పుడు, మీరు మొదట సామాన్య హారంతో సమాన భిన్నాలను కనుగొనాలి [S1].
*   హారాల లబ్ధాన్ని లేదా కనిష్ట సామాన్య గుణిజాన్ని [S1] తీసుకోవడం ద్వారా సామాన్య హారాన్ని కనుగొనవచ్చు.
*   భిన్నాలను కలపడానికి బ్రహ్మగుప్తుని పద్ధతిలో మూడు దశలు ఉంటాయి: సామాన్య హారంతో సమాన భిన్నాలను కనుగొనడం, లవాలను కలపడం మరియు అవసరమైతే ఫలితాన్ని అత్యల్ప రూపంలో వ్యక్తపరచడం [S1].
*   ఒకే హారంతో సమాన భిన్నాలను కనుగొనడం ద్వారా భిన్నాలను ఎలా పోల్చాలో మీకు ఇప్పటికే తెలిసి ఉండవచ్చు [S2]; అదే నైపుణ్యం ఇక్కడ ఉపయోగించబడుతుంది.
