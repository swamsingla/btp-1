# Simple Equations in One Variable

A simple equation in one variable is a statement that two algebraic expressions are equal. The variable is a letter-number that represents an unknown value we need to find. Solving the equation means finding the specific value of the variable that makes the Left Hand Side (LHS) equal to the Right Hand Side (RHS). This skill helps us solve everyday problems, like finding the weight of an unknown object or the position of a pattern, in a systematic way.

## Balancing the Equation

When a weighing scale is balanced, it means the total weight on both sides is exactly the same. If we remove equal weights from both plates, the scale remains balanced. Equations have a similar property: if we perform the same mathematical operation on both sides, the equality is preserved. Because addition and subtraction are inverse operations, we can use them to remove terms from one side and isolate the unknown.

For example, consider the equation $14593 - 1459 + 145 - 14 + 88 = 13353$. To find the value of the expression $14593 - 1459 + 145 - 14$, we do not need to calculate the entire left side. We can simply subtract 88 from both sides to remove the term and find the answer directly [S2].

## Isolating the Unknown

To solve an equation systematically, we need to isolate the unknown variable on one side. We do this by using inverse operations to remove constants and coefficients. If a number is added to the variable, we subtract that number from both sides. If the variable is multiplied by a number, we divide both sides by that number.

Let us look at the equation $5x - 4 = 7$. To isolate the term $5x$, we add 4 to both sides. This gives $5x - 4 + 4 = 7 + 4$, which simplifies to $5x = 11$. To isolate $x$, we divide both sides by 5. This gives $\frac{5x}{5} = \frac{11}{5}$, so $x = \frac{11}{5}$.

We can check this solution by substituting $x = \frac{11}{5}$ back into the original equation. The LHS becomes $5 \times \frac{11}{5} - 4$, which equals $11 - 4 = 7$. Since the LHS equals the RHS, the solution is correct [S2].

## Equations with Variables on Both Sides

Sometimes, an equation has the unknown on both sides, such as $6y + 7 = 4y + 21$. To solve this, we first need to bring all the unknown terms to one side. We can subtract $4y$ from both sides. This gives $6y - 4y + 7 = 21$, which simplifies to $2y + 7 = 21$. Next, we subtract 7 from both sides to isolate the term $2y$, giving $2y = 14$. Finally, dividing both sides by 2 gives $y = 7$ [S2].

## Worked example

Consider a matchstick arrangement where the number of sticks in the $n^{\text{th}}$ position is given by the formula $2n + 1$. We want to find the position number of an arrangement that uses exactly 99 matchsticks. We set up the equation $2n + 1 = 99$. To isolate $2n$, we subtract 1 from both sides, resulting in $2n = 98$. Dividing both sides by 2 gives $n = 49$. Therefore, the position number is 49 [S1].

## Key points

* An equation is a statement of equality between two algebraic expressions.
* Solving the equation means finding the value of the variable that makes the LHS equal to the RHS.
* You can add, subtract, multiply, or divide the same number on both sides of an equation without breaking the equality.
* Use inverse operations to remove constants and coefficients, isolating the unknown variable step by step.
* Always check your solution by substituting the value back into the original equation to verify that the LHS equals the RHS.
