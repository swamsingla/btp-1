2.3 ఒక బహుపది యొక్క సున్నాలు

9వ తరగతి | అధ్యాయం 2: బహుపదులు

1. అవసరమైనవి

ఈ అంశంలోకి ప్రవేశించే ముందు, మీరు అర్థం చేసుకున్నారని నిర్ధారించుకోండి:

  • ప్రత్యామ్నాయం**: వ్యక్తీకరణలలో చరరాశులను సంఖ్యా విలువలతో భర్తీ చేయడం (ఉదాహరణకు, లెక్కింపు $ p(1) $ బహుపది కొరకు $ p(x) $).
  • సమీకరణాలు: సాధారణ సమీకరణాలను పరిష్కరించడం వంటివి $ ax + b = 0 $.
  • ఒక వేరియబుల్ లో బహుపదులు: లాంటి వ్యక్తీకరణలను గుర్తించడం $ 5x^3 - 2x^2 + 3x - 2 $ బహుపదులుగా $ x $.

ఈ నైపుణ్యాలు బహుపదుల యొక్క సున్నాలు ను గుర్తించడానికి పునాదిని ఏర్పరుస్తాయి.

2. పరిచయం

బహుపది లో సంఖ్యలను సున్నాకు సమానం అయ్యే వరకు ప్రతిక్షేపిస్తున్నట్లు ఊహించుకోండి—ఆ సంఖ్యలను సున్నాలు అంటారు! అటువంటి విలువలను ఎలా కనుగొనాలో మరియు వాటి ప్రాముఖ్యతను ఎలా అర్థం చేసుకోవాలో ఈ అంశం వివరిస్తుంది. బహుపది ఎప్పుడు సున్నాకు సమానమవుతుందో మరియు ఇది సమీకరణాలను పరిష్కరించడానికి ఎలా సంబంధం కలిగి ఉంటుందో మీరు తెలుసుకుంటారు. చివరికి, సున్నాలు సమీకరణాల మూలాలకు మరియు బహుపది ప్రవర్తనకు ఎలా కనెక్ట్ అవుతుందో మీరు చూస్తారు.

ఇది ఒక వేరియబుల్ (విభాగం 2.2) లో బహుపదులతో మీ మునుపటి పనిని ఆధారంగా చేసుకుని, విభాగం 2.4 లో కారణాంకాల పద్ధతుల కోసం మిమ్మల్ని సిద్ధం చేస్తుంది.

3. వివరణ

3.1 సున్నాలు యొక్క నిర్వచనం

నిర్వచనం: ఒక ఒక బహుపది యొక్క సున్నా $ p(x) $ ఒక సంఖ్య $ c $ అలాగా $ p(c) = 0 $.

సున్నాను కనుగొనడానికి, ప్రతిక్షేపించండి $ c $ బహుపది లోకి ప్రవేశించి పరిష్కరించండి. $ c $ ఉదాహరణకు, దీని కోసం. $ p(x) = x - 1 $, అమరిక $ p(c) = 0 $ ఇస్తుంది $ c - 1 = 0 $ కాబట్టి, $ c = 1 $.

3.2 ప్రత్యేక సందర్భాలు

ప్రత్యేక సందర్భం 1: ఒక సున్నా కాని స్థిర బహుపది (ఉదాహరణకు, $ p(x) = 5 $) కి సున్నాలు లేదు, ఎందుకంటే ఏదైనా విలువను ప్రతిక్షేపిస్తే $ x $ ఎల్లప్పుడూ 5కి దారితీస్తుంది.

ప్రత్యేక సందర్భం 2: సున్నా బహుపది (ఉదాహరణకు, $ p(x) = 0 $) సంప్రదాయం ప్రకారం ప్రతి వాస్తవ సంఖ్య ను సున్నాగా కలిగి ఉంటుంది.

3.3 సరళ బహుపదులు

రేఖీయ బహుపది కొరకు $ p(x) = ax + b $ (ఎక్కడ $ a \neq 0 $), సున్నాను కనుగొనడానికి పరిష్కరించాలి. $ ax + b = 0 $.

$$ ax + b = 0 \implies x = -\frac{b}{a} $$

ఉదాహరణ: కొరకు $ p(x) = 2x + 1 $ సున్నా అనేది $ x = -\frac{1}{2} $.

3.4 సాధారణ పద్ధతి

ఏదైనా బహుపది యొక్క సున్నాలు ను కనుగొనడానికి:

  1. అభ్యర్థి విలువను ప్రత్యామ్నాయంగా ఉపయోగించండి. $ c $ బహుపది లోకి.
  2. పరిష్కరించు $ p(c) = 0 $.
  3. సొల్యూషన్‌ను తిరిగి అసలైన బహుపదిలో ప్లగ్ చేయడం ద్వారా ధృవీకరించండి.

4. పరిష్కరించబడిన ఉదాహరణలు

ఉదాహరణ 1: బహుపది ను మూల్యాంకనం చేయడం

కనుగొను $ p(1) $ కొరకు $ p(x) = 5x^3 - 2x^2 + 3x - 2 $.

సమాధానం:

$$ p(1) = 5(1)^3 - 2(1)^2 + 3(1) - 2 = 5 - 2 + 3 - 2 = 4 $$

అప్పటి నుండి $ p(1) \neq 0 $ ఈ బహుపది యొక్క 1 సున్నా కాదు.

ఉదాహరణ 2: సున్నాలను తనిఖీ చేయడం

గుర్తుంచుకోండి. $ -2 $ ఒక సున్నా. $ p(x) = x + 2 $.

సమాధానం:

$$ p(-2) = (-2) + 2 = 0 $$

కాబట్టి, $ -2 $ ఒక సున్నా యొక్క $ p(x) $.

ఉదాహరణ 3: సున్నా కోసం పరిష్కరించడం

ఒక సున్నాను కనుగొనండి. $ p(x) = 4x^4 + 5x^3 - x^2 + 6 $.

సమాధానం:

ప్రయత్నించండి $ x = 0 $:

$$ p(0) = 4(0)^4 + 5(0)^3 - (0)^2 + 6 = 6 \neq 0 $$

ప్రయత్నించండి $ x = -1 $:

$$ p(-1) = 4(-1)^4 + 5(-1)^3 - (-1)^2 + 6 = 4 - 5 - 1 + 6 = 4 \neq 0 $$

స్పష్టమైన సున్నా లేదు; అధునాతన పద్ధతులు (ఫ్యాక్టరైజేషన్ వంటివి) అవసరం.

ఉదాహరణ 4: స్థిర బహుపది

సున్నా(ల)ను నిర్ణయించండి. $ p(x) = 5 $.

సమాధానం:

ఏదైనా ప్రత్యామ్నాయం చేయండి $ x $:

$$ p(x) = 5 \neq 0 \quad \text{(for all } x\text{)} $$

ముగింపు: ఈ బహుపది నకు **సున్నాలు లేదు.

ఉదాహరణ 5: సున్నా బహుపది

సున్నాలు యొక్క స్థితిని తెలపండి. $ p(x) = 0 $.

సమాధానం:

సాధారణంగా, **అన్ని వాస్తవ సంఖ్యలు లు సున్నా బహుపది యొక్క సున్నాలు.

5. సాధన సమస్యలు

🟢 సులభం

  1. కనుగొను $ p(2) $ కొరకు $ p(x) = 3x^2 - 4x + 1 $.
  2. ఉందా? $ 1 $ సున్నా యొక్క $ p(x) = x - 1 $ సరి చేయాలా? సమర్థించు.
  3. సున్నాను నిర్ణయించండి. $ p(x) = 7x - 14 $.

🟡 మధ్యస్థం

  1. గుర్తుంచుకోండి. $ -3 $ ఒక సున్నా. $ p(x) = 2x + 6 $.

  3. మూల్యాంకనం చేయండి $ p(0) $ కొరకు $ p(x) = 4x^3 - 2x + 5 $.

🔴 కఠినమైన

  1. బహుపది అని నిరూపించండి. $ p(x) = x^2 + 1 $ సున్నాలు నిజమైనది కాదు.
  2. ఇచ్చబడినది $ p(x) = ax^2 + bx + c $, పరిస్థితులను కనుగొనండి $ a, b, c $ బహుపది కు ఖచ్చితంగా ఒక సున్నా ఉండాలి.

  • సున్నాను కనుగొనడానికి, ప్రతిక్షేపించండి $ c $ బహుపది లోకి వెళ్లి పరిష్కరించండి. $ p(c) = 0 $.
  • సున్నా కాని స్థిరమైనది బహుపదులకు సున్నాలు ఉండదు.
  • సున్నా బహుపది అన్ని వాస్తవ సంఖ్యలు లను సున్నాలు గా కలిగి ఉంది.

  • బహుపది ప్రవర్తన మరియు కారకాలను అర్థం చేసుకోవడానికి సున్నాలు చాలా కీలకం.
