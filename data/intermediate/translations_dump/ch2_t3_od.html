2.3 ଏକ ବହୁପଦୀର ଶୂନ୍ୟଗୁଡ଼ିକ

ନବମ ଶ୍ରେଣୀ | ଅଧ୍ୟାୟ 2: ବହୁପଦୀ ସମୀକରଣ

1. ପୂର୍ବ ସର୍ତ୍ତାବଳୀ

ଏହି ବିଷୟରେ ଆଲୋଚନା କରିବା ପୂର୍ବରୁ, ଆପଣ ନିଶ୍ଚିତ କରନ୍ତୁ ଯେ ଆପଣ ବୁଝିଛନ୍ତି:

  • ବିକଳ୍ପ**: ଏକ୍ସପ୍ରେସନରେ ଭେରିଏବଲ୍‌ଗୁଡ଼ିକୁ ସଂଖ୍ୟାତ୍ମକ ମୂଲ୍ୟ ସହିତ ବଦଳାଇବା (ଉଦାହରଣ ସ୍ୱରୂପ, ଗଣନା କରିବା) $ p(1) $ ବହୁପଦୀ ପାଇଁ $ p(x) $)।
  • ସମୀକରଣ: ସରଳ ସମୀକରଣଗୁଡ଼ିକର ସମାଧାନ କରିବା ଯେପରିକି $ ax + b = 0 $.
  • ଗୋଟିଏ ଭେରିଏବଲ୍ ରେ ବହୁପଦୀ: ଏହିଭଳି ଅଭିବ୍ୟକ୍ତିଗୁଡ଼ିକୁ ଚିହ୍ନିବା ଯେପରିକି $ 5x^3 - 2x^2 + 3x - 2 $ ପଲିନୋମିଆଲ୍ ଭାବରେ $ x $.

ଏହି ଦକ୍ଷତାଗୁଡ଼ିକ ବହୁପଦୀର ଶୂନ୍ୟଗୁଡ଼ିକ ଚିହ୍ନଟ କରିବା ପାଇଁ ଭିତ୍ତି ସ୍ଥାପନ କରେ |

2. ଭୂମିକା

କଳ୍ପନା କରନ୍ତୁ ବହୁପଦୀ ରେ ସଂଖ୍ୟା ପକାଇଲେ ଯେପର୍ଯ୍ୟନ୍ତ ଏହା ଶୂନ ସହିତ ସମାନ ନହୁଏ, ସେହି ସଂଖ୍ୟାଗୁଡ଼ିକୁ ଶୂନ୍ୟଗୁଡ଼ିକ କୁହାଯାଏ! ଏହି ବିଷୟଟି ଏହିପରି ମୂଲ୍ୟଗୁଡ଼ିକୁ କିପରି ଖୋଜିବା ଏବଂ ସେମାନଙ୍କର ମହତ୍ତ୍ୱ ବୁଝିବା ବିଷୟରେ ଅନୁସନ୍ଧାନ କରେ | ଆପଣ ଜାଣିବେ ଯେ କେବେ ଏକ ବହୁପଦୀ ଶୂନରେ ମୂଲ୍ୟାୟନ ହୁଏ ଏବଂ ଏହା ସମୀକରଣ ସମାଧାନ ସହିତ କିପରି ଜଡିତ | ଶେଷରେ, ଆପଣ ଦେଖିବେ ଯେ କିପରି ଶୂନ୍ୟଗୁଡ଼ିକ ସମୀକରଣର ମୂଳ ଏବଂ ବହୁପଦୀ ବ୍ୟବହାର ସହିତ ସଂଯୁକ୍ତ |

ଏହା ଗୋଟିଏ ଭେରିଏବଲ୍ (ବିଭାଗ 2.2) ରେ ବହୁପଦ ସହିତ ତୁମର ପୂର୍ବ କାର୍ଯ୍ୟ ଉପରେ ଆଧାରିତ ଏବଂ ବିଭାଗ 2.4 ରେ ଉତ୍ପାଦନ କୌଶଳ ପାଇଁ ତୁମକୁ ପ୍ରସ୍ତୁତ କରିଥାଏ |

3. ବ୍ୟାଖ୍ୟା

3.1 ଶୂନ୍ୟଗୁଡ଼ିକ ର ସଂଜ୍ଞା

ସଂଜ୍ଞା: ଜଣେ ଏକ ବହୁପଦୀର ଶୂନ $ p(x) $ ଏହା ଏକ ସଂଖ୍ୟା ଅଟେ। $ c $ ଏପରି ଯେ $ p(c) = 0 $.

ଏକ ଶୂନ୍ୟ ଖୋଜିବା ପାଇଁ, ବଦଳ କରନ୍ତୁ | $ c $ ବହୁପଦୀ ଭିତରକୁ ଯାଆନ୍ତୁ ଏବଂ ସମାଧାନ କରନ୍ତୁ | $ c $ ଉଦାହରଣ ସ୍ୱରୂପ, ଉଦାହରଣ ସ୍ୱରୂପ, $ p(x) = x - 1 $ ସେଟିଂ, ସେଟିଂ $ p(c) = 0 $ ଦେଇଥାଏ $ c - 1 = 0 $, ତେଣୁ $ c = 1 $.

3.2 ବିଶେଷ କ୍ଷେତ୍ରଗୁଡ଼ିକ

ବିଶେଷ କ୍ଷେତ୍ର 1: ଏକ ଅଣ-ଶୂନ୍ୟ ସ୍ଥିରାଙ୍କ ବହୁପଦୀ (ଉଦାହରଣ ସ୍ୱରୂପ, $ p(x) = 5 $) ରେ ଶୂନ୍ୟଗୁଡ଼ିକ ନାହିଁ, କାରଣ ଯେକୌଣସି ମୂଲ୍ୟ ବଦଳାଇଲେ $ x $ ସର୍ବଦା 5 ରେ ପରିଣତ ହୁଏ |

ସ୍ୱତନ୍ତ୍ର କ୍ଷେତ୍ର 2: ଶୂନ୍ୟ ବହୁପଦୀ (ଉଦାହରଣ ସ୍ୱରୂପ, $ p(x) = 0 $) ରେ ସମ୍ମେଳନ ଅନୁସାରେ ସବୁ ବାସ୍ତବ ସଂଖ୍ୟା ଶୂନ୍ୟ ଅଟେ।

3.3 ରୈଖିକ ବହୁପଦୀ

ରୈଖିକ ବହୁପଦୀ ପାଇଁ $ p(x) = ax + b $ (ଯେଉଁଠାରେ $ a \neq 0 $), ଶୂନ୍ୟଟି ସମାଧାନ କରି ମିଳିଥାଏ | $ ax + b = 0 $.

$$ ax + b = 0 \implies x = -\frac{b}{a} $$

ଉଦାହରଣ: ପାଇଁ $ p(x) = 2x + 1 $ ଶୂନ୍ୟଟି ହେଉଛି $ x = -\frac{1}{2} $.

3.4 ସାଧାରଣ ପ୍ରଣାଳୀ

ଯେକୌଣସି ବହୁପଦୀର ଶୂନ୍ୟଗୁଡ଼ିକ ଖୋଜିବା ପାଇଁ:

  1. ପ୍ରାର୍ଥୀ ମୂଲ୍ୟ ବଦଳ କରନ୍ତୁ | $ c $ ବହୁପଦୀ ଭିତରକୁ।
  2. ସମାଧାନ କରନ୍ତୁ | $ p(c) = 0 $.
  3. ମୂଳ ବହୁପଦୀ ରେ ପୁନଃ ସଂଯୋଗ କରି ସମାଧାନକୁ ଯାଞ୍ଚ କରନ୍ତୁ।

4. ସମାଧାନ ହୋଇଥିବା ଉଦାହରଣ

ଉଦାହରଣ 1: ଏକ ବହୁପଦୀ ମୂଲ୍ୟାଙ୍କନ କରିବା

ଖୋଜ $ p(1) $ ପାଇଁ $ p(x) = 5x^3 - 2x^2 + 3x - 2 $.

ସମାଧାନ:

$$ p(1) = 5(1)^3 - 2(1)^2 + 3(1) - 2 = 5 - 2 + 3 - 2 = 4 $$

ଯେହେତୁ $ p(1) \neq 0 $, 1 is not a zero of this ବହୁପଦୀ.

ଉଦାହରଣ 2: ଶୂନ ଯାଞ୍ଚ କରିବା

ଯାଞ୍ଚ କରନ୍ତୁ ଯଦି $ -2 $ ଏକ ଶୂନ୍ୟ ଅଟେ $ p(x) = x + 2 $.

ସମାଧାନ:

$$ p(-2) = (-2) + 2 = 0 $$

ଏହିପରି, ** $ -2 $ ଏକ ଶୂନ୍ୟ ଅଟେ। $ p(x) $.

ଉଦାହରଣ 3: ଶୂନ୍ୟ ପାଇଁ ସମାଧାନ କରିବା

ଏକ ଶୂନ୍ୟ ଖୋଜ | $ p(x) = 4x^4 + 5x^3 - x^2 + 6 $.

ସମାଧାନ:

ଚେଷ୍ଟା କର $ x = 0 $:

$$ p(0) = 4(0)^4 + 5(0)^3 - (0)^2 + 6 = 6 \neq 0 $$

ଚେଷ୍ଟା କର $ x = -1 $:

$$ p(-1) = 4(-1)^4 + 5(-1)^3 - (-1)^2 + 6 = 4 - 5 - 1 + 6 = 4 \neq 0 $$

କୌଣସି ସ୍ପଷ୍ଟ ଶୂନ୍ୟ ନାହିଁ; ଉନ୍ନତ ପଦ୍ଧତି (ଯେପରିକି ଉତ୍ପାଦକତା) ଆବଶ୍ୟକ।

ଉଦାହରଣ 4: ସ୍ଥିରାଙ୍କ ବହୁପଦୀ

ଶୂନ୍ୟ(ଗୁଡ଼ିକ) ନିର୍ଣ୍ଣୟ କରନ୍ତୁ | $ p(x) = 5 $.

ସମାଧାନ:

ଯେକୌଣସି ବିକଳ୍ପ ବ୍ୟବହାର କରନ୍ତୁ | $ x $:

$$ p(x) = 5 \neq 0 \quad \text{(for all } x\text{)} $$

ସିଦ୍ଧାନ୍ତ: ଏହି ବହୁପଦୀ ରେ **କୌଣସି ଶୂନ୍ୟଗୁଡ଼ିକ ନାହିଁ।

ଉଦାହରଣ 5: ଶୂନ୍ୟ ବହୁପଦୀ

ଶୂନ୍ୟଗୁଡ଼ିକ ର ଅବସ୍ଥା ବର୍ଣ୍ଣନା କରନ୍ତୁ | $ p(x) = 0 $.

ସମାଧାନ:

ପରମ୍ପରା ଅନୁସାରେ, **ସମସ୍ତ ବାସ୍ତବ ସଂଖ୍ୟା ଗୁଡ଼ିକ ଶୂନ୍ୟ ବହୁପଦୀ ର ଶୂନ୍ୟଗୁଡ଼ିକ ଅଟନ୍ତି।
