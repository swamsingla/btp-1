# 3.2.3 Relation between radian and real numbers

> **Grade 11** | **Chapter 3: TRIGONOMETRIC FUNCTIONS**

---

## 1. Prerequisites  
Before studying this topic, students should:  
- Understand the concept of a **unit circle** and its relation to angles.  
- Be familiar with **arc length** and its calculation using radius and central angle.  
- Know the basics of **real numbers** and their representation on a number line.  

---

## 2. Introduction  
Have you ever wondered how angles can be measured using real numbers? In this topic, we explore the fascinating connection between **radian measures** and **real numbers** through the **unit circle**. By associating real numbers with positions on the unit circle, we can treat angles and real numbers as interchangeable entities. This foundational idea enables us to analyze trigonometric functions algebraically and geometrically. By the end of this section, you’ll understand how moving along the circumference of a circle maps to real numbers and vice versa.  

---

## 3. Explanation  

### 3.1 Unit Circle and Real Numbers  
> **Definition**: The **unit circle** is a circle with radius 1 centered at the origin of a coordinate system. Any point on the circle corresponds to an angle formed by the positive x-axis and the radius vector to that point.  

> **Definition**: The **radian measure** of an angle is defined as the length of the arc on the unit circle subtended by the angle. For a full circle (360°), the arc length equals $2\pi $, so one radian is the angle subtended by an arc of length 1 on the unit circle.  

### 3.2 Mapping Real Numbers to Radians  
> **Theorem**: Every real number corresponds uniquely to a radian measure on the unit circle, and vice versa.  
> **Proof**: Consider the unit circle with center $ O $ and a point $ A $ on the circumference representing the real number 0. Let $ AP $ be the positive real axis and $ AQ $ the negative real axis. When we move along the circumference in the **anticlockwise** direction (positive direction), each position corresponds to a unique real number. Similarly, moving **clockwise** (negative direction) assigns negative real numbers. Thus, the mapping is bijective.  

### 3.3 Coordinate Representation  
> **Definition**: On the unit circle, the **real number** $ x $ corresponds to the point $ (\cos x, \sin x) $, where $ x $ is the radian measure of the angle formed with the positive x-axis.  

This mapping allows us to interpret trigonometric functions as functions of real numbers rather than angles alone. For example, $\sin(0) = 0 $ because the point corresponding to $ x=0 $ is $ (1, 0) $, and the y-coordinate is 0.

## 4. Solved Examples  

**Example 1:**  
Find the radian measure corresponding to the real number $ x = \frac{\pi}{2} $.  
**Solution:**  
By definition, the real number $ x = \frac{\pi}{2} $ corresponds to the point $ (\cos(\frac{\pi}{2}), \sin(\frac{\pi}{2})) = (0, 1) $. This point lies at an angle of $\frac{\pi}{2} $ radians from the positive x-axis. Hence, the radian measure is $\boxed{\frac{\pi}{2}} $.  

**Example 2:**  
Determine the real number associated with the point $ (\cos(\pi), \sin(\pi)) $.  
**Solution:**  
The point $ (\cos(\pi), \sin(\pi)) = (-1, 0) $ corresponds to the angle $\pi $ radians. Therefore, the real number is $\boxed{\pi} $.  

**Example 3:**  
Convert the real number $ x = \frac{3\pi}{4} $ to its corresponding angle in degrees.  
**Solution:**  
Since $ 2\pi $ radians = 360°, $ 1 $ radian = $\frac{180^\circ}{\pi} $.  
Thus, $\frac{3\pi}{4} $ radians = $\frac{3\pi}{4} \times \frac{180^\circ}{\pi} = 135^\circ $.  
Answer: $\boxed{135^\circ} $.  

**Example 4:**  
If a point on the unit circle has coordinates $ (\frac{\sqrt{3}}{2}, \frac{1}{2}) $, find the real number $ x $ corresponding to this point.  
**Solution:**  
From the unit circle, $\cos(x) = \frac{\sqrt{3}}{2} $ and $\sin(x) = \frac{1}{2} $. These values occur at $ x = \frac{\pi}{6} $.  
Answer: $\boxed{\frac{\pi}{6}} $.  

**Example 5:**  
Explain why the real number $ x = 2\pi $ maps to the same point as $ x = 0 $ on the unit circle.  
**Solution:**  
The real number $ x = 2\pi $ represents a full rotation around the unit circle (since $ 2\pi $ radians = 360°). After completing one revolution, the terminal side of the angle coincides with the positive x-axis, which corresponds to $ x = 0 $. Thus, both $ x = 0 $ and $ x = 2\pi $ map to the point $ (1, 0) $.

## 5. Practice Problems  

🟢 **Easy**:  
1. What real number corresponds to the point $ (\cos(\pi), \sin(\pi)) $?  
2. Convert $ x = \frac{\pi}{3} $ radians to degrees.  

🟡 **Medium**:  
3. Find the real number $ x $ such that $\cos(x) = 0 $ and $\sin(x) = 1 $.  
4. If a point on the unit circle has coordinates $ (\cos(-\frac{\pi}{4}), \sin(-\frac{\pi}{4})) $, determine $ x $.  

🔴 **Hard**:  
5. Prove that the real number $ x = 2\pi n $ (where $ n $ is an integer) maps to the same point as $ x = 0 $ on the unit circle.  

**Answers:**  

1. **Answer**: $\boxed{\pi} $  
   **Steps**: The coordinates $ (\cos(\pi), \sin(\pi)) = (-1, 0) $, which corresponds to $ x = \pi $.  

2. **Answer**: $\boxed{60^\circ} $  
   **Steps**: $ x = \frac{\pi}{3} \times \frac{180^\circ}{\pi} = 60^\circ $.  

3. **Answer**: $\boxed{\frac{\pi}{2}} $  
   **Steps**: $\cos(x) = 0 $ occurs at $ x = \frac{\pi}{2} + 2\pi n $, but $\sin(x) = 1 $ only at $ x = \frac{\pi}{2} $.  

4. **Answer**: $\boxed{-\frac{\pi}{4}} $  
   **Steps**: The coordinates match $ x = -\frac{\pi}{4} $, which is coterminal with $\frac{7\pi}{4} $.  

5. **Answer**:  
   **Steps**: The real number $ x = 2\pi n $ represents $ n $ complete rotations around the unit circle. Since rotating $ 2\pi $ radians brings the terminal side back to the positive x-axis, the point $ (1, 0) $ is repeated for all integers $ n $. Thus, $ x = 2\pi n $ maps to the same point as $ x = 0 $.  

---

## 6. Summary  
- **Radian measure** is the arc length on the unit circle corresponding to an angle.  
- Real numbers map to points on the unit circle via the equations $ x = \cos(\theta) $ and $ y = \sin(\theta) $.  
- The mapping is periodic with period $ 2\pi $, meaning $ x = 2\pi n $ (for integer $ n $) corresponds to the same point as $ x = 0 $.  
- The unit circle connects real numbers and angles, enabling algebraic analysis of trigonometric functions.  

---

## 7. Key Formulas  
| Formula | Description |  
|--------|-------------|  
| $ \text{Arc length} = r\theta $ | Where $ r = 1 $ for the unit circle, so arc length = $\theta $ radians |  
| $ x = \cos(\theta) $ | Real number $ x $ corresponds to the x-coordinate on the unit circle |  
| $ y = \sin(\theta) $ | Real number $ y $ corresponds to the y-coordinate on the unit circle |  
| $ \theta = \frac{s}{r} $ | Radian measure $\theta $ is arc length $ s $ divided by radius $ r $ |  
| $ 2\pi \text{ radians} = 360^\circ $ | Conversion between radians and degrees |

## 8. Student Corner  
**Common Mistakes**:  
- ❌ Confusing radians with degrees: Always check units!  
- ❌ Assuming all real numbers map to distinct points: Remember periodicity ($ x = 2\pi n $ maps to the same point).  

**Exam Tips**:  
- Visualize the unit circle to associate real numbers with angles.  
- Use the formula $\theta = \frac{s}{r} $ for quick calculations.  

**Memory Aid**:  
**"Radians are real!"** – Recall that radians are essentially arc lengths (real numbers) on the unit circle.
