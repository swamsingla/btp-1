## 2. Introduction  
Have you ever wondered how engineers calculate the height of a building using angles of elevation? Or how astronomers determine distances to stars using trigonometry? This topic bridges the gap between geometric intuition and analytical rigor by extending trigonometric ratios beyond acute angles to **any real number** using the **unit circle**. Here, we explore how to define trigonometric functions for all angles, analyze their **signs**, and understand their **domains and ranges**. By the end of this section, you’ll master the fundamentals of trigonometric functions and their behavior under different conditions.  

---

## 3. Explanation  

### 3.1 Unit Circle Definition  
> **Definition**: A **unit circle** is a circle with radius 1 centered at the origin $(0, 0) $ in the Cartesian plane. For any angle $ x $ (measured in radians), consider the terminal side intersecting the unit circle at point $ P(a, b) $. The **sine** and **cosine** of $ x $ are defined as:

$$
\sin x = b, \quad \cos x = a

$$  
From the Pythagorean theorem applied to the right triangle formed by the radius, the x-axis, and the vertical line to the circle, we derive the **fundamental identity**:

$$
\sin^2 x + \cos^2 x = 1

$$  

### 3.2 Quadrantal Angles  
> **Definition**: **Quadrantal angles** are angles whose terminal sides lie along the axes (i.e., multiples of $\frac{\pi}{2} $). These include $ 0 $, $\frac{\pi}{2} $, $\pi $, $\frac{3\pi}{2} $, and $ 2\pi $. Their coordinates on the unit circle are:  
- $ A(1, 0) $ for $ 0 $ or $ 2\pi $  
- $ B(0, 1) $ for $\frac{\pi}{2} $  
- $ C(-1, 0) $ for $\pi $  
- $ D(0, -1) $ for $\frac{3\pi}{2} $  

Using these coordinates, we can compute the values of sine and cosine at quadrantal angles:

$$
\begin{align*}
\sin 0 &= 0, & \cos 0 &= 1 \\
\sin \frac{\pi}{2} &= 1, & \cos \frac{\pi}{2} &= 0 \\
\sin \pi &= 0, & \cos \pi &= -1 \\
\sin \frac{3\pi}{2} &= -1, & \cos \frac{3\pi}{2} &= 0 \\
\end{align*}

$$  

### 3.3 Periodicity of Trigonometric Functions  
> **Property**: The **periodic nature** of sine and cosine means their values repeat every $2\pi $ radians. Mathematically:

$$
\sin(2n\pi + x) = \sin x, \quad \cos(2n\pi + x) = \cos x \quad \text{for } n \in \mathbb{Z}

$$  
This implies that trigonometric functions are **repeating patterns** with period $2\pi $.  

### 3.4 Other Trigonometric Functions  
> **Definitions**: The remaining trigonometric functions are derived from sine and cosine:

$$
\begin{align*}
\tan x &= \frac{\sin x}{\cos x}, & \text{(undefined when } \cos x = 0) \\
\cot x &= \frac{\cos x}{\sin x}, & \text{(undefined when } \sin x = 0) \\
\sec x &= \frac{1}{\cos x}, & \text{(undefined when } \cos x = 0) \\
\csc x &= \frac{1}{\sin x}, & \text{(undefined when } \sin x = 0) \\
\end{align*}

$$  
These functions have restricted domains due to division by zero.  

### 3.5 Fundamental Identities  
> **Identity 1**: From $\sin^2 x + \cos^2 x = 1 $, dividing both sides by $\cos^2 x $ gives:

$$
1 + \tan^2 x = \sec^2 x

$$  
> **Proof**:  
Start with $\sin^2 x + \cos^2 x = 1 $. Divide both sides by $\cos^2 x $:

$$
\frac{\sin^2 x}{\cos^2 x} + \frac{\cos^2 x}{\cos^2 x} = \frac{1}{\cos^2 x} \implies \tan^2 x + 1 = \sec^2 x

$$  

> **Identity 2**: Dividing the original identity by $\sin^2 x $ yields:

$$
1 + \cot^2 x = \csc^2 x

$$  
> **Proof**:  
Divide $\sin^2 x + \cos^2 x = 1 $ by $\sin^2 x $:

$$
\frac{\sin^2 x}{\sin^2 x} + \frac{\cos^2 x}{\sin^2 x} = \frac{1}{\sin^2 x} \implies 1 + \cot^2 x = \csc^2 x

$$

## 4. Solved Examples  

### Example 1: Evaluate $\sin \frac{3\pi}{2} $  
**Solution**:  
From the unit circle, the point corresponding to $\frac{3\pi}{2} $ is $ D(0, -1) $. Thus:

$$
\sin \frac{3\pi}{2} = -1

$$  

### Example 2: Simplify $\cos(2\pi + \frac{\pi}{4}) $  
**Solution**:  
Using periodicity:

$$
\cos(2\pi + \frac{\pi}{4}) = \cos \frac{\pi}{4} = \frac{\sqrt{2}}{2}

$$  

### Example 3: Prove $1 + \tan^2 \frac{\pi}{4} = \sec^2 \frac{\pi}{4} $  
**Solution**:  
Calculate $\tan \frac{\pi}{4} = 1 $ and $\sec \frac{\pi}{4} = \sqrt{2} $. Substituting:

$$
1 + (1)^2 = 2 = (\sqrt{2})^2 \implies 2 = 2

$$  

### Example 4: Solve $\sin x = 0 $  
**Solution**:  
From the unit circle, $\sin x = 0 $ when $ x $ is an integer multiple of $\pi $:

$$
x = n\pi \quad \text{where } n \in \mathbb{Z}

$$  

### Example 5: Find $\cot \frac{\pi}{6} $  
**Solution**:  
$\cot x = \frac{\cos x}{\sin x} $. For $\frac{\pi}{6} $:

$$
\cos \frac{\pi}{6} = \frac{\sqrt{3}}{2}, \quad \sin \frac{\pi}{6} = \frac{1}{2} \implies \cot \frac{\pi}{6} = \frac{\frac{\sqrt{3}}{2}}{\frac{1}{2}} = \sqrt{3}

$$

## 5. Practice Problems  

### 🟢 Easy  
1. Evaluate $\cos \frac{\pi}{3} $.  
2. Simplify $\sin(\pi + \frac{\pi}{2}) $.  

### 🟡 Medium  
3. Prove $ 1 + \cot^2 \frac{\pi}{6} = \csc^2 \frac{\pi}{6} $.  
4. Solve $\sec x = 2 $ for $ x \in [0, 2\pi] $.  

### 🔴 Hard  
5. Determine the domain of $\tan x $ and explain why it excludes certain values.  

**Answers**:  
1. $\cos \frac{\pi}{3} = \frac{1}{2} $.  
2. $\sin(\pi + \frac{\pi}{2}) = \sin \frac{3\pi}{2} = -1 $.  
3. Calculate $\cot \frac{\pi}{6} = \sqrt{3} $, then $\csc \frac{\pi}{6} = \frac{1}{\sin \frac{\pi}{6}} = 2 $. Verify $ 1 + (\sqrt{3})^2 = 4 = 2^2 $.  
4. $\sec x = 2 \implies \cos x = \frac{1}{2} $. Solutions: $ x = \frac{\pi}{3}, \frac{5\pi}{3} $.  
5. $\tan x = \frac{\sin x}{\cos x} $ is undefined when $\cos x = 0 $, i.e., at $ x = \frac{\pi}{2} + n\pi $.

## 6. Summary  
- **Unit circle** defines $\sin x $ and $\cos x $ as coordinates of a point on the circle.  
- **Fundamental identity**: $\sin^2 x + \cos^2 x = 1 $.  
- **Periodicity**: $\sin x $ and $\cos x $ repeat every $ 2\pi $.  
- **Quadrantal angles** have specific values (e.g., $\sin \frac{\pi}{2} = 1 $).  
- **Other functions** ($\tan, \cot, \sec, \csc $) are derived from sine and cosine.  
- **Identities**: $ 1 + \tan^2 x = \sec^2 x $ and $ 1 + \cot^2 x = \csc^2 x $.

## 8. Student Corner  

### Common Mistakes  
- ❌ Confusing **degrees** and **radians** (e.g., mixing $\frac{\pi}{2} $ with 90°).  
- ❌ Forgetting that $\tan x $ is undefined when $\cos x = 0 $ (e.g., at $\frac{\pi}{2} $).  
- ❌ Misapplying identities (e.g., using $ 1 + \tan^2 x = \sec^2 x $ incorrectly).  

### Exam Tips  
- Memorize values of $\sin x $, $\cos x $, and $\tan x $ for standard angles (e.g., $ 0, \frac{\pi}{6}, \frac{\pi}{4}, \frac{\pi}{3}, \frac{\pi}{2} $).  
- Always check the **domain** of functions before simplifying expressions.  

### Memory Aid  
Use **"SOHCAHTOA"** to recall sine, cosine, and tangent:  
- **S**in = **O**pposite / **H**ypotenuse  
- **C**os = **A**djacent / **H**ypotenuse  
- **T**an = **O**pposite / **A**djacent
