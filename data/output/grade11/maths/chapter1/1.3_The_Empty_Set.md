## 1.3 The Empty Set

### Importance Score: 3/5 ⭐⭐⭐

Do you know someone who has never attended school? Such a person is said to have an empty set of experiences! In mathematics, an empty set is a set that has no elements. We'll explore what it means to have an empty set, why we need it, and how we work with it.

In our previous chapters, we learned about sets, their representations, and operations on them. Now, let's dive into the concept of an empty set.

### Explanation

A set that has no elements is called the **empty set**, **φ**, or the **null set** or the **void set**. Mathematically, it can be represented as

$$

\phi

$$ or

$$

\{\}

$$

. Let's see how the given example helps us understand the concept better.

> **Definition 1**: A set $\phi $ is said to be the **empty set** if it has no element.
>
> **Definition 2**: For any property P(x), the set $\{x | P(x)\} $ represents the set of all elements x such that P(x) holds true.

Now, consider two sets:

$$

A = \{x | 1 < x < 2, x \text{ is a natural number}\}

$$

and

$$

B = \{x | x^2 - 2 = 0, x \text{ is rational}\}.

$$

Can you think of any natural number between 1 and 2? No, so A is empty!

Similarly, for the second set, there is no rational number whose square is exactly 2. Therefore, B is also empty.

### Solved Examples

1. **Easy**: Suppose the set

$$

S = \{a, b, c\}

$$

is given. Prove that

$$

S

$$ is equal to the empty set.

Step 1: Write down the condition for an element to be in S.

$$

x \in S \iff x = a \text{ or } x = b \text{ or } x = c

$$

Step 2: Since there is no other condition, we don't need to include any other values.

Conclusion: Since S does not satisfy the condition for being non-empty,

$$

S = \phi

$$

.

2. **Medium**: Suppose the set

$$

T = \{x | x^2 = 4, x \text{ is an integer}\}.

$$

Prove that T is either empty or contains one element.

Step 1: Solve the quadratic equation

$$

x^2 = 4.

$$

Step 2: There is only one solution for x, namely x=±2. But since x cannot be negative according to the problem statement, we conclude that there is only one positive solution.

Conclusion: Therefore, T contains exactly one element.

3. **Hard**: Suppose the set

$$

R = \{x | x^3 + 1 = 0, x \text{ is real}\}.

$$

Show that R is empty.

Step 1: Recall the factorization of

$$

x^3+1 = (x+1)(x^2-x+1).

$$

Step 2: Setting each factor equal to zero gives us x=-1 and

$$

x^2-x+1=0.

$$

Since the discriminant of the quadratic is negative, there are no real solutions for the latter.

Conclusion: Since neither

$$

x=-1

$$ nor any real roots exist for

$$

x^2-x+1=0,

$$

we find that

$$

x^3+1=0

$$

has no real solutions, meaning that R is empty.

A = \phi

$$

and

$$

B = \phi.

$$

$$

\bigcup_{i=1}^\infty i^2

$$

### Summary

*   An empty set $\phi $ is a set with no elements.
*   It can be defined using the property $ P(x) $ as $\{x | P(x)\} $.
*   An empty set can be shown to be empty by contradiction.
*   When finding the union of two empty sets, we get an empty set.

### Student Corner

#### Common Mistakes

1.  Don't forget that an empty set doesn't mean the set is null!
2.  Always show why a set is empty by providing a counterexample.
