## 1.6.2 Intervals as subsets of R
### Importance Score: 4/5 
### Target Length: Concise (300-500 words)

#### Introduction
What is an interval? Can you think of a situation where you'd want to define a range of values between two points?

An interval is a subset of the set of real numbers, denoted by [a, b] or (a, b). In this topic, we'll delve into how to understand, create, and manipulate intervals, making them useful tools for solving equations and analyzing functions.

#### Explanation
A **subset** is a set whose elements are all members of another set. Intervals, in particular, are subsets of the set of real numbers, denoted by R.

*   **Interval Notation:** We denote an interval as follows:
    *   Open Interval: \( (a, b) = \{x | a < x < b\} \)
    *   Closed Interval: \( [a, b] = \{x | a \leq x \leq b\} \)
    *   Half-Open Interval: \( [a, b) = \{x | a \leq x < b\} \) and \( (a, b] = \{x | a < x \leq b\} \)

> **Definition:** An interval is said to be **proper** if it does not contain both endpoints \(a\) and \(b\).
>
> **Formulas:**

| Formula                      | Description |
| --------------------------- | ----------- |
| $[a, b] $                  | Closed Interval |
| $ (a, b) $                  | Open Interval |
| $ [a, b) $                | Half-Open Interval from left |
| $ (a, b] $                | Half-Open Interval from right |
| $ (-\infty, b] $          | Half-Open Interval from negative infinity |
| $ [a, \infty) $         | Half-Open Interval from positive infinity |

#### Solved Examples

**Example 1:** Find the length of the interval \((-3, 5)\).
1.  Write down the interval notation.
2.  Calculate the difference between the endpoints: $ 5 - (-3) = 8 $
3.  The length of the interval is the absolute value of the difference, so $\left|-3 - 5\right|= 8 $

**Example 2:** Determine whether the set \(\{x \mid -2 < x < 4\}\) is an interval.

1.  Check if the endpoints are included or excluded.
2.  Compare the endpoints to see if the interval satisfies the definition of an interval.

**Example 3:** Given the interval \((a, b]\), find the midpoint.

1.  Calculate the average of the endpoints.
2.  Take half of the result to get the midpoint.

#### Summary

*   Recall the definitions of open, closed, and half-open intervals.
*   Key Formulas:
    *   $ [a, b] $ = {x | a ≤ x ≤ b}
    *   $ (a, b) $ = {x | a < x < b}
    *   $ [a, b) $ = {x | a ≤ x < b}
    *   $ (a, b] $ = {x | a < x ≤ b}

> **Tips for Exams:**
>
> When taking the midpoint of an interval, always take half of the sum of the endpoints.
>
> To determine if a set is an interval, check if it includes its endpoints.
