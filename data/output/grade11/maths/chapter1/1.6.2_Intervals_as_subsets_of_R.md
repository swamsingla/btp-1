## 2. Introduction  
Intervals are fundamental tools for describing subsets of real numbers. This section explores how open, closed, and half-open intervals define specific ranges of real numbers. By mastering interval notation, students will gain clarity on representing continuous ranges and analyzing their properties.  

---  

## 3. Explanation  

### 3.1 Definition of Intervals  
An **interval** is a subset of real numbers defined by bounds. There are four primary types:  
> **Open Interval**: $ (a, b) $ denotes $\{x : a < x < b\} $; endpoints $ a $ and $ b $ are **not included**.  
> **Closed Interval**: $ [a, b] $ denotes $\{x : a \leq x \leq b\} $; endpoints $ a $ and $ b $ are **included**.  
> **Half-Open Intervals**:  
> - $ [a, b) $ denotes $\{x : a \leq x < b\} $; includes $ a $ but excludes $ b $.  
> - $ (a, b] $ denotes $\{x : a < x \leq b\} $; includes $ b $ but excludes $ a $.  

### 3.2 Length of an Interval  
The **length** of an interval $ (a, b) $, $ [a, b] $, $ [a, b) $, or $ (a, b] $ is calculated as:  
>

$$

\text{Length} = b - a

$$  
This applies regardless of whether the endpoints are included or excluded.  

### 3.3 Subset Relationships  
Intervals can be used to describe subset relationships. For example:  
- If $A = (-3, 5) $ and $ B = [-7, 9] $, then $ A \subset B $ because every element of $ A $ satisfies the condition for $ B $.  
- Similarly, $ [0, \infty) $ represents non-negative real numbers, and $ (-\infty, 0) $ represents negative real numbers.  

### 3.4 Universal Set  
The **universal set** $ U $ encompasses all possible elements under consideration. For real numbers, $ U = (-\infty, \infty) $, representing the entire real line.

## 4. Solved Examples  

### Example 1: Converting Set-Builder Form to Interval Notation  
Convert the set $\{x : -5 < x \leq 7\} $ into interval notation.  
**Solution:**  
- The inequality $-5 < x \leq 7 $ corresponds to a half-open interval.  
- Since $ x > -5 $ excludes $-5 $ but includes $ 7 $, the interval is $ (-5, 7] $.  

### Example 2: Determining Subset Relationship  
Check if $ A = (-3, 5) $ is a subset of $ B = [-7, 9] $.  
**Solution:**  
- All elements of $ A $ satisfy $-7 \leq x \leq 9 $ because $-3 > -7 $ and $ 5 < 9 $.  
- Therefore, $ A \subset B $.  

### Example 3: Calculating Interval Length  
Find the length of the interval $ [-2, 8] $.  
**Solution:**  
- Using the formula $\text{Length} = b - a $:

$$

\text{Length} = 8 - (-2) = 10

$$  

### Example 4: Writing Interval Notation for a Given Set  
Express the set $\{x : -3 \leq x < 5\} $ in interval notation.  
**Solution:**  
- The inequality includes $-3 $ but excludes $ 5 $, so the interval is $ [-3, 5) $.

## 5. Practice Problems  

### 🟢 Easy  
1. Convert $\{x : 1 < x < 4\} $ to interval notation.  
2. Is $ [2, 6] $ a subset of $ (-\infty, 7) $? Justify.  

### 🟡 Medium  
3. Find the length of the interval $ ( -1, 3 ] $.  
4. Express $\{x : x \in \mathbb{R}, -5 \leq x < 0\} $ in interval notation.  

### 🔴 Hard  
5. Determine if $ A = [0, 5) $ and $ B = ( -2, 7 ] $ are disjoint. Explain.  
6. Prove that the intersection of $ [a, b] $ and $ (c, d) $ is either empty or an interval.  

**Answers:**  

1. Solution: $\{x : 1 < x < 4\} $ → $ (1, 4) $.  
2. Solution: Yes. Since $ [2, 6] $ lies entirely within $ (-\infty, 7) $.  
3. Solution: Length = $ 3 - (-1) = 4 $.  
4. Solution: $\{x : -5 \leq x < 0\} $ → $ [-5, 0) $.  
5. Solution: No. $ A \cap B = [0, 5) $, which is non-empty.  
6. Solution: If $ [a, b] $ and $ (c, d) $ overlap, their intersection is an interval. If not, it’s empty.

## 6. Summary  
- An **open interval** $ (a, b) $ excludes endpoints; a **closed interval** $ [a, b] $ includes them.  
- Half-open intervals include one endpoint and exclude the other.  
- The **length** of an interval is always $ b - a $, regardless of endpoints.  
- Intervals can represent subsets of real numbers, e.g., $ [0, \infty) $ for non-negative reals.  
- The **universal set** $ U = (-\infty, \infty) $ includes all real numbers.  

---  

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ (a, b) $ | Open interval: $\{x : a < x < b\} $ |  
| $ [a, b] $ | Closed interval: $\{x : a \leq x \leq b\} $ |  
| $ [a, b) $ | Half-open interval: $\{x : a \leq x < b\} $ |  
| $ (a, b] $ | Half-open interval: $\{x : a < x \leq b\} $ |  
| $\text{Length} = b - a $ | Length of any interval |

## 8. Student Corner  

### Common Mistakes  
- Confusing open and closed intervals: Always remember parentheses `()` for open and brackets `[]` for closed.  
- Miscalculating length: Ensure $ b - a $ is computed correctly, even if endpoints are excluded.  

### Memory Aid  
Use the acronym **O**pen (**O**pen ends) and **C**losed (**C**losed ends) to recall interval notation.
