1.9.1 Union of sets Let \(A\) and \(B\) be any two sets. The union of \(A\) and \(B\) is the set

\[ A \cup B = \{ x \mid x \in A \text{ or } x \in B \}. \]

This means that the union of two sets \(A\) and \(B\) is the set of all elements that are in \(A\), in \(B\), or in both. The symbol \(\cup\) is used to denote the union of two sets.

** Example 1:**
Let \(A = \{1, 2, 4, 6\}\) and \(B = \{2, 3, 5, 6\}\). Then,

\[ A \cup B = \{1, 2, 3, 4, 5, 6\}. \]

** Example 2:**
Let \(A = \{x \mid x \text{ is an even integer}\}\) and \(B = \{x \mid x \text{ is an odd integer}\}\). Then,

\[ A \cup B = \mathbb{Z}, \]
where \(\mathbb{Z}\) is the set of all integers.

** Example 3:**
Let \(A = \{x \mid x > 5\}\) and \(B = \{x \mid x < 2\}\). Then,

\[ A \cup B = \{x \mid x < 2 \text{ or } x > 5\}. \]

** Example 4:**
Let \(A = \{1, 2\}\) and \(B = \{3\}\). Then,

\[ A \cup B = \{1, 2, 3\}. \]

** Example 5:**
Let \(A = \{x \mid x \text{ is a natural number}\}\) and \(B = \{x \mid x \text{ is a prime number}\}\). Then,

\[ A \cup B = \{1, 2, 3, 4, 5, 6, \ldots\} = \mathbb{N}, \]
where \(\mathbb{N}\) is the set of all natural numbers.

** Practice Problem 1:**
If \(A = \{2, 4, 6, 8\}\) and \(B = \{1, 3, 5, 7\}\), find \(A \cup B\).

** Answer:**
\[ A \cup B = \{1, 2, 3, 4, 5, 6, 7, 8\} \]

** Practice Problem 2:**
If \(A = \{x \mid x \text{ is a multiple of 3}\}\) and \(B = \{x \mid x \text{ is a multiple of 5}\}\), find \(A \cup B\).

** Answer:**
\[ A \cup B = \{x \mid x \text{ is a multiple of 3 or 5}\} \]

** Summary:**
- The union of two sets \(A\) and \(B\) is the set of all elements that are in \(A\), in \(B\), or in both. This is denoted by \(A \cup B\).
- The union operation is commutative: \(A \cup B = B \cup A\).
- The union operation is associative: \((A \cup B) \cup C = A \cup (B \cup C)\).
- The union of a set \(A\) and the empty set \(\emptyset\) is \(A\): \(A \cup \emptyset = A\).
- The union of a set \(A\) and its complement \(A^c\) is the universal set \(U\): \(A \cup A^c = U\).
