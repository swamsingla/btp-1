**1.8 Venn Diagrams**

**Introduction:**
Venn diagrams are graphical representations of sets and their relationships. They were introduced by John Venn in the late 19th century. Venn diagrams use rectangles and circles to represent the universal set and subsets, respectively. The universal set is typically represented by a rectangle, and each subset is represented by a circle within that rectangle.

**Explanation:**
- **Universal Set (U)**: The set of all elements under consideration.
- **Subset (A, B, etc.)**: A set whose elements are members of another set.
- **Intersection (A ∩ B)**: The set of elements common to both sets A and B.
- **Union (A ∪ B)**: The set of elements that are in either set A or set B or both.
- **Difference (A - B)**: The set of elements in set A but not in set B.
- **Complement (A')**: The set of elements in the universal set U but not in set A.

**Solved Example:**
Consider the universal set \( U = \{1, 2, 3, \ldots, 10\} \), and two subsets \( A = \{2, 4, 6, 8, 10\} \) and \( B = \{4, 6\} \).
- The intersection \( A \cap B = \{4, 6\} \).
- The union \( A \cup B = \{2, 4, 6, 8, 10\} \).
- The difference \( A - B = \{2, 8, 10\} \).
- The complement \( A' = \{1, 3, 5, 7, 9\} \).

**Practice Problem:**
Given the universal set \( U = \{a, b, c, d, e, f, g, h\} \), and two subsets \( A = \{a, c, e, g\} \) and \( B = \{c, e\} \), find the intersection, union, difference, and complement of these sets.

**Summary:**
Venn diagrams are a visual tool used to represent sets and their relationships. They help in understanding the intersection, union, difference, and complement of sets. Key formulas include:
- \( A \cap B \): Intersection of sets A and B
- \( A \cup B \): Union of sets A and B
- \( A - B \): Difference of sets A and B
- \( A' \): Complement of set A
