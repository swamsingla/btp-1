# 1.9.3 Difference of sets

> **Grade 11** | **Chapter 1: SETS**

---

To create a concise, student-friendly topic page for the mathematics topic "1.9.3 Difference of sets," we will follow these steps:

**Step 1: Identify Key Concepts**

The key concept for "1.9.3 Difference of sets" is the operation of finding the difference between two sets \( A \) and \( B \), denoted as \( A - B \). This operation consists of all elements that are in set \( A \) but not in set \( B \).

**Step 2: Define the Difference of Sets**

The difference of sets \( A \) and \( B \), denoted \( A - B \), is defined as:
\[ A - B = \{ x : x \in A \text{ and } x \notin B \} \]

**Step 3: Explanation with Example**

Let's illustrate this with an example. Consider two sets:
\[ A = \{1, 2, 3, 4, 5, 6\} \]
\[ B = \{2, 4, 6, 8\} \]

To find \( A - B \), we identify the elements in \( A \) that are not in \( B \):
\[ A - B = \{1, 3, 5\} \]

Similarly, to find \( B - A \), we identify the elements in \( B \) that are not in \( A \):
\[ B - A = \{8\} \]

**Step 4: Properties of Difference of Sets**

The difference of sets has the following properties:
1. \( A - B \neq B - A \) (division is not commutative)
2. \( A - A = \emptyset \) (the difference of a set with itself is the empty set)
3. \( \emptyset - A = \emptyset \) (the difference of the empty set with any set is the empty set)

**Step 5: Conclusion**

In conclusion, the difference of sets \( A \) and \( B \), denoted \( A - B \), is the set of all elements that are in \( A \) but not in \( B \). This operation is not commutative, and the difference of a set with itself is the empty set.

\[
\boxed{A - B = \{ x : x \in A \text{ and } x \notin B \}}
\]
