### explanation
- **Definition of a Set:**
  A set is a well-defined collection of distinct objects. The objects in a set are called elements or members.

- ** Representing Sets:**
  There are three common ways to represent a set:
  1. **Roster Method:** List all the elements of the set within curly braces { }.
     Example: \( A = \{1, 2, 3, 4\} \)
  2. **Set-Builder Notation:** Use a rule to describe the elements of the set.
     Example: \( B = \{x \mid x \text{ is a natural number less than 5}\} \)
  3. **韦恩 Diagram:** Use a diagram with a rectangle representing the universal set and circles inside it to represent subsets.

- ** types of Sets:**
  - **Empty Set (\(\emptyset\)):** A set that contains no elements.
  - **Finite Set:** A set with a finite number of elements.
  - **Infinite Set:** A set with an infinite number of elements.
  - **Equal Sets:** Two sets are equal if they contain exactly the same elements.
  - **Subsets:** A set \( A \) is a subset of set \( B \) if every element of \( A \) is also an element of \( B \). denoted as \( A \subseteq B \).
  - **Proper Subset:** A set \( A \) is a proper subset of set \( B \) if \( A \subseteq B \) and \( A \neq B \).
  - **Intervals as Subsets of \( \mathbb{R} \):** Intervals are subsets of the set of real numbers \( \mathbb{R} \). They include:
    - Open interval: \( (a, b) = \{x \in \mathbb{R} \mid a < x < b\} \)
    - Closed interval: \( [a, b] = \{x \in \mathbb{R} \mid a \leq x \leq b\} \)
    - Half-open intervals: \( [a, b) = \{x \in \mathbb{R} \mid a \leq x < b\} \) and \( (a, b] = \{x \in \mathbb{R} \mid a < x \leq b\} \)
  - **Universal Set (\( U \)):** The set of all elements under consideration in a given context.

- ** Operations on Sets:**
  - **Union (\( \cup \)):** The union of two sets \( A \) and \( B \) is the set of all elements that are in \( A \), in \( B \), or in both.
     Example: \( A \cup B = \{x \mid x \in A \text{ or } x \in B\} \)
  - **Intersection (\( \cap \)):** The intersection of two sets \( A \) and \( B \) is the set of all elements that are in both \( A \) and \( B \).
     Example: \( A \cap B = \{x \mid x \in A \text{ and } x \in B\} \)
  - **Difference (\( \setminus \)):** The difference of two sets \( A \) and \( B \) is the set of all elements that are in \( A \) but not in \( B \).
     Example: \( A \setminus B = \{x \mid x \in A \text{ and } x \notin B\} \)
  - **Complement (\( A^c \)):** The complement of set \( A \) with respect to the universal set \( U \) is the set of all elements in \( U \) that are not in \( A \).
     Example: \( A^c = \{x \in U \mid x \notin A\} \)

### solved Examples
**Example 1:**
Determine whether the following sets are equal:
\[ A = \{2, 4, 6, 8\} \]
\[ B = \{8, 6, 4, 2\} \]

**Solution:**
Both sets \( A \) and \( B \) contain the same elements, so \( A = B \).

**Example 2:**
Find the union and intersection of sets \( A \) and \( B \):
\[ A = \{1, 3, 5\} \]
\[ B = \{2, 4, 6\} \]

**Solution:**
- Union: \( A \cup B = \{1, 2, 3, 4, 5, 6\} \)
- Intersection: \( A \cap B = \emptyset \) (since there are no common elements)

**Example 3:**
Find the difference \( A \setminus B \):
\[ A = \{1, 2, 3, 4\} \]
\[ B = \{3, 4, 5\} \]

**Solution:**
\[ A \setminus B = \{1, 2\} \]

### practice problems
1. Determine whether the sets \( C = \{a, b, c\} \) and \( D = \{b, c, d\} \) are equal.
2. Find the union and intersection of sets \( E = \{x \mid x \text{ is a prime number less than 10}\} \) and \( F = \{x \mid x \text{ is an even number less than 10}\} \).
3. Find the difference \( G \setminus H \) where \( G = \{x \mid x \text{ is a positive integer less than 5}\} \) and \( H = \{x \mid x \text{ is a negative integer greater than -5}\} \).

**answers**
1. \( C \neq D \)
2. \( E = \{2, 3, 5, 7\} \), \( F = \{2, 4, 6, 8\} \), \( E \cup F = \{2, 3, 4, 5, 6, 7, 8\} \), \( E \cap F = \{2\} \)
3. \( G \setminus H = \{1, 2, 3, 4\} \)
