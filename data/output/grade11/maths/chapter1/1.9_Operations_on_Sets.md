## 2. Introduction  
Imagine you have two groups of people: one group loves basketball, and another loves cricket. How would you describe the combined group of fans who enjoy either sport? Or, suppose you want to find out who likes both sports. These questions mirror how **operations on sets** work!  

In this topic, you will learn how to perform fundamental operations on sets—**union**, **intersection**, and **difference**—to analyze relationships between collections of elements. These operations are essential tools in mathematics, logic, and computer science, allowing us to model scenarios ranging from data analysis to probability theory. By the end of this section, you’ll understand how to combine, compare, and subtract sets to derive new sets with specific properties.  

This builds upon your prior knowledge of sets and their representations, making it easier to visualize and manipulate abstract collections of objects.

## 3. Explanation  

### 3.1 Union of Sets  
> **Definition**: The *union* of two sets $ A $ and $ B $, denoted $ A \cup B $, is the set of all elements that belong to $ A $, to $ B $, or to both.  

**Formal Statement**:

$$
A \cup B = \{ x \mid x \in A \text{ or } x \in B \}

$$  

**Properties of Union**:  
- **Commutative Law**: $ A \cup B = B \cup A $  
- **Associative Law**: $ (A \cup B) \cup C = A \cup (B \cup C) $  
- **Identity Element**: $ A \cup \emptyset = A $  
- **Subset Property**: If $ A \subseteq B $, then $ A \cup B = B $.  

**Proof of Commutative Law**:  
Let $ x \in A \cup B $. By definition, $ x \in A $ or $ x \in B $. Similarly, $ x \in B \cup A $ implies $ x \in B $ or $ x \in A $. Thus, $ A \cup B = B \cup A $.  

### 3.2 Intersection of Sets  
> **Definition**: The *intersection* of two sets $ A $ and $ B $, denoted $ A \cap B $, is the set of all elements common to both $ A $ and $ B $.  

**Formal Statement**:

$$
A \cap B = \{ x \mid x \in A \text{ and } x \in B \}

$$  

**Properties of Intersection**:  
- **Commutative Law**: $ A \cap B = B \cap A $  
- **Associative Law**: $ (A \cap B) \cap C = A \cap (B \cap C) $  
- **Identity Element**: $ A \cap U = A $, where $ U $ is the universal set  
- **Subset Property**: If $ A \subseteq B $, then $ A \cap B = A $.  

**Proof of Subset Property**:  
If every element of $ A $ is also in $ B $, then intersecting $ A $ and $ B $ yields $ A $. Hence, $ A \cap B = A $.  

### 3.3 Difference of Sets  
> **Definition**: The *difference* of two sets $ A $ and $ B $, denoted $ A - B $, is the set of all elements in $ A $ that are not in $ B $.  

**Formal Statement**:

$$
A - B = \{ x \mid x \in A \text{ and } x \notin B \}

$$  

**Key Observations**:  
- $ A - B \neq B - A $ (non-commutative)  
- $ A - \emptyset = A $, $ A - A = \emptyset $  
- The difference operation is closely tied to the concept of complementation (covered in Section 1.10).  

**Example of Non-Commutativity**:  
Let $ A = \{1, 2, 3\} $, $ B = \{2, 3, 4\} $. Then:

$$
A - B = \{1\}, \quad B - A = \{4\}

$$  
Clearly, $ A - B \neq B - A $.

## 4. Solved Examples  

**Example 1:**  
Given $ A = \{1, 2, 3\} $, $ B = \{2, 3, 4\} $, find $ A \cup B $ and $ A \cap B $.  

**Solution:**  
- $ A \cup B $ includes all elements in $ A $ or $ B $:

$$
  A \cup B = \{1, 2, 3, 4\}

$$  
- $ A \cap B $ includes elements common to both:

$$
  A \cap B = \{2, 3\}

$$  

**Example 2:**  
Let $ A = \{x \in \mathbb{R} \mid x < 5\} $, $ B = \{x \in \mathbb{R} \mid x > 2\} $. Find $ A \cap B $.  

**Solution:**  
- $ A \cap B $ consists of real numbers greater than 2 and less than 5:

$$
  A \cap B = \{x \in \mathbb{R} \mid 2 < x < 5\}

$$  

**Example 3:**  
If $ A = \{a, b, c\} $, $ B = \{c, d, e\} $, compute $ A - B $ and $ B - A $.  

**Solution:**  
- $ A - B $ removes elements in $ B $ from $ A $:

$$
  A - B = \{a, b\}

$$  
- $ B - A $ removes elements in $ A $ from $ B $:

$$
  B - A = \{d, e\}

$$  

**Example 4:**  
Prove that $ (A \cup B) \cap C = (A \cap C) \cup (B \cap C) $.  

**Solution:**  
We show both sides are equal by verifying inclusion in each direction.  
1. **Left-to-right**: Take $ x \in (A \cup B) \cap C $. Then $ x \in A \cup B $ and $ x \in C $. This means $ x \in A $ or $ x \in B $, and $ x \in C $. Hence, $ x \in (A \cap C) \cup (B \cap C) $.  
2. **Right-to-left**: Take $ x \in (A \cap C) \cup (B \cap C) $. Then $ x \in A \cap C $ or $ x \in B \cap C $. In either case, $ x \in A $ or $ x \in B $, and $ x \in C $. Thus, $ x \in (A \cup B) \cap C $.  

Therefore, the equality holds.  

**Example 5:**  
Let $ U = \{1, 2, 3, 4, 5\} $, $ A = \{1, 2\} $, $ B = \{2, 3\} $. Compute $ A - B $ and $ (A \cup B)^c $.  

**Solution:**  
- $ A - B = \{1\} $  
- $ A \cup B = \{1, 2, 3\} $, so $ (A \cup B)^c = \{4, 5\} $

## 5. Practice Problems  

🟢 **Easy**:  
1. Given $ A = \{1, 2, 3\} $, $ B = \{3, 4, 5\} $, find $ A \cup B $ and $ A \cap B $.  
2. If $ A = \{x \in \mathbb{N} \mid x \leq 4\} $, $ B = \{x \in \mathbb{N} \mid x \geq 3\} $, determine $ A \cap B $.  

🟡 **Medium**:  
3. Let $ A = \{a, b, c\} $, $ B = \{c, d, e\} $, $ C = \{e, f, g\} $. Find $ (A \cup B) \cap C $.  
4. Prove that $ A - B = A \cap (B^c) $.  

🔴 **Hard**:  
5. Suppose $ A = \{x \in \mathbb{R} \mid x^2 < 4\} $, $ B = \{x \in \mathbb{R} \mid x > 1\} $. Determine $ A - B $ and $ B - A $.  

**Answers:**  

1. $ A \cup B = \{1, 2, 3, 4, 5\} $, $ A \cap B = \{3\} $.  
2. $ A \cap B = \{3, 4\} $.  
3. $ A \cup B = \{a, b, c, d, e\} $, so $ (A \cup B) \cap C = \{e\} $.  
4. Proof: $ x \in A - B $ iff $ x \in A $ and $ x \notin B $, which is equivalent to $ x \in A \cap (B^c) $.  
5. $ A = (-2, 2) $, $ B = (1, \infty) $, so $ A - B = (-2, 1] $, $ B - A = (2, \infty) $.

## 6. Summary  
- **Union** combines elements from two sets: $ A \cup B = \{x \mid x \in A \text{ or } x \in B\} $.  
- **Intersection** identifies common elements: $ A \cap B = \{x \mid x \in A \text{ and } x \in B\} $.  
- **Difference** excludes elements of one set from another: $ A - B = \{x \mid x \in A \text{ and } x \notin B\} $.  
- Union and intersection are commutative and associative, while difference is non-commutative.  
- These operations help analyze overlaps, exclusions, and combinations of sets in various applications.

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ A \cup B $ | Union of sets $ A $ and $ B $ |  
| $ A \cap B $ | Intersection of sets $ A $ and $ B $ |  
| $ A - B $ | Difference of sets $ A $ and $ B $ |  
| $ A \cup B = B \cup A $ | Commutative law for union |  
| $ A \cap B = B \cap A $ | Commutative law for intersection |  
| $ (A \cup B) \cap C = (A \cap C) \cup (B \cap C) $ | Distributive law |

## 8. Student Corner  

### **Common Mistakes**  
1. **Confusing union and intersection**: Students often mix up the "or" vs. "and" logic. Always ask: "Which elements satisfy the condition?"  
2. **Ignoring the universal set**: When computing complements or differences, always consider the universal set $ U $ as the context.  
3. **Incorrect Venn diagrams**: Shade regions improperly by misapplying operations (e.g., overlapping areas for union).  

### **Exam Tips**  
- Draw Venn diagrams for complex problems to visualize relationships between sets.  
- Practice converting set operations into logical conditions (e.g., $ A \cap B $ = "elements in both").  

### **Memory Aid**  
Use the acronym **UNION** to recall: **U**nion involves **N**either set missing elements. For intersection, think **I**ntersection = **I**n both sets.
