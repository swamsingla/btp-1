## 1.9 Operations on Sets
### Importance Score: 4/5 
### Target Length: detailed (800-1200 words)

As you have learned about sets and their representations in earlier classes, you may wonder what happens when you combine two or more sets together. In this topic, we will explore the three main operations that can be performed on sets: union, intersection, and difference. These operations are essential in various branches of mathematics, including algebra, geometry, and computer science.

### Introduction
Have you ever tried to find the common elements between two sets? Or maybe you wanted to see what's left when you remove the unwanted elements from a set? These questions are answered by the operations of union, intersection, and difference, which we will cover in this topic.

When you perform arithmetic operations on numbers, you usually work with pairs of numbers at a time. However, when you work with sets, things become more interesting. Here, we'll learn how to combine multiple sets to obtain new sets.

### Explanation
#### Definition of Key Terms
Let A and B be any two sets. The **union** of A and B, denoted by A $\cup $ B, is the set of all elements that belong to either A or B or both. Mathematically, this can be represented as:

$$

A \cup B = \{ x : x \in A \text{ or } x \in B\}

$$

The **intersection** of A and B, denoted by A $\cap $ B, is the set of all elements that belong to both A and B. This can be expressed as:

$$

A \cap B = \{ x : x \in A \text{ and } x \in B\}

$$

Finally, the **difference** of A and B, denoted by A $\backslash $ B, is the set of all elements that belong to A but not B. It can be written as:

$$

A \backslash B = \{ x : x \in A \text{ and } x \notin B\}

$$

#### Theorem: Commutativity of Union and Intersection
For any two sets A and B,

$$

A \cup B = B \cup A

$$
and

$$

A \cap B = B \cap A

$$

#### Theorem: Associativity of Union and Intersection
For any three sets A, B, and C,

$$

(A \cup B) \cup C = A \cup (B \cup C)

$$
and

$$

(A \cap B) \cap C = A \cap (B \cap C)

$$

#### Theorem: Distributive Property of Union over Intersection
For any three sets A, B, and C,

$$

A \cup (B \cap C) = (A \cup B) \cap (A \cup C)

$$

#### Theorem: De Morgan's Law
For any two sets A and B,

$$

(A \cup B)^c = A^c \cap B^c

$$
and

$$

(A \cap B)^c = A^c \cup B^c

$$

Where $A^c $ denotes the complement of A.

### Solved Examples
#### Example 1:
Find the union of the sets A = {1, 2, 3} and B = {2, 3, 4}.

Solution:
First, let's list out the elements of each set:

A = {1, 2, 3}
B = {2, 3, 4}

To find the union, we include all elements from both sets:

$$

A \cup B = \{1, 2, 3, 4\}

$$

#### Example 2:
Find the intersection of the sets A = {1, 2, 3} and B = {2, 3, 4}.

Solution:
We only take the elements that are common to both sets:

$$

A \cap B = \{2, 3\}

$$

#### Example 3:
Find the difference of the sets A = {1, 2, 3} and B = {2, 3, 4}.

Solution:
We keep only the elements that belong to A but not B:

$$

A \backslash B = \{1\}

$$

#### Example 4:
Find the union of the sets A = {1, 2, 3}, B = {2, 3, 4}, and C = {3, 4, 5}.

Solution:
We include all elements from each set:

$$

A \cup B \cup C = \{1, 2, 3, 4, 5\}

$$

### Practice Problems

Find the union of the sets A = {1, 2, 3} and B = {3, 4, 5}. 

🟡 Medium
Find the intersection of the sets A = {1, 2, 3, 4} and B = {3, 4, 5, 6}.

🔴 Hard
Show that the distributive property holds for the union and intersection of sets.

### Answers
Union: {1, 2, 3, 4, 5}
Intersection: {3}
Difference: {1}
Distributive Property: (A ∪ (B ∩ C)) = (A ∪ B) ∩ (A ∪ C)

### Summary
• The union of two sets includes all elements from both sets.
• The intersection of two sets includes only elements common to both.
• The difference of two sets includes elements from one set but not the other.
• The commutative, associative, and distributive properties hold for union and intersection.
• De Morgan's law applies to complements of unions and intersections.

### Student Corner
#### Common Mistakes:
- Failing to consider the order of sets when finding the union or intersection.
- Not accounting for the empty set when calculating the union or difference.
- Misapplying De Morgan's law.

#### Exam Tips:
- When working with sets, always remember the definitions and properties.
- Make sure to check for any missing elements in the union or intersection.

#### Memory Aid:
The word "UNION" can help you remember to include all elements from both sets.
