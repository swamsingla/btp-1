**Universal Set**

### Introduction
Have you ever wondered what makes a set a "universal set"? In everyday life, we often consider a universal set as the collection of all possible outcomes or possibilities within a given domain. For instance, in a classroom setting, the universal set could be the set of all students present on a particular day. But what exactly does a universal set represent? Let's dive into the world of sets and explore this fundamental concept!

### Explanation
A **universal set**, also known as the **universe** or **sample space**, is a set that contains every element under consideration. It serves as the foundation for many set operations and is essential in various fields like mathematics, statistics, and computer science. Think of it as a container that holds everything.

**Definition:** A non-empty set U is said to be the **universal set** if it contains every element of the universe.

**Theorem:** If A is any subset of U, then A ⊂ U.

In other words, every element of A is also an element of U.

### Solved Examples

#### Example 1:
Suppose U is the set of all real numbers, and A is the set of all integers. Then A ⊂ U because every integer is a real number.

#### Example 2:
Consider a class with 5 students named A, B, C, D, and E. Suppose we want to find the universal set for this class. The universal set would be the set of all 5 students, i.e., U = {A, B, C, D, E}.

#### Example 3:
Let's say we're dealing with a set of numbers from 1 to 20. We can define the universal set as U = {1, 2,..., 20}. Now, if we choose a subset A = {3, 6, 9, 12, 15, 18}, then A ⊂ U.

#### Example 4:
Now, let's examine the statement: "{ a, b } ⊂ { b, c, a }". Here, both sets contain the same elements, just in a different order. However, since { a, b } is a subset of { b, c, a }, we can conclude that { a, b } ⊂ { b, c, a }.

### Practice Problems

1. Is { 2, 3, 4 } ⊂ { 1, 2, 3, 4, 5 }?
2. Are { a, b } and { b, c, a } the same set?
3. Prove that { 1, 2, 3 } ⊂ { 1, 3, 5 }.

| Difficulty | Problem |
| --- | --- |
| 🟢 Easy | 1. |
| 🟡 Medium | 2. |
| 🔴 Hard | 3. |

### Answers

1. Yes, { 2, 3, 4 } ⊂ { 1, 2, 3, 4, 5 }.
2. No, { a, b } ≠ { b, c, a }.
3. To prove that { 1, 2, 3 } ⊂ { 1, 3, 5 }, we need to show that every element of { 1, 2, 3 } is also an element of { 1, 3, 5 }. Since { 1, 2, 3 } ⊆ { 1, 3, 5 }, we have { 1, 2, 3 } ⊂ { 1, 3, 5 }.

### Summary
• Definition of universal set
• Properties of universal set
• Example 1: A ⊂ U
• Example 2: U = {A, B, C, D, E}
• Example 3: A ⊂ U
• Example 4: { a, b } ⊂ { b, c, a }

**Formulas:**

* A ⊂ B ⇒ ∃x ∈ A ∀y ∈ B (y ∈ x)
* A ⊊ B ⇒ ∃x ∈ A ∀y ∈ B (y ∉ x)
* A ∪ B = { x : x ∈ A or x ∈ B }
* A ∩ B = { x : x ∈ A and x ∈ B }
* A \ B = { x : x ∈ A and x ∉ B }
* φ ⊂ A
* φ ∈ A
* A ⊂ φ ⇒ A = φ
