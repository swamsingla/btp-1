## 1.6.1 Subsets of set of real numbers

### Introduction

Can you think of a subset of the set of real numbers R that contains only even numbers? How about one that contains only prime numbers?

In this section, we'll explore the concept of subsets of R, specifically focusing on subsets of the set of real numbers.

### Explanation

A subset of a set A is a set B such that every element of B is also an element of A. In other words, A ⊆ B means that every element of B is contained within A.

For the set of real numbers R, a subset can be any collection of real numbers. For example, the set of natural numbers N = {1, 2, 3, 4, 5,...} is a subset of R, as every natural number is a real number.

Here's a theorem that helps us understand subsets of R:

> **Theorem:** The set of real numbers R is a universal set, meaning that every set is a subset of R.

### Definition

*   **Subset**: A subset of a set A is a set B such that every element of B is also an element of A.
*   **Universal Set**: A set R is called the universal set, and it contains all possible elements.

### Solved Examples

#### Example 1: Find the subset of R that contains only even numbers.

Let's find the subset of R that contains only even numbers. This subset can be represented as:

$$

E = \{x : x \in R \text{ and } x \text{ is even}\}

$$

To solve this problem, we need to identify which numbers are even.

#### Example 2: Find the subset of R that contains only prime numbers.

Now, let's find the subset of R that contains only prime numbers. This subset can be represented as:

$$

P = \{x : x \in R \text{ and } x \text{ is prime}\}

$$

To solve this problem, we need to identify which numbers are prime.

#### Example 3: Find the subset of R that contains both even and odd numbers.

This might seem tricky! However, since every number is either even or odd, we can simply say that the subset of R that contains both even and odd numbers is the entire set R itself:

$$

R = \{x : x \in R\}

$$

### Practice Problems

🟢 **Easy:** Find the subset of R that contains only multiples of 3.

🟡 **Medium:** Find the subset of R that contains only perfect squares.

🔴 **Hard:** Prove that the set of rational numbers Q is a subset of the set of real numbers R.

### Summary

*   A subset of R is a set B such that every element of B is also an element of R.
*   The set of real numbers R is a universal set, containing all possible elements.
*   To find a subset of R, identify which numbers satisfy certain conditions.
