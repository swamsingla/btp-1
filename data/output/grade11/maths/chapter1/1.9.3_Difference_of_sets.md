**Difference of Sets**
=====================

**Introduction**
---------------

What is the difference between the sets {1, 2, 3, 4, 5, 6} and {2, 4, 6, 8}? Can you think of a situation where knowing this might be useful?

In everyday life, we often deal with sets, which are collections of objects. But sometimes, we need to compare and analyze these sets. This is where the concept of difference of sets comes in.

**Explanation**
--------------

The **difference of sets**, denoted by A - B, is the set of elements that belong to A but not to B. In other words, it's the set of elements that are in A but not in B.

Formally, we define the difference of two sets A and B as follows:

$$

A-B=\{x:x\in A\text{ and }x\not\in B\}

$$

This means that for an element x to be part of A - B, it must satisfy two conditions:

*   x must be an element of A (x∈A).
*   x must not be an element of B (x∉B).

**Theorem:** If A and B are two sets, then A - B is also a set.

**Example 1:** Find the difference of the sets A = {1, 2, 3, 4, 5, 6} and B = {2, 4, 6, 8}.

****Solution:**

To find A - B, we need to identify the elements that are in A but not in B.

$$

A-B=\{1, 3, 5\}

$$

Therefore, the difference of A and B is {1, 3, 5}.

**Example 2:** Find the difference of the sets A = {a, b, c} and B = {c, d, e}.

****Solution:**

Again, we identify the elements that are in A but not in B.

$$

A-B=\{a,b\}

$$

So, the difference of A and B is {a, b}.

**Summary**
----------

*   Definition of difference of sets: A - B = {x : x ∈ A and x ∉ B}
*   Example 1: A - B = {1, 3, 5}
*   Example 2: A - B = {a, b}
*   Theorem: If A and B are two sets, then A - B is also a set.

**Student Corner**
-----------------

### Common Mistakes

1.  Not following the definition of difference of sets.
2.  Not considering the condition x ∈ A and x ∉ B.

### Exam Tips

1.  Always check the definition of difference of sets before solving problems.
2.  Pay attention to the conditions x ∈ A and x ∉ B.

### Memory Aid

The word "diff" can help you remember that the difference of two sets involves finding the elements that are in one set but not the other.

**Did You Know?**

The difference of two sets can be used to find the number of elements in a set. For example, the difference of two sets can give us the number of elements in a set that are only in one of those sets.

**Key Vocabulary**

*   **Difference of sets**: A set of elements that belong to one set but not another.
*   **Subset**: A set whose elements are all contained within another set.
*   **Superset**: A set that contains all the elements of another set.
