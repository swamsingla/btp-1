## 1.9.2 Intersection of Sets

### Importance Score: 4/5 ⭐⭐⭐⭐

Are you ready to explore the fascinating world of intersections? The intersection of two sets is a fundamental concept in mathematics, and understanding it is crucial for tackling various problems in algebra, geometry, and beyond!

As you dive into this topic, you'll learn how to find the set of elements that belong to both sets A and B. This is denoted by the symbol ∩. You'll discover how to apply this operation to various sets, including finite and infinite sets, and how it relates to other set operations like union and difference.

### Explanation

The intersection of two sets A and B is defined as:

> **Definition 7**: The intersection of two sets A and B is the set of all elements that belong to both A and B. Symbolically, we write A ∩ B = {x : x ∈ A and x ∈ B}.

To understand this concept better, consider two sets A and B. The intersection of A and B is the set of elements that are present in both A and B.

Let's explore some key properties of the intersection operation:

> > **Properties of Intersection**

(i) A ∩ B = B ∩ A (Commutative Law)
(ii) (A ∩ B) ∩ C = A ∩ (B ∩ C) (Associative Law)
(iii) φ ∩ A = φ, U ∩ A = A (Law of φ and U)
(iv) A ∩ A = A (Idempotent Law)
(v) A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) (Distributive Law)

These properties will help you simplify and manipulate set operations.

### Solved Examples

#### Example 1:
Find the intersection of sets A = {1, 2, 3, 4, 5, 6} and B = {2, 3, 4, 5, 7, 8}.

>> **Step 1:** List the elements of A and B
A = {1, 2, 3, 4, 5, 6}
B = {2, 3, 4, 5, 7, 8}

>> **Step 2:** Identify the common elements between A and B
Common elements: 2, 3, 4, 5

>> **Step 3:** Write the intersection as a set
A ∩ B = {2, 3, 4, 5}

>> **Answer:** A ∩ B = {2, 3, 4, 5}

#### Example 2:
Find the intersection of sets X = {Geeta, Geetika, Kavita, Nalini} and Y = {Geeta, Geetika, Neerja, Nikita}.

>> **Step 1:** List the elements of X and Y
X = {Geeta, Geetika, Kavita, Nalini}
Y = {Geeta, Geetika, Neerja, Nikita}

>> **Step 2:** Identify the common elements between X and Y
Common elements: Geeta, Geetika

>> **Step 3:** Write the intersection as a set
X ∩ Y = {Geeta, Geetika}

>> **Answer:** X ∩ Y = {Geeta, Geetika}

#### Example 3:
Show that A ∩ B = B when A = {1, 2, 3, 4, 5, 6} and B = {2, 3, 4, 5, 7, 8}.

>> **Step 1:** Calculate the intersection of A and B
A ∩ B = {2, 3, 4, 5}

>> **Step 2:** Compare the result with B
B = {2, 3, 4, 5, 7, 8}

>> **Conclusion:** Since A ∩ B = B, we have shown that A ∩ B = B.

>> **Answer:** A ∩ B = B
