## 3. Explanation  

### 3.1 Definition of Finite and Infinite Sets  
> **Definition 2**: A set which is empty or consists of a definite number of elements is called **finite**; otherwise, the set is called **infinite**.  

#### Key Concepts:  
- **Finite set**: A set with a countable number of elements. For example, $ A = \{1, 2, 3, 4, 5\} $ has $ n(A) = 5 $, so it is finite.  
- **Infinite set**: A set with an unlimited number of elements. For example, the set of natural numbers $ \mathbb{N} = \{1, 2, 3, ...\} $ is infinite because its elements cannot be fully listed.  

#### Notation:  
- $ n(S) $: Denotes the number of elements in set $ S $.  
- If $ n(S) $ is a natural number, $ S $ is finite; otherwise, it is infinite.  

### 3.2 Representation of Infinite Sets  
> When representing infinite sets in roster form, we use **ellipsis (...)** to indicate continuation. For example:  
- $ \{1, 2, 3, ...\} $: Natural numbers.  
- $ \{1, 3, 5, 7, ...\} $: Odd natural numbers.  
- $ \{..., -3, -2, -1, 0, 1, 2, 3, ...\} $: Integers.  

However, **not all infinite sets** can be expressed in roster form. For instance, the set of **real numbers** is infinite but lacks a discernible pattern, making it impossible to describe explicitly.  

### 3.3 Examples from the Source Text  
The source provides several illustrative examples:  
- **Finite sets**:  
  - $ W = \{\text{Days of the week}\} $: Contains 7 elements.  
  - $ S = \{x \in \mathbb{R} \mid x^2 - 16 = 0\} $: Solutions are $ \{-4, 4\} $, hence finite.  
- **Infinite set**:  
  - $ G = \{\text{Points on a line}\} $: Infinitely many points exist along a line.  

These examples highlight the contrast between bounded and unbounded collections.  

### 3.4 Proof of Infinite Set Properties  
**Theorem**: The set of natural numbers $ \mathbb{N} $ is infinite.  
**Proof**: Assume $ \mathbb{N} $ is finite. Then $ n(\mathbb{N}) = k $ for some natural number $ k $. However, $ k+1 \in \mathbb{N} $ contradicts the assumption that $ k $ is the maximum element. Thus, $ \mathbb{N} $ must be infinite.

## 4. Solved Examples  

### Example 1:  
Determine whether the set $ \{x \in \mathbb{N} \mid (x - 1)(x - 2) = 0\} $ is finite or infinite.  
**Solution**:  
- Solve $ (x - 1)(x - 2) = 0 $:  
  $ x = 1 $ or $ x = 2 $.  
- The set is $ \{1, 2\} $, which contains 2 elements.  
- Since $ n(S) = 2 $, the set is **finite**.  

### Example 2:  
Is the set $ \{x \in \mathbb{N} \mid x^2 = 4\} $ finite or infinite?  
**Solution**:  
- Solve $ x^2 = 4 $: $ x = 2 $ or $ x = -2 $.  
- But $ x \in \mathbb{N} $, so only $ x = 2 $ is valid.  
- The set is $ \{2\} $, containing 1 element.  
- Therefore, it is **finite**.  

### Example 3:  
Analyze the set $ \{x \in \mathbb{N} \mid 2x - 1 = 0\} $.  
**Solution**:  
- Solve $ 2x - 1 = 0 $: $ x = \frac{1}{2} $.  
- Since $ \frac{1}{2} \notin \mathbb{N} $, the set is empty ($ \emptyset $).  
- An empty set is **finite** by definition.  

### Example 4:  
State whether the set $ \{x \in \mathbb{N} \mid x \text{ is prime}\} $ is finite or infinite.  
**Solution**:  
- Prime numbers are natural numbers greater than 1 with no divisors other than 1 and themselves.  
- There are infinitely many primes (as proven by Euclid’s theorem).  
- Hence, the set is **infinite**.  

### Example 5:  
Explain why the set $ \{x \in \mathbb{R} \mid x^2 + 1 = 0\} $ is finite.  
**Solution**:  
- Solve $ x^2 + 1 = 0 $: $ x = i $ or $ x = -i $.  
- These are imaginary numbers, not real numbers.  
- Thus, the set is empty ($ \emptyset $), which is **finite**.

## 5. Practice Problems  

### 🟢 Easy  
**Problem 1**: Is the set $ \{x \in \mathbb{Z} \mid x < 10\} $ finite or infinite?  
**Problem 2**: Determine the nature of the set $ \{x \in \mathbb{N} \mid x \text{ is even and } x < 5\} $.  

### 🟡 Medium  
**Problem 3**: Analyze the set $ \{x \in \mathbb{R} \mid x^2 - 9 = 0\} $. Is it finite or infinite?  
**Problem 4**: Classify the set $ \{x \in \mathbb{N} \mid x \text{ is divisible by both 2 and 3}\} $.  

### 🔴 Hard  
**Problem 5**: Prove that the set of all rational numbers $ \mathbb{Q} $ is infinite.  

---

### Answers:  

**Problem 1**:  
- $ \{x \in \mathbb{Z} \mid x < 10\} = \{..., -2, -1, 0, 1, 2, ..., 8, 9\} $.  
- Since integers extend indefinitely in both directions, this set is **infinite**.  

**Problem 2**:  
- $ \{x \in \mathbb{N} \mid x \text{ is even and } x < 5\} = \{2, 4\} $.  
- Contains 2 elements → **finite**.  

**Problem 3**:  
- $ x^2 - 9 = 0 \Rightarrow x = 3 $ or $ x = -3 $.  
- Both are real numbers → Set is $ \{-3, 3\} $, hence **finite**.  

**Problem 4**:  
- Multiples of 6 less than 10: $ \{6\} $.  
- Only one element → **finite**.  

**Problem 5**:  
- Rational numbers $ \mathbb{Q} $ can be written as $ \frac{p}{q} $, where $ p, q \in \mathbb{Z}, q \neq 0 $.  
- For each integer $ q $, there are infinitely many numerators $ p $.  
- Hence, $ \mathbb{Q} $ is **infinite**.

## 6. Summary  
- A **finite set** has a definite number of elements ($ n(S) $ is a natural number).  
- An **infinite set** has an unlimited number of elements (e.g., $ \mathbb{N} $, $ \mathbb{Z} $).  
- The **empty set** ($ \emptyset $) is always finite.  
- Infinite sets are represented in roster form using ellipsis (...).  
- Real numbers cannot be fully described in roster form due to their infinite, non-patterned nature.  

---  

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ n(S) $ | Number of elements in set $ S $ |  
| $ \emptyset $ | Empty set (contains no elements) |  
| $ \{x \in \mathbb{N} \mid P(x)\} $ | Set-builder notation for finite/infinite sets |  
| $ \{a, b, c, ...\} $ | Roster form with ellipsis for infinite sets |

## 8. Student Corner  

### Common Mistakes  
- ❌ Confusing the **empty set** with an infinite set: The empty set is **finite**, not infinite.  
- ❌ Misrepresenting infinite sets: Using ellipsis incorrectly (e.g., $ \{1, 2, 3\} $ instead of $ \{1, 2, 3, ...\} $).  

### Exam Tips  
- Always check if a set has a **definite number of elements** or if it extends indefinitely.  
- For **equations**, solve them to determine if the resulting set is finite or infinite.  

### Memory Aid  
**F**inite = **F**ixed number of elements.  
**I**nfinite = **I**nlimitless elements.
