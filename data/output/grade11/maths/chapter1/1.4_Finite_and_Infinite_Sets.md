## Introduction
Do you ever wonder how many people live in different parts of the world? Can you imagine counting them? Well, let's consider a set C, which represents the set of men living presently in different parts of the world. Although we don't know the exact number of elements in C, we can discuss whether C is finite or infinite.

As you study this topic, you'll learn about the difference between finite and infinite sets, and how to identify and work with both types of sets.

## Explanation
### Definition of Finite and Infinite Sets
A set which is empty or consists of a definite number of elements is called a **finite set**, whereas a set which is not empty and has an infinite number of elements is called an **infinite set**.

### Important Terms
- **Roster Form**: A way to describe a set by listing its elements within braces {... }
- **Universal Set**: A set containing all elements of the sample space (e.g., the set of natural numbers)
- **Empty Set**: A set containing no elements (φ)
- **Subsets**: A subset of a set A is a set B such that every element of B is also an element of A

### Key Formulas

### Example 1:
Show that the set of natural numbers, denoted by N, is an infinite set.

$$

N = \{1, 2, 3,...\}

$$

Since there is no largest natural number, N is an infinite set.

$ A \cap B = \{1, 2, 3, 4, 5\} $

### Example 4:

C is an infinite set since there is no fixed limit to the number of men living in different parts of the world.

## Solved Examples
### Example 1:
Determine whether the set D = {x : x ∈ Z and (x + 1)(x + 2) = 0} is finite or infinite.

Solution:
The equation $ (x+1)(x+2)=0 $ has only two roots, $ x=-1 $ and $ x=-2 $. Therefore, D = {-1, -2}, which is a finite set.

### Example 2:
Show that the set E = {x : x ∈ Q and x^2 < 4} is finite.

Solution:
E is the set of rational numbers whose absolute values are less than 2. Since there are countably infinite rational numbers less than 2, E is finite.

### Example 3:
Find the complement of the set F = {1, 2, 3,..., 100}.

Solution:
F' = {x : x ∉ {1, 2, 3,..., 100}

### Example 4:
Determine whether the set G = {x : x ∈ N and x^2 = 4} is finite or infinite.

Solution:
G = {2}. Therefore, G is a finite set.

## Summary
* A finite set is either empty or has a finite number of elements.
* An infinite set has an uncountable number of elements.
* The **union** of two sets A and B is the set of elements common to both A and B.
* The **intersection** of two sets A and B is the set of elements common to both A and B.
* The **complement** of a set A is the set of elements not in A.
