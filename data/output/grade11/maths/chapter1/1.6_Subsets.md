# 1.6 Subsets

> **Grade 11** | **Chapter 1: SETS**

## 1. Prerequisites  
Before studying this topic, students should already understand:  
- **Set notation**: How to represent sets using curly braces and elements (e.g., $A = \{1, 2, 3\} $).  
- **Element membership**: The symbol $\in $ to denote that an element belongs to a set (e.g., $ 2 \in A $).  
- **Equality of sets**: Two sets are equal if they contain exactly the same elements (e.g., $ A = B $ iff $ A \subset B $ and $ B \subset A $).  

---  

## 2. Introduction  
Imagine a school with multiple classes. Let $ X $ be the set of all students in the school, and $ Y $ be the set of students in your class. Notice that every student in $ Y $ is also in $ X $. This relationship is central to understanding **subsets**. In this topic, you will learn how to determine whether one set is entirely contained within another, explore special cases like the **empty set**, and apply this concept to real-world scenarios. By mastering subsets, you’ll build foundational skills for analyzing relationships between sets, which are essential for advanced topics like Venn diagrams and set operations.  

---  

## 3. Explanation  

### 3.1 Definition of Subset  
> **Definition**: A set $ A $ is a **subset** of a set $ B $ if every element of $ A $ is also an element of $ B $. Symbolically, this is written as $ A \subset B $.  
>  
> **Formal Proof**: To prove $ A \subset B $, we must show that for all elements $ a $, if $ a \in A $, then $ a \in B $. Mathematically, this is expressed as:  
>

$$  
> a \in A \Rightarrow a \in B  
>

$$  
> This implication holds true if **all elements of $A $ satisfy the condition of belonging to $ B $**.  

### 3.2 Proper Subsets vs. Subsets  
> **Definition**: If $ A \subset B $ and $ A \neq B $, then $ A $ is a **proper subset** of $ B $, and $ B $ is a **superset** of $ A $.  
>  
> **Note**: The empty set $\emptyset $ is a subset of **every set**. This is because the condition "every element of $\emptyset $" is vacuously true.  

### 3.3 Special Cases  
#### Case 1: Empty Set  
- The empty set $\emptyset $ is a subset of every set $ B $:

$$  
  \emptyset \subset B \quad \text{for any set } B

$$  
- Example: $\emptyset \subset \{1, 2, 3\} $ is always true.  

#### Case 2: Equality of Sets  
- Two sets $ A $ and $ B $ are equal if and only if:

$$  
  A \subset B \quad \text{and} \quad B \subset A

$$  
- This equivalence ensures both sets contain exactly the same elements.  

### 3.4 Interval Notation as Subsets of $\mathbb{R} $  
The source text mentions intervals as subsets of real numbers $\mathbb{R} $. For example:  
- $ [1, 3] $ represents all real numbers $ x $ such that $ 1 \leq x \leq 3 $.  
- $ (1, 3) $ represents all real numbers $ x $ such that $ 1 < x < 3 $.  
These intervals are subsets of $\mathbb{R} $ depending on their endpoints.

## 4. Solved Examples  

### Example 1:  
Determine whether $ A = \{1, 3\} $ is a subset of $ B = \{1, 2, 3, 4\} $.  
**Solution**:  
- Check if every element of $ A $ is in $ B $:  
  - $ 1 \in B $ ✔️  
  - $ 3 \in B $ ✔️  
- Since all elements of $ A $ belong to $ B $, we conclude:

$$  
  A \subset B

$$  

### Example 2:  
Is $C = \{1, 2, 5\} $ a subset of $ D = \{1, 2, 3, 4\} $?  
**Solution**:  
- Check $ 5 \in D $: False.  
- Therefore, $ C \not\subset D $.  

### Example 3:  
Verify that $\emptyset \subset \{a, b, c\} $.  
**Solution**:  
- The empty set has no elements, so the condition "every element of $\emptyset $" is trivially satisfied.  
- Hence, $\emptyset \subset \{a, b, c\} $.  

### Example 4:  
Given $ P = \{x : x \text{ is an even integer}\} $ and $ Q = \{x : x \text{ is an integer}\} $, show $ P \subset Q $.  
**Solution**:  
- Every even integer is an integer.  
- Therefore, $ P \subset Q $ holds true.  

### Example 5:  
Compare $ A = \{1, 3, 5\} $ and $ B = \{x : x \text{ is an odd natural number less than 6}\} $.  
**Solution**:  
- $ B = \{1, 3, 5\} $ (since odd numbers less than 6 are 1, 3, 5).  
- Both $ A \subset B $ and $ B \subset A $ hold.  
- Thus, $ A = B $.

## 5. Practice Problems  

### 🟢 Easy  
**Problem 1**: Determine if $\{2, 4\} \subset \{1, 2, 3, 4\} $.  
**Problem 2**: Is $\emptyset \subset \{\emptyset\} $? Justify your answer.  

### 🟡 Medium  
**Problem 3**: Given $ E = \{x : x \text{ is a vowel}\} $ and $ F = \{a, e, i, o, u, y\} $, find $ E \subset F $.  
**Problem 4**: Prove that $ A \subset A $ for any set $ A $.  

### 🔴 Hard  
**Problem 5**: Let $ G = \{x : x \in \mathbb{N} \text{ and } x < 10\} $. Identify all subsets of $ G $ that contain only prime numbers.  

**Answers**:  
**Problem 1**: Yes, since $ 2, 4 \in \{1, 2, 3, 4\} $.  
**Problem 2**: Yes, because $\emptyset $ is a subset of every set.  
**Problem 3**: $ E = \{a, e, i, o, u\} $, and all elements of $ E $ are in $ F $, so $ E \subset F $.  
**Problem 4**: By definition, every element of $ A $ is in $ A $, so $ A \subset A $ holds.  
**Problem 5**: Subsets containing primes: $\{2\}, \{3\}, \{5\}, \{7\}, \{2, 3\}, \{2, 5\}, \dots, \{2, 3, 5, 7\} $.

## 6. Summary  
- **Subset**: $ A \subset B $ if every element of $ A $ is in $ B $.  
- **Proper Subset**: $ A \subset B $ and $ A \neq B $.  
- **Empty Set**: $\emptyset \subset B $ for any set $ B $.  
- **Equality**: $ A = B $ iff $ A \subset B $ and $ B \subset A $.  
- **Intervals**: Subsets of $\mathbb{R} $ defined by inequalities.  
- **Venn Diagrams**: Visual tools to represent subset relationships.  

---  

## 7. Key Formulas  
| Formula | Description |  
|--------|-------------|  
| $ A \subset B $ | $ A $ is a subset of $ B $ |  
| $ A \subset A $ | Every set is a subset of itself |  
| $\emptyset \subset B $ | Empty set is a subset of every set $ B $ |  
| $ A = B $ iff $ A \subset B $ and $ B \subset A $ | Equality of sets |  
| $ a \in A \Rightarrow a \in B $ | Formal definition of subset |

## 8. Student Corner  

### Common Mistakes  
- ❌ Confusing **subset** with **equal set**: Always verify if $ A \subset B $ and $ B \subset A $ for equality.  
- ❌ Assuming $\emptyset $ cannot be a subset: Remember $\emptyset $ is a subset of **every** set.  
- ❌ Misinterpreting interval notation: $ [1, 3] $ includes endpoints, while $ (1, 3) $ excludes them.  

### Exam Tips  
- Draw Venn diagrams to visualize subset relationships during exams.  
- Practice distinguishing between proper and improper subsets.  

### Memory Aid  
**"Subsets: All elements in A must live in B!"**  
Remember, for $ A \subset B $, **every** element of $ A $ must exist in $ B $.
