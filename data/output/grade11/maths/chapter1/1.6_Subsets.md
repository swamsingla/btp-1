## Subsets
### Importance Score: 4/5 ⭐⭐⭐⭐

Are you ready to dive into the world of sets and explore the concept of subsets?

As you might recall from your earlier studies, a set is a collection of unique objects, known as elements or members, that can be anything (numbers, letters, shapes, etc.). Now, let's delve deeper into the realm of subsets, which is a fundamental aspect of set theory.

### Definition
A set A is said to be a **subset** of a set B if every element of A is also an element of B. This relationship is denoted by the symbol ⊂, read as "is a subset of" or "is contained in."

### Notation
To express that A is a subset of B, we write A ⊂ B. Conversely, if A is not a subset of B, we write A ⊄ B.

### Definition 4
A set A is a **proper subset** of a set B if A is a subset of B and A ≠ B.

### Example 9
Consider the sets φ, A = {1, 3}, B = {1, 5, 9}, and C = {1, 3, 5, 7, 9}. Insert the symbol ⊂ or ⊄ between each of the following pairs of sets:

(i) φ... B
(ii) A... B
(iii) A... C
(iv) B... C

**Solution:**

(i) φ ⊂ B because φ is a subset of every set.
(ii) A ⊄ B because 3 ∈ A and 3 ∉ B
(iii) A ⊂ C because 1, 3 ∈ A also belong to C
(iv) B ⊂ C because each element of B is also an element of C.

### Important Concepts
#### Theorem
> **Subset Property**: A ⊂ B if and only if (if and only if) a ∈ A ⇒ a ∈ B, where "⇒" denotes implication.

#### Key Formulas

* A ⊂ B if a ∈ A ⇒ a ∈ B
* A ⊄ B if a ∈ A ∧ a ∉ B

### Explanation

To grasp the concept of subsets, let's break it down step by step.

Firstly, consider the definition of a subset: A ⊂ B if every element of A is also an element of B. In other words, A is a subset of B if for every element a in A, a is also in B.

Now, let's examine the notation A ⊂ B. This reads as "A is a subset of B." To prove that A is indeed a subset of B, we need to show that for every element a in A, a is also in B.

For example, suppose we want to show that A = {1, 3} is a subset of B = {1, 5, 9}. To do so, we need to demonstrate that for every element x in A, x is also in B. We can easily verify this by checking each element in A:

* 1 ∈ A and 1 ∈ B
* 3 ∈ A and 3 ∈ B

Since both conditions hold, we conclude that A is indeed a subset of B, and we write A ⊂ B.

Next, let's explore the concept of proper subsets. A set A is a proper subset of B if A is a subset of B but A ≠ B.

For instance, A = {1, 2, 3} is a proper subset of B = {1, 2, 3, 4}, since A ⊂ B but A ≠ B.

### Solved Examples

#### Example 1:
Show that A = {1, 2, 3} is a subset of B = {1, 2, 3, 4}.

**Solution:**
A ⊂ B because for every element a in A, a is also in B:
* 1 ∈ A and 1 ∈ B
* 2 ∈ A and 2 ∈ B
* 3 ∈ A and 3 ∈ B

Since all elements of A are also elements of B, we conclude that A ⊂ B.

#### Example 2:
Determine whether A = {1, 3, 5} is a subset of B = {1, 2, 3, 4, 5}.

**Solution:**
A ⊃ B because for every element a in A, a is also in B:
* 1 ∈ A and 1 ∈ B
* 3 ∈ A and 3 ∈ B
* 5 ∈ A and 5 ∈ B

However, we notice that A does not contain 2, which is an element of B. Therefore, A ⊂ B is false.

#### Example 3:
Show that A = {1, 3} is a proper subset of B = {1, 3, 5, 7, 9}.

**Solution:**
A ⊂ B because for every element a in A, a is also in B:
* 1 ∈ A and 1 ∈ B
* 3 ∈ A and 3 ∈ B

However, A ≠ B because A contains fewer elements than B. Hence, A is a proper subset of B.

#### Example 4:
Determine whether A = {1, 2, 3} is a subset of B = {2, 3, 4, 5, 6}.

**Solution:**
A ⊄ B because 1 ∈ A and 1 ∉ B

Since not every element of A is an element of B, we conclude that A is not a subset of B.

### Summary

* A ⊂ B if a ∈ A ⇒ a ∈ B
* A ⊄ B if a ∈ A ∧ a ∉ B
* A proper subset of B if A ⊂ B and A ≠ B

### Common Mistakes
* Forgetting to check every element of A to see if it's also in B
* Failing to distinguish between subsets and supersets

### Exam Tips
* Read the problem carefully and understand what's being asked
* Make sure to check every element of A to see if it's also in B

### Memory Aid
Use the mnemonic "Subset" to remember the definition: "S" stands for "some" element in A that's also in B, and "T" stands for "the rest" of A's elements that might not be in B.
