## 2. Introduction  
Have you ever compared two collections to see if they contain *exactly* the same items? For example, if you have two bags of marbles—one with red, blue, and green marbles—and the other with the same colors, they’re essentially identical. In mathematics, this idea translates to **equal sets**.  
This topic explores when two sets are considered equal, emphasizing that **order and repetition don’t matter**. By the end of this lesson, you’ll be able to determine whether two sets are equal by examining their elements. This builds on your understanding of sets from Sections 1.1 to 1.4.  

---

## 3. Explanation  

### 3.1 Definition of Equal Sets  
> **Two sets $ A $ and $ B $ are equal** if they contain exactly the same elements. This is written as $ A = B $. If they differ in even one element, they are **unequal** ($ A \neq B $).  

#### Key Points:  
- **Order doesn’t matter**: $\{1, 2, 3\} = \{3, 2, 1\} $  
- **Repetition doesn’t matter**: $\{1, 2, 2, 3\} = \{1, 2, 3\} $  
- **Empty sets are equal**: $\emptyset = \emptyset $  

### 3.2 Properties of Equal Sets  
> **Property 1**: If $ A = B $, then every element of $ A $ is in $ B $ and vice versa.  
> **Property 2**: If $ A = B $ and $ B = C $, then $ A = C $ (transitivity).  
> **Property 3**: A set is equal to itself ($ A = A $).  

### 3.3 Example Analysis  
From the source text:  
- Let $ A = \{1, 2, 3, 4\} $ and $ B = \{3, 1, 4, 2\} $. Here, $ A = B $ because both contain the same elements.  
- Let $ A $ be the set of primes less than 6 ($\{2, 3, 5\} $) and $ P $ be the set of prime factors of 30 ($\{2, 3, 5\} $). Then $ A = P $.  

### 3.4 Note on Repeated Elements  
> **Note**: A set remains unchanged if elements are repeated. For example, $\{1, 2, 3\} = \{1, 1, 2, 2, 3, 3\} $. This is why sets are defined with unique elements.

## 4. Solved Examples  

### Example 1:  
**Question**: Determine if $ A = \{a, b, c\} $ and $ B = \{c, b, a\} $ are equal.  
**Solution**:  
- Check if every element of $ A $ is in $ B $: $ a, b, c \in B $  
- Check if every element of $ B $ is in $ A $: $ c, b, a \in A $  
- Since both sets contain the same elements, $ A = B $.  

### Example 2:  
**Question**: Are $ A = \{1, 2, 3\} $ and $ B = \{1, 2, 4\} $ equal?  
**Solution**:  
- $ 3 \in A $ but $ 3 \notin B $, and $ 4 \in B $ but $ 4 \notin A $.  
- Hence, $ A \neq B $.  

### Example 3:  
**Question**: Given $ A = \{x : x^2 = 4\} $ and $ B = \{2, -2\} $, show $ A = B $.  
**Solution**:  
- Solve $ x^2 = 4 $: $ x = 2 $ or $ x = -2 $.  
- Thus, $ A = \{2, -2\} = B $.  

### Example 4:  
**Question**: Verify if $ A = \{x : x \text{ is a vowel in } \text{"EQUAL"}\} $ and $ B = \{E, U, A\} $ are equal.  
**Solution**:  
- "EQUAL" has vowels $ E, U, A $.  
- $ A = \{E, U, A\} = B $.  

### Example 5:  
**Question**: Prove that $ A = \{x : x \in \mathbb{N}, x < 5\} $ and $ B = \{1, 2, 3, 4\} $ are equal.  
**Solution**:  
- $ A $ contains natural numbers less than 5: $\{1, 2, 3, 4\} $.  
- $ B $ is explicitly $\{1, 2, 3, 4\} $.  
- Hence, $ A = B $.

## 5. Practice Problems  

### 🟢 Easy  
**Problem 1**: Are $ A = \{1, 2, 3\} $ and $ B = \{3, 2, 1\} $ equal? Justify.  
**Answer**: Yes. Both contain the same elements.  

**Problem 2**: Is $ A = \{a, e, i\} $ equal to $ B = \{i, a, e\} $?  
**Answer**: Yes. Order does not affect equality.  

### 🟡 Medium  
**Problem 3**: Let $ A = \{x : x \text{ is a letter in "MATH"}\} $ and $ B = \{M, A, T, H\} $. Are they equal?  
**Answer**: Yes. Both contain $\{M, A, T, H\} $.  

**Problem 4**: Are $ A = \{x : x^2 = 9\} $ and $ B = \{3, -3\} $ equal?  
**Answer**: Yes. Solving $ x^2 = 9 $ gives $ x = 3 $ or $ x = -3 $.  

### 🔴 Hard  
**Problem 5**: Given $ A = \{x : x \text{ is an integer satisfying } x^2 - 5x + 6 = 0\} $ and $ B = \{2, 3\} $, prove $ A = B $.  
**Answer**:  
- Solve $ x^2 - 5x + 6 = 0 $: $ (x-2)(x-3) = 0 $ → $ x = 2 $ or $ x = 3 $.  
- Thus, $ A = \{2, 3\} = B $.  

---

## 6. Summary  
- **Equal sets** have exactly the same elements.  
- **Order and repetition** do not affect equality.  
- If $ A = B $, then $ A \subset B $ and $ B \subset A $.  
- The **empty set** is equal to itself.  
- Use **membership checks** to compare sets.  
- **Equality implies identity** in elements, not just quantity.  

---

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ A = B $ | $ A $ and $ B $ are equal sets |  
| $ A \neq B $ | $ A $ and $ B $ are unequal |  
| $ x \in A $ | Element $ x $ belongs to set $ A $ |  
| $ x \notin A $ | Element $ x $ does not belong to set $ A $ |  
| $ A = \{x : P(x)\} $ | Set-builder notation for $ A $ |

## 8. Student Corner  

### Common Mistakes  
- ❌ Confusing **equal sets** with **equivalent sets** (same size, different elements):  
  - **Correct**: Equal sets must have identical elements.  
- ❌ Assuming repeated elements change the set:  
  - **Correct**: $\{1, 1, 2\} = \{1, 2\} $.  

### Exam Tips  
- Always verify **every element** of one set against the other.  
- Use **set-builder notation** to clarify ambiguous cases.  

### Memory Aid  
**Rhyme**: *"Equal sets, same elements—repeats don't count, order’s a myth!"*
