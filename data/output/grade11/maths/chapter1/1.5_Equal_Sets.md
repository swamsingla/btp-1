### 1.5 Equal Sets

#### Importance Score: 3/5 ⭐⭐⭐

Have you ever wondered how to check if two sets are the same? Are there any special conditions that need to be met for two sets to be considered equal?

This topic will cover the concept of equal sets, including definitions, examples, and techniques for determining equality between sets.

#### Introduction

Have you ever seen a situation where you had to compare two sets? Maybe you were trying to determine if two sets had the same elements or if they were disjoint (had no elements in common). In such cases, the concept of equal sets comes into play.

Equal sets are sets that contain exactly the same elements, regardless of the order or repetition of the elements. In other words, two sets are equal if and only if they have exactly the same elements.

#### Explanation

A set can be defined as:

> **Definition**: A **set** is a collection of unique objects, known as elements or members, that can be anything (numbers, letters, people, etc.).

Two sets are equal if they have exactly the same elements. This means that for every element in one set, there is a corresponding element in the other set, and vice versa.

Here's a simple way to remember it:

*   Two sets are equal if they are mutually **interchangeable**, meaning you can swap them without changing their contents.

For example, let's say we have two sets:

A = {1, 2, 3}

B = {3, 2, 1}

As you can see, both sets contain the same three elements, just in a different order. Therefore, A = B.

On the other hand, suppose we have two sets:

A = {a, b, c}

B = {c, a, b}

These sets are not equal because the order of the elements is different.

#### Theorem

Two sets A and B are equal if and only if they have exactly the same elements.

$$

A = B \iff \forall x (x \in A \implies x \in B) \land \forall y (y \in B \implies y \in A)

$$

Where $x $ and $ y $ represent any element in the respective sets.

#### Solved Examples

Here are a few examples to illustrate the concept of equal sets:

1.  Let A = {1, 2, 3, 4} and B = {3, 1, 4, 2}. Then A = B.
2.  Let A be the set of prime numbers less than 6 and B the set of prime factors of 30. Then A and B are equal, since 2, 3, and 5 are the only prime factors of 30 and also these are less than 6.
3.  Consider the sets A = {0}, B = {x : x > 15 and x < 5}, C = {x : x – 5 = 0 }, D = {x: x2 = 25}, and E = {x : x is an integral positive root of the equation x2 – 2x – 15 = 0}. Further, D = {–5, 5} and E = {5}, we find that, D ≠ E.

#### Summary

Here are some key takeaways from this topic:

*   Two sets are equal if they have exactly the same elements.
*   A set does not change if one or more elements of the set are repeated.
*   To check if two sets are equal, look for identical elements in both sets.

#### Student Corner

*   **Common Mistake**: Forgetting that a set does not change if one or more elements are repeated.
*   **Exam Tip**: When checking if two sets are equal, make sure to compare each element in one set to the corresponding element in the other set.

#### Key Vocabulary

*   **Equal sets**: Sets with exactly the same elements.
*   **Mutually interchangeable**: Two sets that can be swapped without changing their contents.

#### Memory Aid

To remember that two sets are equal if they have the same elements, try to imagine swapping two sets like LEGO blocks. If they fit together perfectly, then they are equal!
