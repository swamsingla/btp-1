## Explanation

### Definition of a Set

A set is a well-defined collection of objects, known as elements or members, that satisfy certain properties. These properties can be based on various characteristics, such as numbers, letters, or shapes.

### Roster Form vs. Set-Builder Form

There are two ways to represent a set: roster form and set-builder form.

*   Roster form: This involves listing all the elements of a set within curly brackets, separated by commas. For example: {1, 2, 3, 4, 5}.
*   Set-builder form: This involves describing a set using a rule or property that defines its elements. For example: {x : x is an integer and -3 ≤ x < 7}.

Both forms are useful, and the choice of form depends on the context and the type of set.

### Types of Sets

Sets can be classified into several types, including:

*   **Finite sets**: These have a finite number of elements.
*   **Infinite sets**: These have an infinite number of elements.
*   **Empty set**: This is a set with no elements.
*   **Universal set**: This is a set that contains all possible elements under consideration.

## Solved Examples

### Example 1:

Find the solution set of the equation x^2 - 5x + 6 = 0 in roster form.

**Solution:**

To find the solution set, we need to factor the quadratic expression:

x^2 - 5x + 6 = (x - 2)(x - 3) = 0

This gives us two solutions: x = 2 and x = 3.

So, the solution set in roster form is {2, 3}.

### Example 2:

Find the set {x : x is a natural number and x^2 < 40} in roster form.

**Solution:**

To find the elements of the set, we need to consider natural numbers whose squares are less than 40.

x^2 < 40

Taking the square root of both sides, we get:

- √40 < x
- √(20)^2 < x < √(50)^2
- 5.657 < x < 7.071

Since x must be a natural number, the elements of the set are: {6}
