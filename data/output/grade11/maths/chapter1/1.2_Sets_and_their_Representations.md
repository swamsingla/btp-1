In this topic, we explore how to formally describe these collections using precise tools. By mastering **sets and their representations**, you’ll gain foundational skills for tackling advanced topics like functions, relations, and probability.  

This section focuses on:

## 3. Explanation  

### 3.1 Definition of a Set  
> A **set** is a **well-defined collection** of distinct objects. These objects, called **elements** or **members**, share a common property that allows us to determine definitively whether a given object belongs to the set or not.  

For example:  
- The set of vowels in the English alphabet is well-defined because we can unambiguously identify $ a, e, i, o, u $.  
- The collection of "most renowned mathematicians" is **not** a set, as the term "renowned" is subjective and varies across individuals.  

### 3.2 Membership and Notation  
> If an object $ a $ is an element of a set $ A $, we write $ a \in A $. Conversely, if $ a $ is not in $ A $, we write $ a \notin A $.  

Examples:  
- $ 2 \in \{1, 2, 3\} $  
- $ 4 \notin \{1, 2, 3\} $  

### 3.3 Representation Methods  
There are two primary ways to represent sets:  

#### 3.3.1 Roster Form (Tabular Form)  
- Lists all elements within curly braces $ \{\} $, separated by commas.  
- Example: The set of even numbers less than 10 is written as $ \{2, 4, 6, 8\} $.  

#### 3.3.2 Set-Builder Form  
- Describes a set using a rule or property that defines its elements.  
- General form: $ \{x \mid P(x)\} $, where $ P(x) $ is a condition that elements $ x $ must satisfy.  
- Example: The set of odd natural numbers less than 10 is written as $ \{x \in \mathbb{N} \mid x < 10 \text{ and } x \text{ is odd}\} $.  

### 3.4 Special Sets and Notation  
The following special sets are frequently used in mathematics:  
| Symbol | Description |  
|--------|-------------|  
| $ \mathbb{N} $ | Natural numbers $ \{1, 2, 3, \dots\} $ |  
| $ \mathbb{Z} $ | Integers $ \{\dots, -2, -1, 0, 1, 2, \dots\} $ |  
| $ \mathbb{Q} $ | Rational numbers $ \left\{ \frac{p}{q} \mid p, q \in \mathbb{Z}, q \ne 0 \right\} $ |  
| $ \mathbb{R} $ | Real numbers (all rational and irrational numbers) |  
| $ \mathbb{Z}^+ $ | Positive integers $ \{1, 2, 3, \dots\} $ |  
| $ \mathbb{Q}^+ $ | Positive rational numbers |  
| $ \mathbb{R}^+ $ | Positive real numbers |  

These sets are **universal** in mathematics and will recur in later topics.  

### 3.5 Universal Set  
> A **universal set** $ U $ is a set that contains all the elements under consideration in a particular context.  

For example, if discussing the set of vowels, the universal set might be the entire English alphabet $ \{a, b, c, \dots, z\} $.

## 4. Solved Examples  

### **Example 1:**  
Represent the set of prime factors of 210 in both roster and set-builder form.  
**Solution:**  
- **Roster form**: $ \{2, 3, 5, 7\} $  
- **Set-builder form**: $ \{x \in \mathbb{N} \mid x \text{ divides } 210 \text{ and } x \text{ is prime} \} $  

### **Example 2:**  
Determine whether $ 5 \in \{1, 3, 5, 7\} $ and $ 6 \in \{1, 3, 5, 7\} $.  
**Solution:**  
- $ 5 \in \{1, 3, 5, 7\} $ is **true**.  
- $ 6 \in \{1, 3, 5, 7\} $ is **false**, since 6 is not in the set.  

### **Example 3:**  
Write the set of solutions to the equation $ x^2 - 5x + 6 = 0 $ in set-builder form.  
**Solution:**  
Factorizing: $ x^2 - 5x + 6 = (x - 2)(x - 3) = 0 $.  
Thus, the roots are $ x = 2 $ and $ x = 3 $.  
**Set-builder form**: $ \{x \in \mathbb{R} \mid x^2 - 5x + 6 = 0\} $  

### **Example 4:**  
Identify whether the following are sets:  
(a) Collection of "most famous scientists"  
(b) Collection of "even numbers greater than 10"  
**Solution:**  
(a) **Not a set**—subjective criteria ("famous") make membership ambiguous.  
(b) **Is a set**—clear property (evenness > 10) allows definitive membership checks.  

### **Example 5:**  
Express $ \{x \in \mathbb{Z} \mid x^2 < 4\} $ in roster form.  
**Solution:**  
Find integers $ x $ satisfying $ x^2 < 4 $:  
- $ x = -1 $: $ (-1)^2 = 1 < 4 $  
- $ x = 0 $: $ 0^2 = 0 < 4 $  
- $ x = 1 $: $ 1^2 = 1 < 4 $  
- $ x = 2 $: $ 4 $ is not less than 4  
Thus, the set is $ \{-1, 0, 1\} $.

## 5. Practice Problems  

### 🟢 Easy  
**Problem 1:**  
Represent the set of months with 31 days in roster form.  
**Answer:** $ \{\text{January}, \text{March}, \text{May}, \text{July}, \text{August}, \text{October}, \text{December}\} $  

**Problem 2:**  
Write $ \{x \in \mathbb{N} \mid x < 5\} $ in roster form.  
**Answer:** $ \{1, 2, 3, 4\} $  

---

### 🟡 Medium  
**Problem 3:**  
Is $ \sqrt{2} \in \mathbb{Q} $? Justify your answer.  
**Answer:** No. $ \sqrt{2} $ is irrational (cannot be expressed as $ \frac{p}{q} $ with integer $ p, q $).  

**Problem 4:**  
Convert $ \{x \in \mathbb{R} \mid x^2 = 9\} $ to roster form.  
**Answer:** $ \{-3, 3\} $  

---

### 🔴 Hard  
**Problem 5:**  
Prove that the set $ \{x \in \mathbb{Z} \mid x \text{ is even} \} $ is infinite.  
**Answer:**  
Assume the set is finite. Then there exists a largest even integer $ M $. However, $ M + 2 $ is also even and larger than $ M $, contradicting the assumption. Hence, the set is infinite.

## 6. Summary  
- A **set** is a well-defined collection of distinct elements.  
- Elements are denoted by lowercase letters (e.g., $ a, b $); sets by uppercase letters (e.g., $ A, B $).  
- **Membership** is indicated by $ \in $ (belongs to) and $ \notin $ (does not belong to).  
- **Roster form** lists elements explicitly: $ \{1, 2, 3\} $.  
- **Set-builder form** uses conditions: $ \{x \mid P(x)\} $.  
- Special sets like $ \mathbb{N}, \mathbb{Z}, \mathbb{R} $ are fundamental in mathematics.  

---

## 7. Key Formulas  
| Formula | Description |  
|--------|-------------|  
| $ a \in A $ | Element $ a $ belongs to set $ A $ |  
| $ a \notin A $ | Element $ a $ does not belong to set $ A $ |  
| $ A = \{x \mid P(x)\} $ | Set-builder form of set $ A $ |  
| $ n(A) $ | Cardinality of set $ A $ (number of elements) |  
| $ \mathbb{N} $ | Set of natural numbers $ \{1, 2, 3, \dots\} $ |  
| $ \mathbb{Z} $ | Set of integers $ \{\dots, -2, -1, 0, 1, 2, \dots\} $ |  
| $ \mathbb{Q} $ | Set of rational numbers $ \left\{ \frac{p}{q} \mid p, q \in \mathbb{Z}, q \ne 0 \right\} $ |  
| $ \mathbb{R} $ | Set of real numbers |

## 8. Student Corner  

### **Common Mistakes**  
1. **Confusing roster and set-builder forms**: Always ensure clarity in specifying conditions for set-builder notation.  
2. **Omitting braces in roster form**: Forgetting $ \{\} $ leads to invalid representations (e.g., $ 1, 2, 3 $ instead of $ \{1, 2, 3\} $).  
3. **Misidentifying universal sets**: Remember that the universal set depends on the context (e.g., $ \mathbb{Z} $ vs. $ \mathbb{R} $).  

### **Exam Tips**  
- Practice converting between roster and set-builder forms for diverse examples.  
- Highlight the distinction between well-defined and ill-defined collections during exams.  

### **Memory Aid**  
Use the acronym **SET** to recall:  
- **S**et: A well-defined collection  
- **E**lements: Members of the set  
- **T**erminology: $ \in $ (belongs to), $ \notin $ (does not belong to)
