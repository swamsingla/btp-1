## **Union of Sets**

### Introduction

Have you ever tried to find the set of all people who like cricket and soccer? Can you think of a way to represent such a set?

In this topic, we will explore the concept of the union of two sets, which is essential for solving problems involving multiple sets.

**What you'll learn:**

* Definition of union of sets
* Notation for union operation (∪)
* Commutative, associative, and identity laws for union
* Important properties and formulas
* Visual representation using Venn diagrams

### Explanation

The union of two sets **A** and **B**, denoted as **A ∪ B**, is the set of all elements which are in **A** or in **B** (or in both). In other words, it includes every element that belongs to at least one of the sets.

**Definition 6**: The union of two sets **A** and **B**, denoted as **A ∪ B**, is given by:

$$
\textbf{A} \cup \textbf{B} = \left\{ x : x \in \textbf{A} \text{ or } x \in \textbf{B} \right\}

$$

The commutative, associative, and identity laws for union are given by:

> **Theorem 1:** $\textbf{A} \cup \textbf{B} = \textbf{B} \cup \textbf{A} $ (Commutative Law)
> **Theorem 2:** $ (\textbf{A} \cup \textbf{B}) \cup \textbf{C} = \textbf{A} \cup (\textbf{B} \cup \textbf{C}) $ (Associative Law)
> **Theorem 3:** $\textbf{A} \cup \phi = \textbf{A} $ (Identity Law)

where $\phi $ denotes the empty set.

We can visualize the union of two sets using a Venn diagram. Each time you enter the region corresponding to set **A**, you are also entering the region corresponding to set **B**.

### Solved Examples

#### Example 1:
Find the union of sets **X** = {Ram, Geeta, Akbar} and **Y** = {Geeta, David, Ashok}.
**Solution:**
Let's start by drawing a Venn diagram:
```
  X     |       Y
  ---------
  Ram   |         |
  Geeta  |          |
  Akbar  |          |
  _______|___________|
           |         |
           |         |
           v         v
```

Now, let's fill in the regions:
```
  X     |       Y
  ---------
  Ram   |          |
  Geeta  |          |
  Akbar  |          |
  _______|___________|
           |         |
           |         |
           v         v
  X ∪ Y = {Ram, Geeta, Akbar, David, Ashok}
```
Therefore, **X ∪ Y** = {Ram, Geeta, Akbar, David, Ashok}.

#### Example 2:
Find the union of sets **Z** = {2, 4, 6} and **W** = {4, 6, 8}.
**Solution:**
Using the definition of union, we get:
$\textbf{Z} \cup \textbf{W} = \left\{ x : x \in \textbf{Z} \text{ or } x \in \textbf{W} \right\} $
= {2, 4, 6, 8}

#### Example 3:
Show that the union of sets **A** = {a, b, c} and **B** = {c, d, e} is equal to set **A** itself.
**Solution:**
Since **B** is a subset of **A**, we can see that **A ∪ B** = {a, b, c, d, e} = {a, b, c} = **A**

### Practice Problems

1. Find the union of sets **P** = {1, 2, 3} and **Q** = {2, 3, 4} 🟢 Easy
2. Prove that the union of sets **R** = {m, n} and **S** = {n, p, q} is equal to set **R** itself. 🟡 Medium
3. Find the union of sets **T** = {1, 2, 3, 4} and **U** = {3, 4, 5, 6} 🔴 Hard

### Answers

1. {1, 2, 3, 4}
2. {m, n, p, q} = {m, n} = **R**
3. {1, 2, 3, 4, 5, 6}

### Key Vocabulary

* **Union** (A ∪ B)
* **Commutative Law**: A ∪ B = B ∪ A
* **Associative Law**: (A ∪ B) ∪ C = A ∪ (B ∪ C)
* **Identity Law**: A ∪ φ = A

### Common Mistakes

* Forgetting to include all elements from one set
* Misinterpreting the commutative law

### Exam Tips

* Make sure to draw a clear Venn diagram for problems involving unions
* Pay attention to the commutative and associative laws

### Memory Aid

C - Commutative Law
O - Opposite order doesn't matter
M - Mutual respect for the laws
M - Mind your associations
I - Identity law is always true
T - Treat the laws with care

### Did You Know?

The union of two sets can be thought of as the set of all possible combinations of the elements from each set. This idea has many applications in real-life scenarios, such as finding the set of all possible outcomes when combining events.
