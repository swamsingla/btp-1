## Explanation
### Definition of a Set
A **set**, denoted by the symbol {... }, is a collection of unique objects, known as **elements** or **members**, that can be anything: numbers, letters, people, or even other sets. This definition is straightforward yet powerful, enabling us to work with abstract concepts.

**Theorem 1:** (Pigeonhole Principle)
For any finite number of pigeonholes and finitely many pigeons, at least one pigeonhole must contain more than one pigeon.

This theorem illustrates the importance of sets in understanding discrete mathematics.

### Types of Sets
We can represent sets using various methods, including:

* **Roster form**: listing elements separated by commas
* **Set builder notation**: describing a set using a rule, such as "the set of all integers greater than 5"
* **Venn diagram**: visualizing overlapping regions of multiple sets

These representations allow us to communicate complex ideas effectively and visualize relationships between sets.

### Properties of Sets
Some essential properties of sets include:

* **Commutativity of union**: A ∪ B = B ∪ A
* **Associativity of union**: (A ∪ B) ∪ C = A ∪ (B ∪ C)
* **Distributivity of intersection over union**: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

These properties help us simplify set operations and build a strong foundation for further studies.

### Notation
In mathematics, we often use the following notation:
* **∅**: represents the empty set (a set containing no elements)
* **n**: represents a set containing n elements
* **A ∪ B**: represents the union of sets A and B
* **A ∩ B**: represents the intersection of sets A and B

## Solved Examples
### Example 1:
Find the union of the sets A = {1, 2, 3} and B = {3, 4, 5}.
 
1. Write down the elements of both sets.
2. Combine the elements using the union operation.
3. Remove any duplicates.

**Solution:**

The elements of set A are 1, 2, 3.
The elements of set B are 3, 4, 5.
The union of sets A and B is {1, 2, 3, 4, 5}.

### Example 2:
Find the intersection of the sets A = {2, 4, 6} and B = {4, 6, 8}.


1. List out the elements of both sets.
2. Identify common elements.
3. Write down the intersection.

**Solution:**

The elements of set A are 2, 4, 6.
The elements of set B are 4, 6, 8.
The intersection of sets A and B is {4, 6}.

### Example 3:
Find the complement of the set A = {1, 2, 3} with respect to the universal set U = {1, 2, 3, 4, 5}.


1. List out the elements of set A.
2. Compare with the universal set U.
3. Identify the missing elements.

**Solution:**

The elements of set A are 1, 2, 3.
The universal set U contains the elements 1, 2, 3, 4, 5.
The complement of set A with respect to U is {4, 5}.

## Summary
Here's a summary of the key concepts and formulas discussed in this topic:

• A set is a collection of unique elements.
• The union of two sets is the combination of their elements.
• The intersection of two sets is the overlap of their elements.
• The complement of a set with respect to a universal set is the set of elements not in the original set.

Formulas:

• A ∪ B = {a ∈ A | a ∈ B}
• A ∩ B = {a ∈ A | a ∈ B}
• A' = {x ∈ U | x ∉ A}

Remember to focus on mastering these concepts to tackle future challenges in mathematics!
