## 3. Explanation  

### 3.1 Historical Context and Significance  
> **Definition**: A *set* is a well-defined collection of distinct objects, called **elements**.  
>  
> **Historical Note**: The theory of sets was pioneered by German mathematician **Georg Cantor** (1845–1918). His work on trigonometric series led him to develop the concept of infinite sets, revolutionizing mathematics.  

Sets serve as the foundation for nearly all branches of mathematics. They enable the definition of **relations**, **functions**, and even more complex structures like **topology** and **calculus**.  

### 3.2 Representation of Sets  
> **Definition**: A set can be represented in three ways:  
> 1. **Roster Method**: Listing all elements within curly braces, e.g., $ A = \{1, 2, 3\} $.  
> 2. **Set-Builder Notation**: Describing elements using a rule, e.g., $ B = \{x \mid x \text{ is a prime number less than 10}\} $.  
> 3. **Venn Diagrams**: Visual representations using closed curves to depict relationships between sets.  

> **Note**: Elements are denoted by lowercase letters (e.g., $ a \in A $), while sets are uppercase letters (e.g., $ A $).  

### 3.3 Empty Set and Membership  
> **Definition**: The **empty set** ($ \emptyset $ or $ \phi $) is a set containing no elements.  
>  
> **Property**: For any set $ A $, $ \emptyset \subset A $.  

> **Membership**: An object $ a $ is an **element** of a set $ A $ if $ a \in A $. Conversely, $ a \notin A $ means $ a $ is not in $ A $.  

### 3.4 Finite vs. Infinite Sets  
> **Definition**:  
> - A **finite set** has a definite number of elements (e.g., $ n(\{1, 2, 3\}) = 3 $).  
> - An **infinite set** has an unlimited number of elements (e.g., $ \mathbb{N} = \{1, 2, 3, \dots\} $).  

> **Symbol**: $ n(A) $ denotes the **cardinality** (number of elements) of set $ A $.  

### 3.5 Equal Sets  
> **Definition**: Two sets $ A $ and $ B $ are **equal** ($ A = B $) if they contain exactly the same elements.  
>  
> **Example**: $ \{1, 2, 3\} = \{3, 2, 1\} $ because the order of elements does not matter.

## 4. Solved Examples  

### Example 1:  
**Problem**: Represent the set of vowels in the English alphabet using roster method and set-builder notation.  
**Solution**:  
- **Roster Method**: $ V = \{a, e, i, o, u\} $.  
- **Set-Builder Notation**: $ V = \{x \mid x \text{ is a vowel in the English alphabet}\} $.  

### Example 2:  
**Problem**: Determine whether $ 3 \in \{1, 2, 3, 4\} $ and $ 5 \in \{1, 2, 3, 4\} $.  
**Solution**:  
- $ 3 \in \{1, 2, 3, 4\} $ is **true**.  
- $ 5 \in \{1, 2, 3, 4\} $ is **false**.  

### Example 3:  
**Problem**: Find the cardinality of $ A = \{1, 2, 3, 4, 5\} $ and $ B = \emptyset $.  
**Solution**:  
- $ n(A) = 5 $  
- $ n(B) = 0 $  

### Example 4:  
**Problem**: Prove that $ \emptyset \subset \{1, 2, 3\} $.  
**Solution**:  
By definition, the empty set is a subset of every set. Since there are no elements in $ \emptyset $ that are not in $ \{1, 2, 3\} $, the statement holds true.  

### Example 5:  
**Problem**: Are $ \{1, 2, 3\} $ and $ \{3, 2, 1\} $ equal?  
**Solution**:  
Yes. Both sets contain the same elements, so $ \{1, 2, 3\} = \{3, 2, 1\} $.

## 5. Practice Problems  

### 🟢 Easy  
**Problem 1**: Represent the set of even numbers less than 10 using roster method.  
**Problem 2**: Is $ 7 \in \{1, 2, 3, 4, 5\} $? Justify your answer.  

### 🟡 Medium  
**Problem 3**: Find $ n(\{a, b, c, d\}) $ and compare it with $ n(\{1, 2, 3, 4\}) $.  
**Problem 4**: Prove that $ \emptyset \subset \emptyset $.  

### 🔴 Hard  
**Problem 5**: Show that if $ A = \{1, 2\} $, then $ \emptyset \subset A $ and $ A \subset A $.  

**Answers**:  
**Problem 1**: $ \{2, 4, 6, 8\} $.  
**Problem 2**: No, because 7 is not in the set.  
**Problem 3**: $ n(\{a, b, c, d\}) = 4 $; both sets have equal cardinality.  
**Problem 4**: By definition, every set is a subset of itself, including the empty set.  
**Problem 5**:  
- $ \emptyset \subset A $: True, as no elements violate the subset condition.  
- $ A \subset A $: True, by the reflexive property of subsets.

## 6. Summary  
- **Set**: A well-defined collection of distinct elements (e.g., $ A = \{1, 2, 3\} $).  
- **Empty Set**: Contains no elements ($ \emptyset $).  
- **Cardinality**: Number of elements in a set ($ n(A) $).  
- **Finite Set**: Has a finite number of elements (e.g., $ n(A) = 5 $).  
- **Equal Sets**: Contain exactly the same elements (e.g., $ \{1, 2\} = \{2, 1\} $).  
- **Subset**: A set $ A $ is a subset of $ B $ if all elements of $ A $ are in $ B $ ($ A \subset B $).

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ A = \{x \mid P(x)\} $ | Set-builder notation for set $ A $. |  
| $ \emptyset $ | Empty set (no elements). |  
| $ n(A) $ | Cardinality of set $ A $. |  
| $ A \subset B $ | $ A $ is a subset of $ B $. |  
| $ a \in A $ | Element $ a $ belongs to set $ A $. |  
| $ a \notin A $ | Element $ a $ does not belong to set $ A $. |

## 8. Student Corner  

### Common Mistakes  
- ❌ Confusing **subsets** with **elements**: $ \{1\} \subset \{1, 2\} $ is true, but $ 1 \subset \{1, 2\} $ is false.  
- ❌ Misrepresenting sets: Always use curly braces $ \{\} $ for sets, not parentheses $ () $.  

### Exam Tips  
- ✅ Practice converting between roster and set-builder notation.  
- ✅ Memorize the definition of the empty set and its properties.  

### Memory Aid  
**Mnemonic**: Think of "SET" as "S" for "Specific", "E" for "Elements", and "T" for "Together"—a set groups specific elements together.
