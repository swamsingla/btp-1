## Introduction

Have you ever wondered what happens to a set when you take away all its elements that are already accounted for? In other words, what's left behind? This concept is crucial in set theory, and today, we'll delve into the fascinating world of complements of sets!

By the end of this lesson, you'll understand the concept of the complement of a set, how it's related to the universal set, and how it's used in various mathematical operations. You'll also get to practice solving problems and exploring the properties of complements.

Don't worry if you're new to set theory; we'll build upon the foundational concepts you've learned previously.

## Explanation

### Definition of a Set

A set is a well-defined collection of unique objects, known as elements or members.

### Definition of a Universal Set

A universal set is a set that contains all possible elements under consideration.

### Definition of a Subset

A subset is a set whose elements are all contained within another set.

### The Complement of a Set

Given a set A and a universal set U, the complement of A, denoted by A', is the set of all elements in U that are not in A.

>quote>
The complement of a set A with respect to a universal set U is defined as:
\[A' = \{x : x \in U \text{ and } x \notin A\}\]

Or equivalently:
\[A' = U - A\]

### Theorem: De Morgan's Law

For any two sets A and B:
>quote>
\[(A \cup B)' = A' \cap B'\]
\[(A \cap B)' = A' \cup B'\]

where'denotes the complement operation.

## Solved Examples

1. Let U = {1, 2, 3, 4, 5, 6, 7, 8, 9} and A = {1, 3, 5, 7}. Find A'.

Solution:

## Step 1: Identify the elements in U that are not in A.
These are the elements of A'.


## Step 2: Write down the elements of A'.
A' = {2, 4, 6, 8, 9}


2. Let U = {a, b, c, d, e, f, g, h} and A = {a, c, e}. Find A'.

Solution:

These are the elements of A'.


A' = {b, d, f, g, h}


3. Let U = {x : x is a natural number} and A = {x : x is an even natural number}. Find A'.

Solution:

These are the elements of A'.


A' = {x : x is an odd natural number}

## Summary

* A set A' is the complement of set A with respect to the universal set U, defined as:
>quote>
\[A' = \{x : x \in U \text{ and } x \notin A\}\]
Or equivalently:
\[A' = U - A\]
* De Morgan's Law states:
>quote>
\[(A \cup B)' = A' \cap B'\]
\[(A \cap B)' = A' \cup B'\]

## Student Corner

* Common mistakes:
	+ Forgetting to include all elements in the universal set when finding complements.
	+ Misapplying De Morgan's Law.
* Exam Tip: When working with sets, always check if the elements in the universal set are included in the complement.
* Memory Aid: To remember De Morgan's Law, think of it as "negating the union" and "negating the intersection".
