## 3. Explanation  

### 3.1 Definition of Complement of a Set  
> **The complement of a set $ A $**, denoted by $ A'$, is the set of all elements in the **universal set $ U $** that are **not** in $ A $.  
Symbolically,

$$
A' = \{x : x \in U \text{ and } x \notin A\}

$$  
This is equivalent to the **difference** between the universal set and set $A $:

$$
A' = U - A

$$  

#### Example from Source Text  
Let $U =$ all prime numbers, and $ A =$ primes not dividing 42. Then:  
- $ A = \{x : x \in U \text{ and } x \nmid 42\} $  
- The complement $ A'$ contains elements of $ U $ not in $ A $, i.e., the prime divisors of 42: $ A' = \{2, 3, 7\} $  

---

### 3.2 Properties of Complements  
> **Property 1:** $ (A')' = A $  
If $ A'$ is the complement of $ A $, then taking the complement of $ A'$ returns the original set $ A $.  

**Proof:**  
By definition, $ A' = \{x : x \in U \text{ and } x \notin A\} $. Taking the complement of $ A'$ gives:

$$
(A')' = \{x : x \in U \text{ and } x \notin A'\} = \{x : x \in U \text{ and } x \in A\} = A

$$  

> **Property 2 (De Morgan’s Laws):**  
- $(A \cup B)' = A' \cap B'$  
- $ (A \cap B)' = A' \cup B'$  

**Proof for $ (A \cup B)' = A' \cap B'$:**  
1. Suppose $ x \in (A \cup B)'$. By definition, $ x \in U $ and $ x \notin A \cup B $.  
2. This implies $ x \notin A $ and $ x \notin B $, so $ x \in A'$ and $ x \in B'$.  
3. Therefore, $ x \in A' \cap B'$.  
4. Conversely, suppose $ x \in A' \cap B'$. Then $ x \in A'$ and $ x \in B'$, meaning $ x \notin A $ and $ x \notin B $.  
5. Hence, $ x \notin A \cup B $, so $ x \in (A \cup B)'$.  
Thus, $ (A \cup B)' = A' \cap B'$  

---

### 3.3 Visual Representation via Venn Diagrams  
The complement of a set $ A $ is represented in a Venn diagram as the region inside the universal set $ U $ but outside the circle representing $ A $.  

**Diagram Description:**  
- Draw a rectangle labeled $ U $ (universal set).  
- Inside the rectangle, draw a circle labeled $ A $.  
- Shade the area of $ U $ **not** overlapping with $ A $; this shaded region represents $ A'$.  

---

### 3.4 Application in Problem Solving  
The complement operation is useful in scenarios where you need to identify "what’s left" after removing certain elements. For example:  
- In Example 21 from the source text, the complement of the set of girls ($ A $) in a class is the set of boys ($ A'$).  
- In Example 22, the complement of $ A \cup B $ is found by identifying elements not in either $ A $ or $ B $.

## 4. Solved Examples  

### **Example 1:**  
Let $ U = \{1, 2, 3, 4, 5, 6\} $ and $ A = \{1, 3, 5\} $. Find $ A'$.  

**Solution:**  
- Elements in $ U $ not in $ A $: $ 2, 4, 6 $  
- Thus, $ A' = \{2, 4, 6\} $  

---

### **Example 2:**  
Let $ U =$ all integers from 1 to 10, and $ A =$ even numbers. Find $ A'$ and $ (A')'$.  

**Solution:**  
- $ A = \{2, 4, 6, 8, 10\} $  
- $ A' = \{1, 3, 5, 7, 9\} $  
- $ (A')' = \{2, 4, 6, 8, 10\} = A $ (verified by Property 1)  

---

### **Example 3:**  
Given $ U = \{1, 2, 3, 4, 5\} $, $ A = \{1, 2\} $, and $ B = \{2, 3\} $, prove $ (A \cup B)' = A' \cap B'$.  

**Solution:**  
1. Compute $ A \cup B = \{1, 2, 3\} $  
2. $ (A \cup B)' = \{4, 5\} $  
3. Compute $ A' = \{3, 4, 5\} $, $ B' = \{1, 4, 5\} $  
4. $ A' \cap B' = \{4, 5\} $  
5. Hence, $ (A \cup B)' = A' \cap B'$ (verified by De Morgan’s Law)  

---

### **Example 4:**  
Let $ U =$ all letters in the English alphabet, and $ A =$ vowels. Find $ A'$ and describe it in words.  

**Solution:**  
- $ A = \{a, e, i, o, u\} $  
- $ A' =$ all consonants: $\{b, c, d, ..., z\} $ (excluding vowels)  

---

### **Example 5:**  
Prove $ (A \cap B)' = A' \cup B'$ using the source text’s Example 22.  

**Solution:**  
From Example 22:  
- $ A = \{2, 3\} $, $ B = \{3, 4, 5\} $  
- $ A \cap B = \{3\} $, so $ (A \cap B)' = \{1, 2, 4, 5, 6\} $  
- $ A' = \{1, 4, 5, 6\} $, $ B' = \{1, 2, 6\} $  
- $ A' \cup B' = \{1, 2, 4, 5, 6\} $  
- Thus, $ (A \cap B)' = A' \cup B'$ (verified)

## 5. Practice Problems  

### 🟢 Easy  
1. Let $ U = \{1, 2, 3, 4, 5\} $, $ A = \{1, 3\} $. Find $ A'$.  
2. If $ U =$ all natural numbers ≤ 10, and $ A =$ multiples of 3, find $ A'$.  

### 🟡 Medium  
3. Given $ U = \{1, 2, 3, 4, 5, 6\} $, $ A = \{2, 4, 6\} $, $ B = \{1, 3, 5\} $, verify $ (A \cup B)' = A' \cap B'$.  
4. Let $ U =$ all letters in "MATHEMATICS", and $ A =$ vowels. Find $ A'$ and describe it.  

### 🔴 Hard  
5. Prove $ (A \cap B)' = A' \cup B'$ for arbitrary sets $ A $ and $ B $ using the definition of complement.  

---

### Answers:  

#### 1.  
- $ A' = \{2, 4, 5\} $  

#### 2.  
- $ A' =$ all natural numbers ≤ 10 **not divisible by 3**: $\{1, 2, 4, 5, 7, 8, 10\} $  

#### 3.  
- $ A \cup B = \{1, 2, 3, 4, 5, 6\} $, so $ (A \cup B)' = \emptyset $  
- $ A' = \{1, 3, 5\} $, $ B' = \{2, 4, 6\} $  
- $ A' \cap B' = \emptyset $  
- Hence, $ (A \cup B)' = A' \cap B'$  

#### 4.  
- $ U =$ letters in "MATHEMATICS": $\{M, A, T, H, E, M, A, T, I, C, S\} $  
- $ A =$ vowels: $\{A, E, I\} $  
- $ A' =$ consonants: $\{M, T, H, M, T, C, S\} $ (note duplicates are ignored in sets)  

#### 5.  
**Proof:**  
1. Let $ x \in (A \cap B)'$. Then $ x \in U $ and $ x \notin A \cap B $.  
2. This implies $ x \notin A $ **or** $ x \notin B $.  
3. Thus, $ x \in A'$ **or** $ x \in B'$, so $ x \in A' \cup B'$.  
4. Conversely, if $ x \in A' \cup B'$, then $ x \in A'$ **or** $ x \in B'$, meaning $ x \notin A $ **or** $ x \notin B $.  
5. Hence, $ x \notin A \cap B $, so $ x \in (A \cap B)'$.  
Therefore, $ (A \cap B)' = A' \cup B'$

## 6. Summary  
- **Complement of a set $ A $** is $ A' = \{x : x \in U \text{ and } x \notin A\} $  
- **Properties**:  
  - $ (A')' = A $  
  - $ (A \cup B)' = A' \cap B'$  
  - $ (A \cap B)' = A' \cup B'$  
- **Applications**: Used to identify elements not in a set, crucial for solving problems involving unions and intersections  

---

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ A' = \{x : x \in U \text{ and } x \notin A\} $ | Definition of complement |  
| $ (A')' = A $ | Self-complementary property |  
| $ (A \cup B)' = A' \cap B'$ | De Morgan’s First Law |  
| $ (A \cap B)' = A' \cup B'$ | De Morgan’s Second Law |

## 8. Student Corner  

### **Common Mistakes**  
1. **Error:** Confusing $ A'$ with $ U - A $  
   **Correction:** Remember $ A' = U - A $ by definition. Always specify the universal set.  
2. **Error:** Forgetting to consider all elements of $ U $ when computing $ A'$  
   **Correction:** List all elements of $ U $ and exclude those in $ A $ systematically.  

### **Exam Tips**  
- When asked to find the complement, explicitly state the universal set used.  
- Use Venn diagrams to visualize complements and verify your answers.  

### **Memory Aid**  
**"NOT A" = Complement of A**  
Remember the complement symbol $'$ resembles a negation mark (¬) in logic, emphasizing "not in A."
