# 1.  5 సమాన సమితులు

> **11వ తరగతి** | **అధ్యాయం 1: సమితులు**

## 1. అవసరమైనవి
ఈ అంశం గురించి చదవడానికి ముందు, విద్యార్థినులు ఈ క్రింది వాటిని చేయాలి:
- **సెట్ నొటేషన్** యొక్క ప్రాథమికాలను అర్థం చేసుకోండి, సెట్‌లను ఎలా సూచించాలో మరియు మూలకాలను ఎలా సూచించాలో తెలుసుకోండి. $x \in A $)
- **పరిమిత** మరియు **అపరిమిత సమితుల** మధ్య వ్యత్యాసాన్ని తెలుసుకోండి (విభాగం 1.4 నుండి)
- **శూన్య సమితి** గురించి తెలుసుకోండి ($\emptyset $) మరియు దాని లక్షణాలు (విభాగం 1.3 నుండి)

## 2. పరిచయం
రెండు సేకరణలలో *ఖచ్చితంగా* ఒకే వస్తువులు ఉన్నాయో లేదో చూడటానికి మీరు ఎప్పుడైనా వాటిని పోల్చారా? ఉదాహరణకు, మీ దగ్గర రెండు సంచుల గోళీలు ఉంటే - ఒకటి ఎరుపు, నీలం మరియు ఆకుపచ్చ గోళీలతో - మరియు మరొకటి కూడా అదే రంగులతో ఉంటే, అవి తప్పనిసరిగా ఒకేలా ఉంటాయి. గణితంలో, ఈ ఆలోచన **సమాన సమితులకు** అనువదిస్తుంది.
ఈ అంశం రెండు సమితులు ఎప్పుడు సమానంగా పరిగణించబడతాయో వివరిస్తుంది, **క్రమం మరియు పునరావృతం ముఖ్యం కాదు** అని నొక్కి చెబుతుంది. ఈ పాఠం చివరికి, మీరు రెండు సమితుల మూలకాలను పరిశీలించడం ద్వారా అవి సమానమో కాదో తెలుసుకోగలుగుతారు. ఇది విభాగాలు 1.1 నుండి 1.4 వరకు సమితుల గురించి మీకున్న అవగాహనను మరింత పెంచుతుంది.

## 3. వివరణ

### 3.1 సమాన సమితుల నిర్వచనం
> రెండు సెట్లు $ A $ మరియు $ B $ సరిగ్గా ఒకే మూలకాలను కలిగి ఉంటే సమానంగా ఉంటాయి. దీనిని ఇలా వ్రాస్తారు. $ A = B $ ఒకవేళ అవి ఒక్క అంశంలోనైనా తేడా ఉంటే, అవి **సమానంగా లేనివి** అవుతాయి. $ A \neq B $).

#### ముఖ్యమైన విషయాలు:
- **క్రమం ముఖ్యం కాదు**: $\{1, 2, 3\} = \{3, 2, 1\} $  
- పునరావృతం ముఖ్యం కాదు: $\{1, 2, 2, 3\} = \{1, 2, 3\} $  
- **శూన్య సమితులు సమానం**: $\emptyset = \emptyset $  

### 3.2 సమాన సమితుల లక్షణాలు
> **ఆస్తి 1**: ఒకవేళ $ A = B $ అప్పుడు, ప్రతి మూలకం యొక్క $ A $ ఉంది $ B $ మరియు దీనికి విరుద్ధంగా.
> **ఆస్తి 2**: ఒకవేళ $ A = B $ మరియు $ B = C $ అప్పుడు, $ A = C $ (సకర్మక).
> **లక్షణం 3**: ఒక సమితి తనతో తానే సమానం ($ A = A $).

### 3.3 ఉదాహరణ విశ్లేషణ
మూల పాఠ్యం నుండి:
- సరే కాని. $ A = \{1, 2, 3, 4\} $ మరియు $ B = \{3, 1, 4, 2\} $ ఇక్కడ, $ A = B $ ఎందుకంటే రెండింటిలోనూ ఒకే అంశాలు ఉంటాయి.
- సరే కాని. $ A $ 6 కంటే తక్కువ ప్రధాన సంఖ్యల సమితిగా ఉండండి ($\{2, 3, 5\} $) మరియు $ P $ 30 యొక్క ప్రధాన కారణాంకాల సమితిగా ఉండండి ($\{2, 3, 5\} $). అప్పుడు $ A = P $.

### 3.4 పునరావృతమయ్యే అంశాలపై గమనిక
> **గమనిక**: మూలకాలు పునరావృతమైతే ఒక సమితి మారకుండా ఉంటుంది. ఉదాహరణకు, $\{1, 2, 3\} = \{1, 1, 2, 2, 3, 3\} $ సెట్లను ప్రత్యేకమైన అంశాలతో నిర్వచించడానికి ఇది ఒక కారణం.

## 4. పరిష్కరించబడిన ఉదాహరణలు

### ఉదాహరణ 1:
**ప్రశ్న**: నిర్ధారించండి. $ A = \{a, b, c\} $ మరియు $ B = \{c, b, a\} $ సమానంగా ఉంటాయి.
సమాధానం:
- ప్రతి మూలకం సరిగా ఉందో లేదో తనిఖీ చేయండి. $ A $ ఉంది $ B $: $ a, b, c \in B $  
- ప్రతి మూలకం సరిగా ఉందో లేదో తనిఖీ చేయండి. $ B $ ఉంది $ A $: $ c, b, a \in A $  
- రెండు సమితులలో ఒకే అంశాలు ఉన్నందున, $ A = B $.

### ఉదాహరణ 2:
**ప్రశ్న**: ఉన్నాయా? $ A = \{1, 2, 3\} $ మరియు $ B = \{1, 2, 4\} $ సమానమా?
సమాధానం:
- $ 3 \in A $ కానీ $ 3 \notin B $ మరియు $ 4 \in B $ కానీ $ 4 \notin A $.
- కాబట్టి, $ A \neq B $.

### ఉదాహరణ 3:
**ప్రశ్న**: ఇవ్వబడింది $ A = \{x : x^2 = 4\} $ మరియు $ B = \{2, -2\} $ చూపించు, $ A = B $.
సమాధానం:
- పరిష్కరించు $ x^2 = 4 $: $ x = 2 $ లేదా $ x = -2 $.
- కాబట్టి, $ A = \{2, -2\} = B $.

### ఉదాహరణ 4:
**ప్రశ్న**: ధృవీకరించండి. $ A = \{x : x \text{ is a vowel in } \text{"EQUAL"}\} $ మరియు $ B = \{E, U, A\} $ సమానంగా ఉంటాయి.
సమాధానం:
- "EQUAL" అనే పదంలో అచ్చులు ఉన్నాయి. $ E, U, A $.
- $ A = \{E, U, A\} = B $.  

### ఉదాహరణ 5:
**ప్రశ్న**: నిరూపించండి. $ A = \{x : x \in \mathbb{N}, x < 5\} $ మరియు $ B = \{1, 2, 3, 4\} $ సమానంగా ఉంటాయి.
సమాధానం:
- $ A $ 5 కంటే తక్కువ సహజ సంఖ్యలను కలిగి ఉంది: $\{1, 2, 3, 4\} $.
- $ B $ ఖచ్చితంగా ఉంది $\{1, 2, 3, 4\} $.
- కాబట్టి, $ A = B $.

## 5. సాధన సమస్యలు

### 🟢 సులభం
సమస్య 1: ఉన్నాయా? $ A = \{1, 2, 3\} $ మరియు $ B = \{3, 2, 1\} $ సమానమా? సమర్థించు.
సమాధానం: అవును. రెండింటిలోనూ ఒకే అంశాలు ఉన్నాయి.

సమస్య 2: ఇది $ A = \{a, e, i\} $ సమానంగా $ B = \{i, a, e\} $?
సమాధానం: అవును. క్రమం సమానత్వాన్ని ప్రభావితం చేయదు.

### 🟡 మధ్యస్థం
సమస్య 3: అనుకుందాం $ A = \{x : x \text{ is a letter in "MATH"}\} $ మరియు $ B = \{M, A, T, H\} $. అవి సమానమా?
సమాధానం: అవును. రెండింటిలోనూ ఉన్నాయి. $\{M, A, T, H\} $.

సమస్య 4: ఉన్నాయా? $ A = \{x : x^2 = 9\} $ మరియు $ B = \{3, -3\} $ సమానమా?
సమాధానం: అవును. పరిష్కరిస్తోంది. $ x^2 = 9 $ ఇస్తుంది $ x = 3 $ లేదా $ x = -3 $.

### 🔴 కఠినమైనది
సమస్య 5: ఇవ్వబడింది $ A = \{x : x \text{ is an integer satisfying } x^2 - 5x + 6 = 0\} $ మరియు $ B = \{2, 3\} $, నిరూపించండి $ A = B $.
సమాధానం:
- సమస్యను పరిష్కరించు $ x^2 - 5x + 6 = 0 $: $ (x-2)(x-3) = 0 $ → $ x = 2 $ లేదా $ x = 3 $.
- కాబట్టి, $ A = \{2, 3\} = B $.

## 6. సారాంశం
- **సమాన సమితులు** ఖచ్చితంగా ఒకే మూలకాలను కలిగి ఉంటాయి.
- **క్రమం మరియు పునరావృతం** సమానత్వాన్ని ప్రభావితం చేయవు.
- ఒకవేళ $ A = B $ అప్పుడు, $ A \subset B $ మరియు $ B \subset A $.
- **శూన్య సమితి** తనతో తానే సమానం.
- సమితులను సరిపోల్చడానికి **సభ్యత్వ తనిఖీలను** ఉపయోగించండి.
- సమానత్వం అనేది మూలకాలలో గుర్తింపును సూచిస్తుంది, కేవలం పరిమాణాన్ని కాదు.

## 7. ముఖ్య సూత్రాలు

| ఫార్ములా | వివరణ |
|--------|-------------|  
| $ A = B $ | $ A $ మరియు $ B $ సమాన సమితులు |
| $ A \neq B $ | $ A $ మరియు $ B $ సమానంగా లేవు |
| $ x \in A $ | మూలకం $ x $ సమితికి చెందినది $ A $ |
| $ x \notin A $ | మూలకం $ x $ సమితికి చెందదు $ A $ |
| $ A = \{x : P(x)\} $ | సెట్-బిల్డర్ సంజ్ఞామానం కోసం $ A $ |

## 9. సంబంధిత విషయాలు
- [1.2 సమితులు మరియు వాటి ప్రాతినిధ్యాలు] — సమితులను ఎలా వర్ణించాలో అర్థం చేసుకోవడం సమానత్వాన్ని నిర్ణయించడానికి పునాది.
- [1.3 ఖాళీ సమితి] — ఖాళీ సమితిని గుర్తించడం వలన మూలకాలు లేని సమితులను గుర్తించడానికి సహాయపడుతుంది.
- [1.6 ఉపసమితులు] — సమానత్వం అనేది ఉపసమితి సంబంధం యొక్క మరింత కఠినమైన రూపం ($ A = B $ సూచిస్తుంది $ A \subset B $ మరియు $ B \subset A $).
