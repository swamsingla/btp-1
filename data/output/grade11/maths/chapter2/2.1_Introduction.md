## 2. Introduction  
Mathematics often revolves around identifying patterns—such as links between changing quantities. From sibling relationships to numerical inequalities, these patterns involve **pairs of objects in a specific order**. This chapter explores how to formally describe such connections between pairs of elements from different sets, ultimately introducing **functions**, which represent specialized types of relations. By studying these concepts, you’ll gain tools to model real-world dependencies and abstract relationships in mathematics.  

---  

## 3. Explanation  
### 3.1 What is a Relation?  
A **relation** connects elements from two sets through an ordered pair. For example, if $ A = \{1, 2\} $ and $ B = \{a, b\} $, a relation $ R $ could be defined as $ R = \{(1, a), (2, b)\} $. Here, the **first element** comes from set $ A $, and the **second element** comes from set $ B $.  

> **Definition**: A relation $ R $ from set $ A $ to set $ B $ is a subset of the Cartesian product $ A \times B $. Each element in $ R $ is an ordered pair $ (a, b) $, where $ a \in A $ and $ b \in B $.  

### 3.2 Importance of Order  
Relations emphasize **order**: the pair $ (a, b) $ is distinct from $ (b, a) $ unless $ a = b $. This mirrors real-life scenarios like “father and son” versus “son and father.”  

### 3.3 Transition to Functions  
Functions are a special type of relation where **each input corresponds to exactly one output**. For instance, the relation $ f(x) = x^2 $ maps every real number $ x $ to its square. This concept is foundational in modeling quantitative dependencies in science and engineering.  

---  

## 4. Solved Examples  
### Example 1: Identifying a Relation  
Let $ A = \{1, 2, 3\} $ and $ B = \{p, q\} $. Determine whether $ R = \{(1, p), (2, q), (3, p)\} $ is a valid relation from $ A $ to $ B $.  

**Solution**:  
- Each element in $ R $ is an ordered pair where the first component is from $ A $ and the second from $ B $.  
- Since all pairs satisfy this condition, $ R $ is indeed a relation from $ A $ to $ B $.  

### Example 2: Verifying a Function  
Consider the relation $ f = \{(1, 2), (2, 4), (3, 6)\} $. Is $ f $ a function?  

**Solution**:  
- A function requires **each input (domain element)** to map to **exactly one output (codomain element)**.  
- Here, every element in the domain $ \{1, 2, 3\} $ maps uniquely to $ \{2, 4, 6\} $.  
- Thus, $ f $ qualifies as a function.

## 5. Practice Problems  
🟢 **Easy**:  
1. Let $ A = \{a, b\} $ and $ B = \{1, 2\} $. Write all possible relations from $ A $ to $ B $.  
   
🟡 **Medium**:  
2. Given $ R = \{(x, y) \in \mathbb{R} \times \mathbb{R} \mid y = x + 1\} $, verify if $ R $ is a function.  

🔴 **Hard**:  
3. Suppose $ A = \{1, 2, 3\} $, $ B = \{2, 3, 4\} $, and $ C = \{3, 4\} $. Define a relation $ R $ from $ A $ to $ B $, and another relation $ S $ from $ B $ to $ C $, such that their composition $ S \circ R $ includes the pair $ (1, 4) $.  

**Answers**:  
1. The total number of relations from $ A $ to $ B $ is $ 2^{n(A \times B)} = 2^{4} = 16 $. Examples include $ \{(a, 1)\}, \{(b, 2), (a, 1)\} $, etc.  

2. For $ R $ to be a function, every $ x \in \mathbb{R} $ must map to **one unique** $ y \in \mathbb{R} $. Since $ y = x + 1 $ assigns a single value to each $ x $, $ R $ is a function.  

3. Let $ R = \{(1, 2), (2, 3), (3, 4)\} $ and $ S = \{(2, 3), (3, 4)\} $. Then $ S \circ R = \{(1, 3), (2, 4), (3, 4)\} $, which includes $ (1, 4) $ via $ (1, 2) \rightarrow (2, 3) \rightarrow (3, 4) $.

## 6. Summary  
- A **relation** is a subset of the Cartesian product of two sets.  
- Ordered pairs in a relation emphasize **specific ordering** of elements.  
- **Functions** are relations where each input maps to **exactly one output**.  
- Relations form the basis for modeling dependencies in mathematics.

## 7. Key Formulas  
| Formula | Description |  
|--------|-------------|

| $ n(A \times B) = n(A) \cdot n(B) $ | Cardinality of Cartesian product |
