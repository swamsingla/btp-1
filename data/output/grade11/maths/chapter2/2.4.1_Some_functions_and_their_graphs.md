## 2. Introduction  
Have you ever wondered how a vending machine maps input coins to output snacks? This is essentially a *function*! In this topic, we explore **basic functions** and their corresponding **graphs**, learning how to represent them visually and analytically. By the end of this section, you’ll be able to identify functions like the identity, constant, polynomial, rational, and modulus functions, and sketch their graphs confidently. These skills are essential for higher-level mathematics and applications in physics, economics, and engineering.

## 3. Explanation  

### 3.1 Identity Function  
> **Definition**: An identity function $ f: \mathbb{R} \rightarrow \mathbb{R} $ is defined by $ f(x) = x $ for all $ x \in \mathbb{R} $. Its **domain** and **range** are both $ \mathbb{R} $, and its graph is a straight line passing through the origin.  

**Graph Characteristics**:  
- Slope = 1  
- Passes through $ (0, 0) $  
- Symmetric about the line $ y = x $  

### 3.2 Constant Function  
> **Definition**: A constant function $ f: \mathbb{R} \rightarrow \mathbb{R} $ is defined by $ f(x) = c $, where $ c $ is a fixed real number. Its **domain** is $ \mathbb{R} $, and its **range** is $ \{c\} $.  

**Graph Characteristics**:  
- Horizontal line parallel to the x-axis  
- Y-intercept at $ (0, c) $  
- No variation in output values  

### 3.3 Polynomial Function  
> **Definition**: A polynomial function $ f: \mathbb{R} \rightarrow \mathbb{R} $ is expressed as $ f(x) = a_0 + a_1x + a_2x^2 + \dots + a_nx^n $, where $ n $ is a non-negative integer and $ a_0, a_1, \dots, a_n \in \mathbb{R} $.  

**Examples**:  
- $ f(x) = x^3 - x^2 + 2 $  
- $ g(x) = x^4 + 2x $  

**Non-example**: $ h(x) = x + 2x $ is **not** a polynomial because it simplifies to $ 3x $, which is a linear function—a special case of a polynomial.  

### 3.4 Rational Function  
> **Definition**: A rational function is of the form $ f(x) = \frac{p(x)}{q(x)} $, where $ p(x) $ and $ q(x) $ are polynomial functions and $ q(x) \neq 0 $.  

**Domain Restrictions**:  
- Excludes values of $ x $ that make $ q(x) = 0 $  

### 3.5 Modulus Function (Source Continues...)  
> **Definition**: The modulus function $ f: \mathbb{R} \rightarrow \mathbb{R} $ is defined as $ f(x) = |x| $, which outputs the absolute value of $ x $. Its graph is V-shaped with a vertex at the origin.  

**Properties**:  
- $ |x| = x $ if $ x \geq 0 $  
- $ |x| = -x $ if $ x < 0 $

## 4. Solved Examples  

### Example 1:  
**Define the function $ f(x) = x^2 $. Complete the table and determine its domain and range.**  

**Solution**:  
| $ x $     | $ -4 $ | $ -3 $ | $ -2 $ | $ -1 $ |  
|------------|---------|---------|---------|---------|  
| $ f(x) $  | $ 16 $ | $ 9 $  | $ 4 $  | $ 1 $  |  

**Domain**: $ \mathbb{R} $ (all real numbers)  
**Range**: $ [0, \infty) $ (non-negative real numbers)  
**Graph**: A parabola opening upwards with vertex at $ (0, 0) $.  

### Example 2:  
**Sketch the graph of $ f(x) = x^3 $.**  

**Solution**:  
- Compute key points:  
  - $ f(-2) = -8 $, $ f(-1) = -1 $, $ f(0) = 0 $, $ f(1) = 1 $, $ f(2) = 8 $  
- The graph passes through the origin and extends infinitely in both directions.  
- It is symmetric about the origin (odd function).  

### Example 3:  
**Define $ f(x) = \frac{1}{x} $. Complete the table and find its domain and range.**  

**Solution**:  
| $ x $      | $ -2 $ | $ -1.5 $ | $ -1 $ | $ -0.5 $ | $ 0.25 $ | $ 0.5 $ | $ 1.5 $ |  
|-------------|--------|----------|--------|----------|----------|----------|----------|  
| $ f(x) $   | $ -0.5 $ | $ -0.67 $ | $ -1 $ | $ -2 $ | $ 4 $ | $ 2 $ | $ 0.67 $ |  

**Domain**: $ \mathbb{R} \setminus \{0\} $ (all real numbers except zero)  
**Range**: $ \mathbb{R} \setminus \{0\} $  
**Graph**: Two hyperbolic branches in the first and third quadrants.  

### Example 4:  
**Identify the type of function $ f(x) = 5 $.**  

**Solution**:  
This is a **constant function** since the output remains 5 for all inputs $ x \in \mathbb{R} $.  

### Example 5:  
**Determine whether $ f(x) = x^2 + 3x - 2 $ is a polynomial function.**  

**Solution**:  
Yes, it is a **polynomial function** because it can be written as $ f(x) = (-2) + 3x + 1x^2 $, matching the general form $ a_0 + a_1x + a_2x^2 $.

## 5. Practice Problems  

### 🟢 Easy  
1. **What is the domain and range of the identity function $ f(x) = x $?**  
2. **Sketch the graph of $ f(x) = 2 $ and describe its shape.**  

### 🟡 Medium  
3. **Complete the table for $ f(x) = x^3 $ with $ x = -3, -1, 0, 1, 3 $.**  
4. **Is $ f(x) = \frac{x^2 + 1}{x - 1} $ a rational function? Justify.**  

### 🔴 Hard  
5. **Find the domain and range of $ f(x) = \frac{1}{x^2 - 4} $.**  

**Answers**:  
1. **Domain**: $ \mathbb{R} $, **Range**: $ \mathbb{R} $  
2. Graph: Horizontal line at $ y = 2 $, no slope.  
3. Table:  
   | $ x $ | $ -3 $ | $ -1 $ | $ 0 $ | $ 1 $ | $ 3 $ |  
   |--------|---------|---------|--------|--------|--------|  
   | $ f(x) $ | $ -27 $ | $ -1 $ | $ 0 $ | $ 1 $ | $ 27 $ |  
4. Yes, since numerator and denominator are polynomials, and denominator $ x - 1 \neq 0 $.  
5. **Domain**: $ \mathbb{R} \setminus \{-2, 2\} $, **Range**: $ (0, \infty) \cup (-\infty, 0) $

## 6. Summary  
- **Identity Function**: $ f(x) = x $, graph is a straight line through the origin.  
- **Constant Function**: Output is always constant, graph is horizontal.  
- **Polynomial Function**: Sum of terms with non-negative exponents, e.g., $ x^2 + 3x $.  
- **Rational Function**: Ratio of two polynomials, e.g., $ \frac{x+1}{x-1} $.  
- **Modulus Function**: Outputs absolute value, graph is V-shaped.  
- **Domain & Range**: Critical for graphing and function analysis.  

---  

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ f(x) = x $ | Identity function |  
| $ f(x) = c $ | Constant function |  
| $ f(x) = a_0 + a_1x + a_2x^2 + \dots + a_nx^n $ | General polynomial function |  
| $ f(x) = \frac{p(x)}{q(x)} $ | Rational function (where $ q(x) \neq 0 $) |  
| $ f(x) = |x| $ | Modulus function |

## 8. Student Corner  

### Common Mistakes  
1. **Confusing Domain and Range**: Always check which variable represents input/output.  
2. **Ignoring Restrictions**: Rational functions exclude values making denominators zero.  
3. **Incorrect Graph Shape**: Modulus functions are V-shaped, not U-shaped.  

### Exam Tips  
- Practice sketching graphs for standard functions (e.g., quadratic, cubic).  
- Memorize the shapes of identity, constant, and modulus functions.  

### Memory Aid  
**"ID, CON, POLY, RATIO, MOD"**  
- ID: Straight line (identity)  
- CON: Flat line (constant)  
- POLY: Curved (polynomial)  
- RATIO: Hyperbola (rational)  
- MOD: V-shape (modulus)
