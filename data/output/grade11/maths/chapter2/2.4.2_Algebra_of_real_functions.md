## 1. Prerequisites  
Before diving into the algebra of real functions, ensure you understand the following concepts:  
- **Set Notation**: Ability to denote sets and their elements using symbols like $ \in $, $ \subset $, and $ \emptyset $.  
- **Functions**: Familiarity with the definition of a function $ f: X \to Y $, where $ X $ is the domain and $ Y $ is the codomain.  
- **Basic Operations**: Knowledge of arithmetic operations (addition, subtraction, multiplication, division) applied to real numbers.  

---

## 2. Introduction  
Imagine combining two quantities measured in the same unit—say, adding lengths or multiplying areas. Similarly, in mathematics, we can combine **real functions** using arithmetic operations to create new functions. This topic explores how to **add**, **subtract**, **multiply**, **divide**, and **scale** real functions. By mastering these operations, you’ll gain tools to manipulate functions algebraically, which is essential for analyzing their behavior and applications in calculus and higher mathematics.  

---

## 3. Explanation  

### 3.1 Definitions of Algebraic Operations on Real Functions  
> **Addition of Two Real Functions**: Given two functions $ f: X \to \mathbb{R} $ and $ g: X \to \mathbb{R} $, their sum $ f + g $ is defined as $ (f + g)(x) = f(x) + g(x) $ for all $ x \in X $.  
>  
> **Subtraction of Two Real Functions**: The difference $ f - g $ is defined as $ (f - g)(x) = f(x) - g(x) $ for all $ x \in X $.  
>  
> **Scalar Multiplication**: Multiplying a function $ f $ by a scalar $ \alpha \in \mathbb{R} $ yields $ (\alpha f)(x) = \alpha \cdot f(x) $.  
>  
> **Multiplication of Two Real Functions**: The product $ fg $ is defined as $ (fg)(x) = f(x) \cdot g(x) $.  
>  
> **Division of Two Real Functions**: The quotient $ \frac{f}{g} $ is defined as $ \left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)} $, provided $ g(x) \neq 0 $ for all $ x \in X $.  

These operations are performed **pointwise**, meaning they act independently on each input value $ x \in X $.  

### 3.2 Domain Considerations  
When performing operations on functions, the **domain** of the resulting function is typically the intersection of the domains of the original functions. However, for division $ \frac{f}{g} $, additional care is needed: $ g(x) \neq 0 $ must hold for all $ x $ in the domain.  

---

## 4. Solved Examples  

### Example 1: Addition and Subtraction  
Let $ f(x) = x^2 $ and $ g(x) = 2x + 1 $. Compute $ (f + g)(x) $ and $ (f - g)(x) $.  
**Solution**:

$$
(f + g)(x) = f(x) + g(x) = x^2 + (2x + 1) = x^2 + 2x + 1

$$

$$
(f - g)(x) = f(x) - g(x) = x^2 - (2x + 1) = x^2 - 2x - 1

$$  

### Example 2: Scalar Multiplication  
Let $ f(x) = 3x - 4 $ and $ \alpha = -2 $. Compute $ (\alpha f)(x) $.  
**Solution**:

$$
(-2f)(x) = -2 \cdot (3x - 4) = -6x + 8

$$  

### Example 3: Multiplication of Two Functions  
Let $ f(x) = x + 1 $ and $ g(x) = x - 1 $. Compute $ (fg)(x) $.  
**Solution**:

$$
(fg)(x) = (x + 1)(x - 1) = x^2 - 1

$$  

### Example 4: Division of Two Functions  
Let $ f(x) = x^2 $ and $ g(x) = x $. Compute $ \left(\frac{f}{g}\right)(x) $.  
**Solution**:

$$
\left(\frac{f}{g}\right)(x) = \frac{x^2}{x} = x \quad \text{for } x \neq 0

$$  

### Example 5: Combined Operations  
Let $ f(x) = \sqrt{x} $ and $ g(x) = x $. Compute $ (f + g)(x) $ and $ \left(\frac{f}{g}\right)(x) $.  
**Solution**:

$$
(f + g)(x) = \sqrt{x} + x

$$

$$
\left(\frac{f}{g}\right)(x) = \frac{\sqrt{x}}{x} = \frac{1}{\sqrt{x}} \quad \text{for } x > 0

$$

## 5. Practice Problems  

### 🟢 Easy  
1. Let $ f(x) = 2x + 3 $ and $ g(x) = x^2 $. Find $ (f + g)(x) $.  
2. Let $ h(x) = 5x - 1 $ and $ \alpha = 3 $. Compute $ (\alpha h)(x) $.  

### 🟡 Medium  
3. Let $ p(x) = \sin x $ and $ q(x) = \cos x $. Find $ (p - q)(x) $.  
4. Let $ r(x) = \frac{1}{x} $ and $ s(x) = x + 1 $. Compute $ \left(\frac{r}{s}\right)(x) $.  

### 🔴 Hard  
5. Let $ u(x) = \sqrt{x + 2} $ and $ v(x) = x - 1 $. Find $ (uv)(x) $ and state its domain.  

---

## 6. Answers  

### 1. Easy Problem 1

$$
(f + g)(x) = (2x + 3) + x^2 = x^2 + 2x + 3

$$  

### 2. Easy Problem 2

$$
(3h)(x) = 3(5x - 1) = 15x - 3

$$  

### 3. Medium Problem 3

$$
(p - q)(x) = \sin x - \cos x

$$  

### 4. Medium Problem 4

$$
\left(\frac{r}{s}\right)(x) = \frac{1/x}{x + 1} = \frac{1}{x(x + 1)}, \quad x \neq 0, -1

$$  

### 5. Hard Problem 5

$$
(uv)(x) = \sqrt{x + 2}(x - 1)

$$  
**Domain**: $ x + 2 \geq 0 $ and $ x - 1 \neq 0 $ ⇒ $ x \geq -2 $ and $ x \neq 1 $.  

---

## 7. Summary  
- **Addition**: $ (f + g)(x) = f(x) + g(x) $  
- **Subtraction**: $ (f - g)(x) = f(x) - g(x) $  
- **Scalar Multiplication**: $ (\alpha f)(x) = \alpha \cdot f(x) $  
- **Multiplication**: $ (fg)(x) = f(x) \cdot g(x) $  
- **Division**: $ \left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)} $, where $ g(x) \neq 0 $  

---

## 8. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ (f + g)(x) = f(x) + g(x) $ | Addition of functions |  
| $ (f - g)(x) = f(x) - g(x) $ | Subtraction of functions |  
| $ (\alpha f)(x) = \alpha \cdot f(x) $ | Scalar multiplication |  
| $ (fg)(x) = f(x) \cdot g(x) $ | Pointwise multiplication |  
| $ \left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)} $ | Quotient of functions |  

---

## 9. Student Corner  

### Common Mistakes  
- **Mistake**: Forgetting to restrict the domain for division $ \frac{f}{g} $.  
  **Correction**: Always specify $ g(x) \neq 0 $ in the domain.  
- **Mistake**: Confusing scalar multiplication with function composition.  
  **Correction**: Scalar multiplication scales the output, not the input.  

### Exam Tips  
- Clearly state the domain of the resulting function after any operation.  
- Simplify expressions algebraically before evaluating them numerically.  

### Memory Aid  
Use the acronym **ADD-SUB-MULT-DIV** to recall the four primary operations on functions.
