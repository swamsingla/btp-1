### Explanation

#### What is Position?

Position refers to the location of an object in a plane, specified by its coordinates $(x, y) $.

**Definition:** The position of an object at a given instant is the set of all ordered pairs $ (x, y) $ that satisfy the equation of the locus of the object.

##### Coordinate Geometry

Coordinate geometry is the study of shapes and figures defined by their coordinates. It helps us describe positions, distances, and relationships between objects in a plane.

**Theorem:** The Distance Formula

> Given two points $ (x_1, y_1) $ and $ (x_2, y_2) $, the distance between them is given by:
>
> $ d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2} $

##### Reference Points

A reference point is a fixed point used as a basis for measuring distances or locations.

*   When you measure the distance from a reference point, you're essentially measuring the distance from that point to the object.
*   Using a reference point allows you to easily compare distances and determine relative positions.

#### Key Concepts and Formulas

*   **Distance Formula**: $ d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2} $
*   **Midpoint Formula**: $ (x_m, y_m) = (\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}) $
*   **Perpendicular Bisector Formula**: The perpendicular bisector of a line segment is the line that passes through the midpoint of the segment and is perpendicular to it.

### Solved Examples

#### Example 1: Finding the Distance Between Two Points

Find the distance between the points $ (2, 3) $ and $ (4, 5) $.

1.  Write down the coordinates of both points.
2.  Plug the values into the distance formula.
3.  Calculate the distance using the formula.

**Solution:**

|  |  |  |
| --- | --- | --- |
| **Step 1** | Write down the coordinates | $ (2, 3) $, $ (4, 5) $ |
|  |  |  |
| **Step 2** | Plug in values into distance formula | $ d = \sqrt{(4-2)^2 + (5-3)^2} $ |
|  |  |  |
| **Step 3** | Calculate distance | $ d = \sqrt{2^2 + 2^2} = \sqrt{8} = 2\sqrt{2} $ |

#### Example 2: Finding the Midpoint of a Line Segment

Find the midpoint of the line segment joining the points $ (1, 2) $ and $ (4, 6) $.

1.  Write down the coordinates of both points.
2.  Plug the values into the midpoint formula.
3.  Calculate the midpoint using the formula.

**Solution:**

|  |  |  |
| --- | --- | --- |
| **Step 1** | Write down the coordinates | $ (1, 2) $, $ (4, 6) $ |
|  |  |  |
| **Step 2** | Plug in values into midpoint formula | $ (x_m, y_m) = (\frac{1+4}{2}, \frac{2+6}{2}) $ |
|  |  |  |
| **Step 3** | Calculate midpoint | $ (x_m, y_m) = (2.5, 4) $ |

#### Example 3: Finding the Equation of a Perpendicular Bisector

Find the equation of the perpendicular bisector of the line segment joining the points $ (2, 3) $ and $ (4, 5) $.

1.  Find the midpoint of the line segment.
2.  Find the slope of the line segment.
3.  Use the slope-intercept form of a line to write the equation.

**Solution:**

|  |  |  |
| --- | --- | --- |
| **Step 1** | Find midpoint | $ (2.5, 4) $ |
|  |  |  |
| **Step 2** | Find slope | $ m = \frac{5-3}{4-2} = 1 $ |
|  |  |  |
| **Step 3** | Write equation | $ y - 4 = -(x - 2.5) $ |
|  |  |  |
