## 2. Introduction  
Have you ever wondered if there’s a number that appears no matter how you play with digits? Meet **D.R. Kaprekar**, a mathematician who discovered a magical number called **6174**! This topic explores his famous process and why this number is so special. By the end, you’ll see how numbers can hide secrets waiting to be uncovered!  

---  

## 3. Explanation  

### 3.1 What is the Kaprekar Constant?  
**Bold**: *Kaprekar constant* refers to the number **6174**, which emerges repeatedly when applying a specific process to 4-digit numbers.  

> **Definition**: The Kaprekar constant is the unique 4-digit number that results from repeatedly performing the following steps:  
1. Take any 4-digit number with **at least two different digits**.  
2. Arrange its digits to form the **largest possible number** (call it **A**).  
3. Arrange its digits to form the **smallest possible number** (call it **B**).  
4. Subtract **B** from **A** to get a new number (**C**).  
5. Repeat the process with **C** until you reach **6174**.  

### 3.2 Steps to Reach the Magic Number  
> **Procedure**:  
1. Choose a 4-digit number (e.g., $6382 $).  
2. Create **A** by arranging digits in descending order: $ 8632 $.  
3. Create **B** by arranging digits in ascending order: $ 2368 $.  
4. Compute $ C = A - B $: $ 8632 - 2368 = 6264 $.  
5. Repeat the process with $ C $ until you get $ 6174 $.  

### 3.3 Why Does This Work?  
> **Property**: No matter which valid 4-digit number you start with, repeated applications of the process always lead to **6174**. This is because the subtraction operation eventually narrows down the possibilities to this unique number.  

> **Note**: For 3-digit numbers, the process does **not** consistently yield a single result. It is still an open question whether starting with $ 196 $ ever produces a palindrome!

## 4. Solved Examples  

### Example 1: Exploring with $ 6382 $  
**Solution**:  
1. **Step 1**: $ A = 8632 $, $ B = 2368 $  
2. **Step 2**: $ C = 8632 - 2368 = 6264 $  
3. **Step 3**: $ A = 6642 $, $ B = 2466 $  
4. **Step 4**: $ C = 6642 - 2466 = 4176 $  
5. **Step 5**: $ A = 7641 $, $ B = 1467 $  
6. **Step 6**: $ C = 7641 - 1467 = 6174 $  

✅ Final Result: $ 6174 $ (the Kaprekar constant)!  

### Example 2: Try with $ 1234 $  
**Solution**:  
1. $ A = 4321 $, $ B = 1234 $  
2. $ C = 4321 - 1234 = 3087 $  
3. $ A = 8730 $, $ B = 0378 = 378 $ (leading zeros are ignored)  
4. $ C = 8730 - 0378 = 8352 $  
5. $ A = 8532 $, $ B = 2358 $  
6. $ C = 8532 - 2358 = 6174 $  

✅ Final Result: $ 6174 $!  

### Example 3: Challenge with $ 9999 $  
**Solution**:  
1. $ A = 9999 $, $ B = 9999 $  
2. $ C = 9999 - 9999 = 0000 $ (but leading zeros are invalid; use $ 0000 $ as $ 0 $)  
3. $ A = 0000 $, $ B = 0000 $  
4. $ C = 0000 - 0000 = 0 $ (invalid input; choose a number with distinct digits!)  

⚠️ Note: The process fails if all digits are the same. Always pick a number with **at least two different digits**!

## 6. Summary  
- The **Kaprekar constant** is **6174**, reachable via a specific process with 4-digit numbers.  
- Steps: Arrange digits to form **largest (A)** and **smallest (B)** numbers, compute $ C = A - B $, repeat.  
- Process always leads to **6174** unless all digits are identical.  
- 3-digit numbers behave differently and remain an unsolved mystery!

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ C = A - B $ | Where $ A $ is the largest number formed by digits, $ B $ is the smallest. |  
| $ 6174 $ | The Kaprekar constant for 4-digit numbers. |  
| $ n $ | Represents the number of iterations needed to reach $ 6174 $. |

## 8. Student Corner  

### Common Mistakes  
1. **Ignoring Leading Zeros**: When forming $ B $, treat $ 0378 $ as $ 378 $ (not $ 0378 $).  
2. **Using Identical Digits**: Avoid numbers like $ 9999 $; they break the process.

Remember: **Arrange, Subtract, Repeat**—the steps to unlock Kaprekar’s secret!
