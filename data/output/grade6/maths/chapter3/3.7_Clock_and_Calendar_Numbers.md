## 3. Explanation  

### 3.1 Clock Patterns  
**Palindromic Times**: A time is palindromic if its digits read the same forward and backward. For example:  
- 4:44 (reads as 444)  
- 10:01 (reads as 1001)  
- 12:21 (reads as 1221)  

> **Definition**: A **palindromic time** on a 12-hour clock has digits that mirror themselves.  

#### Example:  
Time: 10:01 → Digits: 1 0 0 1 → Reversed: 1 0 0 1 ✅  

**Task**: Find all palindromic times on a 12-hour clock.  

### 3.2 Date Patterns  
**Repeating Dates**: Some dates have digits that repeat or form palindromes. For instance:  
- Manish’s birthday: **20/12/2012** (digits ‘2’, ‘0’, ‘1’, ‘2’ repeat)  
- Meghana’s birthday: **11/02/2011** (palindrome: 11/02/2011 → reads same backward)  

> **Definition**: A **repeating date** has digits that follow a pattern (e.g., repetition or palindrome).  

#### Example:  
Date: 11/02/2011 → Digits: 1 1 0 2 2 0 1 1 → Palindrome ✅  

**Task**: Find other dates where digits repeat or form palindromes.  

### 3.3 Calendar Repeats  
**Calendar Repetition**: Jeevan wonders if a calendar can repeat. Calendars change yearly due to leap years and day-of-week shifts. However, certain years may share the same calendar layout after specific intervals.  

> **Rule**: A calendar repeats every **28 years** if the years are not leap years. Leap years may extend this cycle to **28 or 60 years** depending on century rules.  

### 3.4 Digit Manipulation  
**Difference and Sum of Numbers**: Using digits, create the largest and smallest numbers, then calculate their difference and sum.  
- Example: Digits 4, 7, 3, 2 → Largest: 7432, Smallest: 2347  
- Difference: $7432 - 2347 = 5085 $  
- Sum: $ 7432 + 2347 = 9779 $  

> **Formula**:  
- Largest number: Arrange digits in descending order.  
- Smallest number: Arrange digits in ascending order.

## 4. Solved Examples  

### Example 1: Finding Palindromic Times  
**Question**: How many palindromic times exist on a 12-hour clock?  

**Solution**:  
1. A valid time has hours from 1–12 and minutes from 00–59.  
2. For a time to be palindromic:  
   - Hours and minutes must mirror each other.  
   - Example: 10:01 → Mirror: 1001 (valid).  
3. List all possibilities:  
   - 12:21  
   - 11:11  
   - 10:01  
   - 09:50 (invalid, since hour must be 1–12).  
4. Valid palindromic times: **12:21, 11:11, 10:01, 09:50 (if allowed)**.  

### Example 2: Repeating Dates  
**Question**: Find a date where digits repeat in order (like 20/12/2012).  

**Solution**:  
1. Look for dates where digits follow a sequence (e.g., 11/11/1111 or 22/22/2222).  
2. Example: **11/11/1111** (digits ‘1’ repeat).  
3. Another example: **22/22/2222** (digits ‘2’ repeat).  

### Example 3: Calendar Repeat  
**Question**: Why does the calendar change every year?  

**Solution**:  
1. A non-leap year has 365 days, which equals **52 weeks + 1 day**.  
2. This shifts the day-of-week for each date by **1 day**.  
3. For example:  
   - January 1st, 2023: Monday  
   - January 1st, 2024: Tuesday (non-leap year shift).  
4. Over 28 years, the cycle repeats if no century rule disrupts it.

## 6. Summary  
- **Palindromic times** on a 12-hour clock follow mirrored digit patterns.  
- **Repeating dates** often involve digit sequences or palindromes (e.g., 11/02/2011).  
- Calendars change due to leap years and day-of-week shifts, but can repeat every **28 years**.  
- To create the largest/smallest number, arrange digits in descending/ascending order.

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ \text{Largest number} = \text{Digits arranged descending} $ | |  
| $ \text{Smallest number} = \text{Digits arranged ascending} $ | |  
| $ \text{Difference} = \text{Largest} - \text{Smallest} $ | |
