## 3. Explanation  

### 3.1 Number Line Basics  
A **number line** is a straight line with numbers placed at equal intervals. It helps visualize the order and magnitude of numbers. To place numbers on a number line:  
1. Determine the scale (how much each mark represents).  
2. Locate the starting and ending points.  
3. Fill in the gaps between known numbers.  

> **Tip**: Always check the distance between labeled numbers to find the interval. For example, if two numbers are 10 units apart, each small tick represents 1 unit.  

### 3.2 Identifying Numbers  
When given a number line with partial markings, you can deduce missing numbers by analyzing the spacing. For instance:  
- If the numbers 15,077 and 15,083 are marked, the gap between them is $15,083 - 15,077 = 6 $. This means each small tick represents 1 unit, and the missing numbers are 15,078, 15,079, 15,080, 15,081, 15,082.  

### 3.3 Finding Smallest and Largest Numbers  
To identify the smallest and largest numbers in a sequence:  
1. Compare all numbers numerically.  
2. The number farthest to the left is the smallest; the one farthest to the right is the largest.  
For example, in the sequence $ 2180, 2754, 1500, 3600, 9950, 9590, 1050, 3050, 5030, 5300, 8400 $:  
- The smallest is $ 1050 $.  
- The largest is $ 9950 $.  

### 3.4 Labeling Missing Positions  
If a number line has unlabeled ticks, calculate the interval between known numbers and fill in the gaps systematically. For example:  
- Between $ 86,705 $ and $ 87,705 $, the interval is $ 87,705 - 86,705 = 1,000 $. Thus, each major tick represents $ 1,000 $, and intermediate ticks can be labeled as $ 86,805, 86,905, $ etc.

## 4. Solved Examples  

### Example 1:  
**Problem**: Label the missing numbers on the number line between $ 15,077 $ and $ 15,083 $.  
**Solution**:  
1. Calculate the interval: $ 15,083 - 15,077 = 6 $.  
2. Each tick represents $ 1 $ unit.  
3. Missing numbers are $ 15,078, 15,079, 15,080, 15,081, 15,082 $.  

### Example 2:  
**Problem**: Circle the smallest and box the largest number in the sequence $ 2180, 2754, 1500, 3600, 9950, 9590, 1050, 3050, 5030, 5300, 8400 $.  
**Solution**:  
1. Compare all numbers: $ 1050 < 1500 < 2180 < 2754 < 3050 < 3600 < 5030 < 5300 < 8400 < 9590 < 9950 $.  
2. Circle $ 1050 $ and box $ 9950 $.  

### Example 3:  
**Problem**: Determine the interval between $ 86,705 $ and $ 87,705 $.  
**Solution**:  
1. Subtract: $ 87,705 - 86,705 = 1,000 $.  
2. Interval = $ 1,000 $.  

### Example 4:  
**Problem**: Place $ 2754 $ on a number line with labels $ 2000 $ and $ 3000 $.  
**Solution**:  
1. Interval = $ 3000 - 2000 = 1000 $.  
2. Each tick represents $ 100 $.  
3. $ 2754 $ is $ 754 $ units from $ 2000 $, so it lies closer to $ 3000 $.  

### Example 5:  
**Problem**: Find the missing number between $ 5030 $ and $ 5300 $ if the interval is $ 100 $.  
**Solution**:  
1. Total interval: $ 5300 - 5030 = 270 $.  
2. Divide by number of gaps: $ 270 / 3 = 90 $.  
3. Missing numbers: $ 5120, 5210 $.

## 6. Summary  
- **Number lines** show numbers in order, with equal spacing.  
- **Intervals** help determine missing numbers between labeled points.  
- **Smallest/largest numbers** are found by comparing values.  
- **Labeling positions** requires calculating gaps and incrementing appropriately.  
- **Mathematical tools**: Subtraction, comparison, division.  

---  

## 7. Key Formulas  
| Formula | Description |  
|--------|-------------|  
| $ \text{Interval} = \text{Larger number} - \text{Smaller number} $ | Calculates the gap between two numbers. |  
| $ \text{Missing numbers} = \text{Start} + n \times \text{Interval} $ | Finds numbers in a sequence. |  
| $ \text{Position} = \text{Reference point} + \text{Distance} $ | Locates a number relative to a known point. |

## 8. Student Corner  

### Common Mistakes  
- **Mistake**: Assuming all ticks represent the same value.  
  **Correction**: Always verify the interval by subtracting known numbers.  
- **Mistake**: Confusing smallest and largest numbers.  
  **Correction**: Align numbers left-to-right on the number line.  

### Exam Tips  
- **Tip 1**: Sketch the number line to visualize gaps.  
- **Tip 2**: Double-check calculations for intervals and missing numbers.  

### Memory Aid  
**Rhyme**: *Left is less, right is more—compare, compute, and score!*
