## 2. Introduction  
Imagine plugging in numbers into a polynomial until it equals zero—those numbers are called *zeroes*! This topic explores how to find such values and understand their significance. You’ll learn to determine when a polynomial evaluates to zero and how this relates to solving equations. By the end, you’ll see how zeroes connect to roots of equations and polynomial behavior.  

This builds on your previous work with polynomials in one variable (Section 2.2) and prepares you for factorization techniques in Section 2.4.  

---  

## 3. Explanation  

### 3.1 Definition of Zeroes  
> **Definition**: A **zero of a polynomial** $ p(x) $ is a number $ c $ such that $ p(c) = 0 $.  

To find a zero, substitute $ c $ into the polynomial and solve for $ c $. For example, for $ p(x) = x - 1 $, setting $ p(c) = 0 $ gives $ c - 1 = 0 $, so $ c = 1 $.  

### 3.2 Special Cases  
> **Special Case 1**: A **non-zero constant polynomial** (e.g., $ p(x) = 5 $) has **no zeroes**, because substituting any value for $ x $ always results in 5.  
> **Special Case 2**: The **zero polynomial** (e.g., $ p(x) = 0 $) has **every real number** as a zero, by convention.  

### 3.3 Linear Polynomials  
For a linear polynomial $ p(x) = ax + b $ (where $ a \neq 0 $), the zero is found by solving $ ax + b = 0 $.

$$
ax + b = 0 \implies x = -\frac{b}{a}

$$  
**Example**: For $ p(x) = 2x + 1 $, the zero is $ x = -\frac{1}{2} $.  

### 3.4 General Method  
To find zeroes of any polynomial:  
1. Substitute a candidate value $ c $ into the polynomial.  
2. Solve $ p(c) = 0 $.  
3. Verify the solution by plugging it back into the original polynomial.

## 4. Solved Examples  

### Example 1: Evaluating a Polynomial  
Find $ p(1) $ for $ p(x) = 5x^3 - 2x^2 + 3x - 2 $.  
**Solution**:

$$
p(1) = 5(1)^3 - 2(1)^2 + 3(1) - 2 = 5 - 2 + 3 - 2 = 4

$$  
Since $ p(1) \neq 0 $, **1 is not a zero** of this polynomial.  

### Example 2: Checking Zeros  
Check if $ -2 $ is a zero of $ p(x) = x + 2 $.  
**Solution**:

$$
p(-2) = (-2) + 2 = 0

$$  
Thus, **$ -2 $ is a zero** of $ p(x) $.  

### Example 3: Solving for a Zero  
Find a zero of $ p(x) = 4x^4 + 5x^3 - x^2 + 6 $.  
**Solution**:  
Try $ x = 0 $:

$$
p(0) = 4(0)^4 + 5(0)^3 - (0)^2 + 6 = 6 \neq 0

$$  
Try $ x = -1 $:

$$
p(-1) = 4(-1)^4 + 5(-1)^3 - (-1)^2 + 6 = 4 - 5 - 1 + 6 = 4 \neq 0

$$  
No obvious zero exists; advanced methods (like factorization) are needed.  

### Example 4: Constant Polynomial  
Determine the zero(s) of $ p(x) = 5 $.  
**Solution**:  
Substitute any $ x $:

$$
p(x) = 5 \neq 0 \quad \text{(for all } x\text{)}

$$  
**Conclusion**: This polynomial has **no zeroes**.  

### Example 5: Zero Polynomial  
State the zeroes of $ p(x) = 0 $.  
**Solution**:  
By convention, **all real numbers** are zeroes of the zero polynomial.

## 5. Practice Problems  

### 🟢 Easy  
1. Find $ p(2) $ for $ p(x) = 3x^2 - 4x + 1 $.  
2. Is $ 1 $ a zero of $ p(x) = x - 1 $? Justify.  
3. Determine the zero of $ p(x) = 7x - 14 $.  

### 🟡 Medium  
4. Check if $ -3 $ is a zero of $ p(x) = 2x + 6 $.  
5. Find the zero of $ p(x) = x^2 - 5x + 6 $.  
6. Evaluate $ p(0) $ for $ p(x) = 4x^3 - 2x + 5 $.  

### 🔴 Hard  
7. Prove that the polynomial $ p(x) = x^2 + 1 $ has no real zeroes.  
8. Given $ p(x) = ax^2 + bx + c $, find conditions on $ a, b, c $ for the polynomial to have exactly one zero.  
9. Solve for $ k $ such that $ p(k) = 0 $ for $ p(x) = 3x^2 + 2kx - 5 $.  

**Answers:**  

1.

$$
p(2) = 3(2)^2 - 4(2) + 1 = 12 - 8 + 1 = 5

$$  
2.

$$
p(1) = 1 - 1 = 0 \implies \text{Yes, } 1 \text{ is a zero}.

$$  
3.

$$
7x - 14 = 0 \implies x = 2

$$  
4.

$$
p(-3) = 2(-3) + 6 = -6 + 6 = 0 \implies \text{Yes, } -3 \text{ is a zero}.

$$  
5.

$$
x^2 - 5x + 6 = 0 \implies (x - 2)(x - 3) = 0 \implies x = 2 \text{ or } 3

$$  
6.

$$
p(0) = 4(0)^3 - 2(0) + 5 = 5

$$  
7.

$$
x^2 + 1 = 0 \implies x^2 = -1 \implies \text{No real solutions}.

$$  
8.

$$
\text{Discriminant } D = b^2 - 4ac = 0 \implies \text{One real zero}.

$$  
9.

$$
3k^2 + 2k \cdot k - 5 = 0 \implies 3k^2 + 2k^2 - 5 = 0 \implies 5k^2 = 5 \implies k = \pm1

$$

## 6. Summary  
- A **zero of a polynomial** $ p(x) $ is a value $ c $ where $ p(c) = 0 $.  
- To find a zero, substitute $ c $ into the polynomial and solve $ p(c) = 0 $.  
- **Non-zero constant polynomials** have no zeroes.  
- The **zero polynomial** has all real numbers as zeroes.  
- For a linear polynomial $ ax + b $, the zero is $ x = -\frac{b}{a} $.  
- Zeros are critical for understanding polynomial behavior and factorization.  

---  

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ p(c) = 0 $ | Definition of a zero of a polynomial. |  
| $ x = -\frac{b}{a} $ | Zero of a linear polynomial $ ax + b $. |  
| $ \text{Constant polynomial } p(x) = k \Rightarrow \text{No zeroes} $ | Except for $ k = 0 $. |  
| $ \text{Zero polynomial } p(x) = 0 \Rightarrow \text{All real numbers are zeroes} $ | By convention. |

## 8. Student Corner  

### Common Mistakes  
- ❌ Confusing **coefficients** with **zeroes**: e.g., thinking $ x = 5 $ is a zero of $ 5x $ instead of solving $ 5x = 0 $.  
- ❌ Forgetting that **non-zero constants** have no zeroes.  
- ❌ Misapplying the **zero polynomial rule**: Only apply it to the zero polynomial, not others.  

### Exam Tips  
- **Practice substitution**: Regularly evaluate polynomials at various points to build intuition.  
- **Memorize linear zero formula**: Quick recall saves time during exams.  

### Memory Aid  
**Rhyme**: *"Set p(c) to zero, solve for c, that’s the trick!"*
