## 3. Explanation  

### 3.1 Understanding Decimals  
Decimals are numbers that represent parts of a whole. For example, **2.7 meters** means 2 meters and 7 tenths of a meter.  
> **Definition**: A decimal number consists of a whole number part and a fractional part separated by a **decimal point**.  

### 3.2 Aligning Decimals for Operations  
When adding or subtracting decimals, **align the decimal points** vertically. This ensures that digits of the same place value (tenths, hundredths, etc.) are added or subtracted correctly.  
> **Rule**: Always line up the decimal points before performing operations. If needed, add trailing zeros to make the numbers have the same number of decimal places.  

### 3.3 Adding Decimals  
To add decimals:  
1. Write the numbers vertically, aligning the decimal points.  
2. Add digits starting from the rightmost place (hundredths, thousandths, etc.).  
3. Carry over values as needed.  
4. Place the decimal point in the result directly below the aligned decimal points.  

#### Example:  
Adding 2.7 and 3.5:  
```  
  2.7  
+ 3.5  
------  
  6.2  
```  
**Step-by-step**:  
- Add tenths: 7 + 5 = 12 → write 2, carry over 1.  
- Add ones: 2 + 3 + 1 (carried) = 6.  
- Result: 6.2.  

### 3.4 Subtracting Decimals  
Subtracting decimals follows a similar process:  
1. Align the decimal points vertically.  
2. Subtract digits starting from the rightmost place.  
3. Borrow from higher place values if needed.  
4. Place the decimal point in the result directly below the aligned decimal points.  

#### Example:  
Subtracting 2.7 from 3.5:  
```  
  3.5  
- 2.7  
------  
  0.8  
```  
**Step-by-step**:  
- Subtract tenths: 5 - 7 → borrow 1 from ones place.  
- Ones become 2, tenths become 15. Now 15 - 7 = 8.  
- Subtract ones: 2 - 2 = 0.  
- Result: 0.8.  

### 3.5 Estimating Sums and Differences  
Estimation helps check the reasonableness of results. For example:  
- Round 2.7 to 3 and 3.5 to 3 → estimated sum is 6.  
- Actual sum is 6.2, which is close to the estimate.

## 6. Summary  
- **Align decimals** vertically before adding or subtracting.  
- Add or subtract **digit by digit**, starting from the smallest place value.  
- **Carry over** when adding and **borrow** when subtracting.  
- Check results by estimation or reversing operations.  
- Trailing zeros can be added to match decimal places.

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ a + b = c $ | Sum of two decimals $ a $ and $ b $ equals $ c $. |  
| $ a - b = d $ | Difference between decimals $ a $ and $ b $ equals $ d $. |  
| $ a + b \approx \text{Estimated sum} $ | Estimate by rounding decimals. |

## 8. Student Corner  

### Common Mistakes  
- **Misalignment**: Forgetting to line up decimal points leads to incorrect results.  
  ✅ Correction: Always align decimals vertically.  
- **Ignoring zeros**: Missing trailing zeros in numbers with fewer decimal places.  
  ✅ Correction: Add zeros to match decimal places (e.g., 2.5 becomes 2.50).  

### Exam Tips  
- **Check your work**: Reverse the operation (e.g., add instead of subtract) to verify.  
- **Estimate first**: Quick mental math helps catch major errors.  

### Memory Aid  
**Line 'Em Up, Add/Minus, Check Your Work!**  
(Shortened version: L.A.C.W.)
