## 2. Introduction  
Have you ever wondered what happens when you divide powers with the same base? Or how a negative exponent works? This section explores the **laws of exponents** for division, including **negative exponents** and **zero exponents**, using real-world examples like halving lengths and calculating reciprocals. By the end, you’ll master how to simplify expressions like $ 2^4 \div 2^3 $ or $ 10^{-5} $!  

---

## 3. Explanation  

### 3.1 Division of Exponents  
When dividing powers with the **same base**, subtract the exponents:  
> **$ \frac{n^a}{n^b} = n^{a - b} $**  
This rule applies when $ n \neq 0 $ and $ a > b $.  

**Example**:  
If a line of length $ 2^4 = 16 $ units is halved 3 times, the new length is:

$$
2^4 \div 2^3 = 2^{4 - 3} = 2^1 = 2 \text{ units}

$$  

### 3.2 Negative Exponents  
A **negative exponent** indicates the **reciprocal** of the positive exponent:  
> **$ n^{-a} = \frac{1}{n^a} $**  
This extends the division rule to cases where $ a < b $:

$$
\frac{n^a}{n^b} = n^{a - b} = n^{-c} \quad \text{(if } c = b - a\text{)}

$$  

**Example**:

$$
2^4 \div 2^5 = 2^{-1} = \frac{1}{2^1} = \frac{1}{2}

$$  

### 3.3 Zero Exponent  
Any non-zero number raised to the power of 0 equals 1:  
> **$ x^0 = 1 $** (for $ x \neq 0 $)  
This follows from the division rule:

$$
\frac{x^a}{x^a} = x^{a - a} = x^0 = 1

$$  

**Example**:

$$
2^4 \div 2^4 = 2^0 = 1

$$  

### 3.4 Generalized Forms  
These rules apply universally:  
- **Division Rule**: $ \frac{n^a}{n^b} = n^{a - b} $  
- **Negative Exponent Rule**: $ n^{-a} = \frac{1}{n^a} $  
- **Reciprocal Rule**: $ \frac{1}{n^a} = n^{-a} $

## 4. Solved Examples  

### Example 1: Simplify $ 2^{100} \div 2^{25} $  
**Solution**:  
Apply the division rule:

$$
2^{100} \div 2^{25} = 2^{100 - 25} = 2^{75}

$$  
**Answer**: $2^{75} $  

### Example 2: Evaluate $ 10^{-5} $  
**Solution**:  
Use the negative exponent rule:

$$
10^{-5} = \frac{1}{10^5} = \frac{1}{100,\!000}

$$  
**Answer**: $\frac{1}{100,\!000} $  

### Example 3: Simplify $ 3^2 \times 3^{-5} \times 3^6 $  
**Solution**:  
Combine exponents by adding:

$$
3^{2 + (-5) + 6} = 3^{3} = 27

$$  
**Answer**: $27 $  

### Example 4: Express $ (–7)^{-2} $ as a fraction  
**Solution**:  
Apply the negative exponent rule:

$$
(–7)^{-2} = \frac{1}{(–7)^2} = \frac{1}{49}

$$  
**Answer**: $\frac{1}{49} $

## 5. Practice Problems  

🟢 **Easy**: Simplify $ 2^{-4} \times 2^7 $.  
🟡 **Medium**: Calculate $ 10^{-3} \div 10^{-5} $.  
🔴 **Hard**: Solve $ (–5)^{-3} \times (–5)^{-2} $.  

**Answers**:  
1. **Easy**:

$$
2^{-4} \times 2^7 = 2^{-4 + 7} = 2^3 = 8

$$  
2. **Medium**:

$$
10^{-3} \div 10^{-5} = 10^{-3 - (-5)} = 10^{2} = 100

$$  
3. **Hard**:

$$
(–5)^{-3} \times (–5)^{-2} = (–5)^{-3 + (-2)} = (–5)^{-5} = \frac{1}{(–5)^5} = \frac{1}{-3125}

$$

## 6. Summary  
- **Dividing exponents**: $ \frac{n^a}{n^b} = n^{a - b} $  
- **Negative exponents**: $ n^{-a} = \frac{1}{n^a} $  
- **Zero exponents**: $ x^0 = 1 $ (for $ x \neq 0 $)  
- **Reciprocals**: $ \frac{1}{n^a} = n^{-a} $  
- Always ensure the base $ n \neq 0 $ when applying these rules.  

---

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ \frac{n^a}{n^b} = n^{a - b} $ | Division of exponents with the same base |  
| $ n^{-a} = \frac{1}{n^a} $ | Negative exponents as reciprocals |  
| $ x^0 = 1 $ | Any non-zero number to the power of 0 |  
| $ \frac{1}{n^a} = n^{-a} $ | Reciprocal of a power equals a negative exponent |

## 8. Student Corner  

### Common Mistakes  
1. **Confusing subtraction with multiplication**: $ 2^3 \div 2^2 = 2^{1} $, not $ 2^{6} $.  
2. **Ignoring the base**: $ (-3)^{-2} = \frac{1}{(-3)^2} = \frac{1}{9} $, not $-\frac{1}{9} $.  

### Memory Aid  
**"Negative exponents flip the fraction!"**  
- $ n^{-a} = \frac{1}{n^a} $  
- $ \frac{1}{n^a} = n^{-a} $
