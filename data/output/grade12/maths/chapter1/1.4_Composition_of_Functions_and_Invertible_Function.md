## 2. Introduction  
Have you ever wondered how multiple processes can be combined to produce a final result? For instance, consider converting temperature from Celsius to Fahrenheit and then to Kelvin—each step relies on a function applied to the output of the previous one. This is the essence of **composition of functions**, a powerful tool in mathematics.  

In this topic, we explore how to combine two functions into a single function and understand the conditions under which a function can be "reversed" (invertible). These ideas are vital for advanced topics like calculus, linear algebra, and computer science algorithms. By mastering this, you’ll gain insights into how functions interact and transform inputs systematically.

## 3. Explanation  

### 3.1 Composition of Functions  
> **Definition**: Let $ f: A \to B $ and $ g: B \to C $ be two functions. The **composition of $ f $ and $ g $**, written as $ g \circ f $, is a new function $ g \circ f: A \to C $ defined by $ (g \circ f)(x) = g(f(x)) $ for all $ x \in A $.  

This operation applies $ f $ first, then uses its output as input for $ g $. The order matters: $ g \circ f \neq f \circ g $ in general.  

#### Key Properties of Composition  
- **Associativity**: If $ h: C \to D $, then $ h \circ (g \circ f) = (h \circ g) \circ f $.  
- **Non-commutativity**: $ g \circ f \neq f \circ g $ unless specific conditions are met (see Example 16 below).  

### 3.2 Invertible Functions  
> **Definition**: A function $ f: X \to Y $ is **invertible** if there exists a function $ g: Y \to X $ such that:

$$
g \circ f = I_X \quad \text{and} \quad f \circ g = I_Y,

$$  
where $ I_X $ and $ I_Y $ are identity functions on $ X $ and $ Y $, respectively. The function $ g $ is called the **inverse** of $ f $, denoted $ f^{-1} $.  

#### Conditions for Invertibility  
- **Bijectivity**: A function is invertible **if and only if** it is both **injective** (one-to-one) and **surjective** (onto).  
  - **Injective**: $ f(a) = f(b) \Rightarrow a = b $.  
  - **Surjective**: For every $ y \in Y $, there exists $ x \in X $ such that $ f(x) = y $.  

#### Proof Sketch for Bijectivity  
If $ f $ is invertible, then $ g \circ f = I_X $ implies $ f $ is injective (since $ f(a) = f(b) \Rightarrow g(f(a)) = g(f(b)) \Rightarrow a = b $). Similarly, $ f \circ g = I_Y $ implies surjectivity (every $ y \in Y $ is mapped to via $ f(g(y)) $). Conversely, if $ f $ is bijective, define $ f^{-1}(y) = x $ where $ f(x) = y $; this satisfies $ f^{-1} \circ f = I_X $ and $ f \circ f^{-1} = I_Y $.

## 4. Solved Examples  

### Example 1: Composition of Finite Functions  
Let $ f: \{2, 3, 4, 5\} \to \{3, 4, 5, 9\} $ and $ g: \{3, 4, 5, 9\} \to \{7, 11, 15\} $ be defined as:  
- $ f(2) = 3 $, $ f(3) = 4 $, $ f(4) = f(5) = 5 $,  
- $ g(3) = g(4) = 7 $, $ g(5) = g(9) = 11 $.  

**Solution**: Compute $ g \circ f $:  
- $ (g \circ f)(2) = g(f(2)) = g(3) = 7 $,  
- $ (g \circ f)(3) = g(f(3)) = g(4) = 7 $,  
- $ (g \circ f)(4) = g(f(4)) = g(5) = 11 $,  
- $ (g \circ f)(5) = g(f(5)) = g(5) = 11 $.  

Thus, $ g \circ f = \{(2,7), (3,7), (4,11), (5,11)\} $.  

---

### Example 2: Comparing $ g \circ f $ and $ f \circ g $  
Let $ f(x) = \cos x $ and $ g(x) = 3x^2 $. Show $ g \circ f \neq f \circ g $.  

**Solution**:  
- $ (g \circ f)(x) = g(\cos x) = 3(\cos x)^2 = 3\cos^2 x $,  
- $ (f \circ g)(x) = f(3x^2) = \cos(3x^2) $.  

At $ x = 0 $:  
- $ 3\cos^2(0) = 3(1)^2 = 3 $,  
- $ \cos(3(0)^2) = \cos(0) = 1 $.  

Since $ 3 \neq 1 $, $ g \circ f \neq f \circ g $.  

---

### Example 3: Finding an Inverse Function  
Let $ f: \mathbb{N} \to Y $, where $ Y = \{y \in \mathbb{N}: y = 4x + 3, x \in \mathbb{N}\} $, be defined by $ f(x) = 4x + 3 $. Show $ f $ is invertible and find $ f^{-1} $.  

**Solution**:  
- **Step 1**: Prove $ f $ is bijective.  
  - **Injective**: Suppose $ f(a) = f(b) \Rightarrow 4a + 3 = 4b + 3 \Rightarrow a = b $.  
  - **Surjective**: For any $ y \in Y $, $ y = 4x + 3 \Rightarrow x = \frac{y - 3}{4} \in \mathbb{N} $.  

- **Step 2**: Define $ f^{-1}(y) = \frac{y - 3}{4} $.  
- **Verification**:  
  - $ f^{-1} \circ f(x) = \frac{4x + 3 - 3}{4} = x $,  
  - $ f \circ f^{-1}(y) = 4\left(\frac{y - 3}{4}\right) + 3 = y $.  

Hence, $ f $ is invertible with $ f^{-1}(y) = \frac{y - 3}{4} $.

## 5. Practice Problems  

### 🟢 Easy: Composition of Linear Functions  
Given $ f(x) = 2x + 1 $ and $ g(x) = x - 3 $, compute $ g \circ f $ and $ f \circ g $.  

**Answer**:  
- $ (g \circ f)(x) = g(2x + 1) = (2x + 1) - 3 = 2x - 2 $,  
- $ (f \circ g)(x) = f(x - 3) = 2(x - 3) + 1 = 2x - 5 $.  

---

### 🟡 Medium: Invertibility of a Quadratic Function  
Let $ f: \mathbb{R} \to \mathbb{R} $ be defined by $ f(x) = x^2 $. Is $ f $ invertible? Justify your answer.  

**Answer**:  
- $ f $ is **not** invertible because it fails the **horizontal line test**: e.g., $ f(2) = f(-2) = 4 $, violating injectivity.  

---

### 🔴 Hard: Inverse of a Piecewise Function  
Let $ f: \mathbb{R} \to \mathbb{R} $ be defined by:

$$
f(x) = 
\begin{cases}
2x + 1 & \text{if } x < 0, \\
x^2 & \text{if } x \geq 0.
\end{cases}

$$  
Find $ f^{-1}(y) $.  

**Answer**:  
- For $ y < 1 $: Solve $ 2x + 1 = y \Rightarrow x = \frac{y - 1}{2} $ (valid for $ x < 0 $).  
- For $ y \geq 1 $: Solve $ x^2 = y \Rightarrow x = \sqrt{y} $ (since $ x \geq 0 $).  
Thus,

$$
f^{-1}(y) = 
\begin{cases}
\frac{y - 1}{2} & \text{if } y < 1, \\
\sqrt{y} & \text{if } y \geq 1.
\end{cases}

$$

## 6. Summary  
- **Composition of functions** combines two functions into one: $ (g \circ f)(x) = g(f(x)) $.  
- **Invertible functions** satisfy $ g \circ f = I_X $ and $ f \circ g = I_Y $; they must be **bijective** (both injective and surjective).  
- **Key properties**: Composition is associative but not commutative.  
- **Inverse function**: Defined only for bijective functions; satisfies $ f^{-1}(f(x)) = x $ and $ f(f^{-1}(y)) = y $.  

---  

## 7. Key Formulas  

| Formula | Description |  
|--------|------------|  
| $ (g \circ f)(x) = g(f(x)) $ | Composition of functions $ f $ and $ g $. |  
| $ f^{-1}(y) $ | Inverse function of $ f $, satisfying $ f(f^{-1}(y)) = y $. |  
| $ I_X(x) = x $ | Identity function on set $ X $. |  
| $ f $ is injective ⇔ $ f(a) = f(b) \Rightarrow a = b $ | Injectivity condition. |  
| $ f $ is surjective ⇔ $ \forall y \in Y, \exists x \in X $ such that $ f(x) = y $ | Surjectivity condition. |

## 8. Student Corner  

### Common Mistakes  
- **Mistake**: Confusing $ g \circ f $ and $ f \circ g $.  
  **Correction**: Always apply the inner function first, then the outer function.  
- **Mistake**: Assuming all functions are invertible.  
  **Correction**: Only bijective functions are invertible; check injectivity and surjectivity.  

### Exam Tips  
- Practice computing compositions and inverses for linear, quadratic, and piecewise functions.  
- Verify your inverse function by composing it with the original function to confirm identity.  

### Memory Aid  
**"Compose First, Invert Later"**: Remember to apply the inner function first when composing, and ensure the function is bijective before attempting to find its inverse.
