## 2. Introduction  
Have you ever wondered why roll numbers in a class are unique? Or why some tasks require matching inputs to outputs without overlaps? These questions tie into the core idea of **types of functions**—how functions behave when mapping elements between sets. In this section, we explore three critical classifications of functions: **one-one (injective)**, **onto (surjective)**, and **bijective** (both one-one and onto). By understanding these distinctions, you’ll gain tools to analyze functional behavior in algebra, calculus, and beyond. This builds on your prior knowledge of relations and prepares you for advanced topics like invertibility and compositions.  

---

## 3. Explanation  

### 3.1 Definitions  
> **Definition 5**: A function $ f: X \to Y $ is **one-one** (or *injective*) if the images of distinct elements of $ X $ under $ f $ are distinct. Mathematically, for all $ x_1, x_2 \in X $, $ f(x_1) = f(x_2) \Rightarrow x_1 = x_2 $.  
>  
> **Definition 6**: A function $ f: X \to Y $ is **onto** (or *surjective*) if every element of $ Y $ is the image of some element of $ X $. That is, for every $ y \in Y $, there exists an $ x \in X $ such that $ f(x) = y $.  
>  
> **Definition 7**: A function $ f: X \to Y $ is **bijective** if it is both one-one and onto.  

### 3.2 Key Observations  
- A **one-one** function ensures uniqueness: no two inputs share the same output.  
- An **onto** function covers the entire codomain: every possible output is achieved.  
- A **bijective** function is reversible (invertible) because it pairs each input with a unique output and vice versa.  

### 3.3 Formal Proof: One-One Function  
**Theorem**: If $ f: X \to Y $ satisfies $ f(x_1) = f(x_2) \Rightarrow x_1 = x_2 $, then $ f $ is one-one.  
**Proof**: Assume $ f(x_1) = f(x_2) $. By the contrapositive of the definition, this implies $ x_1 = x_2 $. Thus, $ f $ preserves distinctness of inputs.  

### 3.4 Formal Proof: Onto Function  
**Theorem**: If $ f: X \to Y $ satisfies that for every $ y \in Y $, there exists an $ x \in X $ with $ f(x) = y $, then $ f $ is onto.  
**Proof**: By construction, the range of $ f $ equals $ Y $, fulfilling the definition of surjectivity.  

### 3.5 Visual Interpretation  
From the source text’s diagrams (Fig 1.2):

- **Onto functions** (like $ f_3 $, $ f_4 $) ensure every element in the codomain is "hit" by at least one input.

## 4. Solved Examples  

### Example 1:  
**Problem**: Determine whether the function $ f: \mathbb{R} \to \mathbb{R} $ defined by $ f(x) = 2x + 3 $ is one-one, onto, or bijective.  
**Solution**:  
1. **One-one check**: Suppose $ f(a) = f(b) $. Then $ 2a + 3 = 2b + 3 \Rightarrow 2a = 2b \Rightarrow a = b $. Hence, $ f $ is one-one.  
2. **Onto check**: For any $ y \in \mathbb{R} $, solve $ y = 2x + 3 \Rightarrow x = \frac{y - 3}{2} $. Since $ x \in \mathbb{R} $, $ f $ is onto.  
3. **Conclusion**: $ f $ is **bijective**.  

### Example 2:  
**Problem**: Consider $ f: \{1, 2, 3\} \to \{a, b, c\} $ defined by $ f(1)=a $, $ f(2)=b $, $ f(3)=c $. Is $ f $ one-one or onto?  
**Solution**:  
- **One-one**: All inputs map to distinct outputs; yes.  
- **Onto**: Every element in the codomain is covered; yes.  
- **Conclusion**: $ f $ is **bijective**.  

### Example 3:  
**Problem**: Let $ f: \mathbb{Z} \to \mathbb{Z} $ be defined by $ f(n) = n^2 $. Is $ f $ one-one or onto?  
**Solution**:  
1. **One-one**: Counterexample: $ f(2) = 4 $, $ f(-2) = 4 $. Since $ 2 \neq -2 $ but $ f(2) = f(-2) $, $ f $ is **not one-one**.  
2. **Onto**: Not all integers are perfect squares (e.g., $ y = 2 $ has no preimage). Thus, $ f $ is **not onto**.  

### Example 4:  
**Problem**: Prove that the function $ f: \mathbb{N} \to \mathbb{N} $ defined by $ f(n) = 2n $ is one-one but not onto.  
**Solution**:  
1. **One-one**: Suppose $ f(a) = f(b) \Rightarrow 2a = 2b \Rightarrow a = b $.  
2. **Not onto**: For $ y = 1 $, there is no $ n \in \mathbb{N} $ such that $ 2n = 1 $.

## 5. Practice Problems  

### 🟢 Easy  
**Problem 1**: Check if $ f: \{1, 2, 3\} \to \{a, b, c\} $ with $ f(1)=a $, $ f(2)=b $, $ f(3)=c $ is one-one, onto, or bijective.  

### 🟡 Medium  
**Problem 2**: Let $ f: \mathbb{R} \to \mathbb{R} $ be defined by $ f(x) = 3x - 4 $. Prove it is bijective.  

### 🔴 Hard  
**Problem 3**: Consider $ f: \mathbb{R} \to \mathbb{R} $ given by $ f(x) = \lfloor x \rfloor $ (floor function). Determine if it is one-one, onto, or neither.  

---

### Answers:  

#### Problem 1:  
- **Answer**:  
  - **One-one**: Yes (distinct inputs map to distinct outputs).  
  - **Onto**: Yes (all codomain elements are covered).  
  - **Conclusion**: Bijective.  

#### Problem 2:  
- **Answer**:  
  1. **One-one**: Assume $ f(a) = f(b) \Rightarrow 3a - 4 = 3b - 4 \Rightarrow a = b $.  
  2. **Onto**: For any $ y \in \mathbb{R} $, solve $ y = 3x - 4 \Rightarrow x = \frac{y + 4}{3} \in \mathbb{R} $.  
  3. **Conclusion**: Bijective.  

#### Problem 3:  
- **Answer**:  
  - **Not one-one**: $ f(1.2) = 1 $, $ f(1.5) = 1 $, but $ 1.2 \neq 1.5 $.  
  - **Not onto**: $ y = 1.5 $ has no preimage since floor values are integers.  
  - **Conclusion**: Neither one-one nor onto.  

---

## 6. Summary  
- A function is **one-one** if distinct inputs yield distinct outputs.  
- A function is **onto** if every codomain element is mapped to.  
- A function is **bijective** if it is both one-one and onto.  
- Injective functions preserve uniqueness; surjective functions ensure completeness.  
- Bijective functions are invertible.

## 7. Key Formulas  

| Formula | Description |  
|--------|-------------|  
| $ f(x_1) = f(x_2) \Rightarrow x_1 = x_2 $ | Condition for one-one (injective) function |  
| For all $ y \in Y $, $ \exists x \in X $ such that $ f(x) = y $ | Condition for onto (surjective) function |  
| $ f $ is bijective ⇔ $ f $ is one-one and onto | Bijective function condition |

## 8. Student Corner  

### Common Mistakes  
- ❌ Confusing one-one with onto: Ensure you test both conditions separately.  
- ❌ Assuming all linear functions are bijective: Linear functions like $ f(x) = mx + c $ are bijective over $ \mathbb{R} $ only if $ m \neq 0 $.  

### Exam Tips  
- ✔️ Draw diagrams to visualize mappings and identify overlaps or gaps.  
- ✔️ Always verify the domain and codomain explicitly.  

### Memory Aid  
**Rhyme**: *"Injective, surjective, bijective—unique, complete, and reverse!"*
