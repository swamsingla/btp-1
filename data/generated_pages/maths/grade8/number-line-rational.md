# Rational Numbers on the Number Line

Numbers can be placed on the number line, and rational numbers are placed on it in the same way as whole numbers. A rational number is any number that can be written in the form $\frac{p}{q}$, where $p$ and $q$ are integers and $q \neq 0$. These numbers include integers and terminating or repeating decimals. Placing these numbers on the number line helps us compare their sizes and understand their order. For example, knowing where a number sits helps us see if it is closer to zero or to another number. This skill is useful when you measure lengths, compare prices, or estimate distances in everyday life.

## What is a Rational Number?
A rational number is a number that can be written as a ratio of two integers. The top number is called the numerator, and the bottom number is called the denominator. The denominator cannot be zero, because dividing by zero is not allowed in mathematics. When you divide the numerator by the denominator, you get a decimal. This decimal will either stop after a few digits, like $0.5$, or it will repeat a pattern forever, like $0.333...$. Such decimals can be written as fractions. For instance, $0.75$ is the same as $\frac{3}{4}$.

## Locating Fractions and Decimals
To locate a rational number on the number line, you first need to know the two whole numbers it falls between. For example, if you want to locate $\frac{5}{2}$, you know that $2 = \frac{4}{2}$ and $3 = \frac{6}{2}$. Since $\frac{5}{2}$ is between $4/2$ and $6/2$, it lies between $2$ and $3$. Divide the space between $2$ and $3$ into equal parts based on the denominator, which is $2$. This creates two equal parts, and the mark in the middle is $\frac{5}{2}$, which is $2.5$.

You can use the same method for decimals. To locate $0.75$, you divide the space between $0$ and $1$ into four equal parts, because $0.75 = \frac{3}{4}$. The third mark is $0.75$. This method works for any rational number. There are infinitely many rational numbers between any two numbers.

## Comparing and Ordering
Once you have placed rational numbers on the number line, ordering them is easy. The number on the far left is always the smallest. The number on the far right is always the largest. If two positive numbers are compared, the one closer to zero is smaller. If two negative numbers are compared, the one closer to zero is larger, so $-1$ is larger than $-3$. If they are on opposite sides of zero, the negative number is always smaller than the positive number.

Let us look at an example. Suppose we want to order $-1.5$, $\frac{1}{2}$, and $0.25$. We place them on the number line. First, we place $-1.5$ to the left of zero. Then, we place $0.25$ and $\frac{1}{2}$. Since $\frac{1}{2}$ is equal to $0.5$, we see that $0.25$ is closer to zero than $\frac{1}{2}$. Therefore, the order from smallest to largest is $-1.5$, $0.25$, and $\frac{1}{2}$.

## Working with Square Roots
Some numbers involve square roots, such as $\frac{1}{\sqrt{2}}$. A square root is a number that, when multiplied by itself, gives the original number. For example, $\sqrt{4} = 2$ because $2 \times 2 = 4$, so $\sqrt{4}$ is rational. However, not all square roots are rational. For example, $\sqrt{2}$ is an irrational number, meaning it cannot be written as a simple fraction and its decimal never ends or repeats.

Even though $\sqrt{2}$ is irrational, we can still locate it on the number line. We can do this by using a right-angled triangle. If you draw a square with sides of $1$ unit, the diagonal will be $\sqrt{2}$ units long. Place the corner of the square at zero on the number line, then use a compass with its centre at zero and its radius equal to the diagonal to draw an arc that meets the number line. The point where it meets the line is $\sqrt{2}$. This helps you see exactly where $\sqrt{2}$ sits between $1$ and $2$.

## Rationalising the Denominator
Sometimes, a number is written with a square root in the denominator. For example, $\frac{1}{\sqrt{2}}$. It is often easier to locate these numbers if we remove the square root from the bottom. This process is called rationalising the denominator.

To do this, you multiply both the top and the bottom of the fraction by the square root in the denominator. For $\frac{1}{\sqrt{2}}$, you multiply by $\frac{\sqrt{2}}{\sqrt{2}}$. This gives you $\frac{\sqrt{2}}{2}$. Now the denominator is a whole number. You can easily locate $\frac{\sqrt{2}}{2}$ on the number line because it is exactly halfway between $0$ and $\sqrt{2}$.

## Worked example
Let us apply the rule of rationalising the denominator to a new number. Suppose we want to locate $\frac{1}{2 + \sqrt{3}}$. The denominator contains a square root, so we need to remove it. We use the identity $(a + b)(a - b) = a^2 - b^2$, which turns the denominator into a number with no square root. We multiply the top and the bottom by $2 - \sqrt{3}$.

$$ \frac{1}{2 + \sqrt{3}} \times \frac{2 - \sqrt{3}}{2 - \sqrt{3}} = \frac{2 - \sqrt{3}}{(2)^2 - (\sqrt{3})^2} = \frac{2 - \sqrt{3}}{4 - 3} = 2 - \sqrt{3} $$

Now we have a new expression, $2 - \sqrt{3}$. We know that $\sqrt{3}$ is about $1.732$. So, $2 - 1.732$ is about $0.268$. So $\frac{1}{2 + \sqrt{3}}$ lies at about $0.268$ on the number line, between $0$ and $1$.

## Key points
* A rational number is any number that can be written as $\frac{p}{q}$, where $p$ and $q$ are integers and $q \neq 0$.
* When locating a rational number, first find the two whole numbers it falls between, then divide the space into equal parts based on the denominator.
* The number on the far left of the number line is the smallest, and the number on the far right is the largest.
* You can locate square roots like $\sqrt{2}$ on the number line by using a right-angled triangle and a compass.
* Rationalising the denominator means multiplying the top and bottom by a number that removes the square root from the bottom, making it easier to locate the number.
