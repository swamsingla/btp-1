# Linear Equations in One Variable

You may already know how to solve simple equations in one variable where the unknown is on one side of the equals sign. But what if the equation looks a little different and the unknown appears on both sides? This is a very common situation, and solving it is an important step in your maths journey. A linear equation in one variable is a statement of equality between two algebraic expressions that contain exactly one unknown quantity, usually written as a letter, and in which the unknown appears only to the first power (it is never squared or cubed).

## Why We Need to Move Terms

When an equation has the unknown on both sides, we cannot simply divide by the number in front of the variable right away. We must first get all the terms with the unknown on the same side of the equals sign. This makes the equation much easier to solve. To do this, we use the properties of equality. If the Left Hand Side and the Right Hand Side of an equation have the same value, performing the same operation on both sides does not change their equality. This means we can subtract or add terms to both sides without breaking the balance of the equation.

## The Rule of Transposition

The easiest way to move a term from one side of the equation to the other is by using the rule of transposition. When we move a term across the equals sign, we change its sign. If a term is positive on the Left Hand Side, it becomes negative on the Right Hand Side, and vice versa. This works because adding the same number to both sides keeps the equation balanced, and subtracting it does the same thing. For example, if we have the equation $7x = 4x + 21$, we want to get all the $x$ terms together. We can subtract $4x$ from both sides. This gives us $7x - 4x = 21$, which simplifies to $3x = 21$. Subtracting $4x$ from both sides has the same effect as moving $4x$ across the equals sign and changing its sign.

## Solving the Equation

Once all the unknown terms are on one side, we simply isolate the variable. If the variable has a number multiplied by it, we divide both sides by that number. If the variable has a number added to it, we subtract that number from both sides. Let us look at an example. Consider the equation $11y + (-5) = 61$. To retain only the unknown term $11y$ on one side, we need to remove the term $-5$. We can do this by adding $5$ to both sides. The equation becomes $11y = 66$. We can directly find the value of $y$ by dividing both sides by $11$, which gives $y = 6$.

## Checking Your Solution

After finding the value of the unknown, it is always a good practice to check your answer. You do this by substituting the value back into the original equation. If the Left Hand Side equals the Right Hand Side, your answer is correct. Let us check the previous example. We substitute $y = 6$ back into the original equation: $11(6) + (-5) = 66 - 5 = 61$, which is the same as the Right Hand Side. This confirms that $y = 6$ is the correct solution.

## Worked example

Let us apply the systematic method to solve the equation $5x + 12 = 3x + 20$. To collect the unknown terms on the Left Hand Side, we need to remove the term $3x$ from the Right Hand Side. We can do this by subtracting $3x$ from both sides. The equation becomes $5x - 3x + 12 = 20$, which simplifies to $2x + 12 = 20$. Next, we need to remove the term $12$. We can do this by subtracting $12$ from both sides. The equation becomes $2x = 8$. We can directly find the value of $x$ by dividing both sides by $2$, which gives $x = 4$. We can check this solution by substituting $x = 4$ back into the original equation: $5(4) + 12 = 20 + 12 = 32$ and $3(4) + 20 = 12 + 20 = 32$, so the Left Hand Side and the Right Hand Side are equal, and $x = 4$ is the correct solution.

## Key points

*   A linear equation in one variable is a statement of equality between two algebraic expressions containing exactly one unknown that appears only to the first power.
*   When an equation has variables on both sides, bring all unknown terms to one side before isolating the variable.
*   The rule of transposition allows us to move a term across the equals sign by changing its sign.
*   The solution of a linear equation is not affected when the same number is added to or subtracted from both sides, or when both sides are multiplied or divided by the same non-zero number.
*   Always check your solution by substituting the value back into the original equation to ensure the LHS equals the RHS.
