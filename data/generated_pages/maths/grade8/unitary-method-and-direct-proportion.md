# Unitary Method and Direct Proportion

The unitary method is a way to find the value of a single unit when you know the total cost or total amount. If you know the cost of 5 items, you can find the cost of 1 item by dividing the total cost by 5. This single value is called the unit value. Direct proportion is a relationship where two quantities change by the exact same factor. When one quantity goes up, the other goes up by the same amount. This is very useful when you need to compare different prices or rates.

## Finding the Value of One Unit

To use the unitary method, you must first find the value of a single item. You do this by dividing the total value by the number of items. This gives you the cost or amount of exactly one unit. Once you know the value of one unit, you can find the value of any other number of units by multiplying.

If 5 workers can move 4500 bricks in a day, we can find the number of bricks one worker moves in a day. We divide the total number of bricks by the number of workers. So, $4500 \div 5 = 900$ bricks. This means one worker moves 900 bricks in a day.

Now, if we want to know how many workers are needed to move 18000 bricks, we can divide 18000 by the value of one unit, which is 900. So, $18000 \div 900 = 20$ workers. This shows that 20 workers are needed to move 18000 bricks in a day.

## Using Ratios to Check Proportion

You can also check if two ratios are proportional by using cross-multiplication. Two ratios are proportional if their cross-products are equal. For example, if you have the ratio 2 : 1 and another ratio 4 : 2, you can check if they are proportional. You multiply the first number of the first ratio by the second number of the second ratio. Then, you multiply the second number of the first ratio by the first number of the second ratio. In this case, $2 \times 2 = 4$ and $1 \times 4 = 4$. Since the products are the same, the ratios are proportional.

This means that if you double the amount of rice, you must also double the amount of urad dal to keep the same taste. If you use 6 cups of rice, you must use 3 cups of urad dal. If you use 4 cups of rice, you must use 2 cups of urad dal.

## The Rule of Three

When you know three values, you can use the rule of three to find the fourth value. This rule works when two quantities are in direct proportion. If two ratios are proportional, then $a:b::c:d$, you can find the value of $d$ using the formula $d = \frac{bc}{a}$.

Let us look at a worked example. Suppose 5 kg of apples cost 150 rupees. We want to find the cost of 12 kg of apples. Here, the quantity of apples and the cost are in direct proportion. We set up the ratio as $5 : 12 :: 150 : x$, where $x$ is the cost of 12 kg of apples. Using the rule of three, we calculate $x = \frac{12 \times 150}{5} = \frac{1800}{5} = 360$ rupees. So, 12 kg of apples will cost 360 rupees.

## Key points

*   The unitary method involves finding the value of a single unit by dividing the total value by the number of units.
*   Direct proportion means that two quantities change by the same factor.
*   You can use the rule of three to find a fourth quantity when three quantities are in direct proportion, using the formula $d = \frac{bc}{a}$.
*   You can check if two ratios are proportional by using the cross-multiplication method, where $a \times d = b \times c$.
*   When quantities are in direct proportion, the ratio of the first to the second is the same as the ratio of the third to the fourth, so $\frac{a}{c} = \frac{b}{d}$.
