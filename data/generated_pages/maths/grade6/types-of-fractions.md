# Types of Fractions

Fractions are a way to represent parts of a whole. Understanding the different types of fractions helps you work with numbers that are not whole. It matters because you will use these types every time you measure ingredients, divide a pizza, or calculate distances.

## Proper Fractions

A proper fraction is a fraction where the numerator is smaller than the denominator. This means the value of the fraction is always less than one unit. When you look at a number line, these fractions will fall between zero and one. For example, if you take a piece of chikki and eat $\frac { 1 } { 2 }$ of it, you have eaten a proper fraction because the numerator $1$ is smaller than the denominator $2$.

## Improper Fractions

An improper fraction is a fraction where the numerator is larger than the denominator. This means the value of the fraction is greater than one unit. For instance, $\frac {3}{2}, \frac {5}{2}$ and $\frac { 7 } { 2 }$ are all greater than 1 unit. You can break these down to see how many whole units they contain. For example, $\frac {5}{2}$ equals $2 + \frac {1}{2}$ because it contains two whole units and one extra half.

## Mixed Fractions

A mixed fraction combines a whole number with a proper fraction. It is a useful way to write down an improper fraction. You can find out how many whole units are in an improper fraction by dividing the numerator by the denominator and keeping the remainder as the new numerator. For example, $\frac { 3 } { 2 } = 1 + \frac {1}{2} = 1\frac {1}{2}$. This means the improper fraction $\frac { 3 } { 2 }$ can be written as the mixed fraction one and one half.

## Unit Fractions

A unit fraction is a special type of proper fraction where the numerator is exactly $1$. It represents exactly one part of a whole that has been divided into equal pieces. For example, $\frac {1}{2}, \frac {1}{3}$ and $\frac {1}{4}$ are all unit fractions. When you add unit fractions that have the same denominator, you are simply counting how many of those equal pieces you have.

## Worked example

Let us look at a practical situation. Meena ate $\frac { 1 } { 2 }$ of a piece of chikki and her younger brother ate $\frac { 1 } { 4 }$ of the same piece. To find out how much they ate together, we can add these fractions. First, we need to find a common denominator. The denominators are $2$ and $4$. The least common multiple of $2$ and $4$ is $4$. We convert $\frac { 1 } { 2 }$ into an equivalent fraction with a denominator of $4$ by multiplying the numerator and the denominator by $2$. This gives us $\frac { 2 } { 4 }$. Now we can add the fractions. We have $\frac { 2 } { 4 } + \frac { 1 } { 4 } = \frac { 3 } { 4 }$. So, Meena and her brother ate $\frac { 3 } { 4 }$ of the total chikki together.

## Key points

- Proper fractions have a numerator smaller than the denominator and a value less than one unit.
- Improper fractions have a numerator larger than the denominator and a value greater than one unit.
- Mixed fractions combine a whole number with a proper fraction.
- Unit fractions have a numerator of exactly $1$.
- To add fractions with different denominators, first find equivalent fractions with a common denominator and then add the numerators.
