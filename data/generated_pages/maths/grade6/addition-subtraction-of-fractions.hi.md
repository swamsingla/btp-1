# भिन्नों का जोड़ और घटाव

भिन्न (Fractions) हमारे दैनिक जीवन में हर जगह मौजूद हैं। आप किसी दोस्त के साथ बांटने के लिए चॉकलेट बार को बराबर हिस्सों में काट सकते हैं, या किसी रेसिपी के लिए $\frac { 1 } { 2 }$ कप मैदा जैसी सामग्री माप सकते हैं। भिन्नों को जोड़ने और घटाने से आपको इन बराबर हिस्सों को मिलाने या हटाने में मदद मिलती है। जब टुकड़े एक ही आकार के होते हैं, तो गणित आसान होता है। जब टुकड़े अलग-अलग आकार के होते हैं, तो जोड़ने या घटाने से पहले उन्हें एक समान बनाने के लिए आपको एक विशेष तरकीब की आवश्यकता होती है।

## समान हर वाले भिन्नों को जोड़ना

जब भिन्नों का हर समान होता है, तो भिन्नात्मक इकाई समान होती है। इसका मतलब है कि सभी टुकड़े एक ही आकार के हैं। आप बस अंशों (numerators) को जोड़ सकते हैं और हर को समान रख सकते हैं। 

उदाहरण के लिए, $\frac { 2 } { 5 }$ और $\frac { 1 } { 5 }$ पर विचार करें। दोनों भिन्न भिन्नात्मक इकाई $\frac { 1 } { 5 }$ का उपयोग करते हैं, इसलिए प्रत्येक पट्टी 5 बराबर भागों में विभाजित है। भिन्न $\frac { 2 } { 5 }$ इन 2 भागों को दर्शाता है, और $\frac { 1 } { 5 }$ 1 भाग को दर्शाता है। जब आप उन्हें जोड़ते हैं, तो आप केवल छायांकित (shaded) भागों की कुल संख्या गिन रहे होते हैं। कुल 3 छायांकित भाग हैं, इसलिए योग $\frac { 3 } { 5 }$ है।

एक और उदाहरण $\frac { 4 } { 7 }$ और $\frac { 6 } { 7 }$ को जोड़ना है। चूँकि हर 7 है, प्रत्येक भिन्न $\frac { 1 } { 7 }$ आकार के भागों को दर्शाता है। आप अंशों को जोड़ते हैं: 4 जमा 6 बराबर 10 होता है। इससे आपको $\frac { 1 0 } { 7 }$ मिलता है। आपको हर को बदलने की आवश्यकता नहीं है क्योंकि टुकड़े पहले से ही एक ही आकार के थे।

## अलग-अलग हर वाले भिन्नों को जोड़ना

जब भिन्नों के हर अलग-अलग होते हैं, तो भिन्नात्मक इकाइयाँ अलग-अलग होती हैं। आप सीधे अंशों को नहीं जोड़ सकते क्योंकि टुकड़े अलग-अलग आकार के होते हैं। उन्हें जोड़ने के लिए, आपको पहले भिन्नों को समान हर वाले समतुल्य भिन्नों (equivalent fractions) में बदलना होगा। इससे आपको एक उभयनिष्ठ भिन्नात्मक इकाई मिलती है।

आइए $\frac { 1 } { 4 }$ और $\frac { 1 } { 3 }$ का योग ज्ञात करें। हर 4 और 3 हैं। हमें एक समान हर की आवश्यकता है। हरों का गुणनफल, 3 गुना 4, हमें 12 देता है। हम 12 के हर के साथ समतुल्य भिन्न लिख सकते हैं। $\frac { 1 } { 4 } ,$ के लिए, हम $\frac { 3 } { 1 2 } $ प्राप्त करने के लिए अंश और हर को 3 से गुणा करते हैं। $\frac { 1 } { 3 } ,$ के लिए, हम $\frac { 4 } { 1 2 } $ प्राप्त करने के लिए अंश और हर को 4 से गुणा करते हैं। अब दोनों भिन्नों की भिन्नात्मक इकाई समान है, $\frac { 1 } { 1 2 }$। हम अंशों को जोड़ सकते हैं: 3 जमा 4 बराबर 7 होता है। योग $\frac { 7 } { 1 2 } $ है।

## भिन्नों को जोड़ने के लिए ब्रह्मगुप्त की विधि

भिन्नों को जोड़ने की एक स्पष्ट विधि का पहली बार सामान्य रूप से वर्णन 628 ईस्वी में ब्रह्मगुप्त द्वारा किया गया था। यह विधि केवल दो ही नहीं, बल्कि किसी भी संख्या में भिन्नों को जोड़ने के लिए काम करती है। इसमें तीन सरल चरण शामिल हैं।

पहला, समतुल्य भिन्न ज्ञात करें ताकि सभी भिन्नों के लिए भिन्नात्मक इकाई समान हो। आप हरों का एक उभयनिष्ठ गुणज (common multiple) ज्ञात करके ऐसा करते हैं। यह हरों का गुणनफल हो सकता है, या सबसे छोटा उभयनिष्ठ गुणज, जिसे LCM के रूप में जाना जाता है।

दूसरा, समान भिन्नात्मक इकाइयों वाले इन समतुल्य भिन्नों को जोड़ें। आप अंशों को जोड़कर और समान हर रखकर ऐसा करते हैं।

तीसरा, यदि आवश्यक हो तो परिणाम को लघुतम रूप (lowest terms) में व्यक्त करें।

आइए इस विधि को $\frac { 2 } { 3 }$ और $\frac { 1 } { 5 }$ का योग ज्ञात करने के लिए लागू करें। हर 3 और 5 हैं। 3 और 5 का LCM 15 है। हम भिन्नों को बदलते हैं: $\frac { 2 } { 3 } = \frac { 2 \times 5 } { 3 \times 5 } = \frac { 1 0 } { 1 5 } ,$ और $\frac { 1 } { 5 } = \frac { 1 \times 3 } { 5 \times 3 } = \frac { 3 } { 1 5 } .$ अब हम अंशों को जोड़ते हैं: $\frac { 1 0 } { 1 5 } + \frac { 3 } { 1 5 } = \frac { 1 3 } { 1 5 } .$

## भिन्नों को घटाना

भिन्नों को घटाना भी जोड़ के समान तर्क का पालन करता है। यदि भिन्नों का हर समान है, तो आप अंशों को घटाते हैं और हर को समान रखते हैं। यदि भिन्नों के हर अलग-अलग हैं, तो आप पहले जोड़ की तरह ही एक समान हर वाले समतुल्य भिन्न ज्ञात करते हैं। फिर आप अंशों को घटाते हैं।

उदाहरण के लिए, $\frac { 1 } { 3 } $ में से $\frac { 1 } { 6 } $ को घटाने के लिए, आप पहले ध्यान दें कि 6 और 3 का सबसे छोटा उभयनिष्ठ गुणज 6 है। आप $\frac { 1 } { 3 } $ को $\frac { 2 } { 6 } $ के रूप में फिर से लिखते हैं। अब आप अंशों को घटा सकते हैं: $\frac { 2 } { 6 } - \frac { 1 } { 6 } = \frac { 1 } { 6 } .$

## हल किया गया उदाहरण

कल्पना करें कि आप एक फ्रूट सलाद बना रहे हैं। आप $\frac { 2 } { 9 }$ कप सेब और $\frac { 1 } { 6 }$ कप केले जोड़ते हैं। फलों की कुल मात्रा ज्ञात करने के लिए, आपको इन भिन्नों को जोड़ने की आवश्यकता है। हर 9 और 6 हैं। 9 और 6 का LCM 18 है। आप भिन्नों को बदलते हैं: $\frac { 2 } { 9 } = \frac { 2 \times 2 } { 9 \times 2 } = \frac { 4 } { 1 8 } ,$ और $\frac { 1 } { 6 } = \frac { 1 \times 3 } { 6 \times 3 } = \frac { 3 } { 1 8 } .$ अब आप अंशों को जोड़ते हैं: $\frac { 4 } { 1 8 } + \frac { 3 } { 1 8 } = \frac { 7 } { 1 8 } .$ आपने अपने सलाद में $\frac { 7 } { 1 8 }$ कप फल जोड़ दिए हैं।

## मुख्य बिंदु

*   समान हर वाले भिन्नों को जोड़ते या घटाते समय, आप अंशों को जोड़ते या घटाते हैं और हर को समान रखते हैं।
*   अलग-अलग हर वाले भिन्नों को जोड़ते या घटाते समय, आपको पहले एक समान हर वाले समतुल्य भिन्न ज्ञात करने होंगे।
*   समान हर को हरों का गुणनफल या सबसे छोटा उभयनिष्ठ गुणज लेकर ज्ञात किया जा सकता है।
*   भिन्नों को जोड़ने की ब्रह्मगुप्त की विधि में तीन चरण शामिल हैं: एक समान हर वाले समतुल्य भिन्न ज्ञात करें, अंशों को जोड़ें, और यदि आवश्यक हो तो परिणाम को लघुतम रूप में व्यक्त करें।
*   आप पहले से ही समान हर वाले समतुल्य भिन्न ज्ञात करके भिन्नों की तुलना करना जानते होंगे; यहाँ भी उसी कौशल का उपयोग किया गया है।
