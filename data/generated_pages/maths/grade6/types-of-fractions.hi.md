# भिन्नों के प्रकार

भिन्न (fractions) किसी पूर्ण वस्तु के हिस्सों को दर्शाने का एक तरीका है। भिन्नों के विभिन्न प्रकारों को समझने से आपको उन संख्याओं के साथ काम करने में मदद मिलती है जो पूर्ण नहीं होती हैं। यह महत्वपूर्ण है क्योंकि जब भी आप सामग्री मापते हैं, पिज़्ज़ा बाँटते हैं, या दूरियों की गणना करते हैं, तो आप हर बार इन प्रकारों का उपयोग करेंगे।

## उचित भिन्न (Proper Fractions)

उचित भिन्न (proper fraction) एक ऐसा भिन्न है जहाँ अंश (numerator), हर (denominator) से छोटा होता है। इसका मतलब है कि भिन्न का मान हमेशा एक इकाई (unit) से कम होता है। जब आप संख्या रेखा को देखते हैं, तो ये भिन्न शून्य और एक के बीच आते हैं। उदाहरण के लिए, यदि आप चिक्की का एक टुकड़ा लेते हैं और उसका $\frac { 1 } { 2 }$ हिस्सा खाते हैं, तो आपने एक उचित भिन्न खाया है क्योंकि अंश $1$, हर $2$ से छोटा है।

## विषम भिन्न (Improper Fractions)

विषम भिन्न (improper fraction) एक ऐसा भिन्न है जहाँ अंश (numerator), हर (denominator) से बड़ा होता है। इसका मतलब है कि भिन्न का मान एक इकाई (unit) से अधिक होता है। उदाहरण के लिए, $\frac {3}{2}, \frac {5}{2}$ और $\frac { 7 } { 2 }$ सभी 1 इकाई से बड़े हैं। आप इन्हें तोड़कर देख सकते हैं कि इनमें कितनी पूर्ण इकाइयाँ हैं। उदाहरण के लिए, $\frac {5}{2}$, $2 + \frac {1}{2}$ के बराबर है क्योंकि इसमें दो पूर्ण इकाइयाँ और एक अतिरिक्त आधा हिस्सा है।

## मिश्रित भिन्न (Mixed Fractions)

मिश्रित भिन्न (mixed fraction) में एक पूर्ण संख्या और एक उचित भिन्न को मिलाया जाता है। यह एक विषम भिन्न को लिखने का एक उपयोगी तरीका है। आप अंश को हर से विभाजित करके और शेषफल (remainder) को नए अंश के रूप में रखकर यह पता लगा सकते हैं कि एक विषम भिन्न में कितनी पूर्ण इकाइयाँ हैं। उदाहरण के लिए, $\frac { 3 } { 2 } = 1 + \frac {1}{2} = 1\frac {1}{2}$। इसका मतलब है कि विषम भिन्न $\frac { 3 } { 2 }$ को मिश्रित भिन्न डेढ़ के रूप में लिखा जा सकता है।

## इकाई भिन्न (Unit Fractions)

इकाई भिन्न (unit fraction) उचित भिन्न का एक विशेष प्रकार है जहाँ अंश ठीक $1$ होता है। यह एक पूर्ण वस्तु के ठीक एक हिस्से को दर्शाता है जिसे बराबर टुकड़ों में विभाजित किया गया है। उदाहरण के लिए, $\frac {1}{2}, \frac {1}{3}$ और $\frac {1}{4}$ सभी इकाई भिन्न हैं। जब आप समान हर वाले इकाई भिन्नों को एक साथ जोड़ते हैं, तो आप बस यह गिन रहे होते हैं कि आपके पास उन बराबर टुकड़ों में से कितने हैं।

## हल किया गया उदाहरण

आइए एक व्यावहारिक स्थिति को देखें। मीना ने चिक्की के एक टुकड़े का $\frac { 1 } { 2 }$ हिस्सा खाया और उसके छोटे भाई ने उसी टुकड़े का $\frac { 1 } { 4 }$ हिस्सा खाया। यह पता लगाने के लिए कि उन्होंने एक साथ कितना खाया, हम इन भिन्नों को जोड़ सकते हैं। सबसे पहले, हमें एक उभयनिष्ठ हर (common denominator) खोजने की आवश्यकता है। हर $2$ और $4$ हैं। $2$ और $4$ का लघुत्तम समापवर्त्य (least common multiple) $4$ है। हम अंश और हर को $2$ से गुणा करके $\frac { 1 } { 2 }$ को $4$ के हर वाले समतुल्य भिन्न (equivalent fraction) में बदलते हैं। इससे हमें $\frac { 2 } { 4 }$ मिलता है। अब हम भिन्नों को जोड़ सकते हैं। हमारे पास $\frac { 2 } { 4 } + \frac { 1 } { 4 } = \frac { 3 } { 4 }$ है। इसलिए, मीना और उसके भाई ने कुल चिक्की का $\frac { 3 } { 4 }$ हिस्सा एक साथ खाया।

## मुख्य बिंदु

- उचित भिन्नों में अंश हर से छोटा होता है और मान एक इकाई से कम होता है।
- विषम भिन्नों में अंश हर से बड़ा होता है और मान एक इकाई से अधिक होता है।
- मिश्रित भिन्नों में एक पूर्ण संख्या और एक उचित भिन्न को मिलाया जाता है।
- इकाई भिन्नों में अंश ठीक $1$ होता है।
- अलग-अलग हर वाले भिन्नों को जोड़ने के लिए, पहले एक उभयनिष्ठ हर वाले समतुल्य भिन्न खोजें और फिर अंशों को जोड़ें।
