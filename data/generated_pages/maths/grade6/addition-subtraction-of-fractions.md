# Addition and Subtraction of Fractions

Fractions are everywhere in our daily lives. You might cut a chocolate bar into equal parts to share with a friend, or measure ingredients like $\frac { 1 } { 2 }$ cup of flour for a recipe. Adding and subtracting fractions helps you combine or remove these equal parts. When the pieces are the same size, the math is easy. When the pieces are different sizes, you need a special trick to make them match before you can add or subtract.

## Adding Fractions with the Same Denominator

When fractions have the same denominator, the fractional unit is the same. This means the pieces are all the same size. You can simply add the numerators and keep the denominator the same. 

For example, consider $\frac { 2 } { 5 }$ and $\frac { 1 } { 5 }$ . Both fractions use the fractional unit $\frac { 1 } { 5 }$ , so each strip is divided into 5 equal parts. The fraction $\frac { 2 } { 5 }$ represents 2 of these parts, and $\frac { 1 } { 5 }$ represents 1 part. When you add them, you are just counting the total number of shaded parts. There are 3 shaded parts in total, so the sum is $\frac { 3 } { 5 }$ .

Another example is adding $\frac { 4 } { 7 }$ and $\frac { 6 } { 7 }$ . Since the denominator is 7, each fraction represents parts of size $\frac { 1 } { 7 }$ . You add the numerators: 4 plus 6 equals 10. This gives you $\frac { 1 0 } { 7 }$ . You do not need to change the denominator because the pieces were already the same size.

## Adding Fractions with Different Denominators

When fractions have different denominators, the fractional units are different. You cannot add the numerators directly because the pieces are different sizes. To add them, you must first convert the fractions into equivalent fractions with the same denominator. This gives you a common fractional unit.

Let us find the sum of $\frac { 1 } { 4 }$ and $\frac { 1 } { 3 }$ . The denominators are 4 and 3. We need a common denominator. The product of the denominators, 3 times 4, gives us 12. We can write equivalent fractions with a denominator of 12. For $\frac { 1 } { 4 } ,$ we multiply the numerator and denominator by 3 to get $\frac { 3 } { 1 2 } .$ For $\frac { 1 } { 3 } ,$ we multiply the numerator and denominator by 4 to get $\frac { 4 } { 1 2 } .$ Now both fractions have the same fractional unit, $\frac { 1 } { 1 2 }$ . We can add the numerators: 3 plus 4 equals 7. The sum is $\frac { 7 } { 1 2 } .$

## Brahmagupta’s Method for Adding Fractions

A clear method for adding fractions was first explicitly described in general by Brahmagupta in the year 628 CE. This method works for adding any number of fractions, not just two. It involves three simple steps.

First, find equivalent fractions so that the fractional unit is common for all fractions. You do this by finding a common multiple of the denominators. This can be the product of the denominators, or the smallest common multiple, which is known as the LCM.

Second, add these equivalent fractions with the same fractional units. You do this by adding the numerators and keeping the same denominator.

Third, express the result in lowest terms if needed.

Let us apply this method to find the sum of $\frac { 2 } { 3 }$ and $\frac { 1 } { 5 }$ . The denominators are 3 and 5. The LCM of 3 and 5 is 15. We convert the fractions: $\frac { 2 } { 3 } = \frac { 2 \times 5 } { 3 \times 5 } = \frac { 1 0 } { 1 5 } ,$ and $\frac { 1 } { 5 } = \frac { 1 \times 3 } { 5 \times 3 } = \frac { 3 } { 1 5 } .$ Now we add the numerators: $\frac { 1 0 } { 1 5 } + \frac { 3 } { 1 5 } = \frac { 1 3 } { 1 5 } .$

## Subtracting Fractions

Subtraction of fractions follows the same logic as addition. If the fractions have the same denominator, you subtract the numerators and keep the denominator the same. If the fractions have different denominators, you first find equivalent fractions with a common denominator, just like in addition. Then you subtract the numerators.

For example, to subtract $\frac { 1 } { 6 }$ from $\frac { 1 } { 3 } ,$ you first note that the smallest common multiple of 6 and 3 is 6. You rewrite $\frac { 1 } { 3 }$ as $\frac { 2 } { 6 } .$ Now you can subtract the numerators: $\frac { 2 } { 6 } - \frac { 1 } { 6 } = \frac { 1 } { 6 } .$

## Worked example

Imagine you are making a fruit salad. You add $\frac { 2 } { 9 }$ of a cup of apples and $\frac { 1 } { 6 }$ of a cup of bananas. To find the total amount of fruit, you need to add these fractions. The denominators are 9 and 6. The LCM of 9 and 6 is 18. You convert the fractions: $\frac { 2 } { 9 } = \frac { 2 \times 2 } { 9 \times 2 } = \frac { 4 } { 1 8 } ,$ and $\frac { 1 } { 6 } = \frac { 1 \times 3 } { 6 \times 3 } = \frac { 3 } { 1 8 } .$ Now you add the numerators: $\frac { 4 } { 1 8 } + \frac { 3 } { 1 8 } = \frac { 7 } { 1 8 } .$ You have added $\frac { 7 } { 1 8 }$ of a cup of fruit to your salad.

## Key points

*   When adding or subtracting fractions with the same denominator, you add or subtract the numerators and keep the denominator the same.
*   When adding or subtracting fractions with different denominators, you must first find equivalent fractions with a common denominator.
*   The common denominator can be found by taking the product of the denominators or the smallest common multiple.
*   Brahmagupta’s method for adding fractions involves three steps: find equivalent fractions with a common denominator, add the numerators, and express the result in lowest terms if needed.
*   You may already know how to compare fractions by finding equivalent fractions with the same denominator; the same skill is used here.
