# ଭଗ୍ନାଂଶର ଯୋଗ ଏବଂ ବିୟୋଗ

ଆମର ଦୈନନ୍ଦିନ ଜୀବନରେ ଭଗ୍ନାଂଶ ସବୁଆଡେ ଦେଖିବାକୁ ମିଳେ। ଆପଣ ନିଜ ସାଙ୍ଗ ସହିତ ବାଣ୍ଟିବା ପାଇଁ ଏକ ଚକୋଲେଟ୍ ବାର୍‌କୁ ସମାନ ଭାଗରେ କାଟିପାରନ୍ତି, କିମ୍ବା କୌଣସି ରେସିପି ପାଇଁ $\frac { 1 } { 2 }$ କପ୍ ଅଟା ପରି ଉପାଦାନ ମାପିପାରନ୍ତି। ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ଯୋଗ ଏବଂ ବିୟୋଗ କରିବା ଦ୍ୱାରା ଆପଣ ଏହି ସମାନ ଭାଗଗୁଡ଼ିକୁ ଏକାଠି କରିପାରିବେ କିମ୍ବା ବାହାର କରିପାରିବେ। ଯେତେବେଳେ ଖଣ୍ଡଗୁଡ଼ିକ ସମାନ ଆକାରର ହୋଇଥାଏ, ଗଣିତ ସହଜ ହୋଇଥାଏ। ଯେତେବେଳେ ଖଣ୍ଡଗୁଡ଼ିକ ଅଲଗା ଅଲଗା ଆକାରର ହୋଇଥାଏ, ସେଗୁଡ଼ିକୁ ଯୋଗ କିମ୍ବା ବିୟୋଗ କରିବା ପୂର୍ବରୁ ସମାନ କରିବା ପାଇଁ ଆପଣଙ୍କୁ ଏକ ସ୍ୱତନ୍ତ୍ର କୌଶଳ ଦରକାର।

## ସମାନ ହର (Denominator) ଥିବା ଭଗ୍ନାଂଶର ଯୋଗ

ଯେତେବେଳେ ଭଗ୍ନାଂଶଗୁଡ଼ିକର ସମାନ ହର (denominator) ଥାଏ, ସେତେବେଳେ ଭଗ୍ନାଂଶର ଏକକ (fractional unit) ସମାନ ଥାଏ। ଏହାର ଅର୍ଥ ହେଉଛି ସମସ୍ତ ଖଣ୍ଡ ସମାନ ଆକାରର। ଆପଣ କେବଳ ଲବ (numerators) ଗୁଡ଼ିକୁ ଯୋଗ କରିପାରିବେ ଏବଂ ହରକୁ ସମାନ ରଖିପାରିବେ। 

ଉଦାହରଣ ସ୍ୱରୂପ, $\frac { 2 } { 5 }$ ଏବଂ $\frac { 1 } { 5 }$ କୁ ବିଚାର କରନ୍ତୁ। ଉଭୟ ଭଗ୍ନାଂଶ $\frac { 1 } { 5 }$ ଭଗ୍ନାଂଶ ଏକକ ବ୍ୟବହାର କରନ୍ତି, ତେଣୁ ପ୍ରତ୍ୟେକ ଷ୍ଟ୍ରିପ୍ 5 ଟି ସମାନ ଭାଗରେ ବିଭକ୍ତ। ଭଗ୍ନାଂଶ $\frac { 2 } { 5 }$ ଏହି 2 ଟି ଭାଗକୁ ଦର୍ଶାଏ, ଏବଂ $\frac { 1 } { 5 }$ 1 ଟି ଭାଗକୁ ଦର୍ଶାଏ। ଯେତେବେଳେ ଆପଣ ସେଗୁଡ଼ିକୁ ଯୋଗ କରନ୍ତି, ଆପଣ କେବଳ ଛାୟାଯୁକ୍ତ (shaded) ଭାଗଗୁଡ଼ିକର ସମୁଦାୟ ସଂଖ୍ୟା ଗଣନା କରୁଛନ୍ତି। ସମୁଦାୟ 3 ଟି ଛାୟାଯୁକ୍ତ ଭାଗ ଅଛି, ତେଣୁ ଯୋଗଫଳ ହେଉଛି $\frac { 3 } { 5 }$ ।

ଅନ୍ୟ ଏକ ଉଦାହରଣ ହେଉଛି $\frac { 4 } { 7 }$ ଏବଂ $\frac { 6 } { 7 }$ କୁ ଯୋଗ କରିବା। ଯେହେତୁ ହର 7 ଅଟେ, ପ୍ରତ୍ୟେକ ଭଗ୍ନାଂଶ $\frac { 1 } { 7 }$ ଆକାରର ଭାଗକୁ ଦର୍ଶାଏ। ଆପଣ ଲବଗୁଡ଼ିକୁ ଯୋଗ କରନ୍ତି: 4 ଯୁକ୍ତ 6 ସମାନ 10। ଏହା ଆପଣଙ୍କୁ $\frac { 1 0 } { 7 }$ ଦେଇଥାଏ। ଆପଣଙ୍କୁ ହର ପରିବର୍ତ୍ତନ କରିବାର ଆବଶ୍ୟକତା ନାହିଁ କାରଣ ଖଣ୍ଡଗୁଡ଼ିକ ପୂର୍ବରୁ ସମାନ ଆକାରର ଥିଲା।

## ଭିନ୍ନ ହର (Denominators) ଥିବା ଭଗ୍ନାଂଶର ଯୋଗ

ଯେତେବେଳେ ଭଗ୍ନାଂଶଗୁଡ଼ିକର ଭିନ୍ନ ହର (denominators) ଥାଏ, ସେତେବେଳେ ଭଗ୍ନାଂଶ ଏକକଗୁଡ଼ିକ ଭିନ୍ନ ହୋଇଥାଏ। ଆପଣ ସିଧାସଳଖ ଲବଗୁଡ଼ିକୁ ଯୋଗ କରିପାରିବେ ନାହିଁ କାରଣ ଖଣ୍ଡଗୁଡ଼ିକ ଅଲଗା ଆକାରର। ସେଗୁଡ଼ିକୁ ଯୋଗ କରିବା ପାଇଁ, ଆପଣଙ୍କୁ ପ୍ରଥମେ ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ସମାନ ହର ଥିବା ସମାନ ଭଗ୍ନାଂଶ (equivalent fractions) ରେ ପରିବର୍ତ୍ତନ କରିବାକୁ ପଡିବ। ଏହା ଆପଣଙ୍କୁ ଏକ ସାଧାରଣ ଭଗ୍ନାଂଶ ଏକକ ଦେଇଥାଏ।

ଆସନ୍ତୁ $\frac { 1 } { 4 }$ ଏବଂ $\frac { 1 } { 3 }$ ର ଯୋଗଫଳ ବାହାର କରିବା। ହରଗୁଡ଼ିକ ହେଉଛି 4 ଏବଂ 3। ଆମକୁ ଏକ ସାଧାରଣ ହର ଦରକାର। ହରଗୁଡ଼ିକର ଗୁଣଫଳ, 3 ଗୁଣନ 4, ଆମକୁ 12 ଦେଇଥାଏ। ଆମେ 12 ର ହର ସହିତ ସମାନ ଭଗ୍ନାଂଶ ଲେଖିପାରିବା। $\frac { 1 } { 4 } ,$ ପାଇଁ, ଆମେ ଲବ ଏବଂ ହରକୁ 3 ଦ୍ୱାରା ଗୁଣନ କରି $\frac { 3 } { 1 2 } $ ପାଉ। $\frac { 1 } { 3 } ,$ ପାଇଁ, ଆମେ ଲବ ଏବଂ ହରକୁ 4 ଦ୍ୱାରା ଗୁଣନ କରି $\frac { 4 } { 1 2 } $ ପାଉ। ବର୍ତ୍ତମାନ ଉଭୟ ଭଗ୍ନାଂଶର ସମାନ ଭଗ୍ନାଂଶ ଏକକ ଅଛି, $\frac { 1 } { 1 2 }$ । ଆମେ ଲବଗୁଡ଼ିକୁ ଯୋଗ କରିପାରିବା: 3 ଯୁକ୍ତ 4 ସମାନ 7। ଯୋଗଫଳ ହେଉଛି $\frac { 7 } { 1 2 } $।

## ଭଗ୍ନାଂଶ ଯୋଗ କରିବା ପାଇଁ ବ୍ରହ୍ମଗୁପ୍ତଙ୍କ ପଦ୍ଧତି

ଭଗ୍ନାଂଶ ଯୋଗ କରିବାର ଏକ ସ୍ପଷ୍ଟ ପଦ୍ଧତି ପ୍ରଥମେ 628 ଖ୍ରୀଷ୍ଟାବ୍ଦରେ ବ୍ରହ୍ମଗୁପ୍ତଙ୍କ ଦ୍ୱାରା ସାଧାରଣ ଭାବରେ ବର୍ଣ୍ଣନା କରାଯାଇଥିଲା। ଏହି ପଦ୍ଧତି କେବଳ ଦୁଇଟି ନୁହେଁ, ଯେକୌଣସି ସଂଖ୍ୟକ ଭଗ୍ନାଂଶ ଯୋଗ କରିବା ପାଇଁ କାମ କରେ। ଏଥିରେ ତିନୋଟି ସରଳ ପଦକ୍ଷେପ ଅନ୍ତର୍ଭୁକ୍ତ।

ପ୍ରଥମେ, ସମାନ ଭଗ୍ନାଂଶ ଖୋଜନ୍ତୁ ଯାହା ଦ୍ୱାରା ସମସ୍ତ ଭଗ୍ନାଂଶ ପାଇଁ ଭଗ୍ନାଂଶ ଏକକ ସାଧାରଣ ହେବ। ଆପଣ ହରଗୁଡ଼ିକର ଏକ ସାଧାରଣ ଗୁଣିତକ (multiple) ଖୋଜି ଏହା କରିପାରିବେ। ଏହା ହରଗୁଡ଼ିକର ଗୁଣଫଳ ହୋଇପାରେ, କିମ୍ବା ସର୍ବନିମ୍ନ ସାଧାରଣ ଗୁଣିତକ (least common multiple), ଯାହା LCM ଭାବରେ ଜଣାଶୁଣା।

ଦ୍ୱିତୀୟରେ, ସମାନ ଭଗ୍ନାଂଶ ଏକକ ସହିତ ଏହି ସମାନ ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ଯୋଗ କରନ୍ତୁ। ଆପଣ ଲବଗୁଡ଼ିକୁ ଯୋଗ କରି ଏବଂ ସମାନ ହର ରଖି ଏହା କରିପାରିବେ।

ତୃତୀୟରେ, ଆବଶ୍ୟକ ହେଲେ ଫଳାଫଳକୁ ସର୍ବନିମ୍ନ ରୂପରେ ପ୍ରକାଶ କରନ୍ତୁ।

ଆସନ୍ତୁ $\frac { 2 } { 3 }$ ଏବଂ $\frac { 1 } { 5 }$ ର ଯୋଗଫଳ ବାହାର କରିବା ପାଇଁ ଏହି ପଦ୍ଧତି ପ୍ରୟୋଗ କରିବା। ହରଗୁଡ଼ିକ ହେଉଛି 3 ଏବଂ 5। 3 ଏବଂ 5 ର LCM ହେଉଛି 15। ଆମେ ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ପରିବର୍ତ୍ତନ କରୁ: $\frac { 2 } { 3 } = \frac { 2 \times 5 } { 3 \times 5 } = \frac { 1 0 } { 1 5 } ,$ ଏବଂ $\frac { 1 } { 5 } = \frac { 1 \times 3 } { 5 \times 3 } = \frac { 3 } { 1 5 } $। ବର୍ତ୍ତମାନ ଆମେ ଲବଗୁଡ଼ିକୁ ଯୋଗ କରୁ: $\frac { 1 0 } { 1 5 } + \frac { 3 } { 1 5 } = \frac { 1 3 } { 1 5 } $।

## ଭଗ୍ନାଂଶର ବିୟୋଗ

ଭଗ୍ନାଂଶର ବିୟୋଗ ଯୋଗ ପରି ସମାନ ତର୍କ ଅନୁସରଣ କରେ। ଯଦି ଭଗ୍ନାଂଶଗୁଡ଼ିକର ସମାନ ହର ଥାଏ, ତେବେ ଆପଣ ଲବଗୁଡ଼ିକୁ ବିୟୋଗ କରନ୍ତି ଏବଂ ହରକୁ ସମାନ ରଖନ୍ତି। ଯଦି ଭଗ୍ନାଂଶଗୁଡ଼ିକର ଭିନ୍ନ ହର ଥାଏ, ତେବେ ଆପଣ ପ୍ରଥମେ ଯୋଗ ପରି ଏକ ସାଧାରଣ ହର ସହିତ ସମାନ ଭଗ୍ନାଂଶ ଖୋଜନ୍ତି। ତାପରେ ଆପଣ ଲବଗୁଡ଼ିକୁ ବିୟୋଗ କରନ୍ତି।

ଉଦାହରଣ ସ୍ୱରୂପ, $\frac { 1 } { 3 } $ ରୁ $\frac { 1 } { 6 } $ କୁ ବିୟୋଗ କରିବା ପାଇଁ, ଆପଣ ପ୍ରଥମେ ଲକ୍ଷ୍ୟ କରନ୍ତୁ ଯେ 6 ଏବଂ 3 ର ସର୍ବନିମ୍ନ ସାଧାରଣ ଗୁଣିତକ ହେଉଛି 6। ଆପଣ $\frac { 1 } { 3 } $ କୁ $\frac { 2 } { 6 } $ ଭାବରେ ପୁନର୍ବାର ଲେଖନ୍ତି। ବର୍ତ୍ତମାନ ଆପଣ ଲବଗୁଡ଼ିକୁ ବିୟୋଗ କରିପାରିବେ: $\frac { 2 } { 6 } - \frac { 1 } { 6 } = \frac { 1 } { 6 } $।

## ସମାଧାନ କରାଯାଇଥିବା ଉଦାହରଣ

କଳ୍ପନା କରନ୍ତୁ ଯେ ଆପଣ ଏକ ଫ୍ରୁଟ୍ ସାଲାଡ୍ ତିଆରି କରୁଛନ୍ତି। ଆପଣ $\frac { 2 } { 9 }$ କପ୍ ସେଓ ଏବଂ $\frac { 1 } { 6 }$ କପ୍ କଦଳୀ ଯୋଗ କରନ୍ତି। ଫଳର ସମୁଦାୟ ପରିମାଣ ଜାଣିବା ପାଇଁ, ଆପଣଙ୍କୁ ଏହି ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ଯୋଗ କରିବାକୁ ପଡିବ। ହରଗୁଡ଼ିକ ହେଉଛି 9 ଏବଂ 6। 9 ଏବଂ 6 ର LCM ହେଉଛି 18। ଆପଣ ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ପରିବର୍ତ୍ତନ କରନ୍ତି: $\frac { 2 } { 9 } = \frac { 2 \times 2 } { 9 \times 2 } = \frac { 4 } { 1 8 } ,$ ଏବଂ $\frac { 1 } { 6 } = \frac { 1 \times 3 } { 6 \times 3 } = \frac { 3 } { 1 8 } $। ବର୍ତ୍ତମାନ ଆପଣ ଲବଗୁଡ଼ିକୁ ଯୋଗ କରନ୍ତି: $\frac { 4 } { 1 8 } + \frac { 3 } { 1 8 } = \frac { 7 } { 1 8 } $। ଆପଣ ନିଜ ସାଲାଡ୍‌ରେ $\frac { 7 } { 1 8 }$ କପ୍ ଫଳ ଯୋଗ କରିଛନ୍ତି।

## ମୁଖ୍ୟ ବିନ୍ଦୁ

*   ସମାନ ହର ଥିବା ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ଯୋଗ କିମ୍ବା ବିୟୋଗ କରିବା ସମୟରେ, ଆପଣ ଲବଗୁଡ଼ିକୁ ଯୋଗ କିମ୍ବା ବିୟୋଗ କରନ୍ତି ଏବଂ ହରକୁ ସମାନ ରଖନ୍ତି।
*   ଭିନ୍ନ ହର ଥିବା ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ଯୋଗ କିମ୍ବା ବିୟୋଗ କରିବା ସମୟରେ, ଆପଣଙ୍କୁ ପ୍ରଥମେ ଏକ ସାଧାରଣ ହର ଥିବା ସମାନ ଭଗ୍ନାଂଶ ଖୋଜିବାକୁ ପଡିବ।
*   ହରଗୁଡ଼ିକର ଗୁଣଫଳ ନେଇ କିମ୍ବା ସର୍ବନିମ୍ନ ସାଧାରଣ ଗୁଣିତକ ନେଇ ସାଧାରଣ ହର ମିଳିପାରିବ।
*   ଭଗ୍ନାଂଶ ଯୋଗ କରିବା ପାଇଁ ବ୍ରହ୍ମଗୁପ୍ତଙ୍କ ପଦ୍ଧତିରେ ତିନୋଟି ପଦକ୍ଷେପ ଅନ୍ତର୍ଭୁକ୍ତ: ଏକ ସାଧାରଣ ହର ସହିତ ସମାନ ଭଗ୍ନାଂଶ ଖୋଜନ୍ତୁ, ଲବଗୁଡ଼ିକୁ ଯୋଗ କରନ୍ତୁ, ଏବଂ ଆବଶ୍ୟକ ହେଲେ ଫଳାଫଳକୁ ସର୍ବନିମ୍ନ ରୂପରେ ପ୍ରକାଶ କରନ୍ତୁ।
*   ସମାନ ହର ଥିବା ସମାନ ଭଗ୍ନାଂଶ ଖୋଜି ଆପଣ କିପରି ଭଗ୍ନାଂଶଗୁଡ଼ିକୁ ତୁଳନା କରିବେ ତାହା ଆପଣ ପୂର୍ବରୁ ଜାଣିଥାଇପାରନ୍ତି; ଏଠାରେ ମଧ୍ୟ ସମାନ ଦକ୍ଷତା ବ୍ୟବହାର କରାଯାଏ।
