# Simplification of Algebraic Expressions

Simplification of algebraic expressions is the process of making an expression easier to read and use while keeping its value exactly the same. You can do this by collecting like terms and using the rules you already know for numbers. When an expression is simplified, it takes the same value as the original expression when you replace the letters with numbers.

## What are Like Terms?

Like terms are terms that have the exact same letter-numbers. For example, $5c$, $c$, and $10c$ are like terms because they all contain the letter-number $c$. Sets of terms such as $(5c, c, 10c)$ that involve the same letter-numbers are called like terms. On the other hand, sets of terms such as $\{18c, 11d\}$ are called unlike terms as they have different letter-numbers. Unlike terms cannot be combined into a single term.

## Adding Like Terms

You can add like terms together to simplify an expression into a single term. When you have terms like $5c + 3c + 10c$, it means the letter-number $c$ is added $(5 + 3 + 10)$ times. This is the distributive property of numbers. Thus, $5 \times c + 3 \times c + 10 \times c = (5 + 3 + 10) \times c$. The expression $(5 + 3 + 10) \times c$ can be simplified to $18 \times c = 18c$.

## Using the Distributive Property

The distributive property states that a multiple of a sum is the same as the sum of multiples. For example, you can use this property to simplify an expression like $4(x + y) - y$. First, you distribute the 4 to both $x$ and $y$, which gives you $4x + 4y - y$. Since the terms can be added in any order, you can group the like terms together. This results in $4x + (4 - 1)y$, which simplifies to $4x + 3y$.

## Worked example

Imagine a shopkeeper sells pencils and erasers. The price per pencil is $c$, and the price per eraser is $d$. On three different days, the shopkeeper sells 5, 3, and 10 pencils. The total money earned by selling pencils is $5c + 3c + 10c$. Using the distributive property, this simplifies to $(5 + 3 + 10) \times c = 18c$. If the shopkeeper also sells 4, 6, and 1 erasers, the total money earned by selling erasers is $4d + 6d + 1d$. This simplifies to $(4 + 6 + 1) \times d = 11d$. The total money earned by selling both pencils and erasers is $18c + 11d$.

## Removing Brackets

When you have an expression with brackets, you can remove the brackets by changing the signs of the terms inside. For example, consider the expression $(40x + 75y) - (6x + 10y)$. Since the terms can be added in any order, the remaining bracket can be opened and the expression becomes $40x + 75y - 6x - 10y$. You can then group the like terms together to get $(40 - 6)x + (75 - 10)y$, which simplifies to $34x + 65y$.

## Key points

*   Like terms are terms that have the same letter-numbers, and unlike terms have different letter-numbers.
*   You can add like terms together using the distributive property to simplify an expression.
*   You can remove brackets by changing the signs of the terms inside, and then group like terms.
*   The simplified form of an expression takes the same value as the original expression when you replace the letters with numbers.
*   An expression like $18c + 11d$ is in its simplest form because it contains unlike terms.
