# Linear Equations in One Variable

A linear equation in one variable is a statement of equality between two algebraic expressions that contains exactly one unknown quantity, usually written as a letter. This unknown quantity, or variable, can take on different values, and our goal is to find the specific value that makes the Left Hand Side (LHS) exactly equal to the Right Hand Side (RHS) of the equation. The process of finding the value of the unknown for which the equality holds is called solving the equation, and it is a fundamental skill for solving everyday problems involving unknown weights, quantities, or values.

## Setting Up the Equation

Before we can solve for an unknown, we must first express the problem as a mathematical equation. This means translating the words and numbers of a real-world situation into a statement of equality. For example, if an object's total weight is made up of several known items and one unknown item, we can use a letter to represent the unknown. If we have a balance scale, the total weight on one side must equal the total weight on the other side, which gives us an equation. Consider a scale with three slices of bread weighing two units each on one side, and two identical unknown items on the other side. The equation formed is $6 = e + e$, which simplifies to $2e = 6$. Similarly, if we have a scale with two identical unknown items and one known item weighing four units, and the total on the other side is sixteen units, we can write $4 + 2y = 16$. Framing the equation correctly is the first crucial step in finding the unknown value.

## The Trial and Error Method

One way to solve an equation is to substitute different values for the unknown letter and check which value makes the Left Hand Side equal to the Right Hand Side. This method is known as the trial and error method. For instance, if we have the equation $2n + 1 = 99$, we can start by guessing a value for $n$. If we try $n = 5$, the LHS is $2 \times (5) + 1 = 11$, which is far from $99$. We can try larger values, such as $n = 10$ or $n = 30$, and eventually find that $n = 49$ gives an LHS of $99$. While this method works, it can be inefficient, especially if the unknown value is very large or if the equation is more complex, such as $5x - 4 = 7$.

## Solving Systematically

A more efficient way to solve an equation is to use the properties of equality. If the Left Hand Side and the Right Hand Side of an equation have the same value, performing the same operation on both sides will clearly not change their equality. This allows us to remove unwanted terms or factors from one side of the equation by applying the inverse operation to both sides. For example, to solve the equation $5x - 4 = 7$, we want to isolate the term $5x$. We can do this by adding $4$ to both sides, which removes the $-4$ from the Left Hand Side. This gives us $5x = 11$. To isolate $x$, we then divide both sides by $5$, resulting in $x = \frac{11}{5}$.

## Equations with Variables on Both Sides

Sometimes, an equation will have expressions with an unknown on both sides. To solve these, we must first bring all the unknown terms to the same side of the equation. We can do this by subtracting the unknown term from the side with the larger coefficient. For example, consider the equation $6y + 7 = 4y + 21$. We can subtract $4y$ from both sides to get $2y + 7 = 21$. We can then subtract $7$ from both sides to get $2y = 14$. Finally, we divide both sides by $2$ to find $y = 7$. It is always a good practice to check your solution by substituting the value back into the original equation to ensure the Left Hand Side equals the Right Hand Side.

## Worked example

Let us apply the systematic method to solve the equation $11y + (-5) = 61$. To retain only the unknown term $11y$ on one side, we need to remove the term $-5$. This can be done by subtracting $(-5)$ from both sides. The equation becomes $11y + (-5) - (-5) = 61 - (-5)$, which simplifies to $11y = 66$. We can directly find the value of $y$ by dividing both sides by $11$, which gives $y = 6$. We can check this solution by substituting $y = 6$ back into the original equation: $11(6) + (-5) = 66 - 5 = 61$, which is the same as the Right Hand Side, confirming that $y = 6$ is the correct solution.

## Key points

*   A linear equation in one variable is a statement of equality between two algebraic expressions containing exactly one unknown.
*   The process of finding the value of the unknown for which the LHS equals the RHS is called solving the equation.
*   The trial and error method involves substituting different values for the unknown to find the correct one.
*   The systematic method uses the properties of equality, performing the same operation on both sides to isolate the unknown.
*   When an equation has variables on both sides, bring all unknown terms to one side before isolating the variable.
*   Always check your solution by substituting the value back into the original equation to ensure the LHS equals the RHS.
