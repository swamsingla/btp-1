# ବୀଜଗାଣିତିକ ଅଭିବ୍ୟକ୍ତିର ସରଳୀକରଣ

ବୀଜଗାଣିତିକ ଅଭିବ୍ୟକ୍ତିର ସରଳୀକରଣ ହେଉଛି ଏକ ଅଭିବ୍ୟକ୍ତିକୁ ପଢ଼ିବା ଏବଂ ବ୍ୟବହାର କରିବା ସହଜ କରିବାର ପ୍ରକ୍ରିୟା, ଯେଉଁଥିରେ ଏହାର ମୂଲ୍ୟ ସମ୍ପୂର୍ଣ୍ଣ ସମାନ ରହିଥାଏ। ଆପଣ ସମାନ ପଦଗୁଡ଼ିକୁ ଏକାଠି କରି ଏବଂ ସଂଖ୍ୟା ପାଇଁ ଆପଣ ପୂର୍ବରୁ ଜାଣିଥିବା ନିୟମଗୁଡ଼ିକୁ ବ୍ୟବହାର କରି ଏହା କରିପାରିବେ। ଯେତେବେଳେ ଏକ ଅଭିବ୍ୟକ୍ତି ସରଳୀକୃତ ହୁଏ, ଅକ୍ଷରଗୁଡ଼ିକୁ ସଂଖ୍ୟା ସହିତ ବଦଳାଇଲେ ଏହା ମୂଳ ଅଭିବ୍ୟକ୍ତି ସହିତ ସମାନ ମୂଲ୍ୟ ନେଇଥାଏ।

## ସମାନ ପଦଗୁଡ଼ିକ କ'ଣ?

ସମାନ ପଦଗୁଡ଼ିକ ହେଉଛି ସେହି ପଦ ଯାହାର ସମାନ ଅକ୍ଷର-ସଂଖ୍ୟା ଥାଏ। ଉଦାହରଣ ସ୍ୱରୂପ, $5c$, $c$, ଏବଂ $10c$ ହେଉଛି ସମାନ ପଦ କାରଣ ସେଗୁଡ଼ିକରେ ସମାନ ଅକ୍ଷର-ସଂଖ୍ୟା $c$ ଅଛି। $(5c, c, 10c)$ ପରି ପଦଗୁଡ଼ିକର ସେଟ୍ ଯେଉଁଥିରେ ସମାନ ଅକ୍ଷର-ସଂଖ୍ୟା ଥାଏ, ତାହାକୁ ସମାନ ପଦ କୁହାଯାଏ। ଅନ୍ୟପକ୍ଷରେ, $\{18c, 11d\}$ ପରି ପଦଗୁଡ଼ିକର ସେଟ୍‌କୁ ଅସମାନ ପଦ କୁହାଯାଏ କାରଣ ସେଗୁଡ଼ିକର ଅକ୍ଷର-ସଂଖ୍ୟା ଭିନ୍ନ ଅଟେ। ଅସମାନ ପଦଗୁଡ଼ିକୁ ଏକାଠି କରି ଗୋଟିଏ ପଦରେ ପରିଣତ କରାଯାଇପାରିବ ନାହିଁ।

## ସମାନ ପଦଗୁଡ଼ିକୁ ଯୋଗ କରିବା

ଏକ ଅଭିବ୍ୟକ୍ତିକୁ ଗୋଟିଏ ପଦରେ ସରଳୀକୃତ କରିବା ପାଇଁ ଆପଣ ସମାନ ପଦଗୁଡ଼ିକୁ ଏକାଠି ଯୋଗ କରିପାରିବେ। ଯେତେବେଳେ ଆପଣଙ୍କ ପାଖରେ $5c + 3c + 10c$ ପରି ପଦ ଥାଏ, ଏହାର ଅର୍ଥ ହେଉଛି ଅକ୍ଷର-ସଂଖ୍ୟା $c$ କୁ $(5 + 3 + 10)$ ଥର ଯୋଗ କରାଯାଇଛି। ଏହା ସଂଖ୍ୟାର ବିତରଣ ଧର୍ମ (distributive property)। ତେଣୁ, $5 \times c + 3 \times c + 10 \times c = (5 + 3 + 10) \times c$। ଅଭିବ୍ୟକ୍ତି $(5 + 3 + 10) \times c$ କୁ ସରଳୀକୃତ କରି $18 \times c = 18c$ କରାଯାଇପାରିବ।

## ବିତରଣ ଧର୍ମର ବ୍ୟବହାର

ବିତରଣ ଧର୍ମ କହୁଛି ଯେ ଏକ ଯୋଗଫଳର ଗୁଣିତକ, ଗୁଣିତକଗୁଡ଼ିକର ଯୋଗଫଳ ସହିତ ସମାନ। ଉଦାହରଣ ସ୍ୱରୂପ, ଆପଣ ଏହି ଧର୍ମକୁ ବ୍ୟବହାର କରି $4(x + y) - y$ ପରି ଏକ ଅଭିବ୍ୟକ୍ତିକୁ ସରଳୀକୃତ କରିପାରିବେ। ପ୍ରଥମେ, ଆପଣ 4 କୁ ଉଭୟ $x$ ଏବଂ $y$ ରେ ବିତରଣ କରନ୍ତି, ଯାହା ଆପଣଙ୍କୁ $4x + 4y - y$ ଦେଇଥାଏ। ଯେହେତୁ ପଦଗୁଡ଼ିକୁ ଯେକୌଣସି କ୍ରମରେ ଯୋଗ କରାଯାଇପାରିବ, ଆପଣ ସମାନ ପଦଗୁଡ଼ିକୁ ଏକାଠି ଗ୍ରୁପ୍ କରିପାରିବେ। ଏହାର ପରିଣାମ $4x + (4 - 1)y$ ହୁଏ, ଯାହା ସରଳୀକୃତ ହୋଇ $4x + 3y$ ହୋଇଯାଏ।

## ସମାଧାନ କରାଯାଇଥିବା ଉଦାହରଣ

କଳ୍ପନା କରନ୍ତୁ ଯେ ଜଣେ ଦୋକାନୀ ପେନ୍‌ସିଲ୍ ଏବଂ ଇରେଜର୍ ବିକ୍ରି କରୁଛି। ଗୋଟିଏ ପେନ୍‌ସିଲର ଦାମ୍ ହେଉଛି $c$, ଏବଂ ଗୋଟିଏ ଇରେଜରର ଦାମ୍ ହେଉଛି $d$। ତିନୋଟି ଭିନ୍ନ ଦିନରେ, ଦୋକାନୀ 5, 3, ଏବଂ 10 ଟି ପେନ୍‌ସିଲ୍ ବିକ୍ରି କଲା। ପେନ୍‌ସିଲ୍ ବିକ୍ରି କରି ରୋଜଗାର ହୋଇଥିବା ମୋଟ ଟଙ୍କା ହେଉଛି $5c + 3c + 10c$। ବିତରଣ ଧର୍ମ ବ୍ୟବହାର କରି, ଏହା ସରଳୀକୃତ ହୋଇ $(5 + 3 + 10) \times c = 18c$ ହୁଏ। ଯଦି ଦୋକାନୀ 4, 6, ଏବଂ 1 ଟି ଇରେଜର୍ ମଧ୍ୟ ବିକ୍ରି କରେ, ତେବେ ଇରେଜର୍ ବିକ୍ରି କରି ରୋଜଗାର ହୋଇଥିବା ମୋଟ ଟଙ୍କା ହେଉଛି $4d + 6d + 1d$। ଏହା ସରଳୀକୃତ ହୋଇ $(4 + 6 + 1) \times d = 11d$ ହୁଏ। ପେନ୍‌ସିଲ୍ ଏବଂ ଇରେଜର୍ ଉଭୟ ବିକ୍ରି କରି ରୋଜଗାର ହୋଇଥିବା ମୋଟ ଟଙ୍କା ହେଉଛି $18c + 11d$।

## ବନ୍ଧନୀ ହଟାଇବା

ଯେତେବେଳେ ଆପଣଙ୍କ ପାଖରେ ବନ୍ଧନୀ ଥିବା ଏକ ଅଭିବ୍ୟକ୍ତି ଥାଏ, ଆପଣ ଭିତରେ ଥିବା ପଦଗୁଡ଼ିକର ଚିହ୍ନ ପରିବର୍ତ୍ତନ କରି ବନ୍ଧନୀଗୁଡ଼ିକୁ ହଟାଇ ପାରିବେ। ଉଦାହରଣ ସ୍ୱରୂପ, $(40x + 75y) - (6x + 10y)$ ଅଭିବ୍ୟକ୍ତିକୁ ବିଚାର କରନ୍ତୁ। ଯେହେତୁ ପଦଗୁଡ଼ିକୁ ଯେକୌଣସି କ୍ରମରେ ଯୋଗ କରାଯାଇପାରିବ, ବାକି ବନ୍ଧନୀକୁ ଖୋଲାଯାଇପାରିବ ଏବଂ ଅଭିବ୍ୟକ୍ତିଟି $40x + 75y - 6x - 10y$ ହୋଇଯାଏ। ତାପରେ ଆପଣ ସମାନ ପଦଗୁଡ଼ିକୁ ଏକାଠି ଗ୍ରୁପ୍ କରି $(40 - 6)x + (75 - 10)y$ ପାଇପାରିବେ, ଯାହା ସରଳୀକୃତ ହୋଇ $34x + 65y$ ହୁଏ।
