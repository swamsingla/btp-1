# Frequency Distribution Table

Sometimes we collect a lot of numbers, like the scores of a cricket team or the number of students in each classroom. When the list is very long, it is hard to see what is happening. A frequency distribution table helps us organise the data into groups, called classes, and tells us how many times each group appears, which is the frequency. This makes it much easier to read and understand the information quickly.

## Grouping Data into Classes

When we have a large set of numbers, we can arrange them into intervals or classes. Each class has a range of values, and we count how many numbers from our data fall into that range. The count we get for each class is called the frequency. This is also known as grouping data.

For example, imagine a teacher recorded the ages of 20 students in a school. The ages are 11, 11, 12, 12, 12, 13, 13, 13, 13, 14, 14, 14, 15, 15, 15, 16, 16, 17, 17, and 18. We can make a table with classes like 11–12, 13–14, and 15–16. The class 11–12 contains five students, so its frequency is 5. The class 13–14 contains seven students, so its frequency is 7. By doing this, we have organised the data into classes with frequencies.

## Using Tally Marks

To find the frequency of each class, we can use tally marks. Tally marks are a simple way to keep track of counts. We draw a vertical line for the first four items, and then we draw a diagonal line across them to make a group of five.

Let us use tally marks to count the number of students who scored between 10 and 19 marks on a test. Suppose the scores are 14, 17, 12, 14, 18, 10, 11, 16, 13, and 10. We can make a class for 10–19. We draw tally marks for each score. For the first score 14, we draw one vertical line. For 17, we draw another. We continue this process. After we have drawn all the marks, we can count them easily in groups of five to find the frequency.

## Finding the Middle Value

Once we have our frequency distribution table, we can find the middle value, which is called the median. The median is the value that has an equal number of values lower than it and greater than it. To find the median using our table, we can add up the frequencies one by one from the smallest class until we reach the middle.

Let us use the student age example again. We have 20 students, so the middle is between the 10th and 11th student. We add the frequencies from the youngest class upwards. The class 11–12 has a frequency of 5. The class 13–14 has a frequency of 7. Adding these, we get $5 + 7 = 12$. This means the 10th and 11th students are both in the 13–14 class. Therefore, the median age is 14.

## Worked Example

Let us try another example. A shopkeeper recorded the number of customers who visited his store each day for a week: 25, 30, 28, 32, 25, 27, and 30. We want to organise this data into a frequency distribution table.

First, we find the range of the data. The smallest value is 25 and the largest is 32. We can make classes of size 5. Our classes will be 25–29 and 30–34. Now we count the frequencies. The class 25–29 contains the numbers 25, 28, 25, and 27. The frequency of this class is 4. The class 30–34 contains the numbers 30, 32, and 30. The frequency of this class is 3. Our table looks like this:

| Class | 25–29 | 30–34 |
|---|---|---|
| Frequency | 4 | 3 |

This table shows us that most of the days had between 25 and 29 customers.

## Key points

- A frequency distribution table organises data into classes with frequencies.
- Tally marks are a useful tool for counting frequencies.
- The median is the middle value in an ordered data set.
- Adding frequencies helps us find the median without writing out all the data.
- Grouping data makes it easier to understand large sets of numbers.
