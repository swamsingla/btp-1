# ବୈଜିକ ସର୍ବସମିକା

ଏକ ବୈଜିକ ସର୍ବସମିକା ହେଉଛି ଏକ ବିଶେଷ ବୈଜିକ ସମୀକରଣ ଯାହା ଏଥିରେ ଥିବା ଚଳକଗୁଡ଼ିକର ପ୍ରତ୍ୟେକ ସମ୍ଭାବ୍ୟ ମୂଲ୍ୟ ପାଇଁ ସତ୍ୟ ହୋଇଥାଏ। ଆପଣ ହୁଏତ ପୂର୍ବରୁ ଏହି ସର୍ବସମିକାଗୁଡ଼ିକରୁ କିଛି ବ୍ୟବହାର କରିଥିବେ, ଯାହାଦ୍ୱାରା ଆପଣ ଅଭିବ୍ୟକ୍ତିଗୁଡ଼ିକୁ ଶୀଘ୍ର ଗୁଣନ କରିପାରିବେ କିମ୍ବା ଜଟିଳ ବୈଜିକ ଅଭିବ୍ୟକ୍ତିଗୁଡ଼ିକୁ ସରଳ ଗୁଣନୀୟକରେ ଭାଙ୍ଗିପାରିବେ। ଏହି ଅଧ୍ୟାୟରେ, ଆମେ ଦେଖିବା ଯେ ଏହି ମାନକ ସୂତ୍ରଗୁଡ଼ିକୁ ବ୍ୟବହାର କରି କିପରି ଆମର ଗଣନାକୁ ସରଳ କରିପାରିବା ଏବଂ ସମସ୍ୟାଗୁଡ଼ିକୁ ବହୁତ ଶୀଘ୍ର ସମାଧାନ କରିପାରିବା।

## ଚାରୋଟି ମାନକ ସର୍ବସମିକା

ବୈଜିକ ସର୍ବସମିକାର ମୂଳଦୁଆ ଚାରୋଟି ମାନକ ସୂତ୍ର ଉପରେ ନିର୍ଭର କରେ ଯାହାକୁ ଆପଣ ମନେ ରଖିବା ଉଚିତ୍। ଏହି ବିଷୟର ପ୍ରାୟ ପ୍ରତ୍ୟେକ ସମସ୍ୟା ପାଇଁ ଏଗୁଡ଼ିକ ହେଉଛି ମୂଳ ଆଧାର।

ପ୍ରଥମ ଦୁଇଟି ସର୍ବସମିକା ହେଉଛି ଦ୍ୱିପଦୀର ବର୍ଗର ବିସ୍ତାର। ପ୍ରଥମଟି ହେଉଛି ଦୁଇଟି ଚଳକର ଯୋଗଫଳର ବିସ୍ତାର, ଏବଂ ଦ୍ୱିତୀୟଟି ହେଉଛି ସେମାନଙ୍କର ବିୟୋଗଫଳର ବିସ୍ତାର।

ସର୍ବସମିକା I: $(x + y)^{2} = x^{2} + 2xy + y^{2}$
ସର୍ବସମିକା II: $(x - y)^{2} = x^{2} - 2xy + y^{2}$

ତୃତୀୟ ସର୍ବସମିକା ହେଉଛି ଦୁଇଟି ବର୍ଗର ଅନ୍ତର। ଏହା ଦର୍ଶାଏ ଯେ କିପରି ବର୍ଗଗୁଡ଼ିକର ବିୟୋଗକୁ ଦୁଇଟି ଦ୍ୱିପଦୀର ଗୁଣଫଳରେ ପରିଣତ କରାଯାଇପାରିବ।

ସର୍ବସମିକା III: $x^{2} - y^{2} = (x + y)(x - y)$

ଚତୁର୍ଥ ସର୍ବସମିକା ହେଉଛି ଦୁଇଟି ଦ୍ୱିପଦୀକୁ ଗୁଣନ କରିବା ପାଇଁ ଏକ ଉପଯୋଗୀ ସୂତ୍ର ଯାହାର ପ୍ରଥମ ପଦ ସମାନ ଥାଏ। ଏହା ଆପଣଙ୍କୁ ପଦ ପରେ ପଦ ଗୁଣନ ନକରି ସିଧାସଳଖ ଗୁଣଫଳ ବାହାର କରିବାକୁ ଅନୁମତି ଦିଏ।

ସର୍ବସମିକା IV: $(x + a)(x + b) = x^{2} + (a + b)x + ab$

## ତ୍ରିପଦୀଗୁଡ଼ିକର ବିସ୍ତାର

ବେଳେବେଳେ, ଆପଣ ତିନୋଟି ପଦ ଥିବା ଏକ ଅଭିବ୍ୟକ୍ତି ଦେଖିବେ, ଯାହାକୁ ତ୍ରିପଦୀ କୁହାଯାଏ। ଆପଣ ପ୍ରଥମ ମାନକ ସର୍ବସମିକାକୁ ଏକ ଆଧାର ଭାବରେ ବ୍ୟବହାର କରି ଏକ ତ୍ରିପଦୀର ବର୍ଗକୁ ବିସ୍ତାର କରିପାରିବେ। ଆସନ୍ତୁ $(x + y + z)^2$ ଅଭିବ୍ୟକ୍ତିକୁ ବିଚାର କରିବା। ଆମେ ପ୍ରଥମ ଦୁଇଟି ପଦକୁ ଏକକ ଚଳକ ଭାବରେ ନେଇପାରିବା, ଧରିନିଅନ୍ତୁ $t = x + y$, ଏବଂ ସର୍ବସମିକା I ପ୍ରୟୋଗ କରିପାରିବା।

$(t + z)^2 = t^2 + 2tz + z^2$

ସମୀକରଣରେ $t = x + y$ କୁ ପୁନର୍ବାର ରଖିଲେ ଆମକୁ ମିଳିବ:

$(x + y)^2 + 2(x + y)z + z^2$

ବର୍ତ୍ତମାନ, ଆମେ $(x + y)^2$ ଅଂଶରେ ପୁନର୍ବାର ସର୍ବସମିକା I ପ୍ରୟୋଗ କରିବା:

$x^2 + 2xy + y^2 + 2xz + 2yz + z^2$

ଚଳକଗୁଡ଼ିକର ଅବରୋହୀ କ୍ରମରେ ପଦଗୁଡ଼ିକୁ ସଜାଇଲେ, ଆମେ ଏକ ତ୍ରିପଦୀର ବର୍ଗକୁ ବିସ୍ତାର କରିବାର ମାନକ ସୂତ୍ର ପାଇବା।

ସର୍ବସମିକା V: $(x + y + z)^{2} = x^{2} + y^{2} + z^{2} + 2xy + 2yz + 2zx$

ଯେତେବେଳେ ଆପଣଙ୍କୁ ହାତରେ ଗୁଣନ ନକରି ଶୀଘ୍ର $(3a + 4b + 5c)^2$ ପରି ଅଭିବ୍ୟକ୍ତିଗୁଡ଼ିକୁ ବିସ୍ତାର କରିବାକୁ ପଡ଼େ, ସେତେବେଳେ ଏହି ସର୍ବସମିକା ଅତ୍ୟନ୍ତ ଉପଯୋଗୀ ହୋଇଥାଏ।

## ଘନଗୁଡ଼ିକର ବିସ୍ତାର

ଯେପରି ଆମେ ଯୋଗ କିମ୍ବା ବିୟୋଗର ବର୍ଗକୁ ବିସ୍ତାର କରିପାରିବା, ସେହିପରି ଆମେ ଏକ ଦ୍ୱିପଦୀର ଘନକୁ ମଧ୍ୟ ବିସ୍ତାର କରିପାରିବା। ଘନଗୁଡ଼ିକ ପାଇଁ ପ୍ରଥମ ସର୍ବସମିକା ଦୁଇଟି ଚଳକର ଯୋଗଫଳକୁ ବିସ୍ତାର କରେ, ଏବଂ ଦ୍ୱିତୀୟ ସର୍ବସମିକା ସେମାନଙ୍କର ବିୟୋଗଫଳକୁ ବିସ୍ତାର କରେ।

ସର୍ବସମିକା VI: $(x + y)^{3} = x^{3} + y^{3} + 3xy(x + y)$
ସର୍ବସମିକା VII: $(x - y)^{3} = x^{3} - y^{3} - 3xy(x - y) = x^{3} - 3x^{2}y + 3xy^{2} - y^{3}$

ଏହି ସର୍ବସମିକାଗୁଡ଼ିକୁ ବ୍ୟବହାର କରିବା ପାଇଁ, ଆପଣଙ୍କୁ କେବଳ ଚିହ୍ନଟ କରିବାକୁ ହେବ ଯେ ଆପଣଙ୍କ ଅଭିବ୍ୟକ୍ତିର କେଉଁ ଅଂଶ $x$ ଏବଂ $y$ ସହିତ ମେଳ ଖାଉଛି, ଏବଂ ତାପରେ ସେଗୁଡ଼ିକୁ ସୂତ୍ରରେ ରଖିବାକୁ ହେବ। ଜଟିଳ ବୈଜିକ ପଦଗୁଡ଼ିକ ସହିତ କାମ କରିବା ସମୟରେ ଏହା ଅନେକ ସମୟ ବଞ୍ଚାଇଥାଏ।

## ଶୀଘ୍ର ଗଣନା ପାଇଁ ସର୍ବସମିକାର ବ୍ୟବହାର

ବୈଜିକ ସର୍ବସମିକାର ସବୁଠାରୁ ବ୍ୟବହାରିକ ପ୍ରୟୋଗ ହେଉଛି ବିନା କାଲକୁଲେଟରରେ ଗାଣିତିକ ଗଣନା କରିବା। ଆପଣଙ୍କ ଚଳକଗୁଡ଼ିକ ପାଇଁ ବୁଦ୍ଧିମାନ ଭାବରେ ମୂଲ୍ୟ ବାଛି, ଆପଣ ଏକ କଷ୍ଟକର ଗୁଣନକୁ ଏକ ସର୍ବସମିକାର ସରଳ ପ୍ରୟୋଗରେ ପରିଣତ କରିପାରିବେ।

$105 \times 106$ ର ଗୁଣଫଳ ବାହାର କରିବାର ସମସ୍ୟାକୁ ବିଚାର କରନ୍ତୁ। ସିଧାସଳଖ ଗୁଣନ କରିବା ପରିବର୍ତ୍ତେ, ଆପଣ ସର୍ବସମିକା IV ବ୍ୟବହାର କରିପାରିବେ। ଆସନ୍ତୁ $105$ କୁ $(100 + 5)$ ଏବଂ $106$ କୁ $(100 + 6)$ ଭାବରେ ଲେଖିବା। ଏଠାରେ, $x = 100$, $a = 5$, ଏବଂ $b = 6$ ଅଟେ।

ସର୍ବସମିକା IV ବ୍ୟବହାର କରି: $(x + a)(x + b) = x^{2} + (a + b)x + ab$

$(100 + 5)(100 + 6) = 100^2 + (5 + 6) \cdot 100 + (5 \cdot 6)$

$= 10000 + 1100 + 30$

$= 11130$

ଏହି ପଦ୍ଧତି ପାରମ୍ପରିକ ଗୁଣନ ଅପେକ୍ଷା ବହୁତ ଦ୍ରୁତ ଏବଂ ଏଥିରେ ତ୍ରୁଟି ହେବାର ସମ୍ଭାବନା କମ୍ ଥାଏ, ବିଶେଷକରି ବଡ଼ ସଂଖ୍ୟାଗୁଡ଼ିକ ସହିତ କାମ କରିବା ସମୟରେ।

## ସମାଧାନ କରାଯାଇଥିବା ଉଦାହରଣ

ଆସନ୍ତୁ $\frac {2 5}{4} x ^ {2} - \frac {y ^ {2}}{9}$ ଅଭିବ୍ୟକ୍ତିକୁ ଗୁଣନୀୟକ କରିବା ପାଇଁ ସର୍ବସମିକା III ପ୍ରୟୋଗ କରିବା।

ପ୍ରଥମେ, ଆମକୁ ଚିହ୍ନିବାକୁ ହେବ ଯେ $\frac {2 5}{4} x ^ {2}$ ହେଉଛି ଏକ ପୂର୍ଣ୍ଣ ବର୍ଗ। ଆମେ ଏହାକୁ $\left(\frac {5}{2} x\right)^2$ ଭାବରେ ଲେଖିପାରିବା କାରଣ $\left(\frac {5}{2}\right)^2 = \frac {2 5}{4}$।

ସେହିପରି, $\frac {y ^ {2}}{9}$ ହେଉଛି ଏକ ପୂର୍ଣ୍ଣ ବର୍ଗ କାରଣ ଏହାକୁ $\left(\frac {y}{3}\right)^2$ ଭାବରେ ଲେଖାଯାଇପାରିବ କାରଣ $\left(\frac {y}{3}\right)^2 = \frac {y ^ {2}}{9}$।

ବର୍ତ୍ତମାନ, ଆମର ଅଭିବ୍ୟକ୍ତିଟି $\left(\frac {5}{2} x\right)^2 - \left(\frac {y}{3}\right)^2$ ହୋଇଯିବ।

ଆମେ ବର୍ତ୍ତମାନ ସର୍ବସମିକା III ପ୍ରୟୋଗ କରିପାରିବା: $x^{2} - y^{2} = (x + y)(x - y)$

ଧରିନିଅନ୍ତୁ $x = \frac {5}{2} x$ ଏବଂ $y = \frac {y}{3}$।

$\left(\frac {5}{2} x\right)^2 - \left(\frac {y}{3}\right)^2 = \left(\frac {5}{2} x + \frac {y}{3}\right) \left(\frac {5}{2} x - \frac {y}{3}\right)$

ଏହା ହେଉଛି ଦିଆଯାଇଥିବା ଅଭିବ୍ୟକ୍ତିର ସମ୍ପୂର୍ଣ୍ଣ ଗୁଣନୀୟକ ରୂପ।

## ମୁଖ୍ୟ ବିନ୍ଦୁ

*   ଏକ ବୈଜିକ ସର୍ବସମିକା ହେଉଛି ଏକ ସମୀକରଣ ଯାହା ଏଥିରେ ଥିବା ଚଳକଗୁଡ଼ିକର ସମସ୍ତ ମୂଲ୍ୟ ପାଇଁ ସତ୍ୟ ହୋଇଥାଏ।
*   ସର୍ବସମିକା I ଏବଂ ସର୍ବସମିକା II ଏକ ଦ୍ୱିପଦୀର ବର୍ଗକୁ ବିସ୍ତାର କରିବା ପାଇଁ ବ୍ୟବହୃତ ହୁଏ, ଯେତେବେଳେ କି ସର୍ବସମିକା III ଦୁଇଟି ବର୍ଗର ଅନ୍ତରକୁ ଗୁଣନୀୟକ କରିବା ପାଇଁ ବ୍ୟବହୃତ ହୁଏ।
*   ସର୍ବସମିକା IV ହେଉଛି ସମାନ ପ୍ରଥମ ପଦ ଥିବା ଦୁଇଟି ଦ୍ୱିପଦୀକୁ ଗୁଣନ କରିବା ପାଇଁ ଏକ ସହଜ ଉପାୟ।
*   ସର୍ବସମିକା V ଏକ ତ୍ରିପଦୀର ବର୍ଗକୁ ବର୍ଗର ଯୋଗଫଳ ଏବଂ ଗୁଣଫଳ ପଦଗୁଡ଼ିକରେ ବିସ୍ତାର କରେ।
*   ସର୍ବସମିକା VI ଏବଂ ସର୍ବସମିକା VII ଏକ ଦ୍ୱିପଦୀର ଘନକୁ ବିସ୍ତାର କରେ, ଯାହାଦ୍ୱାରା ଉଚ୍ଚ ଘାତଗୁଡ଼ିକୁ ପରିଚାଳନା କରିବା ସହଜ ହୋଇଥାଏ।
*   ଏହି ସର୍ବସମିକାଗୁଡ଼ିକ କେବଳ ବୀଜଗଣିତ ପାଇଁ ନୁହେଁ; ସେଗୁଡ଼ିକୁ ଶୀଘ୍ର ଗାଣିତିକ ଗଣନା କରିବା ପାଇଁ ମଧ୍ୟ ବ୍ୟବହାର କରାଯାଇପାରିବ।
