# Linear Equations in Two Variables

In earlier classes, you may have studied linear equations in one variable, such as $x + 1 = 0$. Such equations have a unique solution that you can represent on a number line. Now, we extend this knowledge to equations involving two variables, such as $x$ and $y$. This page explores what it means to solve these equations and how to write their solutions.

## The Standard Form

A linear equation in two variables is an equation that can be written in the form $ax + by + c = 0$, where $a$, $b$, and $c$ are real numbers, and $a$ and $b$ are not both zero. You can use any letters for the variables, but $x$ and $y$ are customary. 

To recognize this form, you might need to rearrange the equation. For example, the equation $2x + 3y = 4.37$ can be written as $2x + 3y - 4.37 = 0$. In this case, $a = 2$, $b = 3$, and $c = -4.37$. Even equations that look like they have only one variable are technically linear equations in two variables. For instance, $4 - 3x = 0$ can be expressed as $-3x + 0y + 4 = 0$. In the same way, $x = -5$ can be written as $1 \cdot x + 0 \cdot y + 5 = 0$, and $y = 2$ can be written as $0 \cdot x + 1 \cdot y - 2 = 0$.

## Finding Solutions

Because there are two variables, a solution means a pair of values, one for $x$ and one for $y$, which satisfy the given equation. This solution is written as an ordered pair $(x, y)$, with the value for $x$ written first.

A linear equation in two variables has infinitely many solutions. To find a solution, you can pick a value for one variable and solve for the other. For example, consider the equation $2x + 3y = 12$. If you choose $x = 3$, the equation becomes $6 + 3y = 12$, so $3y = 6$ and $y = 2$. The equation holds true because $2(3) + 3(2) = 12$. This gives the ordered pair $(3, 2)$. However, $(1, 4)$ is not a solution because $2(1) + 3(4) = 14$, which is not $12$.

## Worked Example

Let us find two different ordered pairs that satisfy the equation $x + 2y = 6$. First, we can pick a value for $x$. If we choose $x = 0$, the equation reduces to $2y = 6$, which gives $y = 3$. This results in the ordered pair $(0, 3)$. Next, we can pick a value for $y$. If we choose $y = 0$, the equation reduces to $x = 6$. This gives the ordered pair $(6, 0)$. Both of these pairs are valid solutions to the equation.

## Key points

- A linear equation in two variables can be written in the standard form $ax + by + c = 0$, where $a$, $b$, and $c$ are real numbers, and $a$ and $b$ are not both zero.
- A solution to a linear equation in two variables is an ordered pair $(x, y)$ that makes the equation true when the values are substituted.
- A linear equation in two variables has infinitely many solutions, and you can find them by choosing a value for one variable and solving for the other.
- You can represent an equation like $x = -5$ in standard form as $1 \cdot x + 0 \cdot y + 5 = 0$.
- You can represent an equation like $y = 2$ in standard form as $0 \cdot x + 1 \cdot y - 2 = 0$.
- An easy way to find a solution is to take $x = 0$ to get the corresponding value of $y$, or take $y = 0$ to get the corresponding value of $x$.
